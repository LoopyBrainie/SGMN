## §2 机制（不是数字）

### §2-1 `A0` 为什么天生脆：两侧用**不同**的权重

`A0`（= `mech125.w_hat` = 现定义）里 `p₁` 用 `n₁` 权重、`p₂` 用 `n₂` 权重 —— **两侧权重不同**。
本卡的 `A3`/`A4` 把**同一个**权重用到两侧（分别 `n₂`、`n₁`）⇒ 三个量在 `dose=450` 上：

$$A_3 = 1.489622 \;>\; A_0 = 1.433555 \;>\; A_4 = 1.272882,
\qquad \frac{A_3}{A_4} = 1.1703 = \text{（即 } J_{128\text{-}1} \text{ 的 } \max/\min\text{）}$$

⇒ **`A0` 落在 `A3` 与 `A4` 之间**：`1.1703×` 这条裂缝是「**用哪一侧的权重**」造成的，`A0` 的错配只是把它掩在中点。
★ 在另外 8 个剂量上 `A3/A4 ≤ 1.0765×` ⇒ 这条裂缝**只在 `dose=450` 张开**。

### §2-2 为什么偏偏是 `dose=450`：`555` 是唯一 `n₁ > n₂` 的题集

四个题集的 `(n₁, n₂)` 是 **`555: (23,20)` / `556: (18,27)` / `557: (9,29)` / `558: (18,23)`**
⇒ **`555` 是唯一 `n₁ > n₂` 的**，其余三个都是 `n₂ > n₁`。
权重错配的方向在 `555` 身上**反向** ⇒ 两侧加权对它给出**相反**的推挤。
`dose=450` 上 `555` 的单题集读数 `0.8366` 本身就是**全剂量网格上最低的 `555` 读数**
（`400: 1.0414`、`600: 1.2143`），于是它把 `A4`（`n₁` 加权、更听 `555` 的）压到 `1.2729`，
把 `A3`（`n₂` 加权、更听 `556/557` 的）抬到 `1.4896` ⇒ 裂缝最大。
★ 这解释了 `J128-1` 与 `J128-3` **同时且仅在 `dose=450`** 失败：**同一个机制的两个投影**。

### §2-3 ★ 解析引理 `D-128-L1`：`|S|=1` 时五条规则代数恒等

若 `|S| = 1`，因 `N_k` **与 cell 无关**（只由 rng 决定），
`A0 = Σ_c e_c/(nc·n_k) = (1/nc)Σ_c (e_c/n_k) = A2`，`A1 = A0`，`A3 = A4 = A0`。
⇒ **`|S|=1` 上规则间 `max/min` 必然 = `1.0000`（是定理，不是测量）**。
★ 实测：**33 个 `|S|=1` 结构全部精确满足**（`S3` 用 `Fraction` 在 **有理数**上验证；`T6`/`T14` 同）。
★★ **这条引理直接给出 `CORR-37`**（§5）：`dose=450` 子集轴的 `argmax`/`argmin` **都是单元素集**
⇒ 它们的 `ratio` 对**任何**加权规则**逐位相同** ⇒ `2.654×` **不可能是"合并口径"的自由度**。

### §2-4 ★ 本卡最强的正面结果：**符号对规则稳健 9/9，对题集不稳健（且只在一个剂量）**

| 轴 | 符号是否不变 | 证据 |
|---|---|---|
| **规则轴**（`A0..A4`） | ★ **是，9/9 剂量** | `J128-2` = **PASS** |
| **题集轴**（15 个子集） | ★ **否，但只有 `dose=450`** | `J128-3` 的 `fail_doses = [450]` |

⇒ **可带走的一句话**：`ratio` 的**符号**是 **(状态, 题集)** 的联合性质，**不是**状态的单独性质；
但它对**加权口径**是稳健的。**这两件事必须分开说** —— `D-158` 把它们合并成了一句"合并口径"。

## §5 `CORR-37`：`D-158` 的 `2.654×` **归因**更正

**`D-158` 的原文（逐字引，`revolve/DIR-127/VERDICT.md`）**：

> 同一批 cell 只改合并口径，`dose=450` 内 `ratio` 走 `0.836648→2.220149`（`2.654×`）并跨 1，
> 而 `D-157` 赖以论证"剂量驱动转折"的**剂量间**幅度仅 `4.258×`
> ⇒ **`ratio` 的取值是「状态 × 合并口径」的联合性质**

**（逐字引，`evidence/table.md` 的 `D-158` 行）**：

> 同一批 cell** 只改合并口径，`dose=450` 内 `ratio` 走 `0.836648 → 2.220149`（**2.654×**）并**跨过 1**

**本卡的数值展示恒等（`J128-3` + `D-128-L1`）**：
`dose=450` 的 `argmin = {555,}`（`0.8366`）、`argmax = {557,}`（`2.2201`），**两者都是单元素集**；
由 §2-3 的引理，单元素集上 `A0..A4` **逐位相同** ⇒
$$\frac{\max_S \operatorname{ratio}}{\min_S \operatorname{ratio}} = \frac{2.220149}{0.836648} = 2.654\times$$
**对任何加权规则都等于 `2.654×`**（实测 `K0/K1/K2/K6/K7/K8` 六个"比率族"候选全给 `2.654×`，`probe128_battery.py`）。

**⇒ 更正**：`2.654×` 是**题集抽样（哪些 rng 进入样本）**轴上的极差，
而**不是「合并口径（加权规则）」的自由度**。理由：**规则轴在同两个极值点上根本没有自由度**（引理）。

**★ 更正的分寸（`advisor` 要求）**：
* **`D-158` 的任何冻结数字一字不改**（`0.836648`、`2.220149`、`2.654×`、`4.258×` 全部逐位保留；
  本卡的 `S6` 已在 `1e-5` 内复现其中两个，`T6`/`S3`/`T14` 复现引理）；
* **结论方向不变、且被加强**：`ratio` **仍不是**状态 `W` 的单独性质 —— 只是"联合"的另一维是
  **题集抽样**而非"口径"。★ 而抽样这一维**不可通过换口径消除**（引理保证），
  故 "`ratio` 的取值不是状态属性"这一结论**比 `D-158` 更强**，不是更弱。
* 本行**只更正归因与措辞**，**不改** `DIR-126/127` 的判决行、`SUCCEEDED` 计数、`§7.2-7b` 状态。

    用 `ratio` 问不出来**（且现在知道：**主因是题集抽样，不是口径**）。要回答它**仍须换仪器** ⇒ 派生 `P128-1`。

## §8 结论（可带走的 / 不可带走的）

**可带走（逐条有机械证据）**：
1. ★ **`ratio` 的符号对加权规则稳健**：`A0..A4` 在 **9/9 剂量**同号（`J128-2`）。
2. ★★ **`ratio` 的符号对题集不稳健，但只在 `dose=450`**：`{555,} = 0.8366` ↔ `{557,} = 2.2201`（`J128-3`）。
   ⇒ **符号是 (状态, 题集) 的联合性质**。
3. ★★★ **`2.654×` 是题集抽样轴，不是口径轴**（`CORR-37`）：两个极值都是单元素集，
   而单元素集上五条规则**代数恒等**（`D-128-L1`）⇒ 该数**对任何加权规则相同**。
4. ★★ **轴 1 系统量有界**：`≤ 1.0765×`（8/9 剂量）、`1.1703×`（仅 `dose=450`）；
   占判符号余量的比例 `≤ 19.7%`（8/9）、`43.7%`（`dose=450`）⇒ **加权口径不是符号不确定的主因**。
5. ★★ **主因是题集抽样**：簇 bootstrap 下 **3/9 剂量**（`0 / 300 / 350`）的符号 CI **跨 0**；
   且本卡**独立复现**了 `CORR-36` 的三个 `P` 值（`0.436/0.255/0.965` vs `0.435/0.260/0.970`）。
6. ★★ **pair 级率不可作仪器**（族内 `max/min = 3.6973×`）⇒ 仪器必须**先聚合计数、再形成率**。

**不可带走**：
* "不存在任何合并不变的量"（开族上不可否证）；
* "`u` 制度已/未确立"（本卡不测这个）；
* "`dose=450` 有特殊机制"以外的机制读法（`43.7%` 只是余量的比例，不是效应量）；
* 任何跨装置外推（§7-9）。
