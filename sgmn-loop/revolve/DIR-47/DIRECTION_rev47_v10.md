# DIRECTION · DIR-47 —— **`replay` 的作用**：是「**局部修复**」还是「**全局再巩固/全局干扰**」？

> **出处（不得自造）**：`framework/SGMN_v2.4_架构设计.md` §7.2 开放项「**记忆语义** | 信息寿命分解、长期干扰、**replay 作用**、模态持续度及『人格』命题」（第 527 行）。
> **★ 与 §7.1-E 的边界（必须写在卡上）**：§7.1-E 冻结「**不加入早期** Push/Pop、动态栈深度或 **replay 组件**；`S` 只保留未来扩展位置」。
> ⇒ 本卡**不把 replay 加入架构**，只测「**写入预算里花一部分去重访旧对**」这一操作的**表征后果**（即 §7.2 的「replay 作用」）。**架构冻结项一字不动。**
> **★ 与 D-69（DIR-46）的关系**：DIR-46 的 `C(N_w)` 是**7 个槽位的均值**，`period2` 之所以"不衰减"，其机制描述是"反复回访同一对"。
> 本卡把这句话**变成干预**：在**总写入数相同、被测槽位相同**的前提下，把末尾若干次写从「新对」换成「重访旧对」⇒ 直接测 replay 的作用。

## §0 一句话

**把写入预算花在「重访旧对」而不是「写新对」上，究竟救了什么？** 若它是**局部**的 —— 只修好它碰到的槽位、对没碰到的槽位**既无益也无害** —— 则 `C(N_w)` 类曲线必须按「**是否被回访**」分组解读，不能把总均值当"记忆容量"。

## §1 主假说与否证条款

**`H47`（合取，两条都必须成立）**
- **P1（修复）**：被重放抽到的槽位（`hit` 组）的取回余弦 `C_on(hit) ≥ TAU_REPAIR = 0.5`；
- **P2（局部性）**：未被抽到的槽位（`rest` 组）的**配对差** `Δ_rest := C_on(rest) − C_nor(rest)` 落在**等价带** `|Δ_rest| ≤ DELTA_EQ = 0.15` 内。

**否证条款（各自独立，命中即判）**
| 条款 | 条件 | 结局 |
|---|---|---|
| F1 | `C_on(hit) < 0.5` | `NO-REPAIR` —— replay **修不好**它碰到的槽位 |
| F2 | `Δ_rest ≤ −0.15`（显著） | `GLOBAL-COST` —— replay 有**全局代价**（占用写入预算 / 注入干扰） |
| F3 | `Δ_rest ≥ +0.15`（显著） | `GLOBAL-GAIN` —— replay 有**全局再巩固**收益（不是局部） |
| — | 其余 | **`PASS`** ⇒ 「**replay 的作用是局部修复（选择性保持）**」 |

★ **为什么是等价带而不是"≥ 某值"**：`H47` 的 P2 断言的是「**没有**全局效应」⇒ 这是一个**等价性**命题，必须用**双侧带**判，**不得**用"不显著即成立"顶上（那是把"没测出"当"证明没有"）。

## §3 测量对象（**已用 worked example 校验**）

### 3.1 定义

对实例 `sd`，`ctx=3, S=8, R=2`：
1. 内容流 `a_0..a_{M−1}`（`perstep`，逐行归一化到 `√D_H`）—— **逐字**沿用 `dir46/R1_task46.content`；
2. `H_t = tanh(a_t A1 + b1)`，`k_t = tanh((0 if t=0 else H_{t−1}) Pk1)`，`v_t = tanh(H_t Pv1)` —— 逐字沿用；
3. **上下文块** `t = 0,1,2`（**写完再也不过问、永不测**）；**被测块** `t = 3..10`（内部编号 `s = 1..7` 为被测槽位，块首 `s=0` 例外见 §3.2）；
4. 前 `ctx+S = 11` 次写：**两臂逐位相同**；
5. 末尾 `R = 2` 次写：`nor` 写**新对** `t = 11,12`；`rep_on` **重放**被测块内部槽位 `picks`（`Generator(sd + 9899 + 17)`，`randint(1, S)` **有放回**，即 `1..7`）；
6. 每槽取回余弦 `c_s = cos(W k_{3+s}, v_{3+s})`，`s = 1..7`（被测块 `t = 3..10` 的内部编号 `s = t − 3`，块首 `s=0` 不计入 ⇒ **7 个被测槽位**）；
7. **分组**：`hit := {picks} \ {0}`（去重）· `rest := {1..7} \ hit`；
   `C(hit) = mean_{s∈hit} c_s`，`C(rest) = mean_{s∈rest} c_s`，`C(all) = mean_{s=1..7} c_s`。
8. 判据量：`C_on(hit)`（P1）· `Δ_rest = C_on(rest) − C_nor(rest)`（P2，**逐实例配对**）。

★ **`picks` 只依赖 `(sd, REPLAY_TAG, REPLAY_OFF)`、与臂无关** ⇒ `nor` 臂可用**同一组** `picks` 切分 ⇒ 两组实现**配对**比较（`A47-3` 当场断言两臂 `picks` 逐位相同）。

### §3.2 ★ 结构性事实（沿用 `DEF-46-3`，必须写进卡）

`k_0 = 0`（`t=0` 时 `H_{−1}` 不存在 ⇒ 传 `zeros(D_H)`）⇒ 第 0 步写入只走 `LAM` 项、且 `W k_0 = 0` ⇒ **该槽永不可读**。
⇒ 被测块内部 `s=0` 对应的 `t=3` 的 `k` **不是零**（它用 `H_2`）⇒ 该槽**可读**但**不计入被测组**（卡上固定 `1..7`，与 DIR-46 的"跳过槽 0"口径**不同**且**已声明**）。
★ 两臂的 `picks` **不取** 内部 `s=0`（`randint(1,S)` = `1..7`）⇒ 保证"被重放的槽位"**全在被测组内**。

### §3.3 worked example（`dir47/workex47.py`，**逐位**）

手工重算 4 个实例 × 2 臂 × 7 槽位（`c_s`、`C(hit)`、`C(rest)`、`Δ_rest`），与实现**逐位相等**（`ATOL=1e-12`）；
并**独立**用一个不读实现的手写循环复算同一批 ⇒ 两条链一致才算过（`A47-2`）。

## §4 开卡前诊断（`probe47a/b/c`；**读数不进判据**）

| 探针 | 内容 | 关键读数 |
|---|---|---|
| `probe47a`（`n=80`，两臂，无上下文块） | 先确认"等写入数换写谁"有没有效应 | `(S=8,R=4,M=12)`：`C_nor=+0.020`、`C_rep=+0.262`、差 `+0.284`（`3se 0.124`）⇒ 效应**大**；`(4,4)`：差 `+0.446` |
| `probe47b`（`n=80`/`n=200`，三臂 + 上下文块） | 拆「免新干扰」与「重申旧对」 | `(ctx=4,S=8,R=2)`：`Δ_on=+0.203`、`Δ_off=+0.058`、`Δ_pure=+0.145` ⇒ 收益**主要在重申**；`R=0` 锚点 `C=+0.2582`（三臂**逐位相同**，设计自检） |
| ★ `probe47c`（`n=200`，**按槽位切开**） | **本轮最要紧的诊断** | `(ctx=4,S=8,R=2)`：`C_on(hit)=**+0.7605**` vs `C_nor(hit)=+0.0578`（`Δ_hit=+0.703`）；`C_on(rest)=+0.0788` vs `C_nor(rest)=+0.0698`（`Δ_rest=**+0.0089**`，`3se 0.096`）⇒ ★ **整槽均值的 `Δ_on=+0.258` 几乎全部是"被点到的 ~2/7 槽位被修好"的算术后果** |
| `probe47c` 复跑（`ctx=3,S=8,R=2`，**本卡采用的格**） | 确认删失 ≤ `CENS_MAX` | `cens=0.18` · `C_on(hit)=+0.7437`（`sd 0.287`）· `C_nor(hit)=+0.0241` · `C_on(rest)=+0.1045` · `C_nor(rest)=+0.0974` ⇒ `Δ_rest=+0.0071`（`sd 0.364`，`3se 0.085`） |

**诊断结论（决定卡形）**：
1. 若按**整槽均值**判，`Δ_on` 会随 `R/S` **算术化**（重放 2 个槽就抬高 ~2/7）⇒ 那个量**不能**当"replay 保护记忆"的判据 ⇒ **必须**按槽位分组（本卡 §3.1-7）。
2. `ctx=4,S=8,R=2` 的删失比 **0.205 > 0.20** ⇒ 判据点下移到 `ctx=3`（删失 **0.18**）⇒ 卡上冻结 `ctx=3`。
3. `R=0` 时三臂**逐位相同**（`Δ=0.0`、`sd=0.0`）⇒ 设计自检通过，"前缀逐位相同"这条不是口头承诺。

## §8 红线

1. **不得**用整槽均值 `C(all)` 的差代替 `Δ_rest`（那是 `hit` 组的算术后果，§4-1 已量到）；
2. **不得**把「`Δ_rest` 不显著」当 P2 成立 —— P2 是**等价性**命题，必须判**双侧带**；
3. **不得**把本卡读成「replay 提升容量」或「replay 无用」；本卡只问 **hit/rest 的结构**；
4. **不得**改动 `TAU_REPAIR`/`DELTA_EQ`/`CENS_MAX`/`ANCHOR_MIN`/`N_INST`/`MU` 之外任何已冻结项（改则新开 revision）；
5. **不得**与 DIR-46 的 `C(N_w)` 曲线直接相减（格点、`ctx`、`S`、被测槽数**都不同**；须同轮同段）；
6. 删失比 > 0.20 的格**不入判据**；
7. 与 `D-01…D-69`、DIR-43/44/45/46 的判定与计数**一字不改**。
