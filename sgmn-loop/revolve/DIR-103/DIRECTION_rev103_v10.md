### 1.2 主假说

> **`H103`**：`\mathcal O_l` 只拿到 `y`（`=\operatorname{sg}(W)q`）时，**身份信息（问的是哪条事实）已在 `q` 的通路里被压缩掉**
> —— 这是 `D-131` 任何秩都到不了 `0.99` 的原因（`A101-6`：同值/异值 `\|cos\|` 只差 `0.011`）。
> **把读取上下文 `c` 直接并入 `\mathcal O_l`**（`m=\mathcal W_o y+\mathcal W_c c`，`\mathcal W_c\in\mathbb R^{d_{\rm model}\times d_{\rm model}}`，
> **共享、非逐事实**）⇒ `c` 提供**身份**、`y` 提供**值** ⇒ 共享读出可达 **`acc_all32 ≥ 0.99`**，
> 且该路径**经 `W` 中介**（抹掉写入即崩）。

## §2 测量对象（**含手算算例**）

### 2.1 装置（逐字派生 `dir101/R1_task101.py`）

- **写**：`B=600` 块、`MOUNT=[8,12,16]`、white 键（`D-128` 口径，内容 31–32/32）——**写规则一字不改**。
- **读**（唯一改动）：`_read_r103` 在 `_read_r101` 上加**一路** `\mathcal W_c`：
  ```
  c  = sg(hs_in)                    # (B,L,d_model)   ← 读取上下文，stop-grad（Freeze C）
  cf = c.reshape(-1, d_model)
  q  = Wq @ cf ;  q = q_tf(q)
  W  = W0 + U V^T  （或 Wfull）
  y  = sg(W) @ q                    # (·, d_v)
  m  = Wo @ y   +   Wc @ cf         # ★ 新增项；`--inp` 控制哪几项生效
  ```
  `--inp y` ⇒ 只有 `Wo@y`（**逐位复现 `D-131` 满秩臂**）；`--inp c` ⇒ 只有 `Wc@cf`；`--inp cy` ⇒ 两项相加。
- **训练**（`no_write=True`，`W` 冻结）：`read_params = {Wq, Wo, Wc, gamma}`，
  `READ_STEPS=600`、`READ_LR=1e-3`、`CLIP=1.0`，损失 = 4 选 1 交叉熵，逐题（`N_CAND=4`）。
- **主读数** `acc_all32`：`eval_acc`（4 选 1、`N_DRAWS=3` 同题全对才算命中、`no_write`），
  与 `D-131`/`A101-1`/`D-132` **同一口径**。
- **机制臂 `cy_W0`**：训练完成后把每层 `W` 置为 `W0`（等价 `A97-4`/`D-124` 的 `W\leftarrow W^0`），
  **其余（含已训练的 `Wq/Wo/Wc/gamma`）不动**，重测 `acc_all32`。

### 2.2 手算算例（`A103-9`，**直接调被测函数**）

取 `d_model=2`、`d_v=2`、`W=\begin{pmatrix}1&0\\0&2\end{pmatrix}`、`Wq=I`、`Wo=I`、`Wc=I`，
输入 `c=(3,4)`、`q=c`、`y=W q=(3,8)`：
- `--inp y` ⇒ `m = (3,8)`；
- `--inp c` ⇒ `m = (3,4)`；
- `--inp cy` ⇒ `m = (6,12)`；
断言三条 `m` **逐位**等于上式（`‖·‖=0`），且 `--inp y` 与 `--inp cy` 之差**恰为** `Wc@cf`。

### 2.3 为什么 `c` 是「身份」而不是「值」（**前提，须由 `A103-6` 实证**）

`c` = 读出位（`Ln-2`）的隐状态，已 attend 过 prompt 前缀（含 5 字符 nonce 键）
⇒ 编码**问的是哪条事实**；而**值**在句中、被 `build_facts` 的 `assert` 排除在 `prompt` 之外（§1.1 第 1 行）。
★ 该前提**不是断言，是守卫**：由**负对照臂 `c`-only ≤ 0.50**（`A103-6`）实证；若 `c`-only 高 ⇒ 前提失效 ⇒ `C103-VALUE-IN-C`。

## §6 证据边界（**预注册**，写 `VERDICT` 时必须逐条抄）

1. **`acc_all32` 是 4 选 1 检索准确率**，**不是**"记忆改善了 LLM 任务"；本卡**不得**被表述为前向任务收益的完整答案。
2. **训练用全部 32 事实** ⇒ 测的是**容量**，非泛化；`acc_all32` **不得**称"泛化"或"留出"。
3. 判决对**该优化器 + 该步数**（`READ_STEPS=600`、`READ_LR=1e-3`）成立；若 `C103-NOT-REACHED`，**不得**外推为"任何读出结构都不行"（只覆盖 `\mathcal W_o y+\mathcal W_c c` 这一**线性相加**族）。
4. **`c` 通路是 Freeze C 允许的**（`§7.2-2`「$\mathcal O_l$ 内部结构」为开放项，且 `c` 为 stop-grad）；但若判 `C103-BYPASS`，**不得**由此推出"`\mathcal O_l(c,y)` 非法"——只说明其增益不经 `W`。
5. **不得**外推到真实近共线键族（`D-114` `cos` 中位 `0.997`）；本卡用 white 键 = **上界臂**。
6. **`c`-only 的读数**只是**负对照**，不用来主张任何正向结论。
7. 与 `D-131` 的**可比性有限**（`A103-2` 为区间带而非逐位，见 §3）。
