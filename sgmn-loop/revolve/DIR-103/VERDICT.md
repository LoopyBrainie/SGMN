## §2 机制（**不只是数字**）

### 2.1 `c` 通路的本质 = **读出侧记忆化（memorization in `\mathcal O_l`）**

- 值**不在** prompt 里（源码级：`R2_task91.build_facts:192-193` 的
  `assert sent.startswith(prompt + " " + val)`；`prompt` = 值**之前**的前缀）。
- 诊断：`c` **没有**值信息（`cos` 同值/异值差 **0.0028**），但**身份完全可解**（中心化 ridge **32/32**）。
- ⇒ `c` 单独能让 `acc=0.8750`，唯一的通路是 **`\mathcal W_c` 把 32 条「身份→值」存进了自己的权重**
  （**802816 参数/层**，32 条事实绰绰有余）。**全程不碰 `W`**（`--inp c` 时 `Wo y` 一项不参与）。

### 2.2 rev 1.0 的前提错在哪（`DEF-103-01`）

rev 1.0 §2.3 主张「值不在 prompt ⇒ `c` 只可能携带身份 ⇒ `c`-only 应 ≈ chance」。
★ **漏了一条通路**：`\mathcal W_c` **本身可以记忆化** —— 「值不在 `c` 里」**不等于**「`c` 通路答不对」。
⇒ `A103-6` 失败是这个前提**过强**的直接证据，按 `A102-2`/`A102-2p` 的同一先例**降级为只记录**（rev 1.1 §8.2）。
★ **如实披露**：该降级发生在**看到 smoke 之后、正式轮判决之前**；阈值与 §1.4 四分支文字**未改**。

### 2.3 ★★ 对 `D-131` 的**机制更正**（`DEF-103-02`；`D-131` 的**判决保留**）

`D-131` 由「任何秩的 `\mathcal W_o: y\to m` 都 `<0.99`」推出「注入接口**必须**按事实分配自由度（per-fact）」。
★★ 本轮显示该推论**过强**：一个**共享**的 `896\times896` 线性映射**确实能**到 0.8750 —— 只要它的输入**含身份**。
⇒ `D-131` 的真正障碍是 **「`y` 里没有身份」**（`A101-6`：同值/异值 `|cos|` 只差 **0.011**，`y` **有秩、无几何**），
**不是**「共享读出必须 per-fact」。
⇒ **`D-131` 的判决（`A-NOT-SHARED`，针对 `\mathcal W_o: y\to m`）保留**（它对 `y` 仍未达 0.99），
但其 §3 边界 8 与「per-fact 必须」的**机制表述**须按本条更正。

### 2.4 为什么 `cy` 反而在 7777 上不升（`cy` = `c` = 0.8750）

`cy` 两臂**联合训练**时，`\mathcal W_c` 与 `\mathcal W_o` 会**共适应**（各自分担一部分）。
证据：`cy_W0` 塌到 **0.0625**（7777）/ **0.1875**（20261028）—— 抹掉 `W` 后 `\mathcal W_c c` 这一路
**并没有**单独顶住到它在 `c`-only 臂里的 0.8750 ⇒ 说明联合训练把记忆分散到了两路、
且 `\mathcal W_c` 那一路**依赖了 `\mathcal W_o y` 的存在**。
⇒ ★ **`cy` 的 0.9688 不能读作「记忆贡献了 +0.0625」**：它是**两路共适应后的联合读数**，
而 `c`-only 的 0.8750 是**纯记忆化**读数。这两个数**不可相加解释**。

### 2.5 为什么 `0.8750` 两 seed 完全同值，而它不是"结构上界"

- `0.8750 = 28/32`，两 seed **逐位相同**；但诊断证明**身份线性可分 32/32** ⇒ **不是身份可分性上限**。
- 最可能来源：**优化预算**（`READ_STEPS=600`，每步 1 个 batch ⇒ 约 18.75 个 epoch 遍历 32 条）。
  该量**未经实验确定**，故**只记为推测**（`O103-1`），**不得**当作结论。

## §3 证据边界（**不得外推**）

1. **`acc_all32` 是 4 选 1 检索准确率**，**不是**"记忆改善了 LLM 任务"；本卡**不得**被表述为前向任务收益的完整答案。
2. **训练用全部 32 事实** ⇒ 测**容量**，非泛化；`acc_all32` **不得**称"泛化"或"留出"。
3. 判决对**该优化器 + 该步数**（`READ_STEPS=600`、`READ_LR=1e-3`）成立。
   ★ **`C103-NOT-REACHED` 只覆盖「线性相加」族** `m=\mathcal W_o y+\mathcal W_c c`；
   **不得**外推为「任何读出结构都不行」（非线性 `\mathcal O_l`、更长训练**未测**）。
4. **`c` 通路是 Freeze C 允许的**（`c` 为 stop-grad；`§7.2-2`「$\mathcal O_l$ 内部结构」为开放项），
   但它把**记忆化的位置**从 `W` 搬进了 `\mathcal O_l` 的权重 ⇒ 与 `§7.1 C`「写入负责形成关联」的**分工意图**相悖。
   本卡**只报读数**，**不判**该设计是否合法（架构裁定，非实验能定）。
5. **不得**外推到真实近共线键族（`D-114` `cos` 中位 `0.997`）；本卡用 **white 键 = 上界臂**（oracle `A`）。
6. **`c`-only 的读数**是**记忆化**读数，**不得**当作"记忆收益"；同理**不得**把 `0.8750` 记成 SGMN 的能力。
7. 与 `D-131` **可比性有限**：`A103-2` 为**区间带**而非逐位复现（新增 `\mathcal W_c` 改变 RNG 消费）。
8. 诊断的**原始**闭式 ridge（0/32）是**退化读数**（共模支配），**不得**据它说"身份不可解"；
   有效读数是**中心化**的 **32/32**。
9. 诊断只取了 **`layer = 16`**（`MOUNT=[8,12,16]` 的最后一层），**不得**冒充"全部层"。

## §7 结论

1. **`H103` 否证**：把 `c` 并入共享读出，`cy` = **0.9688 / 0.8750**，两 seed 均 `< 0.99` ⇒ **`C103-NOT-REACHED`**。
