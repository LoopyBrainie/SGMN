## 4. ② 已修：`precheck125`/`126` 的 `S12` 重跑必败

**病**：`S12` 断言「开卡时新剂量**还没有 cell**」（`DEF-125-04` 的防污染修法），
`formal` 一跑完 cell 必然存在 ⇒ 此后**任何**重跑必 `rc=1`。这不是卡片缺陷，但会被误读成事故。

**修法（外科式，2 处）**：加 `--stage recheck` —— `S12` 的**盲态部分**由**断言**降为**记录**，
并在输出里**明写**「盲态已不可复现，本次为重跑（RE-CHECK）」；`load_cells` **越界调用**（`extra`）
**仍然断言**（那是仪器纪律，与产物是否存在无关）。

**★ 实测四条件（全部在 trainer 上）**：

| 条件 | 期望 | 实测 |
|---|---|---|
| **A** 默认调用（`formal` 之后、产物齐全） | 与打补丁前**逐字一致**：`125` rc=1、`126` rc=1 | ✓ rc=1 / rc=1，FAIL 文字同前 |
| **B** `--stage recheck` | rc=0 且明写盲态不可复现 | ✓ rc=0 / rc=0，均打「阶段 = recheck（盲态不可复现，S12 降为记录）」 |
| **C** 开卡期（移除本卡 `out/`，默认模式） | `125` 仍 rc=0（不得回归） | ✓ rc=0；`126` rc=1（它本就不能开卡期跑，符合 §2 分类） |
| **D** 变异：把 `STAGE = _stage()` 改成 `STAGE = "precheck"` | `recheck` **必须变红** | ✓ 两卡均 rc=0→**1**；还原后回 0 |

★★ **D 的第一版没测出来，原因是我自己的测试错了**：用 `sed 's/^STAGE = _stage()/…/'` 未匹配
（`126` 的那行有 4 空格缩进），于是"变异"根本没写进文件，`rc` 当然不变 ——
**看起来"变异后仍 rc=0"，实际是"没有变异"**。改为 Python 正则 + `assert s2 != s`
（变异不生效即报错）后，两卡都如期变红。★ 这与 `Cycle 248` 的三次教训同源：
**变异测试必须先证明"变异真的写进去了"**，否则它只是在证明"什么都没变"。
