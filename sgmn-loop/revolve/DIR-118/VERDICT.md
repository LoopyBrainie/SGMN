## §4 机制（★ 本卡真正的产出，比判决本身更重要）

**一、未训练装置在低增益下本来就高于随机。**
`mult=1` 时两臂未训练分别是 **34.7% / 37.5%**，随机 25%。
—— 这不是噪声：`γ=0` 时 `read_gamma ≡ 0` ⇒ `Wq/Wo` 被旁路 ⇒ 先验与 seed 无关（实测 17/18，`A118-1`）；
`mult=1` 时 `γ≠0`、`Wq/Wo` 参与，但未训练时 `W = W^0` 不动 ⇒ **跨 seed 差异很小**（`SPLIT` 16–17 项、`COLOCATED` 恒 18 项）。**这正是 `d=0` 作为"同装置随机投影对照"的定义。**

**二、600 块训练在两臂都把读出打到随机以下，`COLOCATED` 甚至打到随机**一半以下**。**
`SPLIT`：34.7% → **26.6%**（几乎正好塌到随机）。
`COLOCATED`：37.5% → **5.3%**，且 `mult=1e4` 也只有 **4.6%** —— **不足随机 25% 的 1/5**（5.4× / 4.7×）。
★ **低于随机不是"没学到"，是"学到了错的"**：低于随机的读数意味着它**近乎恒定地挑同一个错候选**
⇒ 单调不可能产生这种一致性，这是**结构**（`COLOCATED` 逐 seed `Δ(1)` 落在 **−18…−8**，**9 个里 8 个 ≤ −14**，`t = −15.21`）。

**三、因此 `R > 0` 的含义是「损伤在高增益下较轻」，不是「高增益带来收益」。**
`SPLIT`：`Δ(1) = −3.89` → `Δ(1e4) = +0.67`，即损伤**消失**（两点都贴近随机）。
`COLOCATED`：`Δ(1) = −15.44` → `Δ(1e4) = −10.67`，即损伤**收窄但仍深在随机以下**。
两臂都遵循「低增益受害更重」⇒ **`gap = 0.22` ⇒ 通用**。
★ 换句话说：**`R` 是一个"损伤的增益依赖"的量，两臂共享的是这个依赖，不是任何收益。**

## §6 证据边界（**不得**外推）

1. ★ **`R` 等价是弱陈述，不得读成"两臂行为相同"。** 两臂在 `R` 上只差 0.22，但**绝对水平差近 4 倍**
   （`Δ(1)` = −3.89 vs −15.44；训练后 26.6% vs 5.3%）。本卡只证明「**翻转的形状**（低增益受害更重）在两臂都存在」，
   **没有**证明「两臂等价」。`EQUIV_MARGIN = 2.0` 也是**弱等价**：9 seed 只够分辨 `R ≈ 5` 量级，分辨不了 `R` 上的小差异。
2. **"训练有害"只是本装置、本剂量、本任务集上的读数**（`Qwen2.5-0.5B-Instruct`、600 块、16 事实训练集），
   **不得**推广为"在线训练有害"或"v2.4 写入有害"。
3. **`COLOCATED` 低于随机不得读成"学到了否定知识"。** 已排除的可能性只有"没学到"；**未**排除
   候选集构造工件（4 候选的排列/词面偏置）与 `W^0` 的既有偏好被放大。这是**下一卡**的问题，不是本卡结论。
4. **`d=0` 是同装置随机投影对照，不是打乱标签对照**（`D-144`/`D-145` 的边界沿用）。
5. `mult = 1e4` **不是 v2.4 可用配置**；本卡的 `1e4` 只是 `D-148` 主判点，用于与它对齐。
6. **不改 `§7.2-7b` 的 `不足`**：本卡只判定"翻转的值依赖性"，`7b` 的缺口是"记忆已改善 LLM"，两者不同层。
7. **`|gap| ≤ 2.0` 不是"两臂完全相同"**，是"9 seed 下分辨不出 ≥2.0 项的差异"。
