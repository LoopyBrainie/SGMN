## §2 主判据量（定义逐字沿用 `D-127`，**一字不改**）

$$N_{\rm hit}^{v}(W)=\sum_{i=1}^{N}\Big[\arg\max_{j}\cos\big(Wk_i,\;v_j\big)\in S_i\Big],
\qquad S_i=\{j: v_j\equiv v_i\}$$

- ★ **值一致即命中**（不是严格下标 `j == i`）—— 因为"同一个值"在装置里有**两条事实**，
  两条的 `v` 向量因句子不同而**不相等**，用严格下标会把"值对了但落在另一条"判成错。
- 副读数（只报不判）：`N_hit^s`（严格下标）、`N_hit^v_L2`（欧氏 argmin 版本）。

## §4 测量对象 + 一个具体手算例（round standard 要求）

**测量对象**：`(W, K, V, S)`。`K`/`V` 由 `D98.key_matrices_tf` 用 `m.Pk/m.Pv/pk_scale` 与**本臂同一个** `key_tf` 提取
（读装置字段，不重实现 `COR-114-01`）。`W` 取 `m.Wfull`（`use_factorized=False`）。

**手算例**（写死进自测，手工可验）：令
```
V = [[1,0], [0,1], [1,0]]        # 值 v0, v1, v0（v0 出现两次）
K = [[1,0], [0,1], [.707,.707]]
⇒ S = [[0,2], [1], [0,2]]        ⇒ E_random = (2²+1²+2²)/3 = 9/3 = 3.0
```
- `W = I`：`Wk_0 = [1,0]` ⇒ `cos` 于 `V` = `[1, 0, 1]` ⇒ `argmax = 0 ∈ S_0` ✓；`Wk_1 = [0,1]` ⇒ `argmax = 1 ∈ S_1` ✓；
  `Wk_2 = [.707,.707]` ⇒ `cos` = `[.707, .707, .707]` ⇒ `argmax = 0 ∈ S_2` ✓ ⇒ `N_hit^v = 3/3`。
- `W = 0`：所有 `R` 为零向量 ⇒ `cos = 0` 全并列 ⇒ `argmax = 0` 恒成立
  ⇒ 命中 `i=0`（`0∈S_0` ✓）与 `i=2`（`0∈S_2` ✓），`i=1` 落 `0∉S_1` ✗ ⇒ `N_hit^v = 2/3`。
- ★ 这个例子同时给出**常数 `argmax` 的行为**与**零向量的退化行为**，两者都必须被自测复现。

3. `intact` 用 **1 遍写**（600 块）而非 600 块 ×10 遍：`D-128` 已实测 `intact@1` 与 `intact@10` **同值**（1 与 1），
   `white@1` 与 `white@10` 同为 32 ⇒ 预算不是本轴的约束。**本卡据此取 1 遍，并如实记该选择。**
4. ★ `K`/`V` 提取沿用 `dir97/dir98` 的**探针约定**：每个事实单独前向一次，`k` 与 `v` **同取该块的 `_hs_in`**

   **为可比性而保留**；但它是一处**已知偏离**，**不得**声称本卡的 `K/V` 与训练时的写入键逐位相同。
5. 本卡**不**回答 `§7.2-7b`，**不**改 `COVERAGE-v24.md` 任何格。
