## §1 主假说与证伪（**冻结**）

**H90**：在**记忆依赖型任务**上，写入的记忆内容提供**超出"同形注入但无内容"的增益** ⇒
$$\Delta_{\rm content}\;=\;\mathrm{acc}(\text{MEM})-\mathrm{acc}(\text{INJ})\;>\;0$$

**证伪条款（冻结，不改）**：
- $\Delta_{\rm content}$ 的 $95\%$ CI **跨 0** ⇒ `FALSIFIED`（内容不提供可测增益，与 `D-16` 的 R3 一致）。
- $\Delta_{\rm content}>0$ 但**跨 3 个种子变号** ⇒ `FALSIFIED`（不可分辨，同 `D-14` ④ 对 DIR-06「0.2%」的判法）。
- 若 **S90 存储诊断失败**（见 §3）⇒ `INCONCLUSIVE-STORAGE`（**第三态**：不是"内容无用"，而是"内容没存进去"；**不得**记作 FALSIFIED）。
- 若 **CEIL 臂**在 Stage A 未达门限 ⇒ 本轮**不得开跑**（任务本身不可答）。

## §2 MVP 标准（**这就是"最小可判定产物"**）

**一个三臂 × 3 种子 × 单一任务的正对照实验**，任务须**可判对错**、**答案只能来自写入内容**：

| 臂 | $\gamma$ | 写阶段 | 读侧训练 | 语义 |
|---|---|---|---|---|
| **BASE** | 0 | 关 | **无**（$\gamma{=}0$ ⇒ 注入恒 0、$\partial L/\partial W_q{=}0$，**不可训练**） | 纯冻结基座 = 地板 |
| **INJ** | 0.05 | **关**（`no_write=True`） | 有（同优化器/同步数/同数据） | **有注入、无内容** |
| **MEM** | 0.05 | **开** | 有（**与 INJ 完全相同**） | 有注入、有内容 |

⇒ **内容性** $\Delta_{\rm content}=\mathrm{acc}_{\rm MEM}-\mathrm{acc}_{\rm INJ}$（**唯一主判据**）
⇒ **通用注入** $\Delta_{\rm inj}=\mathrm{acc}_{\rm INJ}-\mathrm{acc}_{\rm BASE}$（**分列报告，不得混报** —— user rules 明文）
⇒ **★ 为何必须用 INJ 而不是"无记忆适配器"**：`D-16` 的 R3 是**外部**替代物，参数量/秩/优化器都与 SGMN 不同，因此只能支持归因、不能构成裁决。**INJ 与 MEM 共享同一模块、同一秩、同一优化器、同一步数、同一数据**，唯一差别是 $W$ 里有没有写进去的东西 ⇒ 这是能真正隔离"内容"的对照。

### 任务（`KVR`，Key–Value Recall）
- **键**：随机 nonce（5 字符大写字母数字，如 `QX7F2`）—— **基座不可能先验知道**。
- **值**：常用短词（颜色/动物，如 `teal`/`otter`）—— 在词表内，但**关联是任意的**。
- **事实句（写入用）**：`The access code for item QX7F2 is teal.`
- **问题（评测用）**：`The access code for item QX7F2 is`
- **判分**：**候选打分**（不生成、不依赖指令遵循）——给 4 个候选值（1 正确 + 3 干扰），取**候选 token 序列 NLL 最小者**为预测；**准确率** = 命中率。**机会水平 = 0.25**。
  ★ 用候选打分而非自由生成：0.5B 模型的**格式遵循**与**记忆读取**会被混在一起（`D-15` 的"读路径随机"就是因为读出没对齐）；候选打分把"能否说出来"降为"能否偏好正确项"，**只测记忆，不测格式**。
- **写入量**：$F=32$ 条事实（每条一句），重复铺满 $B=600$ 块 × 64 token（记忆是关联式的，重复无害）。
- **训练/评测切分（防读侧答案记忆）**：读侧在 **keys 1–16** 的 QA 上训练；**评测只用 keys 17–32**。
  ⇒ 若 MEM 在**未训练过的键**上优于 INJ ⇒ 读的是**记忆内容**；若只在训练键上好 ⇒ 是**读侧参数记住了答案**（须单列，不得算内容收益）。
- **评测项数**：16 题 ×（3 组独立干扰抽样）= **48 项**；★ **同一题的 3 次抽样不独立**，报告时**同时**给"按题计"（$n{=}16$）与"按项计"（$n{=}48$），**裁决用按题计**（保守）。

### 门限（**冻结，开跑后不得改**）
| 量 | 通过条件 |
|---|---|
| **CEIL**（Stage A） | 事实**置于 prompt 内**时 acc $\ge 0.75$（4 选 1，机会 0.25）⇒ 任务可答、打分正确 |
| **FLOOR**（Stage A） | BASE 在**无任何注入**时 acc $\le 0.40$（不得先验知道 nonce 关联） |
| **$\Delta_{\rm content}$** | $>0.05$ 且 $95\%$ CI 不跨 0 且 **3 种子同号** |
| **$\Delta_{\rm inj}$** | **只报告，不设通过门限**（`D-16` 已示注入可有害，本卡不预设方向） |
| **S90 存储诊断** | $\mathrm{rel.err}(Wk_i,v_i)$ 在 MEM 下 $\le 0.5$（相对 `no_write` 基线至少降低 $2\times$）⇒ 内容**存进去了** |
| **功效** | 若真实效应为 $0.25\to0.55$（$+0.30$），$n{=}16$ 双侧 $\alpha{=}0.05$ 下功效 $\ge 0.80$（二项精确检验） |

★ **功效不足 ⇒ 判 `INCONCLUSIVE-POWER`，不得判 FALSIFIED。**（"criterion never computed" 与 "computed and FAILED" 是不同状态 —— Round standard 明文）

## §3 测量对象 + **一个具体工作例**（Round standard 1c）

**测量对象**：$\mathrm{acc}=\dfrac{1}{|Q|}\sum_{q\in Q}\mathbb{1}\big[\arg\min_{c\in C_q}\mathrm{NLL}(c\mid q)=\text{answer}(q)\big]$

**工作例（必须被 Stage A 的 A90-9 逐字复现）**：取 2 题、每题 2 候选（候选数只为手算，正式轮用 4）：

| 题 | 候选 | 假设的 $-\log p(c\mid q)$ | 预测 | 正确 |
|---|---|---|---|---|
| $q_1$：`…item QX7F2 is` | `teal`, `otter` | 0.5, 2.0 | `teal` | ✅ |
| $q_2$：`…item BM4K9 is` | `crimson`, `heron` | 1.8, 0.7 | `heron` | ❌（正确 `crimson`） |

⇒ 手算 $\mathrm{acc}=1/2=0.5$，**按题计**口径。A90-9 用一个**桩打分器**（直接返回表中 NLL）驱动**同一个** `score_and_accuracy()` 函数，须得 $0.5$ 且预测序列为 `[teal, heron]`。
★ **分辨力要求**：该守卫必须能**失败**——同时喂一份把 $q_2$ 两个候选 NLL 互换的桩，须得 $\mathrm{acc}=1.0$；若两次都得 $0.5$，则打分/取最小环节**无分辨力**，守卫作废（`DEF-88-1` 的教训：守卫必须能失败才算守卫）。

## §5 预注册预言（**先写、后核；带宽 ≥0.15**）

| # | 预言 | 置信 |

| 1 | CEIL 臂 acc $\ge0.75$（0.5B 能做 4 选 1 的 nonce 关联题，只要事实在 context 内） | **0.80** |

| 3 | **S90 存储诊断通过**（$\mathrm{rel.err}\le0.5$，$W$ 确实拟合了写入的 $k\to v$） | **0.60** |

## §7 边界（**开跑前写定，结论不得越界**）

1. **不得**外推为「SGMN 无记忆能力」：只测 rank-8 × 3 层 × 32 条事实 × 单槽均值池化这一配置。
2. **不得**把 $\Delta_{\rm content}$ 与 `D-16` 的 NLL 收益相加或比较——**量纲与任务都不同**。
3. **不得**把 BASE 当"训练过的无注入臂"：$\gamma{=}0$ 时读侧梯度恰为 0（A90-4），它是**冻结基座**。
4. **不得**用"$\Delta_{\rm content}$ 不显著"代替"内容无用"——须先看 S90 与功效。
5. **不得**外推为「§7.2-7 已关闭」：本轮只测 1 个记忆依赖任务、1 个基座、1 个容量点。
6. **不得**把 48 项当 48 个独立样本。
7. 若 `INCONCLUSIVE-STORAGE`：**不得**记作"内容无用"，须记作"该容量下存不进"。
