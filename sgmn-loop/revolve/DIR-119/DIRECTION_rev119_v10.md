### §0-2 ★★ 「候选置换」控制**按原文写法是构造性空转**（`DEF-119-01`，本卡必须改写）

`P118-4` 原文控制①：「**候选置换**（打乱 4 个候选的位置、内容不变）—— 预测仍在 ≈5%（排除残留位置效应）」。

`dir90.nll_of_candidate` 的实现（逐字）：

```python
def nll_of_candidate(model, st, prompt_ids, cand_ids):
    assert len(cand_ids) == 1, ...
    seq = torch.tensor([prompt_ids + cand_ids], ...)
    lg = model(input_ids=seq).logits.float()
    lp = torch.log_softmax(lg[0, len(prompt_ids) - 1], dim=-1)
    return float(-lp[cand_ids[0]])
```

而 `dir114.make_items_with_vals` 把 4 个候选做成 `cand = [(ids, ok), …]`，`prompt_ids` 就是 **`facts[ki]["prompt_ids"]`** ——
**4 个候选串从未进入 prompt**，是**分别**对同一个 prompt 独立打分。

⇒ 打乱候选顺序**只置换 `S` 的列**，同时**同等地**置换 `tgt` 与 `cand_val`
⇒ `argmin` 选中的**还是同一个候选** ⇒ `acc` **逐位不变**，**恒等**，与"是否有位置效应"无关。
⇒ ★ 这不是"通过"，是**该控制不可能失败**（"死门"，正是 `DEF-118-05` 的教训：注入不红 ≠ 判据正确）。
⇒ **本卡把控制①改写为两条**：**(A) 把它当作"装置无位置耦合"的*证明性*不变量**（`A119-7`，要求逐位相等，
且**明确不许**把它读成"排除了位置效应"）；**(B) 真正对应上游"候选集构造工件"的控制**换成
**候选集重抽**（`C2`，用 3 个独立 `rng_seed` 重抽干扰项集）+ **词面偏置诊断**（`C3`，逐 token 选中率）。

## §1 问题与主假说

`COLOCATED`（评测 48 项的正确值**全是训练中未见的值**）在 `dose=600` 后 `argmin` 准确率跌到
**5.3%（`mult=1`）/ 4.6%（`mult=1e4`）**，远低于 4 候选的随机 25%（`t = −15.21`，9 seed 极稳）。

**两个候选机制**：

- **M1 · 偏好见过值**：读出偏好"训练中见过的值"。由于 `COLOCATED` 的**正确值一定是未见值**，
  而干扰项里常有见过值（每项"见过干扰项个数"分布 `{0:2, 1:23, 2:20, 3:3}`）⇒ 只要偏好见过值，
  就会**系统性地避开正确项** ⇒ 低于随机。**预测**：`argmin` 选中的错误项里，"见过值"占比
  **显著高于**逐项零假设 `n_seen_distractors / 3`。
- **M2 · 读数符号反向**：训练把读出的符号翻了过来（读出用的是 NLL 的 `argmin`，若内部量被取反，
  `argmin` 就选了"最不该选"的）⇒ 用 `argmax` 就应**几乎全对**。
  ★ 等价形式（本卡用它，因为 4 候选下二者**恒等**）：**正确项落在 rank 4**（`argmax` 选它）
  ⇒ `acc_argmax ≡ rank_hist[3] / 48`。

**主假说 `H119`**：`COLOCATED` 的低于随机现象，可由 **M1 或 M2 之一**解释（判定为可判定）。
**证伪子句**：若 `acc_argmax < 0.90` **且** `GAP < 0.20`（两判据**同时**不成立）
⇒ 记第四态 **`M-OTHER`** ⇒ **`H119` 的二分框架被证伪**（现象仍成立，但**不得**强行二选一，**不**计入 `SUCCEEDED`）。

**前提子句（与证伪子句分开，`CENSORED` 语义）**：若"低于随机"本身**不复制**
（`acc_argmin(1e4)` 在 9 seed 上**不显著**低于 0.25），或任一被判 cell 出现非有限值
⇒ 整卡记 **`REPLICATION-FAILURE` / `CENSORED`** ⇒ M1/M2 **均"从未被计算"**，
依 round standard **不得**记 PASS/FAIL，**不**计入也不扣减 `SUCCEEDED`。

## §2 判据（**冻结；阈值一字不许改**，要改就新开 revision）

优先级 **M2 > M1 > M-OTHER**（预先声明，避免事后择优）：
若 M2 成立即判 M2（符号反向**独自**就能解释整个"低于随机"的缺口，比 M1 更简约）；
M2 不成立而 M1 成立 ⇒ 判 M1；两者皆不成立 ⇒ `M-OTHER`。

| 编号 | 判据（全部在 `dose=600`、`JUDGE_MULT = 1e4` 上读） | 阈值 |
|---|---|---|
| **`J119-1`** | **M2**：`acc_argmax` 的 9 seed 均值（≡ `rank_hist[3]/48` 的均值） | **`≥ 0.90`** |
| **`J119-2`** | **M1**：`GAP = mean_s(err_in_train_frac_s − err_in_train_null_s)` | **`≥ 0.20`** |
| **`J119-3`** | **M1 的稳定性**：对 9 个逐 seed `GAP_s` 做单样本 t 检验（`H0: μ=0`） | **`t ≥ 2.0`** |
| **`J119-4`** | **前提**：`acc_argmin` 的 9 seed 均值**显著低于** 0.25（单样本 t，`H0: μ=0.25`） | **`t ≤ −2.0`** |

★ `J119-2` 的 **0.20 预注册理由**（不可事后调整）：逐项零假设是 `n_seen_distractors/3`
（**条件在"错了"上** ⇒ 只在 3 个干扰项里挑，故除 3，不除 4）。在 `COLOCATED` 的
`{0:2,1:23,2:20,3:3}` 分布下，零假设的解析均值 = `(2·0 + 23·1 + 20·2 + 3·3) / (48·3)`
= `72/144` = **0.5**（§3 手算例与 `A119-4` 都要实测复核这个 0.5）。
纯 M1 的上限 ≈ **1.0**（有见过干扰项时必选它）⇒ **0.20 = 零假设→上限的 40%**：
机制上必须大到"能分辨偏好"，又留出 9 seed 小样本的噪声余量。
★ `J119-1` 的 **0.90** 沿用 `P118-4` 原文（不是本卡新定），且是**保守**方向：它要求**近乎完美**的反向，
故 `argmax` 若只到 60% 之类，M2 **不成立**（该读数只进报告，不许据此改判）。

**统计口径**：`JUDGE_MULT=10000`、`REF_MULT=1`（两点都报，**判定只看 `JUDGE_MULT`**，与 `D-146…D-149` 一致）；
9 seed（`SEEDS = dir118` 的同一组 9 个，**不换 seed** —— 本卡是**同装置重测**，换 seed 会破坏可比性）。

## §3 测量对象与**手算例**（`A119-5` 逐位断言它）

**新测量层**（每 cell、每 mult 都落盘）：由**一次** `score_matrix` 得到 `S (48×4)` 后**同时**导出
`acc_argmin` / `ok` / `rank_hist[4]` / `acc_argmax` / `pick_argmin[48]` / `pick_argmax[48]`，
并在两个被判 mult 上另存逐项 `tgt`、`cand_seen[48][4]`、`n_seen_distr[48]`。
★ **不新增任何前向**：`acc_of` 本来就是"算 `S` 再用它算 `acc`"，本卡只是**不再丢掉 `S`** ⇒ 与 `dir118` 同算力。

**手算例（2 项，`tv = {"x","z","q","r"}`，`N_CAND=4`）**：

| 项 | `cand_val` | 正确下标 | `cand_seen` | `n_seen_distr` | `S` 行 |
|---|---|---|---|---|---|
| A | `x y z w` | **1**（`y`） | `T F T F` | **2**（`x`,`z`） | `[1.5, 0.9, 2.0, 0.4]` |
| B | `p q r s` | **0**（`p`） | `F T T F` | **2**（`q`,`r`） | `[0.1, 3.0, 2.5, 1.8]` |

逐项推导（`n=2`）：
- **A**：`argmin = 3`（`0.4`）≠ 1 ⇒ **错**；`argsort` = `[3,1,0,2]` ⇒ 正确项排名 **rank 2**；`argmax = 2`（`2.0`）。
  选中值 `w` ⇒ 见过标志 `F` ⇒ `err_in = 0`。`null_A = 2/3`。
- **B**：`argmin = 0`（`0.1`）= 0 ⇒ **对**；`argsort` = `[0,3,2,1]` ⇒ **rank 1**；`argmax = 1`（`3.0`）。
  ★ **对** ⇒ 依"条件在错了上"的口径，**不进** `err_in` 统计。

**应得读数（冻结，`A119-5` 必须逐位相符）**：
```
acc_argmin        = 1/2 = 0.5
acc_argmax        = 0/2 = 0.0
rank_hist         = [1, 1, 0, 0]          # rank1:B, rank2:A
rank_hist[3]/n    = 0.0   == acc_argmax    # ★ 恒等式，A119-6 用
n_err             = 1
err_in_train_frac = 0/1 = 0.0
err_in_train_null = (2/3)/1 = 0.6667
GAP               = 0.0 − 0.6667 = −0.6667
n_seen_distr 均值  = (2+2)/2 = 2.0
解析零假设均值     = 2.0/3 = 0.6667
```
★ 这个例子**故意**让 `GAP` 为**负**且 `acc_argmax = 0`，即**两条判据都不触发**
⇒ 它同时充当 `M-OTHER` 的**构造性样例**（`A119-10`/`A119-11` 再各补一个"会触发"的样例）。

## §5 控制

- **`C1` 位置耦合的*证明性*不变量**（原控制①改写，见 §0-2）：固定置换 `S` 的列并**同步**置换
  `tgt`/`cand_val` ⇒ `acc` 必须**逐位相等**；且把 items 按同一置换重排后**真的重跑** `score_matrix`
  （1 seed × 1 mult）⇒ `S` 逐位相等。★ **只许**据此说"装置无位置耦合"，**不得**说"排除了位置效应"。
- **`C2` 候选集重抽**（真正对应上游"候选集构造工件"）：除 `rng_seed=555` 外，另用 **`556/557/558`**
  重抽干扰项集（同 `ev` keys、同 `N_DRAWS`），在 `dose=600` 的两个被判 mult 上重算读数。
  ★ 若"低于随机"与 `GAP` 在这 3 个独立抽法上**同向且量级相当** ⇒ 不是某一组特定候选集的工件。
- **`C3` 词面偏置诊断**（report-only）：逐候选 **token** 统计被选中次数；并比较
  「选中项的分布」在**见过/未见**两类上的占比与在**具体 token** 上的集中度。
  若选中集中在少数 token（与见过无关）⇒ 词面偏置是竞争解释，须在 VERDICT 里如实并列。
