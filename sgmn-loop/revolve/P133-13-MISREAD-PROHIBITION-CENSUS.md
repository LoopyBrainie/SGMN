## §0 一句话答案

**全部带量词**。本轮造出**第三种入口**（**句法框架**：禁止语 ＋（可选 `把/将`宾语）＋ 误读动词 ＋

## §1 口径（先冻结，后普查）

### §1-1 普查单元（★ 与 `P133-10` 的不同之处）

`P133-10` 的单元 = 「一行内同时出现**禁止语**与**全称量词**」。
本轮单元 = 「一行内出现『**禁止语** ＋（可选 `把/将` 宾语）＋ **误读动词** ＋ **引号断言**』」。

★★ **两条判据是互斥的，不是竞争关系**（本普查最硬的结构事实）：
本探针在匹配前**显式**判 `_quant_of(d) is not None ⇒ 返回 []` ⇒ 带量词的行**一律不进**本普查，
那是 `P133-10` 的地盘。**实测重叠 = 0**（见 §5）。

### §1-2 词表（★ 每一处「放宽」都必须有理由，不得为了多抓而放宽）

| 项 | 口径 | 依据 |
|---|---|---|
| **禁止语** | `不得 / 禁止 / 不许 / 严禁 / 不能 / **不可**` | ★ **多收「不可」**。`P133-10` 的 `PROHIB_TOKENS` **故意不收**它，因为本库「不可」多为**属性标签**（「不可判」「不可读」）。但本框架**强制要求**「不可」后接**误读动词**再加**引号断言** ⇒ 标签用法**进不来**（夹具 `-MIS-5` 钉住）。**这不是放宽词表，是换了判据** |
| **误读动词** | `读成/读作/称为/说/当作/断言/记成/写成/解释为/表述为/外推为/视作/视为/理解为/当成/称作/当作是` | 只收**支配被禁断言**的动词。★ 「不得**打印** `C2` 读数」这类**不是**误读禁令（无引号断言，夹具 `-MIS-7` 钉住） |
| **引号断言** | `「…」『…』“…”`（各 ≤60 字） | 实况里被禁断言几乎都带引号；**不带引号的读法禁令**本普查**抓不到**（见 §8 证据边界） |
| **排除** | 带**任何**全称量词的行 | 与 `P133-10` 划分工，且使两族**可相加**而非取并集 |

### §1-3 ★★ 两种真实语序都必须收（这是本普查**实测**出来的，不是设计出来的）

| 语序 | 例 | 收否 |
|---|---|---|
| ① 动词**紧邻**禁止语 | 「不得外推为「AR(1) 修正的一般形式」」 | ✓ |
| ② **`把/将` ＋ 宾语 ＋ 动词** | 「不得**把** gate 达线**读成**「乘性乘积是唯一解释」」 | ✓ |

★★ **窄框架（只收 ①）会漏 37 条**。这不是估计，是**同一语料、同一词表**上两个正则的差
（实测命令见 §10，读数可逐字节重现）：

| 框架 | 命中 |
|---|---|
| ① 仅动词紧邻 | **108** |
| ①② 并收（本普查采用） | **145** |
| 差 | **+37**（仅由 `把/将` 式贡献，占 25.5%） |

★ 该差**已钉成夹具** `-MIS-11`（窄框架必漏、宽框架必中）—— 否则「分支不可删」只是声称。

中间版本（宾语用 `[^，。；：]{0,26}?` 自由匹配），实测会跨句误配（夹具 `-MIS-10` 即钉这一点）。

## §4 ★★★ 被**实测否掉**的那条路：行级「无可判形式」判据（**负结果**，不是缺陷）

`P133-13` 任务正文提出：入口可能是**结构化**的 —— 「卡片是否**显式写出**该纪律的**可判形式**
（白名单 / 载体 / `②留痕` 标记）」。本 cycle **先做了这个版本，然后实测否掉它**：

| 口径 | 卡片命中 | 可不能用 |
|---|---|---|
| 行级「禁止语 ＋ **无**量词 ＋ **无**符号 ＋ **无** token 列举 ＋ **无**载体 ＋ **无**守卫」 | **611** 行 | ✗ **不能用** |
| 其中是**真·纪律**（而非节标题 / 散文片段） | 见下 | — |

611 行里大量是这类：`## §7 边界（不得外推）`（**节标题**）、
`- 若 A-SHARED-LOWRANK 且 rmin ≤ 32 ⇒ 障碍不在注入接口的表达力，而是样本数`（**散文**，
「不能」出现在别处）、`须另起方向，不得再在 Wq 上加臂`（**可判**，但无「可判形式」字样）。

★ 为何**不**记作缺陷（`DEF-`）：缺陷 = 已落进代码/归档的错误。这条路**在落地前**就被否掉，
**从未进入** `check_cards.py` ⇒ 它是**负结果**，记在普查文档即可。若日后有人重新采用它，
则那一轮的**实测数字 611 : 145** 就是现成的反证。

⇒ ★★★ **结论（机制，不是口味）**：**「可判」是「条款在其小节内」的属性，不是单行的属性。**
同一行在节标题下是噪音，在「§7 边界」段内是纪律。任何**行级**代理都会被节标题与散文淹没
（611 : 145 ≈ 4.2 : 1）⇒ **行级代理不可用**，本探针只走**句法框架**这一路，且**不**输出可判性判决。

★ 这条否掉是有价值的**负结果**：它把「结构化入口」从「看起来最自然」降级为
「**只在清单 locus 成立**」（因为清单有 `执行方式` 字段，卡片没有）。

## §8 证据边界（**不得外推**）

1. ★ **不带引号的读法禁令本普查抓不到**。例如若某卡写「不得把玩具规模读成真实 LLM」（无引号），
   本探针**不命中**。⇒ **145 是下界**，与 `P133-10` 的「28% 是下界」同一性质。
2. ★★ **本普查不判「可判性」**。§3 的三项线索是**线索**；98 条「三项皆无」**不等于**「已判欠定义」。
   ★★★ 但 §6 的 116 条在 `P133-10` §1-4 的口径下**按定义**属 `U4`（禁止集 = 推论方式的开放集）
   ⇒ 那一步是**沿用既有口径**，不是本轮新判。
3. ★ **`QUANT_TOKENS` 不含「任意」**（`P133-10` 的表如此）。实测 `DIR-122` 的
   「不得说「对**任意**题目都稳健」」里「任意」在**引号内**，是**被禁断言的一部分**，
   不是对读者的量词 —— 故不收它是**对的**。★ 但若正文写「**任意**卡都不得…」，本普查会漏。
   ⇒ **只记录，不改 `P133-10` 的词表**（改它会动 `--probe-semantic-discipline` 的全部历史读数）。
4. ★ **行级 vs 条款级**：本普查以**行**为单元，同一「条款」若跨行书写会被计成 0 或 2 条。
   实测去重后 116/145 ⇒ 跨卡重复是真实存在的，**不得**用 145 当「不同禁令的个数」。
5. ★ 本普查**未**覆盖 `revolve/*.md` 的其它审计文档（`P107-0`/`P118-*`/`P133-8`/`P134-2`/`P134-3` 等）
   与 `decisions/DECISIONS.md`。它们也含大量「不得把 X 读成 Y」式表述 ⇒ **总体未定义**，只扫了三处。
