## §1 MVP 标准（**先冻结，后动手**）

### §1.0 主假说与证伪条款（冻结）

- **H（主假说）**：在写侧已被 DIR-38 修好（**`n_rep=16`**，见 D-62）之后，
  **层 1 的读控制器若由任务梯度训练**（`(Wq1,bq1)` 共享、任务损失驱动），
  就能比**同一初值但冻结**的随机控制器**更有效地使用已形成的关联** ⇒ **前向任务损失下降**。
- **本卡要避开的坑（Advisor 复核）**：装置现有的 `addr="device"` **同时改两样**
  （层 1 的 `c` 从 `h` 变成**输入**、`q` 从 `Pk` 变成 `Wq,bq`），而损失里的 `m` **直接吃 `c`**
  ⇒ ⇒ **不是单一寻址变量** ⇒ 本卡把 `c` **固定为 oracle 的 `h`**（四档**逐字相同**）⇒ **只换 `q`**。
- **证伪条款（冻结）**：判据档上若出现下列任一情形 ⇒ **H 未被确认，本轮不计入 `SUCCEEDED`**：
  1. **发散**：任一档读数非有限（NaN/Inf）⇒ 该档整档作废（种子与填表**全部留档**，不删不改、不补跑）；
  2. **方向相反且显著**：配对 `mean(L_rand − L_learned) ≤ −3·se`
     ⇒ 记「**训练读控制器在本玩具里反而更差**」（**强负结果**，机制必须查清：见 §2.2）；
  3. **显著性不过**：配对 `mean(L_rand − L_learned) < 3·se` ⇒ 不计数；
  4. **效应量不足**：显著但 `mean(L_rand − L_learned) < 0.20·R`（`R = mean L_rand − mean L_oracle`）⇒ 不计数；
  5. **通用注入而非内容性**：`mean(L_learned_rc − L_learned) < 3·se`
     ⇒ 该收益是**通用注入**而非内容性收益 ⇒ **不计数**（用户规则：二者不得混报）。
- ★ **不可判定**：若 `R ≤ 0` ⇒ 「oracle 是上限」的前提不成立 ⇒ 记「**不可判定**」（**不是失败**），本轮不计数。
- ★ **不搬** DIR-38 的 `CL ≥ 0.50` 与 `Δ_min = 0.25Z`（那是**别的统计量**的阈值，本轮**不用**）。

### §1.1 测量对象（冻结）

- **唯一自变量 = 层 1 的查询来源 `q`**（四档；**`c` 四档逐字相同 = `h`**）：

| 档 | `q` | `(Wq1,bq1)` | 记忆内容 | 角色 |
|---|---|---|---|---|
| `oracle` | `tanh(h · P_k1)`（**逐字** = 现行装置的层 1 读） | 不参与 | 真 | **描述性上限**（不判据） |
| `rand` | `tanh(h · Wq1 + bq1)` | **冻结**的共享随机初值 | 真 | **对照** |
| `learned` | `tanh(h · Wq1 + bq1)` | **被任务梯度训过**（同一初值） | 真 | **处理** |
| `learned_rc` | 同 `learned` | 同 `learned` | **随机置换**（`R.read_W(...,"S",sd)`，范数不变） | **通用注入对照** |

- **头只有一份**（`g1,Wo1,bo1`），在 **`oracle` 档**上训练（`n_train=192`，250 步 / Adam / lr 0.03 / init 4242），
  **四档共用** ⇒ ⇒ 档间**唯一的差别是读控制器**（`rand` vs `learned`）。
  ★ 读控制器 `(Wq1,bq1)` 的训练**头冻结**（`g1,Wo1,bo1` 不动）⇒ 与 `rand` 档的唯一差别是「**训不训**」。
- **写侧逐字冻结在 DIR-38 的 `n_rep=16`**（同一步内重复装置自己的同步因子更新 16 次；`η,α,λ,γ`、键尺度、`T=16` 全不变）。
- **判据档**：训练段 **192** 个实例（`16000..16191`）、评估段 **400** 个实例（`15500..15899`）
  （与训练段、与全部历史段、与 DIR-38/39 的探针段**全部不相交**）。
- **主读数**：各档 `mean L`、**逐实例** `L` 序列、机制读数（§2.2）、`max‖W‖`、发散标志。

### §1.2 手算工作例（冻结；Stage A 必须复现）

1. `n_rep=1` + `oracle` 读 ⇒ 必须与 DIR-37 的装置臂**逐位相同**（`L` 相对差 `0.000e+00`）。
2. `n_rep=16` + `oracle` 读 ⇒ 必须与 DIR-38 的 `n_rep=16` 臂**逐位相同**（跨实现交叉锚：`L` 与 `max‖W‖`）。
3. 层的 1 的 `c` 在四档里都必须是 `h`（**结构性单变量断言**，非数值断言）。
4. `rand` 档的 `(Wq1,bq1)` 训练后必须**逐位等于初值**（冻结）；`learned` 档必须**逐位不等于初值**（训动）。

### §1.3 冻结的数值阈值

| 量 | 阈值（冻结） |
|---|---|
| 显著性（配对逐实例差 `L_rand − L_learned`） | **`mean ≥ 3·se`** |
| 效应量（相对可寻址区间） | **`mean(L_rand − L_learned) ≥ 0.20 · R`**，`R = mean L_rand − mean L_oracle` |
| 内容性（配对 `L_learned_rc − L_learned`） | **`mean ≥ 3·se`**（否则 ⇒ 通用注入 ⇒ 不计数） |
| 可寻址区间 `R` | `≤ 0` ⇒ **不可判定**（不记失败） |
| 发散判据 | 任一档读数非有限 ⇒ 该档整档作废 |
| 判据档规模 | `n_train=192`，评估 **400** 实例，`n_rep=16` |
| 头 | **一份**（`oracle` 档上训），250 步 / Adam / lr 0.03 / init 4242（协议逐字沿用 DIR-37） |
| 读控制器训练 | `(Wq1,bq1)`，**头冻结**，250 步 / Adam / lr 0.03 / init 4242（与 `R.train_arm(learned=True)` 逐字同） |
| ★ **阈值取 `0.20·R` 的理由** | 探针给出的**功效参考**：`n=400` 时 `3se ≈ R 的 16.1%` ⇒ 设计能检出 ≥16% 的区间效应 ⇒ 阈取 **20%**（略高于检测限 ⇒ **非空判据**），且**标度无关**（`R` 在判据档上实测）⇒ 探针的绝对值不必搬到正式轮 |
| ★ **不搬** `CL ≥ 0.50`、`Δ_min = 0.25Z` | 那是**别的统计量**的阈值，本轮**不用** |

## §7 已知偏置与边界（**冻结**）

1. ★ **本玩具的每实例 `P_k1` 独立随机** ⇒ **共享**读控制器天然吃亏（它无法命中 per-instance 的键）
   ⇒ 若 H 被否证，**不得**写成「读取侧不可行」或「共享读取头不可行」（DIR-34 已有的同类告诫），
   只能写成「**在本玩具的 per-instance 随机键映射下，共享读控制器无法利用已形成的关联**」。
2. **玩具规模**；**不得**外推为「记忆改善 LLM」；**不得**把任何比例当架构比例。
3. **头只有一份且在 `oracle` 档上训** ⇒ `rand`/`learned` 档面对的是一个「期待 oracle 读」的头
   ⇒ 两档之间的**比较**是干净的（唯一差别是控制器），但**绝对值**不代表「该读源下的最优系统」。
4. `learned_rc` 用的是**随机置换内容**（范数不变）⇒ 它测的是「**该控制器在内容被破坏后还剩多少**」
   ⇒ **不能**替代 DIR-32/34 的 `N/S/T` 三臂分解。
5. **周期 2 ＋ 损失只读最近一对** ⇒ 本卡同样**测不出多对关联记忆**（D-62-CORR）。
6. **探针档读数**（`L` 的绝对值、每档自训的头）**只是探针档** ⇒ **不是**判据读数。
7. **构造事实**（周期 2 ⇒ 查询逐位等于键 ⇒ `oracle` 档的对齐≈1.1）**不得**写成实测机制。
