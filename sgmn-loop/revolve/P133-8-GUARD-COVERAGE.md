## §1 缺陷的**机制**：见证集与被测判据同源 ⇒ 自证循环

`dir130/precheck130.py` 的 `T13`（自测）原文：

```python
def t13():
    # ★ S9 检测器非空转：干净串 → []，四个禁用词逐个 → 命中
    clean = "Stage A 全过; 结构事实; 工作例 frac=0.0"
    hits = {w: _s9_detect("x" + w + "y") for w in S9_FORBIDDEN}
    ok = (_s9_detect(clean) == [] and all(len(v) == 1 and v[0] == w for w, v in hits.items()))
```

★ **见证字符串直接由 `S9_FORBIDDEN` 拼出** ⇒ 见证集与被测判据**同源**。
`T13` 证明的命题是「对禁用词表里的每个词，检测器都能命中」= **检测器非空转**；
它**没有**、也**不可能**证明「§6 的被禁集被守住」——
因为被禁集（§6 的语义）比词表**大**，而词表是从**自己**出的题。

⇒ **「守卫存在 + 自测全过」这个组合，在结构上不携带任何覆盖信息。**
这正是 `P130-4`（纪律写在卡里不会自己生效）的**第二层**：
`P130-4` 要的是「纪律 ⇒ 有守卫」；本条要的是「守卫 ⇒ **覆盖纪律**」，
而后者的失效方式**不是缺守卫**，是**守卫与见证同源**。

**机械检出**（探针 §④，`_circular_witness`）：在自测函数里找**以禁用词表为迭代源**的
`for` / 推导式 ⇒ 实测命中 `('t13', 'comprehension')`。

## §2 为什么「把词表补长」**不可能**够：被禁集是**语义**定义的

§6 的纪律原文（`revolve/DIR-130/DIRECTION_rev130_v12.md:185`）：

> **不得**打印属于判据的**聚合读数**（`p₃₅₀`/`p₃₀₀` 及其任一中间聚合）。

被禁集由**聚合层级**定义（跨结构 vs 单结构），而文本只能表达**形式**。三处硬证据：

### 2.1 允许集与禁止集在 **token 层面重叠**

| 出现在**合法** precheck 输出里 | 出现在**被禁**形式里 |
|---|---|
| `frac = 0.0`（工作例 §6 **明许**打印的单结构 `frac`） | `k=3: frac==0 的 C 有 84 个`（跨结构计数） |
| `T13` 的"干净串"本身就含 `frac=0.0` | 被禁形式 #6 含 `frac==0` |

★ 同一个 token（`frac`）在合法集与禁止集里**都出现** ⇒ **任何按 token 划界的判据都不可能正确**。
（这不是 `S9` 写坏了：`frac` **本来就不该**被禁——§6 明许"单一结构的可算性"。）

### 2.2 数值碰撞：按**数值**匹配会对合法输出**误伤**

被禁形式 #6 的数值是 **84**；而**合法**的 `T6` 见证串是
`C(9,k) = 9,36,84,126,126,84,36,9,1`（源码 `precheck130.py:116`）——**里面有 2 个 84**
（`C(9,3)=C(9,6)=84`）。整份 precheck 输出里 `"84"` 共出现 **4** 次。

⇒ 任何「按数值识别聚合读数」的检测器 ⇒ 对合法输出**误伤** ⇒ **不 sound**。
⇒ 于是只剩两条路：**枚举全部形式**（做不到：形式无穷）或**让被禁量进不了文本**。

### 2.3 于是只剩一种 sound 的判据：**判「量」，不判「写法」**

★ 这就是本轮方案的核心转向：不是「更好的黑名单」，而是**换判据**——
把被禁量**带上身份**（类型 / 来源标记），使「打印被禁量」这个动作在 precheck 阶段**成为不可能**。
演示见 §5 的 ⑤：6/6 全拦，且对空格、措辞、只留数字**全都形式无关**；
合法的 `C(9,k) = …` 与 `frac = 0.0` 照常渲染（零误伤）。

## §4 ★★ 更重的一条：**已归档的 precheck 输出已经判掉了一个判决分支**

### 4.1 打印的是什么

`dir130/out/precheck130.log`（**已归档、随包发布**）里两行：


`S5` 的代码（`precheck130.py:323-341`）对**两个剂量合并**的全部 15330 行计数：
`n_none` = `frac is None` 的行数，`n_zero` = `frac == 0.0` 的行数。

### 4.2 这两个数就是判据量的**池化原料**（逐位对账）

`mech130.py` 的 `p_flip(rows)`：`comp` = `frac is not None` 的行数、`pos` = `frac > 0` 的行数、
`p = pos/comp`；而 `n_zero = comp - pos`。

|---|---|---|---|---|

| `n_uncomp` | **225** | **45** | **270** | `None=270` ✅ **逐位相同** |

⇒ **precheck 印的三个数（`11092`/`270`/`7665`）就是 `p₃₅₀`、`p₃₀₀` 的全部原料。**

### 4.3 由 precheck 单独可推出的**紧界**

只用 precheck 印的三个数 + 行划分约束（`n_zero(d) + n_none(d) ≤ 7665`）：

```
p(剂量) ∈ [0, 0.536579]
```
（自检：formal 真值 `p₃₅₀=0.000000`、`p₃₀₀=0.520735` **落在界内** ✅）

### 4.4 后果

`decide(c0_ok, p350, p300)` 的分支是：
`c2 ⟺ p₃₅₀ ≤ 0.05`、`c3 ⟺ p₃₀₀ ≥ 0.95`；

★ 由 `p₃₀₀ ≤ 0.536579 < 0.95` ⇒ **`c3` 必不成立** ⇒
**`c2∧c3` 与 `¬c2∧c3` 两支在 precheck 阶段就已被排除**（5 支只剩 3 支）。
真判决 `C130-FRAC-FRAGILE-POSITIVE`（= `c2∧¬c3`）与之相容。

## §6 `DIR-130` 改造示范（**只写方案，不改冻结文件**）

### 6.0 先决条件（§4 的直接推论，**这一步不能跳**）

★ **纪律必须先冻结一个**可枚举的禁止集定义**，否则守卫无从验收、也无从判定"够不够"。
`DIR-130` 现在的散文括注（「`p₃₅₀`/`p₃₀₀` 及其任一中间聚合」）**不够**：
它没有说清"跨剂量合并的计数"算不算 ⇒ §4.1 那行 `零=11092` **无法判定**。
⇒ 建议在 `v1.3` 里把禁止集写成**三条可枚举的规则**，例如：
① 任何 **per-dose 聚合量**（`p` 及其 `n_pos`/`n_comp`/`n_uncomp`/`comp_frac`）；
② 任何 **per-dose 的分子/分母计数**（含逐 `k` 的）；
③ 任何**可由以上两项（或其池化/部分和）导出判据分支结论**的量
（★ 这一条正是 §4.4 的泄漏面：池化计数能**界住** `p`，从而判掉分支）。
★ 这一条是**新增的**，不是收窄 —— 它把 §4 的漏洞显式纳入。

### 6.1 方案 A：**源头脱敏**（改动最小）

`mech130.py::p_flip(rows, redact=False)`：当 `redact=True` 时，返回体的
`p`/`n_pos`/`n_comp`/`n_uncomp`/`comp_frac` 全部置 `None`/占位；
`precheck130.py` 的 Stage A 与工作例路径在 precheck 模式下传 `redact=True`。
⇒ 聚合量在 precheck 阶段**不存在于内存** ⇒ 不可能被打印 ⇒ **形式无关、sound**。

★ **真实成本（不假装免费）**：`precheck130.py` 的自测 `T1`/`T2`/`T12`（用 `M.p_flip`）
与 `T9`（用 `M.per_k`）**会拿到脱敏值** ⇒ 必须显式区分「**合成夹具**」与「**真实读数**」
（真实读数走 `_sweeps()`，夹具走 `fx_mixed()`/`fx_all_none()`/`[_r(0.0),…]`）
⇒ 需要一个**来源标记**（或把脱敏开关只开在"真实读数"那几条路径上）。
★ `T1` 现在打印 `p=0.6666666666666666`、`T12` 打印 `p=0.3333333333333333`
—— 若按最严口径，这些**合成** `p` 也应改为**只报布尔**（照 `DIR-127`/`DIR-128` 的范式）。

### 6.2 方案 B：**带身份载体**（判据形态从「文本」换成「来源」）

给判据量套一个 `Agg(float)` 子类：携带 `tag`（`p350`/`n_pos`/…），
`__format__`/`__str__`/`__repr__` 在 precheck 模式**抛异常** ⇒
任何 f-string 插值判据量都**立刻失败**（而不是"事后被扫出来"）。
⇒ **形式无关**（空格/无空格/换措辞/只留数字，全都拦），**且合法值零误伤**（`84`、`frac = 0.0` 照常渲染）。
★ 探针 §⑤ 已用 `Agg` 的等价载体**实测** 6/6 拦截 + 合法输出零误伤（`check_cards.py --probe-guard-coverage`）。

### 6.3 方案比选

| | 方案 A 源头脱敏 | 方案 B 带身份载体 |
|---|---|---|
| 改动面 | `mech130.py` + `precheck130.py` | `mech130.py` + `precheck130.py`（同量级） |

| 与库内既有范式的关系 | 新 | **对齐 `DIR-127`/`DIR-128` 的"只报布尔"** |

⇒ ★ **推荐 B（带身份载体）**：它与库里已有的正确范式**同构**（判据量不带身份 ⇒ 只能靠"不插值"这条人工约定；
带身份 ⇒ **约定由类型强制**，不再依赖写代码的人记得不插值）。

### 6.4 方案的**验收标准**（未来落地时必须全过）

① 6 条被禁形式**全部**被拒，且**形式无关**（同一语义的任意书写）；

## §7 通用规则 ⇒ `K25`

本轮结论的可推广形式（写入 `sgmn-loop/CARD-CHECKLIST.md` 的 **`K25`**）：

> 凡某条纪律声明「已被 `S\d+` 守住」，则
> ① 若该纪律的**禁止集按语义/层级定义**（含全称量词、聚合层级、来源），
>    守卫必须**判「量」而非判「写法」**（带身份载体 / 源头脱敏 / 只报布尔）——
>    **字面词表只适用于按字面定义的禁止集**；
> ② 守卫的**自测见证集必须独立于被测判据生成** ——
>    由被测词表反推的见证**只证明「检测器非空转」，不证明「纪律被守住」**；
> ③ 卡片必须留下**覆盖声明**：被禁集如何枚举（或为何枚举不完）、
>    见证集覆盖的是纪律的哪个**子集**。
