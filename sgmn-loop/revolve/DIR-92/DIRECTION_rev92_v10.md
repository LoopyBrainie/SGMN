## §1 主假说与证伪（**冻结**）

**H92**：`§3.1`/`§2.3` 在装置里的**块均值取值算子**（`v = sg(h P_v).mean(0)`，64 位平均）是「内容性收益 = 0」的**绑定约束**。

即：把取值算子换成**可学习的位置选择性掩码**（`v = Σ_t g_t · sg(h_t P_v)`，$g\in\mathbb{R}^{64}$ 由**任务损失**训练，初始化 $g\equiv 1/64$）后，在**同一端到端 KVR 任务**上会出现
$$\Delta_{\rm content}^{(\text{select})}\;=\;\mathrm{acc}(\text{MEM})-\mathrm{acc}(\text{INJ})\;>\;0,$$
而同期 `mean` 算子下 $\Delta_{\rm content}^{(\text{mean})}\approx0$（复现 `D-108`）。

### 证伪条款（**冻结，不改**）

| # | 情形 | 判决 |
|---|---|---|
| **F1** | $\Delta_{\rm content}^{(\text{select})}$ 的 $95\%$ CI **跨 0**，或**跨 3 种子变号** | **`FALSIFIED`** ⇒ 块均值**不是**绑定约束，瓶颈在别处（读取侧 / 注入接口） |
| **F2** | 掩码**退化**（$\lVert g-1/64\rVert_\infty < 0.01$，即算子实际未被改变） | **`MASK-DEGENERATE`**（**第三态**）⇒ 装置缺陷，**不得**判 `FALSIFIED` |
| **F3** | `MEM` 与 `INJ` 在 `select` 算子下**同贴地板**（两者 `acc_held` 均 $\le$ 机会 $0.25$） | **`INCONCLUSIVE-ARM-INVALID`**（**第三态**，`D-108` 的原判决）⇒ **不得**判 `FALSIFIED`、**不得**判"内容无用" |
| **F4** | `CEIL` 臂未达 §2 门限 | 本轮**不得开跑**（任务本身不可答） |
| **F5** | 功效不足（§2 门限未满足） | **`INCONCLUSIVE-POWER`**，**不得**判 `FALSIFIED` |

★ **F2/F3/F5 是三个"第三态"**：Round standard 明文「判据从未被计算 ≠ 判据被计算且 FAILED」。**零结果只有在对照臂有效时才有信息量** —— 这正是 `D-108` 踩过的坑。

## §2 MVP 标准（**这就是"最小可判定产物"**）

**一个 $2\times2$ × 3 种子的正对照实验**（+ 一个地板臂），任务**可判对错**、**答案只能来自写入内容**、**键不可先验获知**。

### 2.1 因子设计（**只有这两处可变**）

| 因子 | 水平 |
|---|---|
| **A. 取值算子** | `mean`（`D-108` 原样：$v=\frac1{64}\sum_t z_t$，$k$ 同） · `select`（$k,v$ 各一个**可学习** $g\in\mathbb{R}^{64}$，$g_0\equiv1/64$） |
| **B. 写入内容** | `INJ`（`no_write=True`：$W\equiv W_0$，但 $\gamma{=}0.05$ 的**注入通路存在**） · `MEM`（写入打开） |

⇒ **5 个臂**：

| 臂 | 算子 | $\gamma$ | 写 | 读侧训练 | 语义 |
|---|---|---|---|---|---|
| **BASE** | `mean` | 0 | 关 | **无**（$\gamma{=}0$ ⇒ $\partial L/\partial W_q\equiv0$，`A90-4` 精确断言） | 冻结基座 = 地板 |
| **INJ-mean** | `mean` | 0.05 | **关** | 有 | 复现 `D-108` 的 INJ（$0.021$） |
| **MEM-mean** | `mean` | 0.05 | 开 | 有 | 复现 `D-108` 的 MEM（$0.021$） |
| **INJ-sel** | `select` | 0.05 | **关** | 有（**含 $g$**） | 有注入、无内容、**新算子** |
| **MEM-sel** | `select` | 0.05 | 开 | 有（**含 $g$**） | 有注入、有内容、**新算子** |

- **主判据**：$\Delta_{\rm content}^{(\text{select})}=\mathrm{acc}_{\text{MEM-sel}}-\mathrm{acc}_{\text{INJ-sel}}$
- **对照读数（必须并列报告，不得混报）**：$\Delta_{\rm content}^{(\text{mean})}=\mathrm{acc}_{\text{MEM-mean}}-\mathrm{acc}_{\text{INJ-mean}}$（预期 $\approx0$）· $\Delta_{\rm inj}=\mathrm{acc}_{\text{INJ-sel}}-\mathrm{acc}_{\text{BASE}}$
- **★ 为何 $2\times2$ 而不是只做 `select`**：若只做 `select` 且 $\Delta>0$，无法排除"任何新算子都会带来增益"（参数多了 $2\times64\times3$ 个）。**$2\times2$ 把"算子"与"内容"分开**，`MEM-mean` 是**同算子的无内容对照**的基线复现。

### 2.2 任务（`KVR`，逐字继承 `D-108@DIR-90`）

- **键**：随机 nonce（5 字符，字母表 `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`）—— **基座不可能先验知道**。
- **值**：单 token 常用短词（颜色/动物）—— `A90-7` 已核无 tokenization 歧义。
- **事实句**：`The access code for item {KEY} is {VAL}.` · **问题**：`The access code for item {KEY} is`
- **判分**：**候选打分**（1 正确 + 3 干扰，取 NLL 最小）⇒ **机会 $0.25$**。
- **切分**：读侧在 **keys 1–16** 训练，**评测只用 keys 17–32**（`A90-8`）。
- **块**：$B{=}600$ 块 × `CHUNK=64`，run-based（每事实 18–19 连续块），句**重复铺满**块（`build_chunks` 原样）。
- **★ 新增装置约束（本卡唯一新增的装置控制，见 §2.3）**：32 条事实的**事实句 token 长度必须完全相同**。

### 2.3 `select` 算子的定义与**可学习性**

$$v_i=\sum_{t=0}^{\text{CHUNK}-1} g^{(v)}_{l,t}\,\mathrm{sg}\!\left(h_{l,t}P_{v,l}\right),\qquad
k_i=\sum_{t=0}^{\text{CHUNK}-1} g^{(k)}_{l,t}\,\mathrm{sg}\!\left(h_{l,t-1}P_{k,l}\right)$$

- $g^{(v)}_{l},g^{(k)}_{l}\in\mathbb{R}^{64}$，**逐层**各一，**跨事实共享**（不是 per-fact），softmax 参数化保证 $\sum_t g_t=1$。
- **初始化 $g\equiv1/64$** ⇒ $\sum_t g_t z_t=\frac1{64}\sum_t z_t$ **恰等于块均值** ⇒ **`select` 在 $g_0$ 上与 `mean` 逐位等价**（浮点求和顺序差异除外，`A92-2` 断言 $\le10^{-6}$）。
- **梯度可达**：$\mathrm{sg}(\cdot)$ 只截断到上游隐状态/投影参数，$g$ **不在** $\mathrm{sg}$ 内 ⇒ 任务损失可训练 $g$。这是"**测试时可得**"的关键：$g$ 是**参数**，不是标签（`D-106@DIR-91` 边界⑤ 明确禁止用测试时不可得的位置标签）。
- **为何 $g$ 能对齐**：事实句在块内**周期性重复**，若 32 条事实的句长**相同**（§2.2 新增约束）⇒ 键位与值位在 64 个位置上的**偏移对所有事实一致** ⇒ **单个 $g$ 可同时覆盖全部事实**。若句长不等，$g$ 不可能同时选中所有值位 ⇒ 本卡必须先满足该约束，否则 `select` 臂**无法被公平检验**。

### 2.4 门限（**冻结，开跑后不得改**）

| 量 | 通过条件 |
|---|---|
| **CEIL**（Stage A） | 事实**置于 prompt 内**时 acc $\ge 0.75$（4 选 1，机会 0.25）⇒ 任务可答、打分正确（`D-108` 实测 $1.000$） |
| **FLOOR**（Stage A） | `BASE` acc $\le 0.40$（不得先验知道 nonce 关联） |
| **$\Delta_{\rm content}^{(\text{select})}$（主判据）** | $\ge \mathbf{0.25}$（= 16 题中 4 题）**且** 3 种子**同号** **且** 合并**精确二项检验** $p<0.05$ |
| **$\Delta_{\rm content}^{(\text{mean})}$** | **只报告**（预期 $\approx0$，复现 `D-108`）；不设通过门限 |
| **$\Delta_{\rm inj}$** | **只报告**（`D-108` 实测 $-0.104$ 于 `mean`）；不预设方向 |
| **掩码非退化**（`F2`） | $\lVert g-1/64\rVert_\infty \ge 0.01$ **且** $g$ 的**集中度** $\max_t g_t \ge 0.05$（均匀为 $0.0156$） |
| **键可分性诊断** | 32 事实两两 $\lvert\cos\rvert$ **中位数**，`mean` vs `select` 并列报告；**不设门限**（`D-108` 基线 $0.995$） |
| **S92 存储诊断** | `MEM` 下 $\mathrm{rel.err}(Wk_i,v_i)\le 0.5$（相对 `no_write` 至少 $2\times$）⇒ 内容**存进去了** |
| **功效** | 若真实效应为 $0.25\to0.55$（$+0.30$），$n{=}16$ 双侧 $\alpha{=}0.05$ 下功效 $\ge0.80$ |

★ **阈值 $\ge0.25$ 的依据**（不是随手取）：① 机会 $0.25$ ⇒ $0.25$ 是**整整一个机会宽度**，远超种子噪声（`D-14` ④ 的教训是把 $0.0002$ 当效应）；② `D-108` 实测两臂 $0.021$，若 `select` 真能读出身份，`POOLING` 的 `LOO-10=1.000` 提示**上限接近满**，$0.25$ 是**保守**的中间门限；③ 16 题上 $0.25=4$ 题，二项检验可分辨。

## §3 测量对象 + **一个具体工作例**（Round standard 1c）

**测量对象**（**逐字继承 `D-108`**）：
$$\mathrm{acc}=\frac{1}{|Q|}\sum_{q\in Q}\mathbb{1}\Big[\arg\min_{c\in C_q}\mathrm{NLL}(c\mid q)=\text{answer}(q)\Big]$$

**工作例**（必须被 `A92-9` 用**双桩**逐字复现）：

| 题 | 候选 | 假设的 $-\log p(c\mid q)$ | 预测 | 正确 |
|---|---|---|---|---|
| $q_1$：`…item QX7F2 is` | `teal`, `otter` | 0.5, 2.0 | `teal` | ✅ |
| $q_2$：`…item BM4K9 is` | `crimson`, `heron` | 1.8, 0.7 | `heron` | ❌（正确 `crimson`） |

⇒ 手算 $\mathrm{acc}=1/2=0.5$（**按题计**）。`A92-9` 用**桩打分器**驱动**同一个** `score_and_accuracy()`，须得 $0.5$、预测序列 `[teal, heron]`；
**并且**喂一份把 $q_2$ 两候选 NLL **互换**的桩，须得 $1.0$ —— **若两次都得 $0.5$，则打分/取最小环节无分辨力，守卫作废**（`DEF-88-1` 教训：守卫必须能失败）。

## §7 边界（**开跑前写定，结论不得越界**）

1. **不得**外推为「SGMN 无内容性记忆能力」：只测 rank-8 × 3 层 × 32 事实 × `CHUNK=64` × 单基座（Qwen2.5-0.5B-Instruct）这一配置。
2. **不得**把 $\Delta_{\rm content}$ 与 `D-16` 的 NLL 收益（$-0.244$ nats/token）相加或比较 —— **量纲与任务都不同**。
