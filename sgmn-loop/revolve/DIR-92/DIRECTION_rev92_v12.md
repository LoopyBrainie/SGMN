# DIRECTION · DIR-92 · rev 1.2（**算子分支第二次修订**；判据、阈值、证伪条款**仍一字未改**）

**修订依据（可行性实测，非猜测）**：rev 1.1 的「**模板固定位置掩码**」要求 32 条事实句的 token 长度与键/值偏移**全相同**。
在 `trainer` 上**实测**（`dir92_feas.py`，Qwen2.5-0.5B-Instruct 分词器，`D-108` 的原键/句模板）：

| 量 | 实测 |
|---|---|
| nonce 键的 token 数 | `{4:13, 3:9, 5:9, 2:1}`（**2–5 不等**） |
| 值（我的 32 词表）的 token 数 | `{1:12, 2:20}`（**1–2 不等**） |
| 事实句 token 数 | `{12:11, 13:11, 11:3, 14:6, 10:1}`（**10–14 不等**） |
| 句长=12 的子集内，键位偏移 | **8 / 8 / 7 不等** |
| 句长恰为 12 的事实数 | **11/32** |

⇒ **单一全局位置掩码不可能覆盖 32 条事实**（除非重建事实集，而重建会破坏与 `D-108` 的可比性 ⇒ 违反 round standard「只有测量层与独立变量可变」）。
⇒ rev 1.1 的 §2.3′ **在开跑前被判不可行**，`DEF-92R-02`，留档。**rev 1.1 正文一字未改。**

## §2.3″（**替换 rev 1.1 §2.3′**）：`select` 算子 = **max-pool**（位置无关）

$$\boxed{k_i=\Big(\max_{t} z^{(k)}_{t}\Big)\cdot\text{pk\_scale},\qquad v_i=\max_{t} z^{(v)}_{t}}$$

其中 $z^{(k)}_t=\mathrm{sg}(h_{l,t-1}P_{k,l})$、$z^{(v)}_t=\mathrm{sg}(h_{l,t}P_{v,l})$，$\max$ 为**逐分量**取最大（`torch.amax(dim=0)`）。

**为什么选 max-pool**（三条，均有出处）：
1. **`D-106@DIR-91` 的「派生（下一问）」原文列明**：「把 $v$ 由块均值换成位置选择性取值（如：以查询键注意力加权，或 **max-pool**，或"值位掩码"的可学习代理）」⇒ **非自造**。
2. **位置无关** ⇒ 不需要句长均匀（rev 1.1 的死因），不需要任何位置标签 ⇒ **完全避开** `D-106@DIR-91` 边界⑤ 的"测试时不可得标签"陷阱。
3. **对称函数但保极值**：均值是"只保留位置**分布**内容、丢弃位置**局限**内容"的算子（`D-106@DIR-91` 的机理栏原文）；max-pool 保留**单点极值**内容 ⇒ 正是对"值身份只出现在少数位置"这一诊断的**对症**替换。

**它同时针对两条已诊断失效**：
- **值身份被平均掉**（`vt_pos` 的 `LOO-10=1.000` vs `mean_all` 的 `0.10–0.20`）⇒ max 保留值位的极值。
- **键不可分**（`D-108`：键 $\lvert\cos\rvert$ 恒 $0.995$，因块均值把 32 个不同 nonce 抹平）⇒ max-pool 后 $k_i$ 由**该事实自己的极值 token** 决定 ⇒ 键可分性诊断量（§2.4′）会直接看到是否改善。

### ★ 与 rev 1.0/1.1 的实质简化
| 项 | rev 1.0/1.1 | rev 1.2 |
|---|---|---|
| 新增参数 | $2\times64\times3$ 个（$g$） | **0 个** |
| 是否需要 $g$ 可训练 | 需要（**已证不可行**） | **不需要** |
| 是否需要位置标签 | 1.1 需要（**已证不可行**） | **不需要** |
| 代码改动 | 较大 | **两行**：`.mean(dim=0)` → `.amax(dim=0)`（`k` 与 `v` 各一处） |

⇒ 改动量**最小**，最符合 round standard 第 2 步「只有测量层与独立变量可变」。

## §2.1″（**臂表更新**：新增一个**内容特异性**对照 `MEM-RAND`）

| 臂 | 算子 | $\gamma$ | 写 | 读侧训练 | 语义 |
|---|---|---|---|---|---|
| **BASE** | `mean` | 0 | 关 | 无（不可训练） | 冻结基座 = 地板 |
| **INJ-mean** | `mean` | 0.05 | 关 | 有 | 复现 `D-108` 的 INJ |
| **MEM-mean** | `mean` | 0.05 | 开 | 有 | 复现 `D-108` 的 MEM |
| **INJ-max** | `maxpool` | 0.05 | 关 | 有 | 有注入、无内容、**新算子** |
| **MEM-max** | `maxpool` | 0.05 | 开 | 有 | **主臂** |
| **MEM-RAND-max** | `maxpool` | 0.05 | 开（**值打乱**：键不变、值错配） | 有 | ★ **内容特异性对照** |

- **主判据**：$\Delta^{(\max)}_{\rm content}=\mathrm{acc}_{\text{MEM-max}}-\mathrm{acc}_{\text{INJ-max}}$
- **对照读数（并列报告，不得混报）**：$\Delta^{(\text{mean})}_{\rm content}$（预期 $\approx0$，复现 `D-108`）· $\Delta_{\rm inj}$ · ★ $\Delta_{\rm spec}=\mathrm{acc}_{\text{MEM-max}}-\mathrm{acc}_{\text{MEM-RAND-max}}$
- **★ `MEM-RAND` 为什么必须加**：`MEM-max` 相对 `INJ-max` 的增益可能只是"$W$ 里有东西"这种**通用**效应，而非"记住了**这条**内容"。`MEM-RAND` 与 `MEM-max` **写同样的键、同样的块、同样的写预算、同样的 $\eta$**，唯一差别是**值被错配** ⇒ $\Delta_{\rm spec}$ 才是**内容特异性**的判据。
  ★ 这比 rev 1.1 的"错位掩码"更强：错位掩码只证明"选对位置重要"，`MEM-RAND` 直接证明"**记住的是对的内容**重要"。

## §2.4″（判据量：新增 $\Delta_{\rm spec}$ 为**并列主判据**）

| 量 | 门限 |
|---|---|
| $\Delta^{(\max)}_{\rm content}$ | $\ge\mathbf{0.25}$ 且 3 种子同号且合并精确二项 $p<0.05$（**沿用 rev 1.0 §2.4**） |
| ★ $\Delta_{\rm spec}$ | **只报告**（本卡首次引入，无历史标定 ⇒ 不得设未标定的门限；但**必须**与 $\Delta_{\rm content}$ 并列呈现，供下一轮定门限） |
| 键可分性 $\operatorname{med}_{i\ne j}\lvert\cos(k_i,k_j)\rvert$ | 只报告；`mean` 预期 $\approx0.995$ |
| `S92` 存储诊断 | $\mathrm{rel.err}\le0.5$（沿用） |

★ **为什么 $\Delta_{\rm spec}$ 不设门限**：本 loop 从未测过"值错配"对照，设门限等于**凭空定阈值**（`D-108` 的 $\Delta_{\rm inj}$ 门限就是这么错过的：预注册 $\ge-0.10$，实测 $-0.104$）。**首轮只报告、次轮再冻结**是本 loop 的既有做法。

## §7″（边界追加三条）

10. **不得**把 `maxpool` 的结论外推为"任意位置选择性算子都无效"：本卡只测**位置无关的 max-pool**（对称函数）；**基于注意力/掩码的位置选择**因 §2.3′ 的可行性实测未做，仍属未测。
