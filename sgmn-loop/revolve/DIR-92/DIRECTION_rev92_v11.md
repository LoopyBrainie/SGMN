## §2.3′（**替换 rev 1.0 的 §2.3**）：`select` 算子 = **模板固定位置掩码**（不是可学习参数）

### 关键事实：位置是**全局常量**，不是逐项标签

`D-106@DIR-91` 的边界⑤ 禁止把 `vt_pos`（$|V_i|=2$）当作"装置已能检索答案"，理由是它**用了测试时不可得的位置标签**（每个事实自己的值 token 位置）。
**本卡的关键区别**：在**事实句模板固定、且 32 条事实句 token 长度全相同**（`A92-5`）的前提下，键位与值位是 **`CHUNK` 内的一个全局常量偏移** $o_k,o_v$ —— 对**所有**事实**同一个数**，由**模板+分词器**决定，**不依赖任何逐项信息**。

⇒ 固定掩码
$$g^{(k)}_t=\mathbb{1}[t\equiv o_k\ (\!\!\bmod L_s)]/n_k,\qquad g^{(v)}_t=\mathbb{1}[t\equiv o_v\ (\!\!\bmod L_s)]/n_v$$
是**可部署**的算子（$L_s$ = 句长，$n_\bullet$ = 一个句周期内该类位置的个数），**不是** oracle 捷径。
★ **本卡的 `select` 仍会在 §7 边界里被降低外推等级**：它证明的是「**位置选择性算子**能否救内容性收益」，**不是**「装置已能自动发现位置」。

### 算子定义

$$v_i=\sum_{t} g^{(v)}_{t}\,\mathrm{sg}\!\left(h_{l,t}P_{v,l}\right),\qquad
k_i=\Big(\sum_{t} g^{(k)}_{t}\,\mathrm{sg}\!\left(h_{l,t-1}P_{k,l}\right)\Big)\cdot\text{pk\_scale}$$

- 掩码**逐层同一**（三个挂载层用同一 $o_k,o_v$；因为模板相同）。**无新增可训练参数**（这是相对 rev 1.0 的实质简化：不改参数量 ⇒ 排除"参数多了所以变好"）。
- **`mean` 臂 = 掩码全为 $1/\text{CHUNK}$** ⇒ 两臂共享**同一段代码**，唯一差别是掩码常数 ⇒ `A92-2` 可机械断言「掩码取均匀时与 `mean` 逐位等价」。
- **★ 该改动同时修两条已被诊断的失效**（这是它值得做的理由，不是"再试一次"）：
  1. **值身份被平均掉**（`D-106@DIR-91`：`vt_pos` 的 `LOO-10=1.000` vs `mean_all` 的 `0.10–0.20`）⇒ 掩码直接取到值位。
  2. **键不可分**（`D-108@DIR-90`：键 $\lvert\cos\rvert$ 恒 $0.995$）⇒ 块均值把 32 条不同 nonce 的键抹成同一个；取**单点键位**后 $k_i$ 由**该事实自己的 nonce token** 决定 ⇒ 键间余弦应显著下降（§2.4 的诊断量会看到）。

### 为什么**不**做可学习掩码（诚实披露）

在 `D-108`/`D-90` 的**两阶段协议**（先写 600 块，再冻结写入、只训读侧）下，$g$ 拿不到任务梯度（`DEF-92R-01`）。可行的替代有三条，本卡**均不采用**，理由如下（留档备查）：
| 替代 | 为何不用 |
|---|---|
| 单阶段联合写读 | 会**改变协议**，`mean` 臂不再与 `D-108` 可比 ⇒ 失去 $2\times2$ 的对照意义 |
| 用「$v$ 的跨事实可分性」作无监督准则学 $g$ | 准则**不是任务损失**，且与"内容性收益"之间多一层假设 ⇒ 作为**次优先后续**（`task.md` 记），不进本卡主判据 |
| 对 $g$ 做网格/在评测集上挑 | **用评测集选超参 = 泄漏**，直接违反预注册纪律 |

⇒ 本卡用**固定模板掩码**作为"位置选择性算子"的**最强可实现形式**。**这使证伪更决断**：若连最强的位置选择性都无法产生内容性收益，则「块均值是绑定约束」**必假**（H92 否证），瓶颈在更下游。

## §4′（**替换 rev 1.0 的 A92-2 / A92-15 / A92-16 三条**；其余 13 条**逐字沿用**）

| 编号 | 断言 | 为什么必须 |
|---|---|---|
| **A92-2′** | ★★ 掩码取**均匀**（$g\equiv1/\text{CHUNK}$）时，`select` 与 `mean` **逐位等价**（$\lVert\cdot\rVert_\infty\le10^{-6}$，三层两分支） | 证明两臂只差掩码常数 ⇒ 归因有效（`DEF-92-01` 同类事故的机械排除） |
| **A92-5′** | ★ 32 条事实句 token 长度**全相同**；且**键位偏移 $o_k$**、**值位偏移 $o_v$** 在句周期内**唯一**（$n_k=n_v=1$），并对**每条事实逐条核对**（32/32） | 掩码是全局常量的前提；任一条不符则 `select` 不可公平检验 |
| **A92-15′** | ★ **掩码非退化**：`select` 臂的 $g$ 与均匀掩码的 $\lVert\cdot\rVert_\infty$ 距离 $\ge0.01$，**且**被选位置上的 $z_t$ 与块均值的余弦 $\le0.999$（证明选到了不同的东西） | 否则静默等于 `mean`（`DEF-92-01` 的**原症状**） |
| **A92-16′** | ★ **负向对照**：`MEM-sel` 用**错位掩码**（$o_v$ 偏移 $+3$，落在句内无关 token）跑一次，其 acc 与 `MEM-mean` 的差 $\le0.05$ | 证明增益**来自选对位置**，而非"少平均一次"这种通用副作用 |

★ 新增 `A92-15′`/`A92-16′` 的目的：rev 1.0 用"$g$ 被训练"作守卫已不可能；改用**两条更硬的机械断言**——**选的东西确实不同**、**选错位置就没有增益**。若 `A92-16′` 失败（错位掩码也有增益），则"位置选择性"的解释**崩塌**，主判据**不得**按 H92 解释。
