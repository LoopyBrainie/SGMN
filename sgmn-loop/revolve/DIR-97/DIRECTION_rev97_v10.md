## §0 为什么必须先做这一步（动机来自代码，不是猜测）

`sgmn_module.py` 读路径实测（`md5 80e334a5…`）：

| 行 | 事实 | 后果 |
|---|---|---|
| `read()` L77 | `y = sg(W) q` | **`W` 在读路径里被 stop-gradient** ⇒ 任务损失**无法**塑造 `W` |
| `read_params()` L177-180 | 返回 `Wq, Wo, gamma` | 读侧任务损失只更新**读侧**（与 v2.4 §4 一致） |
| `write_params()` L187-188 | 含 `Wfull` | `W` 只由显式局部写规则驱动 |
| `forward()` L161 | `hs_out + gamma * m` | 注入是**逐 token 加性**，`m` 由 `c` 决定 |

`c = sg(h)` 编码 nonce 键（`R2_task91.build_facts` 明写"基座不可能先验知道"）⇒
**`Wq`/`Wo`/`gamma`（≈1.6 M 参数）可以只凭 `c` 记住 16 个训练键，完全绕过 `W`**。
这与 `D-125` 全部读数一致：`W←W⁰` 仍 `0.8750/0.8125`、`acc_held ≡ 0`、内容贡献**精确为零**。

⇒ **未测的关键问题**：`W` 自己到底有没有把这 32 个事实存成**可分辨**的内容？
若 `W` 存的是一张"所有事实都映到同一点"的退化映射，则「内容贡献=0」是**写侧结构性**的，
与读侧是否绕过无关；反之则必须重判。**该测试从未做过，且有真正的阳性对照。**

## §1 主假说与否证条款（冻结）

- **`H97`**：**写入规则把 32 个事实存成了可分辨的内容** ——
  即 `argmax_j cos(W k_i , v_j) = i` 的事实数 **≥ 24/32**（两个 seed、三个层各自成立）。
- **否证条款**：任一 (seed, 层) 上该计数 **≤ 8/32** ⇒ **`H97` 否证**。
- **中间带 `(8/32, 24/32)`**：记 `AMBIGUOUS`，**不得**计入 `SUCCEEDED`，且**不得**据此改写 `§7.2-7`。
  （★ 本卡**显式定义空档含义**，遵 `DEF-96-10` 的教训：判据定义域必须封闭。）

> ★ 注意方向：`H97` 断言"**能**分辨"。否证它 ⇒ 写侧结构性不可达。**两种结果都终结一条线**。

## §2 判据（数字全部在此冻结，此后不得改）

### §2.1 测量对象（逐符号定义）

- `k_i` ∈ ℝ^{896}：事实 `i` 的写键 = **与写规则同源**的 `K_mean`（`key_matrices_arm` 逐字，`RULE=("mean","mean")`）。
- `v_i` ∈ ℝ^{896}：事实 `i` 的写值 = 同源的 `V_mean`。
- `W`：写相结束后的 `m.Wfull`（`W0` 为同栈初始化）。
- `r_i = W k_i`。
- **判据量**：`N_hit(W) = Σ_i [ argmax_j cos(r_i, v_j) = i ]`（**只取 32 个 `j` 的全集**，不含抽查）。
  ★ 同时报 `N_hit_L2(W)`（用 `−‖r_i − v_j‖²` 取 argmax），**两者不一致时以 `cos` 为准并披露差异**
  （防读出选择造成假象）。

### §2.2 三个臂（同一 seed、同一层、同一 `k_i/v_i`）

| 臂 | `W` | 作用 |
|---|---|---|
| `intact` | 写相后的 `Wfull` | **被测对象** |
| `W0` | 初始化 `W0`（未写） | **零假设**：`N_hit` 应 ≈ 随机（1/32） |
| `oracle` | `W_or = argmin ‖W K − V‖_F` 的**最小范数解** = `V K⁺` | **阳性对照（已知答案）** |

- `oracle` 必然精确拟合 32 对约束 ⇒ 若探头有效，`N_hit(W_or)` 应 ≈ 32/32。
- 另报 `W0 + ΔW_or`（`ΔW_or = W_or − W0`）的 `N_hit`，作为"更贴近真实臂"的阳性对照。

### §2.3 阈值（冻结）

| 编号 | 判据 | 阈值 |
|---|---|---|
| `G97-1` | **阳性对照**：`N_hit(W_or)` ≥ | **30/32**（否则 `INVALID`，无判决） |
| `G97-2` | 同 `G97-1` 于 `W0+ΔW_or` ≥ | **30/32** |
| `M97-1` | **主判据**：`N_hit(intact)` | 见 §1：≥24 确认 / ≤8 否证 / 其余 `AMBIGUOUS` |
| `M97-2` | **零假设**：`N_hit(W0)` ≤ | **6/32**（若 `W0` 已能分辨，说明 `k_i` 本身泄漏答案 ⇒ `INVALID`） |

### §2.4 Stage A 守卫（全过才允许正式轮）

| 编号 | 断言 |
|---|---|
| `A97-1` | 32 个 `v_j` **可分辨**：所有两两 `cos(v_j,v_l)` 的**最大值 < 0.90**（否则 argmax 无意义 ⇒ `INVALID`） |
| `A97-2` | `k_i` 非退化解：`‖k_i‖` 两两差异 < 10×（否则 `N_hit` 受尺度主导） |
| `A97-3` | `oracle` 拟合残差 `‖W_or K − V‖_F / ‖V‖_F < 1e-6`（最小范数解应精确） |
| `A97-4` | ★ **`W` 在写相后不再被改动**：读侧训练前后 `‖Wfull − W_write‖/‖W_write‖ < 1e-12`（验证 `sg(W)`；若失败则"D-125 的 W 是写相 W"这一前提被推翻，须停轮） |
| `A97-5` | `N_hit` 实现正确性：对**构造的** `W = W_or` 与 `W = W0` 各算一次，结果须与 `G97-1`/`M97-2` 同批一致（同一函数、不同形参） |
| `A97-6` | 每事实块数 `≥ 18`（装置保证 600=24×19+8×18） |
| `A97-7` | `ΔW = W − W0` 的 **stable rank** 复现 `D-126` 量级（`≤ 1.02`），否则装置漂移 ⇒ 停轮 |
| `A97-8` | 一次一栈；`no_write` 必须显式重封（`DEF-95-01`） |

### §2.5 两侧闭合判据（预注册 —— 防第四次「改写缺口」）

1. `G97-1..2` 过 **且** `M97-1` 判**否证**（≤8/32）
   ⇒ **写侧结构性不可达**：v2.4 的局部写规则在 32 事实下存不下可分辨内容。
   ⇒ `§7.2-7b` 记 **`已足够`**（附边界：本装置/本规则/32 事实；**不再**开 `O96-1`）。
2. `G97-1..2` 过 **且** `M97-1` 判**确认**（≥24/32）
   ⇒ **内容确实被存下**，则历轮"内容贡献=0"必须**重新归因**到读出侧/任务侧 ⇒ **开 `O96-1`**（键去相关不再是第一优先）。
3. `G97-1..2` **未过** ⇒ `INVALID`：探头看不见内容，**本卡不能给任何判决**，须先修测量。

## §5 边界（不得外推）

1. 本卡只测**存储内容的可分辨性**，**不测** LLM 任务收益、不测生成质量（`acc_held≡0` 仍是事实）。
2. `oracle` 是**上界探查**，**不是**任何可行机制；**不得**把它当"架构可以做到"。
3. 结果只在**本装置**（`d=896`、600 块、32 事实、`K_mean_V_mean`、`η=3e-5`、2 seed、3 层）成立。
4. 即使判 `否证`，**也不得**说"读侧绕过 `W` 是 v2.4 的缺陷" —— 本卡未测架构，只测本实现。
5. `N_hit` 是**单步线性探针**（一次 `W k_i`），**不**等于多步读出、**不**等于 `W` 在任何下游任务中的可用性。
