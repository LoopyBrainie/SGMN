## 二、机制：rank-1 已**解析地**决定这个上界

`D-126` 测得 `ΔW` 的 stable rank ≈ **1.0005–1.0034**、`cos(v₁,k̄)=±0.999`。于是

```
W k_i = (W⁰ + ΔW) k_i ≈ W⁰k_i + σ₁ u₁ (v₁·k_i)
```

`ΔW` 的部分**逐 i 只差一个标量** `(v₁·k_i)`，方向恒为 `u₁`。故（在 `ΔW` 主导时）所有 `r_i` 同向
⇒ `cos(r_i, v_j)` 的**排序对 i 恒定** ⇒ `argmax_j` 是**同一个常数下标** `j*`
⇒ **`N_hit^v ≤ |S_{j*}| ≤ max_v m_v = 2`**。

实测 **≤ 1**，落在该解析上界之内。★ 即：**"内容贡献=0" 不是"存得差"，而是"根本没有存下可区分的方向"**。

### 与 `D-125` 的关系（两者正交，不互相抹掉）

- `A97-4` **实测**：读侧训练前后 `‖W_after_read − W_write‖/‖W_write‖ = **0.000e+00**`
  ⇒ `read()` 里 `y = sg(W) q` 的作用被**实证**，不是靠读代码推断 ⇒ 读侧任务损失**完全不改动 `W`**。
- 而 `c = sg(h)` 编码 nonce 键（`build_facts` 明写"基座不可能先验知道"）⇒ `Wq/Wo/gamma`（≈1.6 M 参数）
  **可以只凭 `c` 记住 16 个训练键**。这解释 `D-125` 的 `W←W⁰` 仍 `0.8750/0.8125` 与 `acc_held ≡ 0`。
- ⇒ 两个事实并存且互补：**写侧没内容**（本卡）+ **读侧不需要它**（`D-125`）。

5. **不得**把「否证」当「实验失败」：这是**有效机制结论**（`DEF-96-07`）。
6. **不得**引用 `D-126` 的秩来**代替**本卡的 `N_hit` 读数：二者是不同量（秩是结构、`N_hit` 是可分辨性）。
