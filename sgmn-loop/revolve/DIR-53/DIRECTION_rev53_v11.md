## §1 主假说与否证条款（**冻结**）

### §1.1 主假说 `H53`

> **`H53`**：把写键映射 $P_k$ 用**写侧自监督目标**（**不经任务梯度**）在**离线训练段**上学出来（**只改方向、不改行尺度**），
> 比**同初值的固定随机** $P_k$ 在**未见过的评估实例**上有**独立的、内容性的**收益。

★ **为什么必须是写侧目标（`DEF-53-1`，探针实测）**：v2.4 **Freeze C** 规定 `k,v` 与读取上下文 **stop-gradient**，
装置逐字实现该冻结 ⇒ **任务损失对 $P_k$ 的梯度恒为零**（探针三张抽取上 `OFF ≡ FIX`、`‖ΔP_k‖ = 0`）。
因此「用任务损失学 $P_k$」在 v2.4 装置里**结构上不可实现**；「离线学习」只能指**离线地**（不看任务损失地）学。

**「独立」的操作化**：两臂的**头+控制器**都在**同一训练段、同一预算（250 步）**上自训（matched-head 协议）
⇒ 唯一差别 = $P_k$ 是"固定初值"还是"被离线训练过的矩阵"。

**「内容性」的操作化**：`OFF` 臂训练后在评估段把**内容**随机置换（`rand_content=True`）
⇒ 若收益随内容置换消失，则收益来自"学到的键与内容的对应关系"，而不是"键尺度/数值噪声底"。

### §1.2 否证条款（**逐条冻结**）

`H53` 被否证，当且仅当以下**任一**成立：

- **(F1)** 5 张预注册 $P_k$ 抽取中，完整满足 §3.3 三谓词的张数 **`p < 4`**；
- **(F2)** 有 ≥1 张抽取的「可寻址区间」`R_j ≤ 0`（装置不可判，见 §4 第 3 支 —— 这不是否证，是 `INDETERMINATE`）；
- **(F3)** 出现 `DIVERGED`（非有限损失）。

★ **否证不等于坏结果**：`H53` 被否证 ⇒ 合法结论 =「**在本玩具、本协议、本训练预算下，固定随机 $P_k$ 已足够**；
v2.4 不必为 $P_k$ 规定离线学习程序」——这是**架构结论**，不是失败。

### §2.2 唯一自变量：$P_k$ 的来源（**三臂**）

| 臂 | $P_k$ | 头/控制器 |
|---|---|---|
| **`FIX_j`** | **固定随机**：`randn(D_H,D_K)·(1/√D_H)·KEY_SCALE`，独立生成器种子 `20262201+j−1`（`j=1..5`） | 训练段自训 250 步 |
| **`OFF_j`** | **同一初值**，用**写侧自监督目标**（§2.2a）在**训练段**上离线训练 250 步（Adam `lr=0.03`）；**每步后按行把 ‖P_k‖ᵢ 投影回初值行范数** | 与 `FIX_j` **同一协议**（250 步，头/控制器） |
| **`ORACLE_j`** | 与 `FIX_j` **逐位相同** | 读源换成 `q = tanh(h·P_k)`（本格真键读，**描述性上限**），头自训 |

★ `OFF` 的**行范数投影**是本卡的核心控制：**只改方向、不改尺度** ⇒ 排除「键变大 ⇒ SNR 变好」的平凡解释。
★ `ORACLE_j` 定义**可寻址区间** `R_j := L_FIX_j − L_ORACLE_j`（本格内、同一 $P_k$、同一评估段）。
★ 三臂共用**同一训练段/评估段/头初值**（同一生成器 4242、同一抽取顺序）⇒ 逐位配对。

### §2.2a `OFF` 臂的**离线学习程序**（冻结；rev 1.1 新定义）

**目标（写侧自监督，单位温度，无新超参）**：对训练段的每个写步 $i$（96 实例 × `T=16` 步 ⇒ 1536 对）：

```
k_i = tanh(h_i · P_k)        v_i = tanh(h_i · P_v)        （h_i, P_v 由装置给定，均 stop-gradient）
L_off(P_k) = − mean_i [ ⟨k_i, v_i⟩ − logsumexp_j ⟨k_i, v_j⟩ ]
```

- **只对 $P_k$ 求梯度**；`h`、`P_v`、头、控制器全部冻结 ⇒ **不含任何任务损失项**（与 Freeze C 一致）。
- **温度 = 1（不引入新尺度）**：$k,v$ 都是 `tanh(−)` 且有界，单位温度是唯一不引入额外尺度的选择。
- **步数 / 优化器 / 学习率**：`250 / Adam / 0.03` —— 与头/控制器的冻结常数**逐字相同**（不新增超参）。
- **行范数投影**：每步后把 `‖P_k‖ᵢ` 投回初值行范数 ⇒ **只改方向、不改尺度**（排除 SNR 平凡解释）。
- ★ **离线**的含义在此被写死为：**训练目标里不出现任务损失、不出现评估段数据**。其他离线程序（不同目标、不同预算）**未测**。

### §2.3 $P_k$ 抽取的合法性

`20262201..20262205` 是**5 张预注册的独立抽取**，公式与装置源码**逐字同式**
（`dir31/R1_grad.build`：`randn(D_H,D_K)·(1/√D_H)`；`dir33/R1_task33.build`：再乘 `KEY_SCALE`）。
★ **不得**为了与装置某一次实例抽样逐位相同而改公式：装置的 `Pk1` 是**该实例生成器流的第 3 笔**抽取，
共享抽取用的是**独立生成器的第 1 笔** ⇒ 「公式相同」≠「逐位相同」，**边缘律相同**才是本卡需要的性质。

## §3 测量对象、量与判据（**冻结**）

### §3.1 量（每张抽取 `j`；评估 = **400 个未见过**的实例，**逐实例配对**）

- `L_FIX_j, L_OFF_j, L_ORACLE_j`：三臂在评估段上的 `mean L`。
- `R_j := L_FIX_j − L_ORACLE_j` —— 本格「可寻址区间」（学 $P_k$ 最多能补上的那段）。
- `Δ_j := L_FIX_j − L_OFF_j`，配对 ⇒ `se(Δ_j)`、`3se(Δ_j) = SIG_K·se`。
- `C_j := L_OFF_rc_j − L_OFF_j`，配对 ⇒ `se(C_j)`（`OFF_rc` = 同一训好模型的**内容置换**评估）。
- 诊断量（**不作判据**）：`‖ΔP_k‖_F/‖P_k₀‖_F`、`P_k` 行对余弦均值、`cos_q_k`、`Wmax`、训练段 `L` 首/末。

### §3.3 每张抽取的判定（**冻结**）

> **`PASS_j` ⟺ 以下三条全部成立：**
> - **(P1) 显著性**：`Δ_j ≥ SIG_K·se(Δ_j)`（配对，`n=400`）

## §5 两个工作例（验证判定表逻辑**真的**按冻结文字走）

> **例 A · 一张抽取（`PASS_j` 的计算）。** 设 `L_FIX = 6.00`、`L_ORACLE = 1.50`、`L_OFF = 2.00`、`L_OFF_rc = 6.40`，
> `se(Δ) = 0.10`、`se(C) = 0.11`。
> ⇒ `R = 4.50`、`Δ = 4.00`、`3se(Δ) = 0.30`；`0.20·R = 0.90`；`C = 4.40`、`3se(C) = 0.33`。
> ⇒ P1 `4.00 ≥ 0.30` ✔ · P2 `4.00 ≥ 0.90` ✔ · P3 `4.40 ≥ 0.33` ✔ ⇒ **`PASS_j`**。

> **例 B · 反例（效应量不足）。** 设 `L_FIX = 6.00`、`L_ORACLE = 1.50`、`L_OFF = 5.60`、`L_OFF_rc = 6.10`，
> `se(Δ)=0.05`、`se(C)=0.06`。
> ⇒ `R = 4.50`、`Δ = 0.40`、`3se = 0.15`、`0.20·R = 0.90`；`C = 0.50`、`3se(C)=0.18`。
> ⇒ P1 ✔（0.40 ≥ 0.15）· **P2 ✘**（0.40 < 0.90）⇒ **该格不 `PASS`**（★ 这是"统计显著但量级不够"，
> **不得**写成"学习无效"）。
