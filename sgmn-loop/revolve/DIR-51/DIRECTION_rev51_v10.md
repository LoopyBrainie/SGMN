## §1 冻结的操作化（用户 2026-11-16 锁定，逐字承接）

固定人格 trait 键 `k_P` 与原始人格参考值 `v_P^0`，**实验期间均不得随写入更新**。

```
r_P(t) = W_t k_P
c_P(t) = cos( r_P(t), v_P^0 ) = <r_P(t), v_P^0> / (||r_P(t)||_2 ||v_P^0||_2)
```

- `t0` = 人格 trait 已完成初始化、**实验性干扰写入尚未开始**的时刻；`c_{P,0} = c_P(t0)`。
- **主判据量（唯一）**：

  ```
  D_P^{(a)}(N) = c_P^{α=0}(t0+N) − c_P^{(a)}(t0+N)
  ```

  其中 `α=0` = **无数据写入对照**（**保留正则化与其余状态动力学**，**相同在线步数**）。

- 符号读法（冻结）：
  - `D_P^{(a)}(N) > 0` ⇒ 条件 `a` 造成**额外**的人格方向偏移；
  - `D_P^{(a)}(N) < 0` ⇒ 条件 `a` **反而增强**与原人格锚点的方向一致性；
  - `D_P^{(a)}(N) ≈ 0` ⇒ **未观察到**明显额外偏移；★ **不得**据此宣称「人格稳定」
    （须走 P3 等价性分支）。

★ **不得**用单纯基线差分 `Δc_P(t) = c_{P,0} − c_P(t)` 单独承担因果判据：
`α=0` 下正则项仍使状态向 `W^0` 收缩，基线差分**无法区分**自然变化与额外写入干扰。

★ **表述更正（强制）**：早期探针摘要中出现的 `1.72×`（同键写入后 persona 读出相对基线的倍率）
是**上升约 72%**，**不得**解释为「几乎不变」或「记忆没被扰动」。
它**是**「写入把 `W` 拉向 `v_P`」的**强化**证据（幅度被抬高），**不是**未被扰动的证据。

## §2 写入条件的实验分工（用户指定，逐字承接）

| 臂 | 写入内容（每次 `step_pair`） | 角色 |
|---|---|---|
| `alpha0` | `(k_P, v_P^0)`，**`α = 0`** | **无数据写入对照**：数据项恒为 0，只保留正则与其余状态动力学；**在线步数与其他臂相同** |
| `random` | `(k_P, v_rand_j)`，`α = 1` | **阳性对照**：同键换**非人格**值 ⇒ 装置须能发现「明确覆盖」 |
| `ortho` | `(KEY_SCALE·perp_j, v_rand_j)`，`α = 1` | ★ **主干扰条件**：正交键写入**非人格**内容（「外挂记忆过多导致人格被覆盖」） |
| `orthoP` | `(KEY_SCALE·perp_j, v_P^0)`，`α = 1` | ★ **阴性对照**：与 `ortho` **结构完全相同**（同样的正交键、同样的步数），只差**值的性质**（人格值 vs 非人格值）⇒ 给出「正交写入**动作本身**」的效应基线 |
| `replay` | `(k_P, v_P^0)`，`α = 1` | **强化/可学习性对照** ⇒ ★ **不得**称「稳定」证据 |

- `v_rand_j`：每次写入**重新采样**的单位向量（`D_V` 维），与 `v_P^0` 不平行（Stage A 断言 `|cos| ≤ 1e-9`）。
- `perp_j`：在 `D_K` 维内对 `k_P` 做 Gram–Schmidt 得到的单位正交向量（构造保证 `|k_P · perp_j| ≤ 1e-12`）。
- 五个臂**共享**同一 `k_P`、`v_P^0`、初始 `(U, V)`、内容流种子与写入预算；**唯一自变量 = 写入臂**。

## §5 阈值标定（独立标定运行，正式轮前冻结）

标定运行与正式轮**使用不相交的种子段**，且**先于**正式轮完成。

- **阴性对照臂 `orthoP`** 与主条件 `ortho` 结构完全相同 ⇒ 其 `D_P` 给出「正交写入动作本身
  （正则衰减 + 低秩因子化二阶耦合 + 实际键非正交残差）」的效应基线。

  ```
  τ_null := q95_seed( D_P^{orthoP}(N) )          # 单侧 95 分位（标定运行，n_cal 个种子）
  ```

  ⇒ 正式判定用 `D_P^{(a)}(N) > τ_null`。

- **等价性界限**（P3 用）：以**无写入对照自身的自然漂移**为实质尺度 ⇒

  ```
  Δc^{α0} := c_P^{α0}(t0+N) − c_{P,0}
  τ_eq    := q95_seed( |Δc^{α0}| )               # 标定运行
  ```

  ⇒ 「额外漂移不超过连什么都不写时的自然漂移尺度」。

- 标定运行**同时**产出：随机锚点零假设分布（E1）、噪声底（E2）、`s_d = sd(D_P^{orthoP})`、`s_a = sd(D_P^{ortho})`、
  `mean/se` 估计（**只用于算功效，不用于定阈值**）。

★ **不得**用正式轮结果回改 `τ_null`/`τ_eq`；若正式轮前发现标定本身不可用 ⇒ 新开 **rev 1.2**，旧版留档。

## §6 判据表（冻结；数值于 rev 1.1 回填）

设 `n` = 正式轮有效样本数，`se = sd_seed(D_P)/√n`（跨种子）。

| 编号 | 谓词 | 阈值来源 |
|---|---|---|
| **P1（主）** | `mean_seed(D_P^{ortho}(N)) > τ_null` **且** `mean > 3·se` | `τ_null`（标定） |
| **P2（阳性对照）** | `mean_seed(D_P^{random}(N)) > τ_null` | 同上 |
| **P3（等价性）** | `mean(D_P^{ortho}(N)) + t_{0.95,n−1}·se < τ_eq` | `τ_eq`（标定） |
| **P4（有效性）** | `indeterminate` 剔除率 ≤ 上限 且 有效 `n` ≥ 下限 | rev 1.1 冻结 |
| **P5（分解义务）** | 正交臂读数可区分 ① 正则衰减 ② 因子化耦合 ③ 键非正交残差 | 三项诊断量均落盘 |

**判定分支（互斥、按序）**：

1. **P4 不过** ⇒ `NOT-ADDRESSING`（判据不可计算，**不得**记 PASS/FAIL）。
2. **P2 不过** ⇒ `NOT-ADDRESSING`（连阳性对照都测不出 ⇒ P1 不可解释）。
3. **P1 过 且 P2 过 且 P4 过** ⇒ 主假设**确认** ⇒ `PASS` ⇒ 计入 `SUCCEEDED`。
4. **P1 不过 且 P2 过 且 P3 过** ⇒ 主假设**被否证**（未检测到超出对照与等价界的人格漂移）⇒ `FALSIFIED`，**不计数**。
5. **P1 不过 且 P3 不过** ⇒ `INCONCLUSIVE`（既未确认也未否证）⇒ **不计数**，须如实记为「未检测到但未能证明在等价界内」。

★ **不得**在 P1 不过时写「人格稳定」（即使 P3 不过）：那只能是「未检测到超出对照的额外漂移」。
