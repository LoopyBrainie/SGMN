## §0 本 rev 的变更清单（逐条留档）

| 编号 | 变更 | 理由 | 依据 |
|---|---|---|---|
| **C1** | `τ_null` 的**定义**由 `q95(D_P^{orthoP})` 改为 **`median(\|Δc^{α0}\|)`** | ① **尺度匹配**：`D_P` 是**跨种子均值**量，标尺须同用中位/均值尺度（`q95` 是极端值尺度）；② **稳健性**：实测 `\|Δc^{α0}\|` 的 median=0.120 而 q95=0.879、max=1.250 ⇒ 由**少数极端种子**（正则收缩到近零，14% 剔除率同源）支配 ⇒ q95 不稳健；③ 该规格**先于**效应量读数定义，且**与效应量数值无关** | 卡 §5 原则；实测见 §2 |
| **C2** | `τ_eq := τ_null`（**同一实质尺度**） | 「超过自然漂移」（P1）与「不超过自然漂移」（P3）必须用同一把尺 ⇒ 互斥互补 | rev 1.0 §6 |
| **C3** | `orthoP` 臂**不再**充当零假设/阈值来源，改任**内容特异性对照 + 机制分解项** | 实测 `orthoP` 有**系统性效应**（`D=+0.660`）⇒ 不是零假设臂 | §2 实测 |
| **C4** | 装置真实参数更正：**`D_K = 16`**（非 4）、`D_H = 8`、`D_V = 4`、`KEY_SCALE = 0.5` | rev 1.0 §3 误抄 `dir31` 注释里的 `D_K=4`；`R1_task33` 的标定把键维定为 16 | 实测 `T.D_K` |
| **C5** | 新增**敏感性分析义务** | 阈值规格对结论有影响 ⇒ 必须同时报告 `q95` 规格下的结论 | §3 |
| **C6** | `E1` 改为**实例内多锚点**（32 个随机锚点的 q95）；`E2` 改为**相对精度噪声底** `1e-8·‖W‖_F` | rev 1.0 的跨种子绝对分位把「余弦的维度涨落」误当噪声（无效率 0.91）；`基座读出范数` 是**正常读出尺度**不是噪声底 | DEF-51-3 / DEF-51-2 |

## §4 判据表（数值回填版；**自本 rev 起一字不改**）

设 `n_eff` = 有效样本数，`se = sd_seed(D_P)/√n_eff`，`t = t_{0.95, n_eff−1}`（双侧 95%）。

| 编号 | 谓词 | 阈值 |
|---|---|---|
| **P1（主）** | `mean(D_P^{ortho}(N)) > τ_null` **且** `mean > 3·se` | `0.12024568877431446` |
| **P2（阳性对照）** | `mean(D_P^{random}(N)) > τ_null` | 同上 |
| **P3（等价性）** | `mean(D_P^{ortho}(N)) + t·se < τ_null` | 同上 |
| **P4（有效性）** | 剔除率 ≤ `0.20` **且** `n_eff ≥ 500` | 冻结值 |
| **P5（分解义务）** | ① 键正交性实测 `max\|k_P·k_Q\| ≤ 1e-12`；② 正则衰减单独量化（`\|Δc^{α0}\|` 分布）；③ 因子化耦合量化（`D^{orthoP}` 与 `c_anchor_last`）；④ **报告**内容特异性差 `D^{ortho} − D^{orthoP}` | 见下 |

**P5 的地位**：① 不过 ⇒ **NOT-ADDRESSING**（数据不可解释）；
②③④ 为**报告义务 + 机制限定**，**不**作通过/失败判据（rev 1.0 §6 的 P5 定位：正交臂结果必须可分解）。
★ 内容特异性差 `D^{ortho} − D^{orthoP}` 若不显著 ⇒ **必须**在结论中限定：「本装置**不能**区分『人格内容』与『一般内容』」。

**判定分支（互斥、按序）**：

1. **P4 不过** ⇒ `NOT-ADDRESSING`。
2. **P5① 不过** ⇒ `NOT-ADDRESSING`。
3. **P2 不过** ⇒ `NOT-ADDRESSING`（阳性对照测不出 ⇒ P1 不可解释）。
4. **P1 过 且 P2 过 且 P4 过** ⇒ 主假设**确认** ⇒ `PASS` ⇒ 计入 `SUCCEEDED`。
5. **¬P1 且 P2 过 且 P3 过** ⇒ 主假设**被否证** ⇒ `FALSIFIED`，不计数。
6. **¬P1 且 ¬P3** ⇒ `INCONCLUSIVE`，不计数。

★ 敏感性规格（`τ^{(q95)}`）下的分支必须**并行报告**，结论翻转时必须显式声明敏感性。
