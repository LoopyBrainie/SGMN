### §2.2 事实 B —— Adam **尺度不变**，`|grad|` 在原理上不能作「是否被训练」的判据

`train_read_v105` 用的是 `torch.optim.Adam(ps, lr=R91.READ_LR)`，`R91.READ_LR = 1e-3`。
Adam 稳态下单坐标步长 = `lr · m̂/(√v̂ + ε)`；对**恒定**梯度 `g`：
`m = 0.1g`、`v = 0.001g²` ⇒ `m̂ = g`、`v̂ = g²` ⇒ 步长 **`= lr · g/(|g| + ε)`**。

### §2.2′ 修正（rev 1.1，`DEF-108-01`）：`ε` 地板两个 regime

`ε = 1e-8` ⇒ 步长与 `|g|` 的关系**分两段**：

| regime | 条件 | 步长 | 实测/公式 |
|---|---|---|---|
| **平台区** | `\|g\| ≫ ε`（如 `1e-2`, `1e+2`） | `≈ lr`（= 1e-3） | `9.99999e-04` / `1.000000e-03` |
| **线性区** | `\|g\| ≲ ε`（如 `1e-9`） | `≈ lr·\|g\|/ε ≪ lr` | `9.0909e-05` |

★ 关键推论：`gate` 的 `|grad|max = 8.699e-08` 只有 `ε` 的 **8.7 倍** ⇒ 步长 `= 0.8969·lr`
（**几乎没被压低**）。但 `|grad|max` 只是**最大**坐标；**典型坐标**可能远低于 `ε`，
那些坐标的步长会**按比例缩水**（`lr·g/ε`）。⇒ 只看 max 会**高估**整体位移能力，
这正是 §3.1 必须直接测 `‖ΔW‖` 的理由，也说明 §6 新增 `M108-2`（梯度分位数）有必要。

⇒ 用 `|grad|max` 判断「参数几乎未被推动」仍然**无效**，理由**修正为**：
`|grad|max` 只覆盖**一个**坐标、且经 Adam 归一后被 `ε` 地板截断，
它对**整体位移**既不充分也不线性。唯一合法判据是 `‖Δθ‖`。

### §2.3 顺带核出的两处**事实性笔误**（不影响推理，但须更正）

1. `P105-1` 写 `Adam(lr=1e-2)`；**实测 `R91.READ_LR = 1e-3`**（小 10×）。
2. `P105-1` 写 "~8e5 参数"；`W_g` 是 `(d_v, d_m) = (896, 896) = 802,816`/层，

★ 这两条**不改变** `|grad|` 的量级论证，只说明原推理链上的**细节**也没被核过。

## §3 主判据（**预注册；本节数字从未跑过**）

### §3.1 判据量 `ρ`（唯一主判据）

在 **`gate` 族、`seed = 7777`、`steps = 3000`**（与基线 `gate_3000_7777` **逐字同配置**）上：

```
ρ  ≡  ‖W_g^final − W_g^init‖_F  /  ‖W_g^init‖_F        （对三个挂载层分别算，再取全参数拼接的 F 范数）
```

- `W_g^init` = `set_family("gate", …)` 刚创建、**任何前向之前**的 `_Wgp.detach().clone()`
  （由 `torch.Generator(device="cpu").manual_seed(7919+li+100)` 决定 ⇒ 可重建）。
- `W_g^final` = 训练结束（3000 步）后的 `_Wgp`。
- **训练路径一字不改**（不加 hook、不改优化器、不改 lr、不改步数）⇒ 该格应**逐位**复现基线。

### §3.2 阈值（**冻结**）

| 量 | 阈值 | 含义 |
|---|---|---|
| `ρ` | **≥ 0.01** | `W_g` 的位移达到其自身范数的 **1%** ⇒ **"几乎未被推动"为假** |
| `ρ` | **< 0.01** | 支持"几乎未被推动" |

★ 阈值取 `0.01` 的理由（现在写清，避免事后解释）：`W_g^init` 单坐标 std = `1/√896 = 0.0334`；
`ρ = 0.01` 对应**全参数平均每坐标位移 3.34e-4**，即 **`lr = 1e-3` 的三分之一**。
若 Adam 连"每步 1/3 个 lr 的累计位移"都做不到，说明门控梯度**方向**极不稳定
（`m̂/√v̂` 长期接近 0），那才是"真的没学起来"。⇒ 该阈值**不是随手取的**。

### §3.3 轨迹臂（报告，非判据）

同配置 `steps = 600`、`seed = 7777` 的一格，报 `ρ`，与 3000 步比较 ⇒ 看位移是否随步数增长。

### §3.3′ `M108-2`（**report-only，新；不是判据**）：`W_g` 梯度分布

在同一格训练**末步**，对 `W_g` 的 `|grad|` 取分位数
（`p50 / p90 / p99 / max`）与「大于 `ε` 的坐标占比」。

★ 为什么加它：§2.2′ 表明 `ε = 1e-8` 是**逐坐标**的地板。若 `p50 ≪ ε`，
则**多数坐标**的 Adam 步长远小于 `lr` —— 那时 `ρ` 小就是**装置/尺度必然**，
而不是「门控不想学」。⇒ 它用来**解释** `ρ`，**不参与**分支判定。

### §3.4 合成 Adam 检验（`A108-3`，纯 torch，不接模型）

一维参数 `θ ← 0`，恒定梯度 `g`，`Adam(lr=1e-3, ε=1e-8)` 走 1 步：

- **解析预测**：`θ = −lr·g/(g+ε)`（§2.2′）。
- **平台区**：`g ∈ {1e-2, 1e+2}` ⇒ 两者步长相对差 `< 1e-6`，且 `|step − lr| < 1e-9`。
- **线性区**：`g = 1e-9` ⇒ `step = lr·1e-9/(1e-9+1e-8) = 9.0909e-05`，与公式相对误差 `< 1e-9`。

★ rev 1.0 在此处断言「两次都得 `−1e-3`」——**已被实测推翻**（实测 `−9.091e-05`），
记 `DEF-108-01`。**新的断言是"两个 regime 各自符合正确公式"**，不是"尺度不变"。
★ 这条把 §2.2′ 变成**可执行事实**，且**不是** §3.1 的判据（单独报告）。

### §4.1 `ρ` 的算术（两个可手算的例子）

| 例 | `W^init` | `ΔW` | `‖W^init‖_F` | `‖ΔW‖_F` | `ρ` | 判定（阈值 0.01） |

★ 例 2 专门用来贴近真实尺度（`W_g` 单坐标 std ≈ 0.0334）：**1e-3 的绝对位移**

这正是我们要的（它测的是**相对自身尺度**的位移）。

### §4.2 Adam 单步（把 §2.2 的推导坐实）

`β1 = 0.9, β2 = 0.999, ε = 1e-8`，`g` 恒定：
`m₁ = 0.1g`，`v₁ = 0.001g²`；`m̂ = m₁/(1−0.9) = g`，`v̂ = v₁/(1−0.999) = g²`；
**`step = lr·g/(|g| + ε)`**（rev 1.1：原版漏 `ε`，`DEF-108-01`）。

| `g` | `step` | `step/lr` |
|---|---|---|
| `1e-9` | **9.0909e-05** | 0.0909 |
| `8.699e-08`（`gate` 实测 `\|grad\|max`） | **8.9690e-04** | **0.8969** |
| `1e-2` | 9.99999e-04 | 0.999999 |
| `1e+2` | 1.000000e-03 | 1.000000 |

⇒ §3.4 的预测：线性区 `−9.0909e-05`，平台区 `−1e-3`。★ **不是**"两次都 `−1e-3`"。

### §4.3 预期量级（**只作参照，不作判据**）

若每坐标每步位移 ~`lr`、方向随机游走 ⇒ 3000 步后单坐标 ~`1e-3·√3000 = 0.0548`，
而 `W_g` 单坐标 std 仅 `0.0334` ⇒ `ρ` 可能 **≫ 1**。
★ 这只是**数量级直觉**：若实测 `ρ ≫ 1` 成立，说明 `W_g` 被推动得**远超**自身尺度；
若实测 `ρ < 0.01`，则 §2.2 的尺度不变性在真实梯度**方向抖动**下不足以累积位移 ——
**两种情况都必须如实报告，不得回填**。
