## 3. 机制（不只是数字）

### 3.1 效应落在**策略臂**，不在**动力学臂**

- **动力学臂 `E0`（无条件写）**：$\mathrm{ret}_1$ −0.0123（10/19，**不过 P2**）、$\mu$ −0.0017（6/24，**不过 P2**）、写次数按构造恒等；
  ⇒ **原始写动力学几乎不受输入相关性的影响**。
- **策略臂 `tau`（内容门控）**：`ret1` **−0.1050**（**0/30**）、$\mu$ **−0.0103**（**0/30**）、**多跳 54 次写**、门控率 0.418→0.474 ⇒ **塌陷**。

### 3.2 为什么相关输入会伤到门控臂

1. **写侧**：AR(1) 让**同一条目跨轮的键**指向几乎相同的方向 ⇒ 记忆里的写**不再部分抵消、而是同向叠加**
   ⇒ 两臂的 $\lVert P\rVert$ 都**变大**（`E0` +0.0247、`tau` +0.0366，各 30/30 正）⇒ 写侧的"质量"（$\mu$）反而略降。
2. **读侧**：读查询是**原型键**（**无抖动**）⇒ 能把记忆指到读查询方向的，是各轮写入键的**方位角多样性**。
   iid 方位角下，四轮的方向**在对称意义下平均回原型方向** ⇒ 条目可检索；
   AR(1) 下，四轮几乎写在**同一个偏离原型的方向** ⇒ 累积方向**带固定偏置** ⇒ 检索变差（$\mu$ 降、`ret1` 降）。
3. **门控**：门控判据是「$\cos(Wk,v)>\tau$ 就跳」；方向持久 ⇒ 第 0 轮之后记忆"看着就对" ⇒
   **门控把「同方向重复」误当成「已编码」** ⇒ **多跳 54 次**，而且跳掉的正是那些本该提供**方位角多样性**的写
   ⇒ **门控增益从 +0.0660 反转到 −0.0267**。

### 3.3 门控收益有两个可分离的部分，只有一个对相关输入敏感

| 收益来源 | 观测 | 对 AR(1) 的敏感度 |
|---|---|---|
| **① 冗余/干扰剔除**（冗余世界 $b{=}4$ 为主） | 门控增益 +0.3127 | **不敏感**（缩水 36%，仍为正） |
| **② 对齐/多样性补偿**（非冗余世界 $b{=}40$ 为主） | 门控增益 +0.0660 | **高度敏感**（**反转**为 −0.0267） |

⇒ 装置线此前把"门控收益"当作**一个**量（D-45/DIR-26-N 报的是 $\Delta_{24}$、$\Delta_{60}$）；
本轮显示它**至少含两个机制不同的分量**，只有 ② 与输入的时间结构耦合。

### 3.4 与 D-08 的对照：**形态不同型**

| | D-08（DIR-02，标量 $d{=}1$、全矩阵、**目标固定**） | DIR-26-O（$r{=}8$ 因子化、**目标由写流构造**） |
|---|---|---|
| AR(1) 的边缘矩 | 与 $\varphi$ 无关（无边缘修正项） | 与 $\varphi$ 无关（**键矩相对极差 $\le3\times10^{-4}$**）⇒ **一致** |
| AR(1) 的作用通道 | **只**在罕见轨迹/分位临界步长（p=0.999 临界步长 −35.9%） | **a.s. 口径**（p50/p90/p99 同等出现）⇒ **不同型** |
| 为什么 | 目标固定 ⇒ 相关性只能进入偏差的罕见轨迹 | 目标由写流构造 ⇒ 相关输入改变**强化结构**与**门控决策** ⇒ 直接改写读侧收益 |

⇒ **框架层面的结论**：§7.2 的「非 iid 与 AR(1) 修正」**不是空项**；
且 D-08 的"AR(1) 只落在罕见轨迹通道"**不可**外推到因子化装置。

## 4. 对架构的直接含义（**建议，不作结论**）

1. **"iid" 是承重假设，不是中性默认值**：装置线的剂量/收益结论（D-43/D-45 的 $G$、DIR-26-N 的门控收益）
   都是**条件于输入时间过程**的；架构文档若要引用它们，必须写明"在 iid 输入下测得"。
2. **门控阈值是输入谱的函数**：$\tau=0.0950$ 由 iid pilot 标定，在 AR(1) 输入下**过度跳过**（跳写率 0.418→0.474）
   ⇒ 任何"标定出的阈值"都必须附带**输入过程的声明**；跨过程搬运阈值需要**重新标定**（本轮未测，留作后续）。
3. **若要给"记忆"配一个内容门控，必须区分收益的两个分量**（剔冗余 vs 补对齐）：只有后者与输入相关结构耦合。
4. **与 DIR-26-N 的合成**：DIR-26-N 发现"门控判据的参照系必须**外部**"（R 的残差判据在有兄弟时自动退化成价值门控）；
   本轮发现"**参照系之外的输入时间结构**同样能改写门控行为" ⇒ 两条独立的可调旋钮：**参照系**（兄弟/邻居）与**输入谱**（iid/AR(1)）。

## 5. 证据边界（**不可外推为**）

1. **不可**外推为「AR(1) 修正的一般形式」：只测了**一阶、跨轮、逐条目、作用于键的抖动方向**这一族，4 档 $\varphi\in\{0,0.3,0.6,0.9\}$。
2. **不可**外推为「AR(1) 一定有害」：本轮只测**正**相关；**负相关**（交替主题）与**谱形状**（$1/f$、突发）未测。
3. **不可**外推到 $\eta$ 临界步长、**操作域**与**跨层耦合稳定性**（§7.2 同一行的另外两项，本轮不测）。
4. **不可**外推到 LLM / 任务层 / 跨会话 / 真实信息寿命（§7.2「时间与情节状态」「记忆语义」仍未答）。
5. **不可**外推为「门控机制不好」：在 iid 输入下门控是**正收益**（$b{=}40$：+0.0660；$b{=}4$：+0.3127）；本轮测的是**收益对输入过程的稳健性**。
6. **剂量律未测**：D-43/D-45 的 $G=-(\mu_F-\mu_K)$、$R_\mu$、标尺律需要 F/K/U 三条额外臂（成本 ×2.5）⇒ **留作后续任务**；
   本轮只有**写侧剂量代理**（写次数、$\lVert P\rVert$、$\mu$）。
7. **机制解释（"方位角多样性 = 检索所需"）是读数一致的解释，非直接测量**：本轮**未**直接测"写入键方位角与读出方向的夹角"，
   也**未**做"把方位角多样性人为打散"的对照 ⇒ 属**可检验的机制假设**，不是已验证的因果链。
