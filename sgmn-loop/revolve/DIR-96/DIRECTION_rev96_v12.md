## §1 主假说与否证条款

### §1.1 主假说 `H96`

> **抑制发生在读出侧**：读出映射 `A = W_o W W_q` 对真实写入增量 `ΔW` 的敏感度，**显著低于**同范数各向同性随机扰动。
> 即 **`κ_A ≤ 0.2`**（见 §2.2 定义）—— `ΔW` 相对同范数随机扰动，被 `W_q/W_o` 的几何额外压掉 **≥5×**。

### §1.2 否证条款

- **`κ_A ≥ 0.5`** ⇒ **`H96` 否证**：`ΔW` 在读出映射层面**是忠实的**（与随机扰动同量级），抑制必在读出侧之**后**（§4 的 B/C/D 支），本卡按预注册分类法落到 B/C/D。

### §1.3 为何 `H96` 值得单独作为主假说（先验依据，非事后）

`D-125` 的 `margin_train` 变化只有 **0.001–0.002**（`8.236→8.235`、`8.971→8.969`）。
若 `ΔW` 忠实通过读出侧，注入幅度按 `ν=3.6%` 缩放，而注入的总效应是 `margin: +8.24 → −1.87`（`W` vs `W=0`，约 **10.1** 个单位）⇒ 朴素预期变化 **≈0.36**。
实测 **0.001** ⇒ **≈360× 的额外压制**。这正是 `H96` 要检验的对象（但 margin 是**非线性聚合量**，故本卡改用线性的 `κ_A`/`κ_m`/`κ_logit` 直接测，不拿 margin 当判据）。

## §2 MVP 标准与阈值（冻结）

### §2.1 MVP 标准（最小可判定产物）

**一份三级 `κ` 读数 + 预注册四支归类**，由 2 个 seed × 3 层给出：
`κ_A`（读出映射级，**纯线性代数，不需 LLM 前向**）· `κ_m`（真实上下文上的注入级）· `κ_logit`（候选 logit 级）。
三者共用同一套 `W`/`W⁰`/`Wq`/`Wo`/`c`，除「`W` 取值」外无其他变量。

### §2.2 定义（唯一口径，冻结）

记号：`ν = ‖ΔW‖_F/‖W⁰‖_F`（`ΔW = W − W⁰`，**名义相对幅度**，`D-125` 实测 `3.63%–3.73%`）。

| 量 | 定义 | 含义 |
|---|---|---|
| `A`, `A₀` | `A = W_o W W_q`，`A₀ = W_o W⁰ W_q`（各 `896×896`） | 读出侧对 `c` 的**有效线性映射** |
| `ρ_A` | `‖A − A₀‖_F / ‖A‖_F` | 增量对读**出映射**的相对影响 |
| **`κ_A`** | **`ρ_A / ν`** | **读出侧的"穿越系数"**：`1` = 忠实穿越，`≪1` = 结构性压制 |
| `ρ_m` | `sqrt( Σ_k ‖(A−A₀) c_k‖² / Σ_k ‖A c_k‖² )`，`c_k` = 训练项实测上下文（**同一批 `c`，逐层各自**） | 增量对**实际注入向量**的影响 |
| **`κ_m`** | **`ρ_m / ν`** | 上下文子空间上的穿越系数 |
| `δ₁` | `mean_{item,cand} |L^{(W)} − L^{(W⁰)}|`（候选 next-token logit） | 增量的 logit 级效应 |
| `δ₂` | `mean_{item,cand} |L^{(W)} − L^{(W=0)}|` | **注入总效应**（同一单位、同一批题） |
| `ρ_logit` | `δ₁ / δ₂` | 增量占注入总效应的比例 |
| **`κ_logit`** | **`ρ_logit / ν`** | 下游的穿越系数 |

★ `c_k` 的取法（**消除路径依赖，本卡唯一允许的简化**）：**只捕获 `W=W` 条件下的 `c`**，然后 `m = A c`、`m₀ = A₀ c` 用**同一批 `c`** 线性算出。
理由：`m` 对 `c` 是**逐 token 线性**的（`sgmn_module.py` `read()`：`q=Wq c`、`y=W y`、`m=Wo y`），故固定 `c` 对比 `W`/`W⁰` 是**同一 `c` 上的干净对照**，不会把「换了 `W` 导致前层注入变化进而 `c` 变化」的二次效应混进 `κ_A`/`κ_m`。
★ **不得**改 `W` 后重跑前向去取 `c` 再比（那会把路径依赖算进 `κ_m`）。

### §2.3 阈值（冻结，先验校准）

| 判据 | 阈值 | 来源 |
|---|---|---|
| `H96` 成立 | **`κ_A ≤ 0.2`** | 5× 压制是"结构性不可见"的最小因子；且 `D-125` 的 360× 先验暗示真效应远低于此 ⇒ **保守门限** |
| `H96` 否证 | **`κ_A ≥ 0.5`** | 与随机扰动同量级（2× 以内）即视为"忠实穿越" |
| 四支分类 | 见 §4 | **预注册**，不看数据即固定 |
| 合议 | 2/2 seed **同支** | 否则 `INCONCLUSIVE-SEED-SPLIT` |

★ **阈值先验校准的声明**：`0.2` 与 `0.5` 由 `D-125` 的**既有**读数（margin `0.001` vs 朴素 `0.36`）与"5× = 结构性"这一**效应量**判据共同设定。
这**不是**事后调整：本卡在任何 `κ` 数据产生之前冻结，`D-125` 是**上一轮**的独立产物。

## §2.3′ 聚合规则（rev 1.1 新增 → **rev 1.2 订正**；**只补聚合，不动阈值、不动四支**）

每 seed 有 **3 层**（`MOUNT=[8,12,16]`），故需把多层折成一个数。**必须先区分两类量**（rev 1.2 订正）：

**(i) 逐层量** `κ_A`、`κ_m` —— 每层有**自己的** `W` 与 `ΔW`，故天然是三个值。
- seed 级取 **三层中位数**（n=3，中位对单层离群稳健；不用均值以免被单层主导）。
- 必须同时报告三层原值。

**(ii) 整栈量** `κ_logit` —— 最终 logit 由**三层注入共同**决定，**逐层不可分**。
- 故 **每 seed 只有一个值**，**不做中位**（rev 1.1 误把此量当逐层量，此处订正）。
- 其 $
u$ 取 **三层 $
u_l$ 的均值**（`ΔW` 是三层同时改变，无单一 $
u_l$ 可用）。

**分支归类**（§4）：
- seed 级：`(κ_A^med, κ_m^med, κ_logit^seed)` ⇒ §4 机械归类。
- **层支**：`(κ_A^(l), κ_m^(l), κ_logit^seed)` ⇒ 同一个 `κ_logit^seed` 代入（因它是共享量）。
- `n_agree_out_of_3` = 与 **seed 级支** 同支的层数。
- `n_agree_out_of_3 ≤ 1` ⇒ 该 seed 标 **`UNSTABLE-LAYERS`**；任一 seed 为 `UNSTABLE-LAYERS` ⇒ 合议记
  **`INCONCLUSIVE-LAYER-HETEROGENEITY`**，**不得**记作 PASS 或 FAIL。
- 合议：**2/2 seed 同支** ⇒ 取该支；两 seed 异支 ⇒ **`INCONCLUSIVE-SEED-SPLIT`**。

★ 本规则**不改变** §2.3 的 `0.2`/`0.5` 阈值，不改变 §4 四支的判据顺序；只规定"多层怎么合成一个 seed 值"。
★ 为何必须事前补：若不预设，会在看到三层读数后**挑选**有利的聚合方式（选均值/选最大/只看最有利层），那是事后调参。

## §3 测量对象与 worked example（开卡前必须先算通）

### §3.1 装置（逐字派生）

**逐字派生自** `dir95/R1_task95.py`（而后者逐字派生自 `dir94/R1_task94.py`）：同一 `dir91` 装置、同一 `probe91_kpool.py` 原生臂 `K_mean_V_mean`、同一写入（`write_phase_arm`，600 块）、同一读侧训练（`R2_task91.train_read_task`，`READ_STEPS=600`、`lr=1e-3`、Adam、只训 `Wq/Wo/γ`）。
**只换测量层**：不再测 4 个 `W` 条件 × 准确率，而测 §2.2 的三级 `κ`。
常量（已核于 trainer）：`d_model = d_k = d_v = 896`、`R = 8`（`use_factorized=False` ⇒ 不用）、`ALPHA=1.0`、`LAM=0.05`、`ETA_WRITE=3e-5`、`MOUNT=[8,12,16]`（**层下标**）、`N_FACTS=32`、`N_TRAIN_KEYS=16`、seed ∈ `{20261028, 7777}`。
★ `‖W⁰‖_F = sqrt(d_k) = sqrt(896) = 29.933`，与 `D-125` JSON 的 `w0_fro = 29.9329/29.9462/29.9249` **逐位吻合** ⇒ 形状与初始化**已核实**。

### §3.2 worked example（解析锚点，必须先算通）

**取 `ΔW = s·W⁰`（`s = 0.036`，即 `ν = 0.036`）**：则 `A − A₀ = W_o (sW⁰) W_q = s·A₀`，`A = (1+s)A₀`，故

$$\rho_A = \frac{s\|A_0\|_F}{(1+s)\|A_0\|_F} = \frac{s}{1+s},\qquad \kappa_A = \frac{\rho_A}{\nu} = \frac{1}{1+s} = 0.9653$$

⇒ **`κ_A ≈ 1`（比例不变性）**：`κ` 对 `ΔW` 的**整体缩放不变**，只对**方向结构**敏感。这正是本卡能区分"结构性不可见"与"单纯小"的原因。
另两个锚点：`ΔW = 0` ⇒ `κ_A = 0`；`ΔW` 各向同性随机且 `‖ΔW‖_F = ν‖W⁰‖_F` ⇒ **`E[κ_A] ≈ 1`**（因 `W⁰` 本身即 `randn/sqrt(d_v)` ⇒ 与同尺度高斯扰动**同分布**）。
★ 后者**同时是守卫**：`κ_A^rand ∈ [0.5, 2.0]` 必须成立，否则说明测量被破坏（`A96-4`）。

### §3.3 `κ` 的可计算性核（开卡前已核）

`W_o W W_q` 三次矩阵乘 `896×896`，单层 < 10 ms；
`κ_A` **不需要任何 LLM 前向**（只用训练好的 `Wq/Wo/W`）⇒ 主判据**零装置风险**。
`κ_m` 只需一次前向捕获 `c`；`κ_logit` 只需 3 条件 × 16 题 × 4 候选的前向（`D-125` 已在同一装置跑过等价规模）。

## §4 四支分类法（**预注册**，不看数据即固定）

按 §2.2 的 `κ`，对**每个 seed** 机械归类（`κ_A` 优先）：

| 支 | 条件 | 机制结论 |
|---|---|---|
| **A · 读出侧** | `κ_A ≤ 0.2` | `W_q/W_o` 的几何把 `ΔW` 压掉 ⇒ 抑制在**读出映射** |
| **B · 上下文子空间** | `κ_A > 0.2` 且 `κ_m ≤ 0.2` | 映射对一般向量敏感，但**实际 `c` 落在 `ΔA` 的弱方向上** |
| **D · 下游非线性** | `κ_m > 0.2` 且 `κ_logit ≤ 0.2` | 注入向量确实变了，但 **LLM 的 logit 响应把它吸收** |
| **C · 无抑制（余量）** | `κ_m > 0.2` 且 `κ_logit > 0.2` | 增量**忠实传到底**，`acc` 不变只因**判据余量充裕**（margin ≈ +8.2） |

★ 四支**穷尽**（`κ_A` → 否则 `κ_m` → 否则 `κ_logit`），任一读数都能落到唯一支。
★ `H96` 成立 ⟺ 落在 **A 支**；落在 B/C/D ⇒ `H96` 否证（但**四支本身都是有价值的机制结论**，不因否证而不算完成）。
