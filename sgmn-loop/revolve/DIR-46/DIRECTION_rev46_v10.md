## §0 一句话

**在「写入键逐步互不相同」的内容下，外积记忆的取回相似度 `C(N_w)` 会不会在有限次写入内跌破 0.5？而「内容周期重复」时会不会永远不跌破？**

## §1 主假说与否证条款

**H46（内容持续度决定容量）**：
> `C_perstep(8) < 0.5` **且** `C_period2(8) ≥ 0.9`
> ——即「**键逐步不同**」的内容在 **8 次写入**内就失效，而「**键只有 2 种（周期 2）**」的内容在 8 次（乃至 128 次）写入后仍**完好**。

**否证条款（任一命中即否证）**：
- `C_perstep(8) ≥ 0.5` ⇒ **并非**在 8 次内失效（容量更大或不存在失效）；
- `C_period2(8) < 0.9` ⇒ 周期内容**也会**衰减 ⇒ 「内容持续度决定容量」**不成立**。

★ 否证 ≠ 失败：本轮结局会落在 `NO-CAPACITY-LIMIT` 或 `CONTENT-INDEPENDENT`（见 §5），**不计入** `SUCCEEDED`。

## §3 测量对象（**已用 worked example 校验**）

### 3.1 定义

对内容序列 `a[0..N_w-1]`：
- `h(s) = tanh(a[s]·A1 + b1)`；`k_s = tanh(h(s-1)·Pk1)`（`s=0` 时 **`k_0 = 0`**）；`v_s = tanh(h(s)·Pv1)`。
- 写入（逐字同装置，`n_rep=16`）：`W = U Vᵀ`，`G = ALPHA·(W k_s − v_s) k_sᵀ + LAM·W`，
  `U ← U − ETA·(G Vᵀ)`，`V ← V − ETA·(Gᵀ U)`。
- **`C(N_w) := mean_{s=1..N_w−1, 可读} cos(W^{(N_w)}·k_s, v_s)`**
  （`W^{(N_w)}` = 写完 `N_w` 对之后的权重；**`s=0` 恒跳过**，见 3.2）。
- **删失**：若 `W^{(N_w)}` 非有限 ⇒ 该实例在该 `N_w` **删失**（`finite=false`）⇒ **不计入均值**、**必须计数**。

### 3.2 ★ 结构性事实（worked example 顺带测到，必须写进卡）：**第 0 步写入是空操作**

`k_0 = 0` ⇒ `W·k_0 = 0` ⇒ `G = ALPHA·(0 − v_0)·0ᵀ + LAM·W = LAM·W`
⇒ ⇒ **第 0 步只按 `LAM` 衰减、不写入任何值**，且该槽位**永远读不回来**（`W·0 = 0`）。
⇒ 因此 `N_w=1` 的 `C` **不存在**（`n_read=0`），判据非空锚点只能用 `N_w=2`。

### 3.3 worked example（`dir46/workex46.py`，**36/36 逐位一致**）

用**独立手写实现**（`W = U @ V.T`，不用 `M._W`，不 `import probe46a`）重算三个格 × 12 实例：

| 格 | `C` 参考值 | `C` 独立值 | `‖W‖` 参考 | 判定 |
|---|---|---|---|---|
| `perstep, N_w=4` | `0.587556643383422` | `0.587556643383422` | `1.0995332622181742` | ✓ |
| `perstep, N_w=8` | `0.43070029786233643` | `0.4307002978623364` | `1.6523758289503496` | ✓（≤1 ulp） |
| `period2, N_w=8` | `0.9820710315601012` | `0.9820710315601013` | `1.2083044275597286` | ✓（≤1 ulp） |

⇒ **测量对象定义无歧义**（两条独立实现给出同一数，差异 ≤ 1 ulp ≪ `ATOL=1e-12`）。

## §4 开卡前诊断（`probe46a`，种子 `23800+`，`n=12`；**读数不进判据**）

| `N_w` | 2 | 4 | 8 | 16 | 32 | 64 | 128 |
|---|---|---|---|---|---|---|---|

- **④ 稳定性前置**：`N_div(perstep)=8`、`N_div(period2)=32` ⇒ 均 **≠ 1** ⇒ 非 `DIVERGED-EARLY`；判据点 `N_w=8` 的删失比 **1/12 = 8.3% ≤ 20%** ⇒ ✓

## §8 红线

1. **容量是装置性质**：结论**不得**写成「读头学不会寻址」（那是 DIR-43 的对象）。
2. `CENSORED` / `INCOMPLETE` / `DIVERGED` **不得**记成 PASS/FAIL；**删失格不得参与均值**，且必须报占比。
3. 判据点之外的曲线点（含 `*` 号格）**不得**用于判定，只作机制说明。
4. 阈值（`0.5 / 0.9 / 2 / 8 / 0.20 / 400 / 3`）与种子起点**开卡后一字不改**；要改须新开 revision 并全部留档。
5. 与 DIR-39/40/41/42/43/44/45/26-S′ **均不矛盾**：各自判定与计数**一字不改**，`SUCCEEDED` 现为 **32/32**，本卡 `PASS` 后为 **33/32→33**（届时按台账规则登记）。
6. 探针读数（§4）**不进判据**；正式轮必须**换种子段重测同曲线**（不得复用探针行）。
