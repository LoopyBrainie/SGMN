## 2. 本卡要修的缺陷（`DEF-93R-01`，本轮**在开卡前**机械查出）

`dir91/R2_task91.py:186`：
```python
vals = [VALUE_POOL[i % len(VALUE_POOL)] for i in range(N_FACTS)]   # 27 类 → 32 事实
rng.shuffle(vals)
```
`N_FACTS=32`、`|VALUE_POOL|=27` ⇒ **5 类重复 + 22 类单例**；`shuffle` 后按**下标**切分（训练 `0–15`，留出 `16–31`）。

用 `random.Random(9091)` **逐字复现**（纯 Python，不涉 torch）得到：

| 量 | 值 |
|---|---|
| 训练事实覆盖类数 | **13 / 27** |
| **留出事实中答案类「训练集出现过」** | **1 条**（`olive`，fact 29）|
| **留出事实中答案类「训练集从未出现」** | **15 条** |
| **⇒ `acc_held` 结构上界** | **1/16 = 0.0625** |
| 机会水平（`N_CAND=4`）| **0.2500** |

$$ \boxed{\text{acc\_held 的结构上界 } 0.0625 < \text{机会水平 } 0.25} $$

⇒ 该指标**在本装置上是反信息的**：一个**完美**的记忆+读出**最多**得 `0.0625`，**低于**瞎猜的 `0.25`；而读出器只能在**见过的类**里挑，故必然「自信地答错」（`D-115` 实测 `margin_held=−5.66…−8.61`）。
★ 与证据表 `DEF-96-09` 独立实测的「`M3` 实测 `seen-value = 1`、`unseen = 15`」**逐位吻合**（该处当时只用于降级守卫 `A96-12`）。

**因此本轮的全部既有零结果被重新解释（读数一字不改，只换解释）**：`D-108@DIR-91` 的 `NO_HELP`、`D-115@DIR-91` 的 `SEPARABLE_BUT_UNREADABLE`、`D-120@DIR-92` 的 `INCONCLUSIVE-ARM-INVALID` —— 其 `acc_held` 全部 **$\le 0.0625$ = 上界**。★ 尤其 `D-108` 的 `E_vtpos_qor` 得 **`0.062` = 恰好 `1/16` = 上界** ⇒ 它**打满了上界**（那 1 条正是唯一 seen 类），**不是**"零响应"。

## 3. 唯一独立变量（**只改这一处**）

**`build_facts` 的值-类分配**：由「27 类按 `i%27` 循环后洗牌」改为「**16 类 × 每类 2 条事实，1 训练 1 留出**」。

```python
C = VALUE_POOL[:16]                      # 16 类（确定性；其余 11 类不参与 —— 有意，见 §7 边界 3）
vals = [C[i % 16] for i in range(N_FACTS)]   # fact j 与 fact j+16 同类
```

⇒ 训练事实 `0–15` 覆盖 **全部 16 类**；留出事实 `16–31` **也覆盖全部 16 类** ⇒ **`acc_held` 结构上界 = 16/16 = 1.0**（$\gg$ 机会 `0.25`）。
★ **这是「新键 → 已知值类」的组合泛化**：留出事实的 **nonce 键从未被训练**（`Wq`/`Wo` 没见过它），但它的**答案类在训练集出现过** ⇒ 要通过必须**真的从记忆里检索出该事实的值**（`D-108` 真正结论 3 已实测「关联式对留出键同样成立，训练/留出 `rel` 最大差 `0.046`」）。
★ 键、句模板、写规则、$\gamma_0$、$\eta$、$\lambda$、`MOUNT`、块构造、读出训练、判据门 —— **全部逐字不动**。

## 4. 主假说与证伪条款（**冻结**）

**H93**：在**类覆盖分割**下，写入记忆带来**内容性收益**：
$$\Delta_{\rm content}=\mathrm{acc}_{\rm held}(\mathrm{MEM})-\mathrm{acc}_{\rm held}(\mathrm{INJ})\ \ge\ 0.25$$
（$\mathrm{acc}$ 按**题**计，$n{=}16$，机会 $0.25$，粒度 $1/16=0.0625$。）

**臂**（沿用 `dir92/R1_task92.py` 的臂定义，**一字不改**，只换 `build_facts`）：

| 臂 | $\gamma$ | 写 | 读训练 | 作用 |
|---|---|---|---|---|
| **BASE** | 0 | 关 | 开 | 不可训练基线（`γ=0` ⇒ 注入恒 0）|
| **INJ** | 0.05 | **关** | 开 | **对照臂**：同形注入、无记忆 |
| **MEM** | 0.05 | **开** | 开 | 主臂 |
| **MEMR** | 0.05 | 开（**值错配**）| 开 | 内容特异性对照 |

**F 条款（任一命中即按该条判，按 F1→F5 顺序取第一条命中）**

| # | 条件 | 判决 |
|---|---|---|
| **F1** | $\Delta_{\rm content}$ 的 3 种子**变号**，或 $\lvert\Delta\rvert<0.0625$（= 一个分辨率单位） | **`FALSIFIED`**（H93 否证）|
| **F2** | 类覆盖守卫失败（留出类覆盖 $\ne16/16$）| **`INVALID-SPLIT`**（判据不可计算）|
| **F3** | `INJ` 与 `MEM` **双双** $\le$ 机会 $0.25$ | **`INCONCLUSIVE-ARM-INVALID`**（第三态，**不计** `SUCCEEDED`）|
| **F4** | `S90` 存储诊断 $>0.5$（内容没存进去）| **`INCONCLUSIVE-STORAGE`**（第三态）|
| **F5** | $n{=}16$ 下 $\Delta$ 的 80% 区间宽 $\ge0.5$ | **`INCONCLUSIVE-POWER`**（第三态）|

★ **F1 与 F3 的优先关系**：`F3` 只在**两臂同贴地板**时命中；若 `MEM` 已显著 $>0.25$ 而 `INJ` 贴地板，则 `F3` **不**命中（那是**有效**对照臂，`Δ` 有信息量）。

**★ `S90` 存储诊断（承重，沿用 `dir92/R1_task92.py:storage_diag`）**：$\gamma{=}0$ **干净口径**（避开 `DEF-90-2` 的 $\gamma m$ 污染），`rel.err` 门限 $\le0.5$。

## 7. 测量对象与**工作例**（开跑前手算，冻结）

**测量对象**：`acc_held` = 留出 16 条事实上、4 候选（`N_CAND=4`）按**题**准确率；`n_q=16`，粒度 $1/16=0.0625$，机会 $0.25$。

**工作例（逐个手算，非估计）**

| 情形 | 应有 `acc_held` | 依据 |
|---|---|---|
| 瞎猜（4 选 1，独立） | $\approx0.25$ | 机会水平 |
| **完美记忆 + 完美读出**（新分割） | **$16/16=1.000$** | 每类在训练集出现过 ⇒ 正确类**可被发出** ⇒ 上界 $=1$ |
| **完美记忆 + 完美读出**（**旧**分割） | **$1/16=0.0625$** | 15/16 的正确答案类**从未在训练集出现** ⇒ 线性读出**不可能**发出（**本卡缺陷的核心**）|
| `INJ` 臂（无记忆、同形注入） | $\approx0.25$（可低于，因注入扰动）| 无内容可读 ⇒ 只能靠先验；`D-120` 实测 `0.021`（旧分割） |
| `MEMR` 臂（值错配） | $\approx0.25$ 或更低 | 记住了**错**的值 ⇒ 与 `MEM` 的差即 $\Delta_{\rm spec}$ |

★ **工作例的可判性检查**：上表"完美记忆"两行**只差分割**，却给出 `1.000` vs `0.0625`（**16 倍**）且后者**低于机会**；这正是 `A93-S2` 要机械复现的量。**若 A93-S2 复算不出 `1/16`，本卡的整个动机不成立，必须停卡。**

**必报量**：`acc_train`、`acc_held`、`margin_train`、`margin_held`、`S90`、`Δ_content`、`Δ_spec`、`Δ_inj`、`div`、`viol`、`write_calls`。
