## §1 主假说与证伪条款（**阻断门**）

### §1.1 主假说 `H105`

> 在 `white` 键（上界臂，内容 `D-128` 已判 31–32/32）、`W` 冻结、**训练全部 32 事实**的同一装置上，
> 「身份不可达」（`D-131`）是**线性相加族**的限制，**不是**结构不可能：
> 把 $\mathcal O_l$ 换成**含乘性乘积项**的非线性族后，`acc_all32` 能到 **`0.99`（=32/32）**，
> 且该读数**不是**读出侧记忆化（由 §2.4 的 `W←W⁰` 对照判定）。

**为什么这条假说有机制依据、而不是「试试更大」**：`D-131` 的机制是「**`y` 线性不含答案身份**」，
`D-133` 的机制是「`c` **携带身份、不含值**」。任务要求的运算是「**用 `c` 里的身份去选 `y` 里的值分量**」——
这在数学上是 $c$ 与 $y$ 的**乘积**（双线性），而线性相加族 $W_o y+W_c c$ **在原理上无法**表达乘积。
⇒ 乘性门控是**与已定位瓶颈同构**的最小结构，不是盲目加容量。

### §1.2 证伪条款 `F105`

> 若**所有**非线性族（`gate`、`mlp1`）在**所有**测试预算（`steps ∈ {600, 3000}`）上
> 都**未能**同时满足 §2.1 的 `M105-1` **与** `M105-2`（即：要么 `acc_all32 < 0.99`，
> 要么虽 `≥0.99` 但 `acc_W0 > 0.50` 判为记忆化）
> ⇒ **`H105` 否证** ⇒ 判 **`C105-NL-NOT-ENOUGH`**，
> 且 `§7.2-7b` 的**剩余缺口 ① 关闭（负向）**，缺口只剩「真实任务收益」一项。

★ **`SUCCEEDED` 规则**：只有 `H105` 被**确认**才 +1；否证则本轮**不增不减**（round standard）。

### §1.3 两个子问题（**都测**，各自报告，但只有 §1.1 进 `SUCCEEDED`）

### §2.4 ★ 手算算例（`A105-9`，**冻结前逐条手算**）

设 `d_model = d_k = d_v = 2`（`R91.make_stack` 传的是 `d,d,d`，故实机三者恒等）。

**(a) `lin` 族**（复算 `D-103` 的 `A103-9`，保持一致）：`W=diag(1,2)`、`Wq=Wo=Wc=I`、`c=(3,4)`
⇒ `q=(3,4)`、`y=Wq... = (3,8)`、`m = Wo y + Wc c = (3,8)+(3,4) = (6,12)`。**须逐位 = 0**。

**(b) `gate` 族**（新）：`g = σ(W_g c)`，`m = W_o (g ⊙ y) + W_c c`。
取 `W_g = I`、`W_o = I`、`W_c = 0`、`c=(3,4)`、`y=(3,8)`：
- `g = σ((3,4)) = (0.9525741268, 0.9820137900)`
- `m = (0.9525741268×3, 0.9820137900×8) = (2.8577223805, 7.8561103203)`

**(c) `gate` 的退化恒等式**（**结构性检查，比数值更硬**）：取 `W_g = 0` ⇒ `g = σ(0) = 0.5` 恒等
⇒ `m = 0.5·(W_o y)`（当 `W_c = 0`）⇒ 与 `lin` 族的 `y` 臂**恰好相差因子 2**。
实测须满足 `‖m_gate(W_g=0) − 0.5·m_lin(y)‖_∞ < 1e-12`。★ 这条能抓住「门控写错了方向/漏乘」这类错误。

**(d) `mlp1` 族**（新）：`h = GELU(W_1 [y;c] + b_1)`，`m = W_2 h`，`GELU(x)=x·Φ(x)`。
取 `c=(0.3,0.4)`、`W=diag(1,2)` ⇒ `y=(0.3,0.8)`；`W_1 = [I | 0]`（只取 `y` 两维）、`b_1=0`、`W_2=I`：
- `Φ(0.3)=0.6179114222` ⇒ `GELU(0.3)=0.1853734267`
- `Φ(0.8)=0.7881446014` ⇒ `GELU(0.8)=0.6305156811`
- `m = (0.1853734267, 0.6305156811)`

**(e) `acc_all32` 的算术**（`N_DRAWS=3`，按题计）：
构造 3 题 × 3 draws，令**每题**的 draws 中「全对」者为 `2 / 1 / 3`
⇒ `hit = 2`（第 3 题只有 3 个 draw 里…. 见下）—— **口径**：
`per[key] = [argmax 选中的候选是否正确, …共 N_DRAWS 个]`；`hit = Σ_key [all(per[key])]`。
例：`per = {0:[T,T,T], 1:[T,F,T], 2:[T,T,T]}` ⇒ `hit = 2`、`nq = 3`、`acc = 2/3 = 0.666667`。
★ 特别核：`per = {0:[T,T,T]}` ⇒ `acc = 1.0`；且 `31/32 = 0.96875 < 0.99`（**阈值不可被 31/32 满足**）。

★ **`A105-9` 四条 (a)(b)(c)(d) + 一卷 (e) 须全部 PASS**，否则阻断正式轮（`toy` 不进判据）。

### §3.3 ★ 新增参数的初始化规则（**冻结，为了让 `A105-1` 能逐位复现**）

> **所有新参数（`W_g`、`W_1`、`W_2`、`b_1`）必须用专属 `torch.Generator(device="cpu").manual_seed(7919 + li + K)`
> 初始化，`K∈{100,200,300}` 按参数名区分；`σ(·)` 用 `torch.sigmoid`；`GELU` 用 `torch.nn.functional.gelu`（erf 精确式）。

**理由（`DEF-103-*` 的直接教训）**：`dir103` 因新增 `W_c` **改变了 RNG 消费顺序**，导致无法与 `dir101` 逐位比对。

## §6 裁决规则（**离线、可重算**）

对每个 `(family, steps)` 组合，取两 seed：

1. **达线** ⟺ 该组合**两 seed 都** `acc_all32 ≥ 0.99` **且** `acc_W0 ≤ 0.50`。
   ★ 两 seed 都要（`D-133` 先例：单 seed 31/32 而另一 seed 28/32）。
2. `H105` **确认** ⟺ **至少一个非线性组合**（`gate` 或 `mlp1`，任一 `steps`）达线。
3. `H105` **否证** ⟺ 所有非线性组合均未达线 ⇒ **`C105-NL-NOT-ENOUGH`**。
4. **其他标签**：
   - `C105-NL-REACHED`：`H105` 确认（计数 +1）。
   - `C105-MEMORIZED`：某非线性组合 `acc_all32 ≥ 0.99` 但 `acc_W0 > 0.50`
     ⇒ **达线失败**，且**必须**在 `VERDICT` 里明写「这是读出侧记忆化，不是记忆检索」。
   - `C105-BUDGET-ONLY`：仅 `lin@3000` 达线、非线性均未达线
     ⇒ `H105` 按 §1.2 **仍判否证**（主假说讲的是**非线性**），但 `VERDICT` **必须**同时记
     「缺口 ① 的**预算轴**已被解释、**非线性轴**为负」——**这是允许的、也必须如实报的组合结果**。
5. 若某格删失/窗口外 ⇒ 该组合**不得**判达线（`loop.md`：删失不算）。

## §7 边界（**不可外推**，逐条预注册）

1. **不得**外推为「非线性 `\mathcal O_l` 在 v2.4 里可行」——v2.4 §2.2 原文明写
   「更复杂的记忆读取算子**不进入本版核心**」⇒ 若非线性达线，结论是
   **「v2.4 核心之外的读出结构能达线」**，**不是**「v2.4 核心能达线」。
2. **不得**外推为「记忆检索成立」——本卡测的是 `acc_all32`（**容量**、训练键=全部 32），
   **不是泛化**；`M105-2` 只排除了「写下的记忆完全没承重」，**没有**证明它泛化。
3. **不得**外推为「`D-133` 被推翻」——`D-133` 的判决覆盖**线性相加族**，本卡不改它；
   `A105-1` 反而是对它的**复现确认**。
4. **不得**把 `acc_all32` 与 `acc_held` 混报——本卡**不测** `acc_held`（16 训/16 留出）。
