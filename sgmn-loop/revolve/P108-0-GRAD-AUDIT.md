## 1 判据（事先定死，本文件不另设阈值）

被清查的错误推理只有一种，记作 **(b) 类**：

> **由梯度（或梯度范数、`|grad|max`、`‖∇θ‖`）的大小，推断「该参数被训练过 / 未被训练 / 位移了多少」。**

其余两类是**合法**的，不计入错误：

- **(a) 活性 / 契约 / 结构性断开**：只断言梯度**非零、有限、为 `None`、恰好 `≡0`**，
  或断言 autograd 通道**是否连通**。这是 `§7.2`「集成接口验收」四项之一
  （「读取参数的非零有限梯度」）的**法定**读法，**不涉及幅度比较**。
- **(c) 方向 / 信息量**：断言梯度**指向哪里**（夹角、`cos`、`ρ_desc`），或断言**监督信号是否覆盖某个目标**。
  方向与覆盖是**可辩护**的机制论证，与幅度无关。

**(b) 与 (a) 的分水岭**：**是否做了跨臂的幅度比较，并用它替代位移量**。
单点「非零有限」是 (a)；「A 的梯度比 B 小 4–5 个数量级 ⇒ A 没学起来」是 (b)。
