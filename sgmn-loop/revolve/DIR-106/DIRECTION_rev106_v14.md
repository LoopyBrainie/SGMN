## §1 主假说与证伪条款（**阻断门**）

### §1.1 主假说 `H106`

> **`W_o: y→m` 的留出泛化失败是样本效率问题，不是结构性不可泛化。**
> 即：保持装置、键臂、写规则、读接口族**全部不变**，只把**已训练事实数** `n_train` 从 16 抬高，
> `acc_held` 会离开地板并达到 `D-91` 已冻结的 `GATE_GEN = 0.50`。

### §1.2 证伪条款 `F106`

> 若在 `n_train = 28`（最有利样本量）上 `acc_held < 0.50`，**并且**
> 四个样本量点上 `acc_held(n) ≤ CHANCE + 2·SE(n)` **全部**成立，
> 则 `H106` **否证** ⇒ 判 **`C106-NO-GENERALIZATION`**（结构性不可泛化）。

### §1.3 第三支（**必须预注册，否则会是第四次「改写缺口」**）

> 若 `acc_held` 随 `n_train` 上升、但 `acc_held(28) < 0.50`；或 `acc_held` 曲线**非单调**，
> 则 `H106` **既不确认也不否证** ⇒ 判 **`C106-PARTIAL`**，
> `§7.2-7b` **维持 `不足`**，只登记曲线与其机制。
> ★ **禁止**把「有上升趋势」追认为「可达」；**禁止**在 `C106-PARTIAL` 下把该行记 `已足够`。

## §2 MVP 标准（**最小可判定工件 + 数值阈值**）

**MVP 工件**（最小足以结题者）：
`dir106/out/stage_formal.json` —— 一张 `acc_held` 对 `n_train` 的表（4 个点 × 4 划分 × 3 seed，池化），
外加 **`n_train=32` 的可学性上界臂**（§5 `A106-2`）与 **`W←W⁰` 内容对照臂**。
此工件足以在 §1 的三支之间**离线、机械**地判定。

### §2.1 阈值（**全部沿用已冻结值，不新造**）

| 量 | 值 | 出处 |
|---|---|---|
| `CHANCE` | **0.25** | `D-91` / `probe91_womap.py`：`CHANCE = 1.0 / N_CAND`，`N_CAND = 4` |
| `GATE_FIT`（`acc_train` 下限） | **0.50** | 同上，`probe91_womap.py` §1 冻结门 |
| `GATE_GEN`（`acc_held` 下限） | **0.50** | 同上 |
| `GATE_LOW`（「贴地板」判定） | **0.25** | 同上 |

★ **本卡不新增任何阈值**：`M106-1` 用 `GATE_GEN`、`M106-2` 用 `CHANCE`，都是 `D-91` 早已冻结的常量。

### §2.2 主判据（**封闭定义域**，`n_train ∈ {16,20,24,28}` × 4 划分 × 3 seed）

- **`M106-1`（可达性）**：池化 `acc_held(n_train=28)` **≥ 0.50**。
- **`M106-2`（样本效率单调性）**：池化 `acc_held` 关于 `n_train` 的 4 点序列**严格递增**
  （等价判据：Spearman `ρ = 1.0`，且最小步长 `> 0`）。

★ **池化口径（冻结）**：每个 `(n_train, 划分)` 的留出题全部并入同一分母；
**不得**按 seed 分别判（那会退化为 4–16 题的小样本噪声）。

### §2.3 副判据（**report-only，不进判决**）

`acc_train(n)` 曲线、`margin_held`（留出集 top-1 与次优的 logit 差）、
`W_o` 的有效秩、`N_hit^v(n)`（应与 `n` 无关，因为写侧全 32 都写了 —— 若不是，说明写阶段被污染）。

### §2.4 ★ 手算算例（`A106-11`，**冻结前逐条手算**）

1. `CHANCE = 1/4 = 0.25`；`GATE_GEN = 0.50` ⇒ 池化 `acc_held(28) = 0.50` 恰在线上 ⇒ **判 PASS**（`≥`）。
2. 池化题数：`n=16` ⇒ `4 划分 × 16 题 = 64`；`n=20` ⇒ `4×12 = 48`；`n=24` ⇒ `4×8 = 32`；`n=28` ⇒ `4×4 = 16`。
   ⇒ `acc_held(28) = 0.50` ⟺ **8/16 题**；`acc_held(16) = 0.25` ⟺ **16/64 题**。
3. `2·SE` 的算法（冻结，二项近似）：`SE(n) = sqrt(p̂(1−p̂)/N_ho(n))`，其中 `p̂ = acc_held(n)`、`N_ho(n)` 见第 2 条。
   在 `p̂ = 0.25`、`N_ho = 16` 时 `SE = sqrt(0.25·0.75/16) = 0.1083` ⇒ `CHANCE + 2·SE = 0.4665`。
   ★ 注意：该门随 `p̂` 变动（**比率型判据**），故 `A106-5` 要求**实测零假设**而非套用此式 —— 见 `DEF-96-08` 的教训。
4. `M106-2` 的 Spearman：4 点严格递增 ⇒ 秩相关 `ρ = 1.0`；若任一步长为 0 ⇒ `ρ < 1.0` ⇒ FAIL。
5. 若 `n=32`（`A106-2` 上界臂）`acc ≥ 0.90` 而 `n=28` 的池化 `acc_held` 仍 `≤ 0.25` ⇒ 可学性成立但泛化不成立 ⇒ `C106-NO-GENERALIZATION`。

### §3.2 自变量（**本卡唯一改动**）

**`N_TRAIN_KEYS`：从硬常量改为自变量**，取 `n_train ∈ {16, 20, 24, 28}`。

- 划分规则（冻结）：`order = 由 seed 决定的固定置换`；`tr = order[:n_train]`、`he = order[n_train:]`。
  ★ **`order` 的生成必须与 `n_train` 无关**（同一 seed 下，`n=16` 与 `n=28` 用的是**同一个** `order`），
  否则曲线混合了「划分不同」与「样本量不同」两个变化。
- **每 `(n_train, seed)` 额外取 4 个独立划分**（`split ∈ {0,1,2,3}`，以 `seed*100+split` 派生置换），
  以把 `n=28` 时仅 4 题的粗分辨率摊薄（§2.4 第 2 条）。
- **`n_train = 32` 只作 `A106-2` 可学性上界臂**，**不进** `M106-1`/`M106-2`（其 `he` 为空集）。

### §3.3 ★ 新增的**唯一**实现改动（其余零改动）

1. `N_TRAIN_KEYS` 由常量改为参数，并在 `RES` 里记录实际值。

## §6 裁决规则（**离线、可重算**）

```
读 out/cells/*.json → 按 (n_train, split, seed) 分组
池化 held 题：正确数 / 总题数  (分母见 A106-9)
M106-1 = 池化 acc_held(28) >= 0.50
M106-2 = Spearman(acc_held, n_train) == 1.0 且 min(步长) > 0

if A106-2 FAIL                              -> UNTESTABLE      (不进判决)
elif M106-1                                 -> C106-REACHABLE  (H106 确认, SUCCEEDED +1)
elif 所有 n: acc_held(n) <= CHANCE + 2*SE(n) -> C106-NO-GENERALIZATION (H106 否证)
else                                        -> C106-PARTIAL    (§7.2-7b 维持 不足)
```

★ **`C106-NO-GENERALIZATION` 的闭合后果（**预注册**，`D-127` 的教训：否证 ≠ 该行已足够）**：

- 它是**一次有效计算**的否证，**不是**「从未计算」。因此它**替换**`§7.2-7b` 原有的
  「`D-108` `INCONCLUSIVE-ARM-INVALID`（判据从未被有效计算）」这一空白状态。
- 但 `§7.2-7b` 记 `已足够` 还需**额外**满足：本卡 §7 的边界表明「在 `white` 上界臂 + oracle 查询 + 线性 `W_o`
  这一最优条件下都不泛化」⇒ 任何**更弱**的合法配置也不可能更好（单调性论证，须在 §7 逐条写清）。
- ★ **若该单调性论证不成立**（即存在本卡未覆盖的合法配置），则**不得**记 `已足够`，
  须在 `VERDICT.md` 明写「还差哪一条」并新开方向。

## §7 边界（**不可外推**，逐条预注册）

1. **不得**外推到真实近共线键族（`D-114` `cos` 中位 `0.997`）：本卡用 **`white` = 上界臂**。
2. **不得**外推为「SGMN 读接口不可实现」：本卡只测 `W_o: y→m` **线性、共享、无 `c`** 这一族。
3. **不得**把 `acc_held` 的改善当作「真实 LLM 任务收益」：本卡是 **KVR 合成任务**，
   `D-108` 的 `INCONCLUSIVE-ARM-INVALID` 仍需真实任务另立方向。
4. **不得**在 `C106-PARTIAL` 下把 `§7.2-7b` 记 `已足够`（§1.3）。
5. **不得**用 `n_q` 很小的单点（如 `n=28` 的 4 题）单独下结论：必须用 §2.2 的**池化**口径。
6. **不得**说「v2.4 的键生成是错的」：`white` 是本实现的外置键臂（`D-98` 边界）。
7. **不得**把 `A106-2` 的 `acc ≥ 0.90` 读成「7b 已解决」：它只证明「给定样本足够时映射可学」，
   是**上界臂**，不是任务收益。
8. **不得**在 `n_train=32` 上计算 `acc_held`（`he` 为空，`A106-12`）。
9. **不得**把本卡的 `acc_train` 与 `D-130` 的 `0.9375` 逐位比较：`DEF-105-05` 的教训 ——
   只有**有余量**的量才可主张逐位复现，本卡只判**分支**（`A106-1`）。

## §14 结题缺陷（**判据量本身取错对象** —— 卡片最致命的一条，不追认）

**`DEF-106-13`（★★ 致命，本卡据此判第三态）**：`M106-1` 是 **CEIL 死臂**。

- **结构上界核算**（开卡时**漏做**）：`acc_held` 用 `acc_by_question`（同题 `N_DRAWS=3`

  ⇒ 即使 `W_o` 完全不泛化，**仅靠覆盖度**也会造出上升曲线
  ⇒ **`M106-2`（严格递增）亦不可解释**；本卡「唯一自变量 = `n_train`」的前提**不成立**。
- **经验核**：48 格中 **47 格**满足 `acc_held ≤ class_seen_frac_held`，唯一例外
  （`n=16,split=0,seed=7777`：0.125 vs 0.0625）是 16 题里多对 1 题的偶中；
  全网格单格最高 `acc_held` 仅 **0.25**。
- **本应加而没加的 Stage A 守卫**：`class_seen_frac_held(n) ≥ GATE_GEN`（全 `n`）——
  不满足则该臂作废、不得进判决。

  留出 16 条里 15 条答案类未出现、上界 0.0625 < 机会 0.25）→ **本轮 `DEF-106-13`**。
  `D-121` **当时已修好这个问题**（上界 0.0625 → 1.0000），本轮**又把坑踩了一遍**。
