## §3 机制（不只是数字）

### 3.1 直接机制：**键冗余**让每一臂都变差，但**前重比后重变得更差**

1. $\varphi = 0.9$ 的实现是**边缘精确匹配**的 AR(1)（实测 $\bar\rho_u = 0.899979$，卡 A26S-4 的下界 $0.85$ 满足）⇒ ⇒ 同一条目**相邻轮次**的抖动高度同向（lag-1 相关 $0.90$）。
2. 抖动同向 ⇒ 相邻轮次写出的**键彼此冗余**（同样的抖动方向重复出现）⇒ ⇒ 每个条目**有效独立键数**变少 ⇒ **六臂的分离度全部显著下降**（§2.3，六臂 $\Delta\mu$ 全部显著为负）。
3. 但下降**不是等量的**：前重 $F$ 掉 $0.003498$，后重 $K$ 掉 $0.002637$ ⇒ $F$ 掉得**更多** ⇒ ⇒ $\mu_K - \mu_F$ **变大**。

### 3.2 为什么"后重"在相关输入下相对占优（**观察层面的解释，不是已证因果**）

- 因为配额被夹在 `cnt0`，两档**写入的位置数完全相同**（`cnt_source == frozen_cnt0` 全真、A26S-8/9 全 PASS）⇒ ⇒ 差异**不可能**来自"写了多少次"，只能来自**键的内容**。
- AR(1) 的作用集中在**轮次 1–3 相对轮次 0 的偏离**（$g_{i,0} = U_{i,0}$ 两档逐位相同）⇒ ⇒ 相关性把"后几轮"的信息**向第 0 轮拉回**。
- 前重 $F$ 把写入**铺在靠前的轮次**，其信息本来就与第 0 轮接近 ⇒ $\varphi$ 再把它拉近 ⇒ **边际损失更大**；后重 $K$ 的写入靠后，本来离第 0 轮远，被拉回后**仍有残留差异** ⇒ 损失更小。
- ★ **这条"为什么"是解释性假设**，本轮**没有**做逐轮分解（见 §4 未测项）。可判定的只有 §2.3 的两个数字 $\Delta\mu_F$、$\Delta\mu_K$。

### 3.3 副产物：`B` 臂（$\tau$ 门控）塌得最狠，但它不是判据

- $\Delta\mu_B = -0.010031$，是六臂中**最大**的（$F$ 的 $2.87$ 倍）；同时 $\bar q$ 从 $9.266$ 掉到 $8.347$（$-9.92\%$）。
- 这与 **D-47**（"AR(1) 在**读侧**上 CORR-SENSITIVE、`tau` 臂塌陷"）**方向一致**，但 ★ **本轮不能用它解释 $\Delta G$**：判据臂 `Fu`/`Ku`/`Uu` 的写入配额取自**冻结的 `cnt0`**，与 `B` 臂的实时发行数**无关**（卡 §6-2 的设计目的正是切断这条混淆）。$\bar q$ 只是**报告量**。

## §6 rev 2.1 的**设备护栏订正**（DEF-26S-20）与证明义务

### 6.1 发生了什么

rev 2.0 正式轮在**第 90 行**被一条**继承来的**断言杀死（继承自 `dir26k/R1_gating12.py` 的 `measure_hit`）：

```
assert (m["mu"] > 0) == (m["ret1"] > 0.5), f"符号与命中不一致：{m['mu']} / {m['ret1']}"
AssertionError: 符号与命中不一致：0.005133817973546684 / 0.49375
```

### 6.2 为什么它是**缺陷**而不是数据问题

- $\mu$ 是 $160$ 个 $m_{i,\rho}$ 的**均值**，`ret1` 是**命中比例（多数）** ⇒ **均值符号 $\ne$ 多数符号**。

- ★ 该断言的 docstring 还声称"$\mu>0 \iff \arg\max$ 命中 ⇒ 与 `ret1` **逐位一致**"——**这个声称本身是错的**。
- ★ **判据输入未被触碰**：崩溃在 `P` 臂（**报告臂**）；$G_O/U0_O/R_O$ 来自 `Fu`/`Uu`/`Ku` 的 $\mu$ 均值。
