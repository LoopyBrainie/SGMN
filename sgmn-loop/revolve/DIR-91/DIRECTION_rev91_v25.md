# DIR-91 · rev 2.5（`DIR-91-rev2.6`）— **值编码的可辨识性**：是「块均值」还是「`$P_v$`／层选」抹掉了答案身份？

> 派生自 `D-105`（`FIT_ONLY`）的**承重读数**：M2 岭回归 `$V\to$`27 类 **LOO top-1 = 0.031–0.062**
> （chance `1/27≈0.037`），而**样本内 = 1.000**。本卡回答**为什么**。
> **不训练读侧、不写预算、不重测寻址/存储**（`D-103`/`D-104` 已否证）。

---

## §0 · 两条**开跑前**的结构事实（决定本卡形状）

### 0.1 `$P_v$` 是**随机方阵** ⇒ 它在数学上**不可能**破坏线性可分性（任务的一个分支被**解析排除**）

`sgmn_module.py:46-49` 实际执行读出（不是注释）：
```python
mk = lambda *s: (torch.randn(*s, generator=gen) / math.sqrt(s[0])).to(device)
self.Pv = mk(d_model, d_v)            # d_model = d_v = 896  (make_stack 传 d, d)
```
⇒ `$P_v\in\mathbb{R}^{896\times896}$` 是**随机高斯方阵**，以概率 1 **满秩**。
⇒ `$h\mapsto hP_v$` 是**线性双射**。双射**保持**线性可分性（至多改变条件数）。
⇒ **"`$P_v$` 抹掉了答案身份"这一分支在测量之前就应被排除**，本卡把它降级为
**需要实测反驳的备用分支**（`A92-07` 用"`$h$` 与 `$hP_v$` 的可辨识性一致"来实测这一断言）。

### 0.2 块是**同一句子的重复** ⇒ 「块均值」= 对 64 个位置求均值，而值 token 只占 **3–4 个位置**

`R2_task91.py:204-221` `build_chunks`：`ids=tok(sent+" ")`，`while len(seq)<64: seq.extend(ids)`，`seq[:64]`
⇒ 每块是**同一句子的循环平铺**，周期 ` = len(ids) ≈ 19`。
`R2_task91.py:332-350` `key_matrices`：`V = (pf @ m.Pv).mean(dim=0)`，`pf` = **该块全部 64 个位置**
⇒ `$v_i = \frac{1}{64}\sum_{t=0}^{63} h_t P_v$`，其中答案 token 只出现在 `$\lfloor 64/19\rfloor=3$` 个位置。
⇒ 答案 token 在均值中的**质量占比 ≈ 3/64 ≈ 4.7%**，其余 61 个位置由**非答案**内容主导
（其中 **nonce 键**能标识"这是哪条事实"、但**不标识答案**——键与值是任意配对的）。
⇒ 这给出一个**可测的替代解释**：`$v_i$` 是**事实特异**（含键）但**非答案特异**的。

## §1 · 主假说与否证条款（**冻结**）

**主假说 `H1`（池化假说）**：答案身份**存在于**值 token 所在位置（`$h_tP_v$`, `$t$` 为值 token 位），
但在 `$v_i$` 的**64 位均值**中被稀释到不可线性辨识。
⇒ **若 `H1` 成立**，架构缺陷定位为 `v2.4 §3.1` 的**取值方式**（`mean over block`），
**不是** `$P_v$`、**不是**层选、**不是**寻址（`D-104`）、**不是**存储（`D-103`）。

**否证条款**：若**值 token 位**的可辨识性也在机会水平（`②<0.40`），则 `H1` **否证**
⇒ 答案身份在这三层的 `$h$` 里**根本不线性可辨**（或不在这些层），缺陷升级到
**层选／`$h$` 的表征**，本卡判 `NOT_AT_TOKEN`。

**次级否证**：若**块均值**本身已可辨识（`①>0.20`），则与 `D-105` 的承重读数**冲突**
⇒ 必须先查我的分解是否错（判 `CONTRADICT`，不得解释为机制）。

## §2 · MVP 标准与**数值门**（冻结，永不改动）

### 2.1 测量对象
对每个事实 `$i$`（32 条）取 `$c_i = $` `owner.index(i)+1`（该事实 run 的第 2 块，与 `key_matrices` 逐字同口径），
在 `MOUNT=[8,12,16]` 三层各取 `$h^{(l)}\in\mathbb{R}^{64\times896}$`（`st._hs_in[l]`，`$\gamma{=}0$`、`no_write=True`，逐位为基座隐态），
逐位置投影 `$z_t = h_t P_v \in \mathbb{R}^{896}$`，`$t=0..63$`。

### 2.2 三个臂（唯一区别 = **对哪些位置取均值**）

| 臂 | 定义 | 角色 |
|---|---|---|
| **① `mean_all`** | `$\frac{1}{64}\sum_{t=0}^{63} z_t$` | **复现 `D-105` 的 `$v_i$`**（装置现状） |
| **② `vt_pos`** | `$\frac{1}{\lvert\mathcal{V}_i\rvert}\sum_{t\in\mathcal{V}_i} z_t$` | **主假说臂**：值 token 位 |
| **③ `nonvt`** | `$\frac{1}{64-\lvert\mathcal{V}_i\rvert}\sum_{t\notin\mathcal{V}_i} z_t$` | 阴性对照：非值位 |

`$\mathcal{V}_i$` = 该块中**值 token 所在位置集合**，用 **offset-mapping 精确定位**（见 `A92-02`），
**不靠**解码字符串猜测。三臂**同一 `lam`、同一正交/去均值、同一 LOO 划分**。

### 2.3 ★★ 判据口径（`CORR-12` 修正：**用天花板可分离的那一份**）

`$\mathrm{LOO}$` 27 类岭回归（与 `D-105` 的 `ridge_scores` **逐字同一实现**，`lam=1.0`，对偶形式）。
32 事实 / 27 值 ⇒ **22 个类是单例**。留一法**不可能**预测一个在其余 31 条中**不出现**的类 ⇒

- **`LOO-32`**（全部 32 条）：**天花板 `=10/32=0.3125`**（恰 5 个类重数 2，`$5\times2=10$`），chance `1/27≈0.037`
- **`LOO-10`** ★ **主判据**：只在 `重数≥2` 的 **10 条**事实上算准确率 ⇒ **天花板 `=1.0`**，chance `1/27≈0.037`

⇒ **主判据 = `LOO-10`**（天花板 1.0，与 chance 0.037 间距最大）。
`LOO-32` 与 `IN-SAMPLE` **必须同时报**（`CORR-12`：样本内只作"记忆 vs 结构"的对照，**不得**承重）。

### 2.4 数值门（**冻结**）

| 门 | 条件（`LOO-10`） | 判读 |
|---|---|---|
| **`G_pool`** | `② ≥ 0.70` **且** `① ≤ 0.20` **且** `③ ≤ 0.50` | **`POOLING`** — 池化是凶手（`H1` 确认） |
| `G_both` | `② ≥ 0.70` **且** `③ > 0.50` | `BOTH` — 上下文也携带，池化非唯一 |
| `G_weak` | `0.40 ≤ ② < 0.70` | `WEAK` — 部分可辨 |
| **`G_none`** | `② < 0.40` | **`NOT_AT_TOKEN`** — `H1` 否证 |
| **`G_contra`** | `① > 0.20` | `CONTRADICT` — 与 `D-105` 冲突，先查缺陷 |

**判决合成规则（冻结）**：对**每个 seed**分别看三层。
`POOLING` ⟺ `G_pool` 在三层**全部**成立（两 seed 都是）；若仅 `≥4/6` 成立 ⇒ `POOLING_PARTIAL`；
否则按 `②` 的三层中位数落 `G_none`/`G_weak`/`G_both`。

## §5 · 边界（不得外推）

1. 只测**线性**可辨识性（岭回归）。`②<0.40` **不得**推"任何非线性读侧都不行"。
2. 只在 Qwen0.5B 的 `[8,12,16]` 三层、64 token 块、32 条 nonce 事实上测。
3. `LOO-10` 只有 **10** 个样本（每事实 0.1）⇒ 单 seed 单层的粒度是 0.1；判读一律用**两 seed × 三层**合成。
4. **不得**由本卡推"改取值方式即可泛化" —— 那需要另开一轮端到端重测（`D-103`/`D-104` 已证寻址/存储不是瓶颈，
   但"位置选择性取值"的端到端收益**本卡不测**）。
5. **不得**把 `②` 高解读为"装置已能检索答案"：`②` 用的是**测试时不可得**的"值 token 在哪"这一位置标签。
