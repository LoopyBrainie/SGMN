## §1 主假说与**否证条款**

**`H1`**：写侧 `k` 的池化方式（`sgmn_module.py:86` 的 `.mean(dim=0)`）是**残余瓶颈**。
具体可测形式：把 `k` 由「64 位均值」改为「值 token 位」后，
1. **键变得可分**（`cos(k_i,k_j)` 中位数由 `0.997` 显著下降），且
2. **完整读通路的 `acc_held` 由 ≈`0` 抬起**（`≥ G_GEN = 0.50`，两 seed）。

**否证条款（`CORR-13`：机理措辞须自带可推翻的对照）**：若 `K_vt_V_mean`、`K_vt_V_vt`
两臂的 `acc_held` 在两 seed 上**均 ≤ `G_LOW = 0.25`**，**且** `M1b(K)` 仍在噪声底
（`≤ G_ABSENT = 0.15`）⇒ **`H1` 被否证**：键池化不是瓶颈，须另找（`P_k` 本身 / `d_k` / `α` / `η`）。

## §3 测量对象与**工作算例**（必须先对一个具体例子核过）

唯一独立变量 = 写侧池化规则**对** `(k_rule @ line 86, v_rule @ line 87)`：

| 臂 | line 86 `k` | line 87 `v` | oracle |
|---|---|---|---|
| `K_mean_V_mean` | `pk_raw.mean(0)*s` | `zv.mean(0)` | 无（**原生**） |
| `K_mean_V_vt` | `pk_raw.mean(0)*s` | `zv[idx].mean(0)` | `v` 位 |
| **`K_vt_V_mean`** | `pk_raw[idx].mean(0)*s` | `zv.mean(0)` | `k` 位 |
| **`K_vt_V_vt`** | `pk_raw[idx].mean(0)*s` | `zv[idx].mean(0)` | `k`+`v` 位 |
| **`K_last_V_mean`** | `pk_raw[-1]*s` | `zv.mean(0)` | **无（可实现）** |

其中 `pk_raw = sg(pf @ Pk)`、`s = pk_scale`、`pf = prev_hs.reshape(-1,d)`、
`zv = sg(hf @ Pv)`、`idx` = 值 token 在 64 位块内的位置集（`value_positions`）。

★ **算序纪律（`CORR-19` 规则 ③ / `DEF-93-02`）**：`K_mean` **必须**保持原式
`pk_raw.mean(dim=0) * s`（**先均后乘**），不得写成 `(pf@s).mean`；否则浮点重排会在
600 步写入中累积差异。`K_vt` 必然是另一算序 ⇒ 只与自身直接复算比，**不与 `K_mean` 比**。

**工作算例（`A98-00` 承重）**：patch 内的 `write` 把当次实际使用的 `(k, v)` 记入 `REC`；
对第 0 号事实的第一块，用**同算序**从捕获的 `prev_hs`/`hs_in` 复算三者，断言与 `REC` **逐位相同**。

# §7 rev **3.5.1** —— 只更正判决表 branch-3 的**辖域**（阈值一字未改；`v35` 原文留档不改）

**事由（`DEF-98-01`）**：`v35` §5 branch-3 的条件写成
`all(d[a]["M1bK"] >= G_AVAIL for a in NEW_ARMS)`，即要求**每一条**新臂都把「值身份」放在键上。
但本卡 §3 明确 `K_last_V_mean` 的角色是「**唯一可实现**的臂，末位是固定规则、无需 oracle」——
它测的是**可分性**，**没有任何理由**认为末位就是值 token 位。要求它也满足 `M1bK ≥ G_AVAIL`
是**范畴错误**：实测它 `M1bK = 0.0104 / 0.0208`（正确地不携带值身份），
于是整条 branch-3 被一条**不该参与该条件**的臂否掉 ⇒ 把决定性读数误判成 `INCONCLUSIVE`。

**更正（只改辖域，不改阈值、不改分支顺序）**：
`all(... M1bK >= G_AVAIL ...)` → **`any(... M1bK >= G_AVAIL ...)`**
理由：待验证的命题是「键**既**可分**又**带值身份，却仍读不出来」，
该命题只需**至少一条**臂同时满足两个性质；不需要每条臂都满足。
`G_GEN = 0.50`、`G_LOW = 0.25`、`G_DELTA = 0.125`、`G_ABSENT = 0.15`、
`G_AVAIL = 0.28125`、`COS_SEP = 0.90`、`COS_NATIVE = 0.99` **全部未变**。

**两版判决并列留档**（`dir91/rejudge98.py` 用**同一份已落盘读数**同时算两版；不重跑实验）：

## §8 rev 3.5.1 的一句话结论（供证据行引用，措辞不得加强）

**写侧不是瓶颈。** 把键抬到「值身份 = 结构上限」（`M1b(K) = 0.3125 = CAP_LOO`）**且**
把键几何从 `cos` 中位 `0.996` 拉开到 `0.650`（`K_last` 更到 `0.454`），
**甚至把键与值同时抬到上限**（`K_vt_V_vt`：`M1b(K) = M2loo = 0.3125`），
`acc_held` 仍然**逐臂逐 seed 全为 `0.0000`**；而 `acc_train` 达 `0.875`、
`margin_held = −5.66 … −8.61`（**自信地答错**）。
⇒ 残余瓶颈在**读出的泛化**（cue→query→决策 对未见事实不迁移），
**不在记忆内容**。⇒ `D-114` 的写侧诊断**必要但不充分**：修到上限也无改动。

**`DEF-98-02`（confound，必须并列）**：vt 池化使 `‖k‖` 由 `≈62` 降到 `≈36`
（`A98-05`：mean `60.53` / vt `24.61` / last `28.65`），`k` 以二次进入
`G = α(Wk−v)kᵀ` ⇒ 写入步变弱。这**可能**解释 `K_vt_*` 在 seed 20261028 的
`acc_train` 降到 `0.6875`。★ 但它**不能**解释主读数：`acc_held = 0.0000`
**同样出现在 `acc_train = 0.875` 的 `K_vt_*`（seed 7777）与 `K_mean_*` 两臂上**。
⇒ 主结论不受该 confound 影响；**`acc_train` 的下降不得归因于可分性**。
