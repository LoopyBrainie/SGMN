## §1 · 主假说 / 否证条款 / 机理措辞（`CORR-13`）

**H1（主假说）**：`v` 的**取值方式**（对块内哪些位置、以什么权重求和）是当前端到端的**约束**；
把均匀块均值换成**位置选择性**取值，能提升**留出键**上的按题准确率 `acc_held`。

**否证条款**：若两 seed 下 `B`（键条件注意力）与 `C`（逐维 max）**都没有**使
`acc_held` 同时满足 `≥ G_gen` 与 `≥ acc_held(A) + G_delta`，则 H1 **被否证**（见 §2.3 分支）。

**机理措辞（写入证据行时照此）**：值身份**位置局限**（`D-106`：只在 `d∈{0,+1}` 可辨），
而块均值**只保留位置分布内容**；故把取值改为**位置选择性**应能把它取回来。

### §1.2 ★★ `CORR-13` 强制：本机理措辞**自带可推翻的对照**（进臂表 + 数值门）

`CORR-13` 规定：机理措辞必须配一条**能把它推翻**的对照。本轮配的是 **臂 `D`（`vt_pos` oracle）**：

- 臂 `D` = 用**已知的真实值 token 位置**取 `v`（`v = mean_{t∈V_i} z_t`），是"位置选择性"的**上界实现**。
  它用**测试时不可得**的位置标签 ⇒ **不可实现配置**，只作**上界诊断**（与 `D-104` 的 `oracle` 同性质）。
- **对照门 `G_ctrl`（冻结）**：若 **臂 `D` 在 `acc_held` 上也达不到 `G_gen`**，则
  **§1 的机理措辞被否证** —— 即使 §2.3 判出 `HELPS`，证据行**也不得**写"取值算子是瓶颈、已被修复"，
  只能写"某条可实现规则有增益，但位置选择性机理**未**被上界证实"。
- 反向不成立：`D` 达标**不**证明 H1 成立（`D` 不可实现），只证明机理**未被推翻**。

### §1.3 报告项（非门控）：`E` = `vt_pos` + `q`-oracle 的**叠加上界**

用于消除本轮无法回避的混杂：若 `D`（只修 `v`）不达标而 `E`（修 `v` **且** 完美寻址）达标
⇒ 说明**值通道与寻址同时**受限，`D` 的失败**不能**单独归因于取值方式。
`E` **只报告、不参与判决**，且其量级受 `DEF-91-33` 类混杂（常量偏置）影响，须照 `D-105` 的边界写法限定。

## §2 · MVP 标准（**最小足以裁决的产物**）与数值门（冻结）

**MVP 标准**：同一 seed 内、**同一初值**、**同一数据顺序**、**同 600 读步**下，
5 条臂各自从"用该臂 `v` 规则写完 600 块"的状态出发，只训练**读侧**，
给出 `acc_train`/`acc_held`（`n_q=16`，`N_CAND=4`，chance `0.25`）。
**最小产物** = `dir91/out/probe91_valread.json` 的 10 行（5 臂 × 2 seed）读数 + `VERDICT`。

### §2.1 主判据量
`acc_held` = **留出键**（`N_TRAIN_KEYS=16` → 另 16）上的**按题**准确率，
`acc_by_question` 口径（同题 `N_DRAWS=3` 次**全对**才算命中），与 `D-105` **逐字同口径**。
同时报 `acc_train`（拟合）与 `acc_item`、`margin`。

### §2.2 数值门（**冻结**；全部沿用 `D-105` 已冻结的常数，**不新造**）
| 门 | 值 | 来源 |
|---|---|---|
| `G_gen` | **0.50** | `D-105` 的 `GATE_GEN` |
| `G_low` | **0.25** | chance（`1/N_CAND`），`D-105` 的 `GATE_LOW` |
| `G_delta` | **0.125** | `D-103`/`D-104` 已用的最小可辨差 |
| `G_partial` | **0.375** | `= G_low + G_delta`（派生量，非新常数） |

### ★ `CORR-12` 天花板先验算（**开跑前**已核，写死）
4 选 1 候选选择任务：候选取自其余事实的值，**不要求**预测训练中未出现的类
⇒ **`acc_held` 的天花板 = `1.0`**（无单例类问题，与 `D-106` 的 27 类 LOO 不同）。
故 `G_gen = 0.50 ≤ 1.0` ⇒ **门未设在天花板之上**（`CORR-10`/`DEF-91-38` 的教训）。
`G_delta = 0.125` 在 `G_low=0.25` 之上仍 ≤ 天花板。

### §2.3 判决分支（冻结，四分支互斥且穷尽）
记 `A = acc_held(A_mean)`。
1. **`SELECTIVE_HELPS`** —— **两 seed 均** ∃ 臂 ∈ `{B, C}`：`acc_held ≥ 0.50` **且** `acc_held ≥ A + 0.125`。⇒ **H1 确认**。
2. **`SELECTIVE_PARTIAL`** —— 非 1；且 **两 seed 均** ∃ 臂 ∈ `{B, C}`：`acc_held ≥ 0.375` **且** `acc_held ≥ A + 0.125`。⇒ H1 **部分支持**（记 `FALSIFIED`，不计入 `SUCCEEDED`）。
3. **`NO_HELP`** —— **两 seed 的所有** `B/C`：`acc_held ≤ 0.25`。⇒ **H1 否证**（取值方式不是约束）。
4. **`INCONCLUSIVE`** —— 其余（含两 seed 指向不同分支）。

### §2.4 `CORR-13` 控制门（冻结）
`D_HELPS` ⟺ **两 seed 均** `acc_held(D_vtpos) ≥ 0.50` **且** `≥ A + 0.125`。
- `D_HELPS = False` ⇒ **§1 机理措辞被否证**（约束 §2.3 落在 `HELPS` 时的**措辞**；不改判决本身）。
- `D_HELPS = True` 且 §2.3 = `NO_HELP` ⇒ 记 **`ORACLE_ONLY`**：机理**未被推翻**，但**没有可实现的规则**能取到它
  —— 这是**信息量最大**的落点之一，须在证据行显式标注。

## §3 · 测量对象 + 一个具体 worked example（`§4` 守卫 `A93-03` 断言它）

**测量对象**：`v_arm` = 写规则 `sgmn_module.py:87` 那一行的取值的**唯一替代**。
`zv = sg(hf @ P_v)`（`hf` = 本块 `hs_in`，展平 `(N=64, d_v)`），`kp = sg(pf @ P_k) * pk_scale`，
`k = kp.mean(0)`（**与原装置逐位相同**）。五臂：

| 臂 | `v` | 可实现？ |
|---|---|---|
| `A_mean` | `zv.mean(0)` | ✔（**装置现状**，复现 `D-105`/`D-106`） |
| `B_attn` | `Σ_t a_t zv_t`，`a = softmax_t( √d_k · cos(kp_t, k) )` | ✔ |
| `C_max` | `zv.max(0).values`（逐维 max） | ✔ |
| `D_vtpos` | `zv[V_i].mean(0)`（**真值 token 位**） | ✘ **上界诊断**（测试时不可得位置标签） |
| `E_vtpos_qor` | 同 `D`，且读通路 `q ← k_i`（仅读出位） | ✘ **叠加上界** |

`B` 的 `a`：**标准 scaled dot-product 作用于单位化向量** = `softmax(√d_k · cos)`，
**无温度超参、无调参**（`C`/`A` 同样无参）。`B` 是**一条**特定可实现规则，结论只对它成立（§6）。

**worked example（`A93-03` 逐条断言，在**一条**具体事实上打印）**：
取 `fi=0` 的块 `ci=owner.index(0)+1`，单次前向（`no_write=True`）取 `zv, kp, k`，然后：
1. `v_A` 与 `zv.mean(0)` **逐位相同**（`max|Δ| = 0`）⇒ 臂 `A` 复现装置现状；
2. `v_D` 与 `zv[V_0].mean(0)` **逐位相同**（`max|Δ| ≤ 1e-6`），且 `|V_0| = 2`；
3. `Σ_t a_t = 1`（`|Σ-1| ≤ 1e-5`），且 `max_t a_t > 1/64 × 2`（注意力**非均匀**）；
4. `v_C` 与 `zv.max(0).values` **逐位相同**；
5. ★ **退化检查**：`rel(v_arm, v_A) > 1e-3` 对 `arm ∈ {B,C,D}` 全成立
   （`rel(x,y)=||x-y||/||y||`）⇒ 没有臂静默退化成 `A`（`DEF-92-01` 的教训）。
6. `k` 与 `sgmn_module.py:86` 原式**逐位相同**（`max|Δ| = 0`）⇒ **键通道未被改动**（唯一独立变量）。

## §6 · 边界（**不得外推**）
1. **只改 `v` 的取值**：`k` 通道、写规则、`P_v`、`P_k`、层位置**全部未动**；不得据此推"取值方式已解决"。
2. `B` 是**一条**特定可实现规则（`softmax(√d_k·cos)`）；`B` 失败**不得**推"所有位置选择性规则都不行"。
3. `D`/`E` 用**测试时不可得**的位置标签/事实编号 ⇒ **上界诊断，非可实现配置**；不得当作"装置已能检索"。
4. 全程 `γ=0`、Qwen0.5B、`[8,12,16]`、600 读步、16+16 键、27 值池 ⇒ 不外推。
5. `acc_held` 的 `n_q=16` ⇒ 单格粒度 `1/16=0.0625`；判决一律用**两 seed × 五臂**合成，**不得**用单格下结论。
6. `NO_HELP` 只否证"取值方式在**本配置**下是约束"，**不**否证"架构不可救"。
7. **不得**再引 `DEF-91-33` 的常量偏置解释（`D-105` 已推翻）；`E` 的量级须按 `D-105` 边界写法限定。
8. **不得**用「稀释」描述机理（`DEF-92-02` 已推翻其字面含义）。
