## §0 开卡前的前提更正（**必须先读**）

`task.md` 原先把本卡写成「把监督目标从向量回归 `t_j` 换成 4 选 1 CE 任务损失」。**该前提部分不成立**，
在写任何代码前已查明，据实更正如下（**决策留档，非事后追认**）：

1. **CE 任务损失不是未测项。** `dir91/R2_task91.py:289 train_read_task` **本身**就是
   4 选 1 候选 CE（`F.cross_entropy` over `pick_logits`），且 `read_params(st) = [Wq, Wo, gamma]`
   （`R2_task91.py:116`）。`probe91_woform.py:289 run_adam` 调的正是它 ⇒ **`adam16` 就是 `task16`**。
   其已落盘读数（`D-109`/`D-111` 两轮逐位复现）：`acc_train=0.875/0.812`、`acc_held=0.000/0.000`。
2. **`adam16` 是 `§7.1` Freeze C 的忠实实现，而非代理。** 框架原文（`framework/…§7.1` 表 C 行）：
   > 「任务损失只更新读取侧 $\phi^q,\phi^o,\gamma$；$k,v$、读取上下文 $c$ 与读取记忆状态均 stop-gradient；
   > 这不阻断 $\mathcal Q,\mathcal O$ 自身参数训练；冻结基座不更新参数但保留所需输入梯度」
   同节并声明「其中 C 是**必须满足的接口定义**，不是『已通过 EXP-03』的事实陈述」。
   ⇒ 基座**冻结**、读取侧**由任务损失训练** = `adam16` 的形状；**不是**"端到端与 LM 联合训练"。
   ⇒ 故 `ridge16`/`lr{r}`（向量回归代理）与 `adam16`（忠实实现）**两侧都失败**，
   DIR-91 链条的结论**被忠实实现独立支持**，不因"代理不像"而失效。
3. **因此本卡不改"目标形状"作为主问**（那会重复 `adam16`），改判定**瓶颈落在哪一层**：
   `y` 是否携带答案身份（机制门）→ 若携带，再问样本量与目标构造。

## §1 主假说与推翻条款

**H1（主假说）**：`D-111` 剩下的瓶颈是**样本量** —— 即读出向量 `y = sg(W) q` **携带**答案身份，
只是 16 条样本不足以定位共享映射 `M`（`Wo`）；给出更多样本即可泛化。

**推翻条款（falsification）**：若 **`M1` 的 `top1(y_held) ≤ CEIL_LOW`（= 0.25）**
（即：用 `y_train` 岭回归拟合 27 类值身份、判别 `y_held`，命中率不高于 `CEIL_LOW`），
则 `y` **本身不携带可线性读取的答案身份** ⇒ **无论多少样本、无论目标怎么构造都不可能救**
⇒ H1 **被推翻**，判决 `Y_NO_IDENTITY`。

★ 本卡**不**声称"样本多就一定行"，**不**声称"必须非线性"，**不**声称"目标构造一定无用"。
它只判三件事：`y` 有没有身份（门）、共享目标能否救（`M2`）、同值拆分指向哪一侧（`M3`，仅报告）。

## §2 MVP 标准（最小可判定的产物）与数值门（**冻结**）

**MVP 产物** = 每个 seed 四项读数 `M1 / M2 / M3 / M4`，外加 `M0` 跨轮参照：

| 项 | 内容 | 位置 |
|---|---|---|
| **`M0`** | **跨轮参照**：`ridge16`（自由目标 `t_j`）＋ `zero` ＋ `free`。**`ridge16` 必须逐位复现 `D-111`**（`1.000/0.062`、`1.000/0.188`） | 承重（装置未变） |
| **`M1`** | **★ 机制门**：27 类值身份能否从 `y_held` 线性读出。岭回归拟合 `y_train → 值类`，判别 `y_held`；报 `top1`、`CEIL_LOW/HIGH` 判定 | **主判据** |
| **`M2`** | **共享目标**：把自由目标 `t_j` 换成**共享**目标（值 token 的 unembedding 方向、归一化；只有 27 个不同列），重拟合岭回归，报 `acc_train/acc_held` | 次判据 |
| **`M3`** | **同值留出拆分**：32 事实 / 27 值 ⇒ 5 值重复。按"该值是否出现在训练集"拆留出事实，分别报 `acc_held` | **仅报告**（`n` 太小） |
| **`M4`** | **未覆盖网格格**：`{Wo-only} × CE`（冻结 `Wq`、`γ`，只训 `Wo`） | 次判据 |

**冻结的门（与 `D-109`/`D-111` 同口径，一字未改）**

| 常量 | 值 | 含义 |
|---|---|---|
| `G_gen` | **0.50** | "会" 的门（4 选 1） |
| `G_low` | **0.25** | "不会" 的门（4 选 1） |
| `G_delta` | **0.125** | 容差（= 2 题，`n_q=16`） |
| `CHANCE` | **0.25** | 4 选 1 机会水平 |
| **`CEIL_LOW`** | **0.25** | ★ `M1` 的"无身份"门（27 类，机会 `1/27=0.037`） |
| **`CEIL_HIGH`** | **0.50** | ★ `M1` 的"有身份"门 |
| `CEIL_D106` | **0.3125** | 参照：`D-106`/`D-108` 在 `v_i` 上的**结构天花板** `10/32` |

**判决表（冻结）**

| 条件 | 判决 | 含义 |
|---|---|---|
| `M1 ≤ CEIL_LOW` | **`Y_NO_IDENTITY`** | `y` 不携带答案身份 ⇒ H1 推翻，样本量与目标构造**都不是**出路 |
| `M1 ≥ CEIL_HIGH` 且 `M2.acc_held < G_low` 且 `M4.acc_held < G_low` | **`SAMPLE_LIMIT`**（确认） | `y` 有身份，但共享映射在 16 条样本下无法定位 ⇒ H1 **未被推翻** |
| `M2.acc_held ≥ G_gen` | **`TARGET_STRUCTURE`** | 共享目标救得回来 ⇒ 瓶颈是**目标的构造** |
| `M4.acc_held ≥ G_gen` | **`WQ_CONFOUND`** | `Wq` 联合训练是元凶 |
| 其余（`CEIL_LOW < M1 < CEIL_HIGH` 且无臂达标） | **`Y_PARTIAL`** | 部分身份；判"样本量不足以利用部分身份" |

★ **两 seed 必须同支**；不同支则记 `AMBIGUOUS` 并如实报两 seed 读数，**不得**取平均。
★ `M3` **仅报告**：`n_held` 仅 16，其中"值在训练集出现过"的至多 5 条，粒度 `0.2`
⇒ **不作为任何判决的门**，不得据它下判决（`CORR-10` 精神：不得把门设在噪声之上）。

## §3 量测对象（须先对一个具体 worked example 验证非空转）

- **`M1` 的量测对象**：`Y[li]`（`capture_y` 抓到的 `_y_out`，`(n_facts, 896)`）与
  **值类标签** `cls[i] ∈ [0,27)`（该事实的答案在 `VALUE_POOL` 中的下标）。
  ★ 必须**逐位**证明 `y` 不是常量/未捕获：`‖y_i‖` 分布、`y_i` 两两余弦不恒 1。
- **`M2` 的量测对象**：共享目标列 `T_shared[c] = normalize(E_unembed[token(v_c)])`，
  其中 `E_unembed` = 冻结基座的输出嵌入（`model.lm_head.weight`），`token(v_c)` 为该值词的单 token id。
  ★ worked example：**先证明** 在 `t_j := T_shared[cls_j]` 的**合成可解**情形下，
  `M2` 的闭式解能把 `acc_train` 推到 1（否则"共享目标失败"可能只是装置坏了）。
- **`M4` 的量测对象**：`{Wo-only} × CE` 的 `acc_train/acc_held`（同一 `train_read_task`，
  仅把 `Wq`/`γ` 的 `requires_grad` 置 `False`）。★ 必须断言 `Wq`/`γ` **逐位未变**。

## §5 边界（**不得外推**）

1. `free` 用**测试时不可得信息**（逐事实答案）⇒ 上界诊断、**非可实现**；`M0` 的 `ridge16` 只用 16 条 ⇒ 可实现。
2. `M1` 判的是「**线性**可读」；**不得**外推为"`y` 完全不含信息"（非线性可读未测）。
3. `M3` 仅报告，`n` 太小；**不得**据它下判决。
4. `M2` 只测**一种**共享目标形状（值 token unembedding 方向）；**不得**外推为"所有共享目标都无用"。
5. `M4` 只判定「`Wq` 联合训练是否为元凶」这一格；**不得**外推为"CE 任务损失无用"。
6. 只在 Qwen0.5B / `MOUNT=[8,12,16]` / 600 写步 / 32 事实（16+16）/ 27 值池 / `N_DRAWS=3` 下成立。
7. `n_q=16` ⇒ 单题粒度 `0.0625`。
8. **不得**改 `D-103`…`D-111` 任何一行的门与口径；**不得**再引 `D-105` 的"值通道是 `FIT_ONLY` 根因"；
   **不得**再引 `D-108` 的"叠加完美寻址也没用"（已被 `DEF-94-01` 推翻）。
9. 本卡**不**改 `§2.2` 装置、**不**新增架构组件、**不**扩事实池（样本量扫描因"存储负荷共变"而**不做**，
   见 §6）。

## §6 明确**不做**的事（以及为什么）

- **不做事实池扩容 / `n_train` 扫描**：`32→144` 会同时改变「监督样本数」与「`W` 中叠加的事实数」与
  「干扰 SNR」，读数不可解释；且 `W` 的"前 32 条逐位不变"这条守卫**不可满足**
  （写入按 `B` 块均值，加事实会改块构成）。若将来要做，须**固定存储事实数**、只变 `n_train`，
  并把 32/16 那点标为**不同装置**的跨轮参照。
- **不做 `y` 的非线性可读性**：那是另一个问题，需要另开卡。
