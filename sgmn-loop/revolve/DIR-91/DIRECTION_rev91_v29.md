# DIR-91 · rev **2.9** —— 瓶颈是**参数太多**还是**样本太少**？低秩映射 `M = A Bᵀ` 能否只用 16 条样本泛化

> 父版：rev 2.0 / `_r21` / `_r22` / `_r23` / `_v28`（rev 2.8）**全部留档不改**。
> **派生自 `D-109` §七「可分辨的下一问」**，非自造议题。
> ★ **判据在此冻结，此后不得改阈值**；要改须新开 revision，旧版全部留档。

## §1 主假说与推翻条款

**H1（主假说）**：`D-109` 剩下的瓶颈是**参数个数** —— `W_o`（`d_model×d_v = 896×896`）参数太多，
16 条样本无法确定它。**把 `M` 限制成低秩 `M = A Bᵀ`（`rank ≤ r`，`r ≤ 8`）后，同样只用 16 条训练样本，
就能在留出事实上泛化（`acc_held ≥ G_gen`）。**

**推翻条款（falsification）**：若**每一个**能拟合训练集（`acc_train ≥ G_gen`）的 `r ∈ {1,2,4,8}`，
其 `acc_held ≤ G_low`（**两 seed 均如此**），则 H1 **被推翻** ⇒ 瓶颈**不是参数个数**，
参数化不是出路，瓶颈落在**样本量 / 函数形式**一侧。

★ 本卡**不**声称"样本多就一定行"，也**不**声称"必须非线性"；它只判定**参数个数**这一层。

## §2 MVP 标准（最小可判定的产物）与数值门（**冻结**）

**MVP 产物** = 每个 seed、每个 `r ∈ {1,2,4,8,12,16}` 的一组读数
`(acc_train, acc_held, rel_res_train, rel_res_held, rank(M_r), λ, 等效参数数 2·896·r)`，
外加 `zero` / `free` / `ridge16` 三条**跨轮参照**（`ridge16` 必须逐位复现 `D-109`）。

**冻结的门（与 `D-109` 同口径，一字未改）**

| 常量 | 值 | 含义 |
|---|---|---|
| `G_gen` | **0.50** | "会" 的门 |
| `G_low` | **0.25** | "不会" 的门 |
| `G_delta` | **0.125** | 容差（= 2 题，`n_q=16` ⇒ 1 题 = 0.0625） |
| `CHANCE` | **0.25** | 4 选 1 |
| `RIDGE_REL` | **1e-3** | `λ = rel·tr(YYᵀ)/n`（与 `ridge_closed` 逐字相同） |
| `RES_NULL_RATIO` | **0.90** | 次级判据：留出重构残差须比 `ridge16` 改善 >10% 才算"低秩有用" |
| `SEEDS` | **20261028, 7777** | 两 seed |
| `N_TRAIN_KEYS` | **16** | 拟合集只有 16 条；`he` = 其余 16 条，**永不进拟合** |

**分支表（冻结，先判 INSTRUMENT_INVALID 再判其余）**

| 分支 | 判据 |
|---|---|
| **INSTRUMENT_INVALID** | （**抢占**）`r=16` 控制臂未能复现 `ridge16` 的 `(acc_train, acc_held)`（差 `> G_delta`，任一 seed），**或** `A95-02` 的代数恒等式失败 ⇒ 装置无效，本轮**不得**出结论 |
| **RANK_TOO_SMALL** | `∀ r ∈ {1,2,4,8}`：`acc_train < G_gen` ⇒ 秩约束**连拟合都做不到** ⇒ **无法分辨**两假说，**如实报告为不可分辨**（不得算 H1 成立） |
| **PARAM_LIMIT** | `∃ r ∈ {1,2,4,8}`：`acc_train ≥ G_gen` **且** `acc_held ≥ G_gen`（**两 seed 均**）⇒ H1 成立 |
| **SAMPLE_LIMIT** | 拟合窗口非空（`∃ r ∈ {1,2,4,8}: acc_train ≥ G_gen`）**且** `∀` 这样的 `r`：`acc_held ≤ G_low`（两 seed 均）⇒ **H1 被推翻** |
| **PARTIAL** | `r ∈ {1,2,4,8}` 有拟合窗口，但存在 `G_low < acc_held < G_gen` ⇒ 判据落在门之间，不下结论 |
| **BRIDGE_ONLY** | （**报告项，不进分支表**）`r ≤ 8` 全是 `RANK_TOO_SMALL`，但 `r=12` 既拟合又泛化 ⇒ 记明"可分辨窗口 ≥12"，**不计**为 `PARAM_LIMIT` |

## §3 测量对象（先证明非空转）

**与 `D-109` / `D-108` / `D-105` 完全同口径**：读出位（每行 prompt 末位 `b·L+(L−2)`）注入 `m`，
问"4 个候选里哪个是正确值"，`acc_q` 按题聚合，`n_q=16`，`n_item=48`（16 题 × 3 draws），chance `0.25`。
`held` 的 16 条事实**从不进入任何拟合**。

**目标向量 `t_j` 来自 `optimise_free`（`Random(555)`，`STEPS_FREE=120`，`LR_FREE=0.05`）** ——
即"每事实一个自由 896 维向量"的机器输出，与 `D-109` 逐字相同 ⇒ `ridge16` 必须复现 `D-109` 的 `1.000/0.062`、`1.000/0.188`。

**worked example（已手算核对，`A95-00`）**：取 `d_v=3, d_model=2, n=4, λ` 取 `ridge_closed` 同式。
构造 `T = C Y`，其中 `C = u vᵀ`（`rank 1`）⇒ 存在精确 rank-1 解，`rel_res = 0`、`rank(M_1) = 1`。
再把 `C` 换成 `rank 2`（`C = u₁v₁ᵀ + u₂v₂ᵀ`）⇒ **`rank-1` 不可能精确拟合**，`rel_res(r=1) > 0`、
`rel_res(r=2) ≈ 0`、且 `rel_res` 随 `r` **单调不增**。两者都实测。

## §4 臂（唯一独立变量 = **`M` 的秩上界 `r`**）

| 臂 | `m` 从哪来 | 性质 |
|---|---|---|
| `zero` | `m ≡ 0` | 对照（无注入） |
| `free` | 每事实一个自由 896 维向量（`optimise_free`） | ✘ 表达力天花板（`D-109` 已定 `1.000/1.000`） |
| `ridge16` | `M_λ = T Yᵀ(YYᵀ+λI)⁻¹`，只用 16 条 | **跨轮参照**（必须复现 `D-109`） |
| **`lr{r}`** | **`M_r` = 秩约束岭回归精确闭式解**，`r ∈ {1,2,4,8,12,16}`，只用 16 条 | **本轮主判据** |
| `adam16` | `Wo` 由 Adam 600 步学（`D-108` 的 `A_mean`） | 跨轮参照（`D-109` 已定 `0.875/0.000`） |

★ `adam16_g1` **不进本轮**（`D-109` 已定为定向诊断、不入分支表，且 `γ` 方向已三向排除）；**理由留档于此**。
★ 写侧一律 `A_mean`、**写阶段 `γ=0`**、写后 `W` 冻结、所有臂共用一次写 ⇒ 各臂 `W` **逐位相同**。

**秩约束岭回归的精确闭式解（冻结，`A95-02` 断言其与 `ridge_closed` 恒等）**

```
Y = U Σ Vᵀ                       # SVD，Y ∈ R^{d_v×n}
λ = rel · tr(YYᵀ)/n              # 与 ridge_closed 逐字相同
G = T V Σ                        # (d_model × q)
W̃* = G (Σ²+λI)^{-1/2}           # 无约束最优
W̃_r = trunc_r(W̃*)               # SVD 截断（在 whiten 后的度量里最优）
M_r = W̃_r (Σ²+λI)^{-1/2} Uᵀ
```

★ `r ≥ rank(Y)` 时 `M_r` **代数恒等于** `ridge_closed` 的 `M_λ`（下式逐项展开即可）：
`T V Σ(Σ²+λI)^{-1}Uᵀ = T Yᵀ(YYᵀ+λI)^{-1}`。⇒ **`r=16` 是"约束不起作用"的精确控制臂**。
★ 用闭式解而**不用 ALS/交替最小二乘**：ALS 会引入局部最优，"低秩失败"就可能只是没优化好，
与"参数个数不是瓶颈"无法区分（`CORR-13`：机理措辞必须自带可推翻的对照）。

## §6 证据边界（**不得外推**）

1. `free` 用**测试时不可得信息**（每事实答案）⇒ **上界诊断、非可实现**；`ridge16` 只用 16 条 ⇒ 可实现。
2. 本轮只判定**参数个数（秩）**这一层；**不**判定"样本量增加能否解决"（未测）、**不**判定"必须非线性"（未测）。
3. `RANK_TOO_SMALL` 是**不可分辨**状态，**不得**记成 H1 成立，也**不得**记成 H1 被推翻。
4. 只在 Qwen0.5B / `MOUNT=[8,12,16]` / 600 写步 / 16+16 键 / 27 值池 / `N_DRAWS=3` 下成立。
5. `n_q=16` ⇒ 单题粒度 `0.0625`；判决用两 seed 合成。
6. **不得**改写 `D-103`…`D-109` 任何一行的门与口径；**不得**再引 `D-105` 的"值通道是 `FIT_ONLY` 根因"；
   **不得**再引 `D-108` 的"叠加完美寻址也没用"（已被 `DEF-94-01` 推翻）。
7. 本卡**不**改 `§2.2` 装置、**不**新增架构组件；结论只到"秩 / 参数个数"这一层。
