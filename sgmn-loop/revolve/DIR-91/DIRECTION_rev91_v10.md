## §0 前提探测（**开卡前已跑完，实测，不是假设**）

`dir91/probe91_premise.py` → `dir91/out/probe91_premise.json`。四种语料的 $\max_{i\ne j}\lvert\cos\rvert$：

| 语料 | 原始均值隐状态 (L8/L12/L16) | 经 $P_k$ 投影后的 $k$ | **去均值后的 $k$** |
|---|---|---|---|
| V0 同构（=DIR-90 原文） | 0.999 / 0.999 / 0.998 | 0.999 | 0.488 / 0.524 / 0.610 |
| V1 换句式（6 帧） | 0.999 / 0.999 / 0.998 | 0.999 | 0.878 / 0.884 / 0.888 |
| V2 换句式 + 换话题/动词 | 0.997 / 0.997 / 0.995 | 0.997 | 0.484 / 0.444 / 0.501 |
| V3 最大多样（话题+动词+长注记） | 0.999 / 0.999 / 0.996 | 0.999 | **0.379 / 0.417 / 0.421** |

**三条实测结论，直接决定本卡怎么写**：

1. ★ **「词面去同构」对原始均值隐状态无效**。V3 的句子在**话题、动词、句式、长度**上全部不同，$\max\lvert\cos\rvert$ 仍是 **0.999**。⇒ `D-108` §派生①「改用多句式把键余弦压到 $\ll0.5$」**在原理上做不到**，若照它冻结卡片就是冻结一个不可达阈值。
2. ★ **$P_k$ 投影不改变余弦**（$d_k{=}d{=}896$，方阵近正交）⇒ 投影不是共线的来源，也不是解药。
3. ★ **共线来自残差流的共享高范数方向，去均值即可移除**：V0 $0.61\to$ V3 $0.42$（L16），V3 在 L8/L12 已到 $0.38/0.42$。

**为什么"去均值余弦"是**正确的**守卫量（而非放宽阈值）**：共享方向 $u$ 给每个键加上**同一个**向量 $c\,u$，它在任何**键与键之间**的比较中**完全抵消**（$\cos(k_i{-}\bar k,\,k_j{-}\bar k)$ 与 $c$ 无关）。⇒ 它**不可能**帮助或妨碍判别，把它计入余弦只会掩盖真正的可分性。故本轮把守卫量改到**去均值键**上，并把原始余弦作为**诊断**同时报告。

**V1 反而更差（0.878）**：去掉固定模板但话题不变，句子彼此更同质 ⇒ 这是"修复"方向被数据反证的第二处，一并留档。

$$\Delta_{\rm content}=\mathrm{acc}_{\rm MEM}-\mathrm{acc}_{\rm INJ}>0.05,\quad\text{且 } \mathrm{CI}_{95\%}\text{ 不跨 }0,\quad\text{且 3 种子同号}.$$

**证伪条件（任一成立即 FALSIFIED）**：① 上述主判据不成立；② 3 种子变号。

- `INCONCLUSIVE-STORAGE` ⟺ S91 存储诊断不过（见 §2），此时 `INCONCLUSIVE-STORAGE` **优先于** FALSIFIED（内容未存住时，$\Delta_{\rm content}{=}0$ 不可解释）。

## §3 测量对象 + **一个具体工作例**（Round standard 1c）

测量对象 = `score_and_accuracy` 返回的**按题计准确率**。工作例桩（A91-9 用）：
- **正确桩**：对每题把正确候选的 NLL 设为 $0$、其余设为 $1$ ⇒ 按题计 $=1.0$。
- **互换桩**：把正确候选的 NLL 设为 $1$、其余 $0$ ⇒ 按题计 $=0.0$。
- **半对桩**：一半题目正确 ⇒ 按题计 $=0.5$。
★ 三桩必须分别复现 $1.0/0.0/0.5$，否则守卫本身没有分辨力（沿用 `DEF-88-1` 教训）。

## §7 边界（**开跑前写定，结论不得越界**）

1. 本轮只改**语料**与 $\gamma$；**不得**把结论外推为"$\eta$/$\lambda$/$r$ 不是瓶颈"——那是 `D-107`/`D-108` 各自的边界。
2. **不得**把「去均值余弦」当作装置性质：它是**语料+键构造**的内在可分性度量，装置内的写入规则**不做**去均值。
3. 若 H91 成立，**不得**外推为"§7.2-7 已足够"——仍是单基座、单容量、$n{=}16$ 题。
4. **不得**把 $\gamma^\ast$ 外推到其它任务/其它 $\eta$（`D-107` 已证 $\eta$ 改变稳定域）。
5. $\gamma^\ast$ 由 **INJ 臂**选出，**不得**用 MEM 的结果反选 $\gamma$；扫描表全量报告。
6. **不得**用 NLL/困惑度冒充任务收益（`D-15`/`D-16` 教训）。
7. **不得**把本任务（32 条事实的 KVR）等同于检索/跨会话等其它记忆依赖任务。
8. BASE 与 seed 无关（$\gamma{=}0$ 不可训练）⇒ **不是**三次独立重复。
