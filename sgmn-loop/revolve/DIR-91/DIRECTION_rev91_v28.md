# DIR-91 · rev 2.8 —— `W_o` 的失败是**优化/目标**问题，还是**注入通路表达力**问题？

> 派生自 `D-108`（§八「可分辨的下一问」），**不是自造议题**。
> 上游：v2.4 **§7.2-7**（持久化与 LLM 协同）＋ **§2.2**（读通路 `y=sg(W)q, m=W_o y`）。
> 装置：`R2_task91.py` / `sgmn_module.py` **零改动**；唯一改动是 `dir91/probe91_woform.py` 内的
> monkey-patch（读通路的注入向量可被指定）。**判决门一经冻结不得改动，改动须新开 revision 且旧版留档。**

## §1 主假说与可推翻条款

**H1**：训练 16 条事实上的 `W_o` 之所以在留出键上停在 chance，是**优化/目标**问题 ——
即：**同一个线性环节，换成闭式解就能泛化**。

**H1 的可推翻条款（写死）**：若 `ridge16 ≤ 0.25`（chance 带）**而** `free ≥ 0.50` **且** `ridge32 ≥ 0.50`，
则 H1 **被推翻** —— 信息够、通路够、全样本闭式解也够，唯独"从 16 条样本学一个线性映射"不够
⇒ 约束在**样本量/线性性**，**不在**优化。

★ 本卡**不**主张"`W_o` 是唯一根因"。它只判一件事：**换成闭式解，留出准确率会不会动**。
若也不动，则 `§2.2` 的读通路（"值身份 → 候选排序"这一步）**本身**要改，这是下一个方向，不是本卡的结论。

## §2 MVP 标准（**冻结，先于任何实验代码**）

**最小判据物**：一个脚本 `dir91/probe91_woform.py`，产出 `out/probe91_woform.json`，
内含每 seed 的 6 臂 `acc_train / acc_held` 与**分支判定**，外加 Stage A 守卫。

**主判据量（唯一裁决口径，与 `D-105`/`D-108` 逐字同口径）**：
按题准确率 `acc_q` —— 同题 `N_DRAWS=3` 组抽样**全对**才算该题命中；`n_q=16`；`N_CAND=4`；chance `= 0.25`；
评测入口**必须**复用 `R2_task91.make_eval_items` ＋ `score_and_accuracy` ＋ `acc_by_question`（`A93-08` 口径）。

**冻结阈值**：

| 名 | 值 | 含义 |
|---|---|---|
| `G_gen` | **0.50** | "泛化到位" |
| `G_low` | **0.25** | chance 带上沿（"没动"） |
| `G_delta` | **0.125** | 相对 chance 的可辨增量 |
| `CHANCE` | **0.25** | `1/N_CAND` |
| `SEEDS` | **`[20261028, 7777]`** | 与 `D-105`/`D-108` 同 |

**分支表（冻结，`free` / `ridge16` / `ridge32` 三者定分支）**：

| 分支 | 条件 | 含义 |
|---|---|---|
| `EXPR_FAIL` | `free ≤ G_low` | **注入通路本身**无法把"自由向量"变成正确候选排序 ⇒ `§2.2` 要改 |
| **`OPT_LIMIT`** | `free ≥ G_gen` ∧ `ridge16 ≥ G_gen` | **H1 确认**：闭式解能泛化 ⇒ Adam 的失败是优化/目标问题 |
| **`SAMPLE_LIMIT`** | `free ≥ G_gen` ∧ `ridge16 ≤ G_low` ∧ `ridge32 ≥ G_gen` | **H1 推翻**：线性映射存在，但 16 条样本不够 |
| `LINEAR_LIMIT` | `free ≥ G_gen` ∧ `ridge16 ≤ G_low` ∧ `ridge32 ≤ G_low` | 线性 `y→m` 即使给全样本也不够（⇒ 需非线性或换 `y`） |
| `PARTIAL` | 其余 | 判决**不下**，记读数 |
| `INCONCLUSIVE` | 两 seed 落在不同分支 | 判决**不下** |

**★ 两 seed 一致性要求**：`OPT_LIMIT`/`SAMPLE_LIMIT`/`LINEAR_LIMIT` 须**两 seed 同支**才成立；
否则如实记 `INCONCLUSIVE`（不得挑一个 seed 报）。

## §3 六臂（唯一独立变量 = **注入向量 `m` 从哪来**）

`m` 一律**只替换读出位**（`idx = cf.shape[0] − 2` = prompt 末位），其余位置与原生逐位相同。
写侧一律 `A_mean`（`D-108` 的现状臂），**写后 `W` 冻结**，读侧数据顺序/种子与 `D-108` 相同。

| 臂 | `m` 的来源 | `γ` | 训练 | 测试时信息 | 性质 |
|---|---|---|---|---|---|
| `zero` | `m ≡ 0`（无注入） | `1.0` 固定 | 无 | 无 | **对照**：无注入的基座准确率 |
| `adam16` | `m = W_o y`，`W_o` 由 Adam **600 步**在 16 条训练事实上学 | 可学（init `0`） | 有 | 无 | **复现 `D-108` 的 `A_mean`**（须落在 `0.000`） |
| `adam16_g1` | 同上，但 **`γ` init `1.0`** | 可学（init `1`） | 有 | 无 | **定向诊断**：`γ_init=0` 是否在扼杀读侧梯度 |
| **`free`** | 每个事实**各自一个自由向量** `m_i`（逐层 `896` 维），**只优化 `m_i`** | `1.0` 固定 | 有（仅 `m_i`） | **有**（用了该事实的答案） | **表达力天花板**（上界诊断） |
| **`ridge16`** | `m = M y`，`M` 由**闭式岭回归**在 **16 条训练**上拟合（目标 = `free` 的 `m_i`） | `1.0` 固定 | 无（闭式） | 无 | **主判据**（可实现的闭式解） |
| **`ridge32`** | 同上，拟合集 = **全部 32 条** | `1.0` 固定 | 无（闭式） | **有**（含留出） | **声明式泄漏上界** |

**闭式解（冻结公式）**：`M = T Yᵀ (Y Yᵀ + λI)⁻¹`，`Y = [y_i]`（`d_v × n`），`T = [m_i^tar]`（`d_model × n`），
`λ = 1e-3 · tr(Y Yᵀ)/n`（**尺度无关**，逐层各算）。`A94-06` 用独立求解器复核。

**`free` 的优化（冻结）**：`m_i` init `0`，Adam `lr=0.05`，**`STEPS_FREE=120`**，
损失 = 该事实 `N_DRAWS=3` 组 4 选 1 的 CE **均值**（一组前向算完 3 组）。

## §4 量测对象 + 一个**已算过的**worked example（先于实现）

**量测对象**：读出位的注入向量 `m` 与 4 个候选的 NLL 排序。
读出位 = `cf.shape[0] − 2`；序列长度 `P+1`（prompt `P` ＋ 1 个候选 token）⇒ 读出位 = `P−1` = **prompt 末位**。
★ 因**因果**注意力，`h_{P−1}` 只依赖 `[0..P−1]` = **整段 prompt** ⇒ `y` 与"哪个候选在后"**无关**（`A94-05` 断言）。

**worked example（`A94-00` 现场算出并登记，不取历史值）**：取 `seed=20261028`、事实 0、层 `8`：
① 打印 `‖y_0‖`、`‖m_0^free‖`、`‖M y_0‖`；② 打印 `m=0` 与 `m=m_0^free` 两种情况下该题的 4 个 NLL；
③ 断言"换 `m` ⇒ NLL 排序**确有变化**"（否则整个量测对象是死的，`A94-03` 同时覆盖）。

## §6 证据边界（**先写死，判决后不得扩写**）

1. `free` 与 `ridge32` **用了测试时不可得信息**（答案 / 含留出的拟合集）⇒ **上界诊断、非可实现配置**；
   **不得**当作"装置已能检索"。
2. `ridge16` 是**唯一**可实现的闭式候选，也是**唯一**承担 H1 判据的臂。
3. 若判 `EXPR_FAIL`，**只**说明"以 896 维自由向量在读出位注入"这一条路不通，
   **不得**推"注入式读通路整体不可行"（还可以改注入位置/维度/多步）。
4. 若判 `LINEAR_LIMIT`，**只**说明"线性 `y→m`"不够，**不得**推"必须非线性"（也可以换 `y`、换读出位）。
5. `adam16_g1` 是**定向诊断**，不进分支表；它的读数**不得**单独作为判决。
6. 只在 `γ` 见 §3、Qwen0.5B、`MOUNT=[8,12,16]`、`600` 写步、`16+16` 键、`27` 值池下成立，不外推。
7. `n_q=16` ⇒ 单格粒度 `1/16 = 0.0625`；判决一律两 seed 合成。
8. **不得**改写 `D-103`…`D-108` 任何一行的门与口径。
9. `free` 的 120 步／`lr 0.05` 是**冻结值**；不得因结果调大调小（要改就新开 revision）。
