## §3 机制（不只是数字）

1. ★★★ **「键映射跨实例共享」确实是读侧可学性的前提 —— 而且这次是**类级别**的读数。**
   DIR-40 只在**一张**预注册共享 `Pk1` 上拿到正面读数（D-64-CORR §收窄一）⇒ 本卡在 **5 张独立抽取**上重做：
   共享格 **5/5** 全部满足三条谓词，闭合率 `Δ/R` = **0.9821 / 0.9648 / 0.9721 / 0.9754 / 0.9807**、
   效应/地板 = **4.911× / 4.824× / 4.860× / 4.877× / 4.903×**、`L(oracle)` = **1.49–1.54**、
   `R_j` = **14.53–16.82** ⇒ ⇒ 跨抽取**高度一致**（极差 < 2%）
   ⇒ ⇒ 合法表述：**「在 5 张预注册的独立共享抽取中，读控制器均可学（可寻址区间的 96.5%–98.2% 被闭合）」**
   ⇒ ⇒ 而在同一协议、同一批实例上，**逐实例随机 `Pk1` 未能给出可测的读侧收益** ⇒ ⇒ **共享性是前提**成立。
2. ★★★ **逐实例格的三条谓词**（★ **必须分项读**）：
   - `Δ_PI = −4.989980`，`3se = 2.062446` ⇒ **未达「显著为正」**（P1 不过）。
     ★ 点估计为负、方向与共享格相反，但 `|−4.99| / 3se = 2.42 < 3` ⇒ ⇒ **不得**写「训练有害」
     （延续 **DEF-39-4** 的教训：不自造机制）。
