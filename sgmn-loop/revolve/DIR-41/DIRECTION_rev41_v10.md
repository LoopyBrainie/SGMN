## §2 装置 revision 与「格」的设计（冻结）

### §2.1 唯一的装置 revision：层 1 的写键映射 `Pk1` 的**共享性**

- 装置文件 `dir31/R1_grad.py` **逐字零改** ⇒ revision 以「实例构造后覆盖 `P["Pk1"]`」实现，
  与 DIR-40（决定五十二-1）**同一形式**。
- 共享格：`P["Pk1"]` 被覆盖为**一张固定矩阵**（跨实例**逐位相同**）。
- 逐实例格 PI：**不覆盖** ⇒ 保留装置**自己**的逐实例 `Pk1`（每实例独立抽样）。
- ⇒ ★ **只改「是否跨实例共享」，不改分布**（见 §2.2）。

### §2.2 `Pk1` 的生成式（**按装置源码逐字核对**，开卡前已完成）

装置 `dir31/R1_grad.py::build`：

```python
g = torch.Generator().manual_seed(seed)
def rn(*shape, scale=1.0, rg=False):
    return (torch.randn(*shape, generator=g) * scale).requires_grad_(rg)
s_h = 1.0 / math.sqrt(D_H)
P["Pk1"] = rn(D_H, D_K, scale=s_h)        # = randn(D_H, D_K, generator=g) * s_h
```

任务层 `dir33/R1_task33.py::build`：`P["Pk1"] = P["Pk1"] * KEY_SCALE`（`KEY_SCALE = 0.5`）。

⇒ ★ **装置的有效 `Pk1` 的边缘律** = `randn(D_H, D_K) × (1/√D_H) × KEY_SCALE`
⇒ 共享抽取**逐字复刻该式**（**先乘 `s_h` 再乘 `KEY_SCALE`**，与装置的乘法次序一致）：

```python
g = torch.Generator().manual_seed(seed)
Pk1_shared = torch.randn(D_H, D_K, generator=g) * (1.0 / math.sqrt(D_H)) * KEY_SCALE
```

⇒ 逐元素 `~ N(0, σ²)`，`σ = KEY_SCALE/√D_H = 0.5/2.8284271247461903 = 0.17677669529663687`；
`E‖Pk1‖_F = √(D_H·D_K)·σ = √128 × 0.17677669529663687 = 2.0000000000000004`。

★ **不得**为了与 `build()` 的某一次抽样**逐位相同**而改公式：装置的 `Pk1` 是该实例生成器流的
**第 3 笔**抽取（其后还有 `Pv1` 等），而共享抽取用的是**独立生成器的第 1 笔** ⇒
**「公式相同」≠「逐位相同」**，而**边缘律相同**才是本卡需要的性质（⇒ 用 §7 的 `A41-13` 分布闸门核验）。

## §3 测量对象、量与判据（**冻结**）

### §3.1 量（每格 `j`；评估 = **400 个未见过**的实例，配对逐实例）

- `L_oracle_j, L_rand_j, L_learned_j, L_learned_rc_j`：四档在评估段上的 `mean L`。
- `R_j := L_rand_j − L_oracle_j` —— **本格**的「可寻址区间」：
  `rand`（冻结随机读源）到 `oracle`（本格真键读）之间的损失差。
- `Δ_j := L_rand_j − L_learned_j`，**配对**（逐实例）⇒ `se(Δ_j)`、`3se(Δ_j) = SIG_K · se`。
- `C_j := L_learned_rc_j − L_learned_j`，**配对** ⇒ `se(C_j)`、`3se(C_j)`。

### §3.2 阈值（**冻结**，改动须开新 revision）

| 常数 | 值 | 含义 |
|---|---|---|
| `SIG_K` | **3.0** | 配对差判显著的 se 倍数 |
| `FRAC_HEADROOM` | **0.20** | 效应量阈 = `0.20 · R_j`（**逐格**） |
| `PASS_RATE_MIN` | **4 / 5** | 5 张共享抽取中至少 4 张通过 |
| `CONTRAST_MIN` | **4 / 5** | 对比检验至少 4/5 张图显著 |
| `N_TRAIN` | **96** | 每臂训练实例数 |
| `N_EVAL` | **400** | 每臂评估实例数（未见过） |
| `STEPS` | **250** | Adam 步数 |
| `LR` | **0.03** | Adam 学习率 |
| `N_REP` | **16** | 写侧每步重复写更新次数（冻结于 D-62） |

### §3.3 每格的判定（**冻结**）

> **`PASS_j` ⟺ 以下三条**全部**成立：**
>
> - **(P1) 显著性**：`Δ_j ≥ SIG_K · se(Δ_j)`（配对，`n = 400`）
> - **(P2) 效应量**：`Δ_j ≥ FRAC_HEADROOM · R_j`（**逐格**的 `R_j`）
> - **(P3) 内容性**：`C_j ≥ SIG_K · se(C_j)`（配对，`n = 400`）

### §3.4 对比检验（**冻结**；逐图，不合并）

> 对每张共享图 `j ∈ {SH1..SH5}`，在**同一批 400 个评估实例**上**逐实例配对**：
>
> ```
> C_j[i] := (L_rand_j[i] − L_learned_j[i]) − (L_rand_PI[i] − L_learned_PI[i])
> ```
>
> 该图**通过**对比检验 ⟺ `mean(C_j) ≥ SIG_K · se(C_j)`。
>
> ★ **禁止**把 `5 × 400` 当作 2000 个独立样本；★ **禁止**只对 5 张图的均值做一次 `3se`
> （图间方差近 0 时组内噪声会误过）；★ 这 5 个检验**共用 PI 序列** ⇒ **只作冻结的计数规则**，
> **不得**换算成二项 `p` 值。

## §4 总体判定表（**冻结** · **按序命中**，只有最后一支 `counted = true`）

| # | 条件 | 结局 | 计入 `SUCCEEDED` |
|---|---|---|---|
| 1 | 缺臂 / `n` 不符 / `merge` 读到探针文件 | `INCOMPLETE` | ❌ |
| 2 | 任一损失或 `se` 非有限 | `DIVERGED` | ❌ |
| 3 | **任一格**（含 PI）`R_j ≤ 0` | `INDETERMINATE` | ❌ |
| 4 | **PI 同时满足** `Δ_PI ≥ 3se` **且** `C_PI ≥ 3se` | `NOT-NECESSARY` | ❌ |

| 6 | 对比检验通过数 `< 4/5` | `CONTRAST-FAIL` | ❌ |

★ 第 3 支**不得**把该格算作失败后继续凑 `4/5`（判据「从未被计算」≠ FAIL）。
★ 第 4 支**只**要求 PI 的**显著性与内容性**；即使 PI 未过 `0.20·R_PI`，只要它有
**显著的内容性收益**，就**不能再宣称共享是前提**（这是**保守方向**）。

**合法表述（冻结）**：`PASS` ⇒ 「**在 5 张预注册的独立共享抽取中至少 4 张**上，
读侧可学；且在逐实例随机 `Pk1` 下（同一匹配头协议）未出现这种优势
⇒ **共享性是读侧可学性的前提**（**条件于本玩具规模**）」。

## §5 手算工作例（**合成数**；不取探针读数）

> **例 A · 一格的判定（`PASS_j`）。** 设某共享格：`L_oracle = 1.50`、`L_rand = 16.00`、`L_learned = 2.00`、
> `L_learned_rc = 15.50`；`se(Δ) = 0.40`、`se(C) = 0.45`。
> ⇒ `R = 16.00 − 1.50 = 14.50`；地板 `0.20·R = 2.90`。
> ⇒ `Δ = 16.00 − 2.00 = 14.00`，`3se = 1.20` ⇒ **P1 过**（`14.00 ≥ 1.20`）。
> ⇒ **P2 过**（`14.00 ≥ 2.90`）。⇒ `C = 15.50 − 2.00 = 13.50`，`3se = 1.35` ⇒ **P3 过**。
> ⇒ ★ **该格 `PASS`**。

> **例 B · 判定表第 7 支（整体 `PASS`）。**
> 共享格 `SH1..SH4` 全部满足例 A 的 `PASS_j`（各 `Δ_j = 14.00`、`R_j = 14.50`）；
> `SH5` 满足例 D 的读数（不 `PASS`）⇒ `p = 4 ≥ 4` ⇒ 不命中第 5 支。

> `se(Δ) = 0.80`、`se(C) = 0.90`。
> ⇒ `R_PI = 16.40 > 0` ⇒ 不命中第 3 支；`Δ_PI = −6.00`，`3se = 2.40` ⇒ `−6.00 < 2.40`
> ⇒ PI **不**同时满足显著性与内容性 ⇒ 不命中第 4 支。

> `3se = 2.40` ⇒ **显著**（`3.00 ≥ 2.40`）。
> ⇒ ★ 注意 `Δ_PI = 3.00 < 3.28` ⇒ PI **未过**效果量地板（未完整 `PASS`），
