## §1 主假设与否证条件

### `H125`（合取，两部分都必须成立）

> **(a) 超加性在 `dose > 0` 的其它训练 run 上成立。**
> 即：在新剂量 `dose ∈ {150, 300, 450}` 上，「`k=2` 候选的每候选加成高于 `k=1`」
> （`w₂ > w₁`）仍然成立。
>
> **(b) 超加性是学习的产物，不是先验。**
> 即：`dose = 0`（未训练 `W = W⁰`）用**定义域正确**的求解器重读时，**不出现同向不对称**。

### 否证条件（任一成立即否证对应支）

| 支 | 否证条件 |
|---|---|
| **(a)** | `J125-1` **不拒绝**（`p_two > 0.05`），或拒绝但 `direction ≠ high` |
| **(b)** | `J125-3` 在 `dose = 0` 上**拒绝且 `direction = high`** ⇒ 未训练态也有同向超加性 ⇒ 超加性是**先验**，与学习无关 |

★ **两侧都是实质结论**：
- (a) 成立 + (b) 成立 ⇒ 超加性**存在且是学习产物** ⇒ `D-155` 的「归因不可判」被**解决**为「学习产物」；
- (a) 成立 + (b) 否证 ⇒ 超加性存在但是**先验性质** ⇒ `D-155` 的判决**从第 1 行降为第 2 行**（`H124_CONFOUNDED`）；
- (a) 否证 ⇒ `H124` 只在 `dose = 600` 成立 ⇒ `D-155` 的结论**不可外推到训练量**，必须记为剂量特异。

## §2 MVP 标准（最小可判产物 + 数值阈值，**冻结**）

### §2-1 判据

#### `J125-1`（主判据 · 支 (a)：独立确认）

**池化 `3 个新剂量 × 9 个 seed = 27 层`** 的精确条件检验：

1. 每层 `s`：`N1ˢ`、`N2ˢ` 只由**结构**决定（`n_seen` 直方图；见 §2-3）；
2. 每层观测 `m_s = e₁ˢ + e₂ˢ`；
3. 每层用**该层自己的** `m_s` 解 `û_s`（§2-4 的**放宽定义域**求解器）；
4. `θ_s = N1ˢ·P1(û_s)/m_s`；
5. 零假设：`e₁ˢ | m_s ~ Binomial(m_s, θ_s)`，**层间独立**；
6. `S = Σ_s e₁ˢ` 的零分布 = 各层二项分布的**精确卷积**；
7. **双侧**精确 `p`（`Σ_{k: pmf(k) ≤ pmf(S)}`）。

**阈值**：`p_two ≤ 0.05` **且** `direction = high`。

★ **为什么这是独立确认**：27 层全部来自**新的训练 run**（`dose ∈ {150,300,450}` 从未跑过）
⇒ 全新的 `W` ⇒ 与 `D-154`/`D-155` 的 `dose = 600` cell **没有任何共享**。

#### `J125-2`（主判据 · 支 (a) 的逐剂量形式，**模型无关**）

对每个新剂量 `d ∈ {150, 300, 450}`，用 4-qset 合并的**模型无关**估计量：

```
p̂_k = e_k / N_k          ŵ_k = (1 - p̂_k)·(3-k) / (p̂_k·k)          ratio = ŵ₂ / ŵ₁
```

**阈值**：三个剂量的 `ratio` **全部 `> 1`**。

★ 为什么需要它：`J125-1` 池化 27 层，测的是「**某处**有超加性」。若只有 `dose=150` 有、
另两个没有，池化仍可能拒绝。`J125-2` 逐剂量要求**符号全部为正**，且**不用 `solve_u`**
（无定义域风险、无功效问题）。

#### `J125-3`（主判据 · 支 (b)：归因）

在 **`dose = 0`** 的 9 个 cell 上跑**与 `J125-1` 完全相同的统计量**（同一求解器、同一双侧设定）。

**阈值**（**否证条件**）：`p_two ≤ 0.05` **且** `direction = high` ⇒ **支 (b) 否证**。

★ 这是 `DEF-124-01` 的正面修复，也是任务 `P124-3` 的答案：
`D-155` 的 `J124-2` 因 `u ≥ 1` 夹紧而 size 达 `0.9405`，**不能**回答归因问题；
本卡用 `u ∈ (0,∞)` 的求解器给它一次**有效**的机会。
★★ 诚实边界：`dose = 0` 的数据**不是新的**（与 `D-155` 同一批 9 个 cell）
⇒ `J125-3` 是**有效重读**，不是独立证据。它只能**否证**支 (b)，不能单独**确立**支 (b)。

### §2-4 ★★ 放宽定义域（本卡的**核心装置改动**，开卡前冻结）

`mech123.solve_u(m, n1, n2)` 解 `n1·P1(u) + n2·P2(u) = m`，其中
`P1(u) = 2/(u+2)`、`P2(u) = 1/(2u+1)`，左侧对 `u` **严格递减**。

**旧版（`DIR-122/123/124` 继承）**：`if m >= n1·P1(1) + n2·P2(1): return 1.0`
（理由「`u < 1` 无物理意义：加成不可能为负」）⇒ 上限 `(2n₁+n₂)/3`。

**本卡（`v10`，开卡前冻结）**：定义域 **`u ∈ (0, ∞)`**，上限 `n₁ + n₂`（`u → 0⁺` 的极限），
`m ≥ n₁+n₂` 时返回 `0.0` 并**记夹紧触发一次**。

**理由（三条，全部在开卡前成立）**：
1. `D-155` §5 已**实测** `dose = 0` 的真实每候选加成 `≈ 0.55 < 1` ⇒ **真参数空间必须含 `u < 1`**；
2. `DIR-124` 的 `diag124_clamp.py` 已实测旧夹紧使该检验在 `H124` 为真、`u = 0.55` 时
   **size = 0.9405**（应 `0.05`）⇒ 旧域是**被数据违反**的边界，不是物理约束；
3. ★ **本决定在看到任何新剂量数据之前做出** —— 现有的只有 `dose ∈ {0, 600}`，
   而 `dose = 600` 的**逐层** `m_s`（`≤ 49`）全部 `< 78.33`（`hi_old`）⇒ **旧域在 `J124-1` 上从未被触发**，
   故放宽**不改变** `J124-1` 的任何读数（`A125-4` 硬断言这一点）。

★★ **并额外确立一个开卡前就已知的结构事实**（`P124-1` 的副产品）：
**池化口径**下 `dose = 600` 的 `m = 133 > hi_old = 78.33` ⇒ 旧夹紧**会**触发 ⇒
`û_pooled = 1.0`、`θ = 0.3409`；而放宽后 `û = 0.19639`、`θ = 0.46556`（`Δθ = +0.1247`）。
⇒ 这**再次**证明「必须分层」（`D-155`）与「必须放宽域」（本卡）是**两条独立**的修正。

**夹紧计数**：`mech125.solve_u` 必须返回 `(u, clamped: bool)`；`R125-5` 报告总触发数。
★ 若 `J125-1` 的有效层中出现**任一** `clamped=True`，该层**记不可执行**（`m > n₁+n₂` 意味着
观测数超过「`u→0` 时全部候选都逃逸」的上限 ⇒ 数据与模型不相容，不是夹紧问题）。

## §3 测量对象与一个具体工作例（`A125-1` 逐位断言）

**测量对象**：给定 cell 的 `pick_argmin`（所选候选下标）、题集 `items`（每题的候选值）、
训练值集合 `tv`，`mech123.counts_by_stratum` 把每题归类到 `k = |cand ∩ tv|`，若
`pick_argmin` 选中的候选值 **不在** `tv` 里则记一次**逃逸** ⇒ 得 `e₁`（`k=1` 的逃逸数）、
`e₂`（`k=2` 的逃逸数）。

### 工作例（手算，冻结）

`n₁ = 23`、`n₂ = 20`、`m = 35`（= `dose = 0`、seed `20260501` 的 `e₁=22, e₂=13` 之和）。

**旧版（夹紧）**：`hi_old = 23·(2/3) + 20·(1/3) = 22.0`；`m = 35 ≥ 22` ⇒ `û = 1.0`
⇒ `θ = 23·(2/3)/35 = 0.4380952381`。

**本卡（放宽）**：解 `23·2/(u+2) + 20/(2u+1) = 35`：

| `u` | `23·P1(u)` | `20·P2(u)` | 和 |
|---|---|---|---|
| `0.50` | 18.400 | 10.000 | 28.400 |
| `0.30` | 20.000 | 12.500 | 32.500 |
| `0.21` | 20.814 | 14.085 | 34.899 |
| `0.2065` | ≈20.847 | ≈14.150 | ≈35.000 |
| `0.20` | 20.909 | 14.286 | 35.195 |

⇒ `û = 0.2065603008`（机器精度）⇒ `θ = 23·P1(û)/35 = 0.5956264661`。

★ **`Δθ = +0.1575312280`** —— 旧零模型把 `θ` 低估了 `0.158`，这正是 `size` 崩溃的来源。
★ **连续性核**：`m = 22` 时 `û = 1.0000000000`、`θ = 0.6969696970`；`m = 22.5` ⇒
`û = 0.94898202`、`θ = 0.69327125` ⇒ **在 `u = 1` 处连续**（旧版在此处截断，不连续）。
`m = 21.5` ⇒ `û = 1.05369363`；`m = 25` ⇒ `û = 0.72842880`。

## §8 证据边界（**不得外推**，开卡前写死）

1. ★★ 本卡只测「`w_k` 随**见到次数**的**超加性**」，**不**测真实 LLM 任务收益
   ⇒ **不得**据本卡动 `§7.2-7b` 的状态（仍 `不足`）。
2. ★★ `J125-3` 用的是 `D-155` **同一批** `dose=0` cell ⇒ **只能否证支 (b)，不能单独确立支 (b)**
   （确立需要**新的**未训练对照，本卡没有）。
3. ★★ 只有 `k ∈ {1,2}` 两个可用层 ⇒ 一个自由度 ⇒ **两点无法确定形状**（不能区分
   二次/阶跃/饱和）；`R125-3` 的曲线只是 6 个点。
4. ★ 剂量是**离散 6 点**：`0/25/150/300/450/600`，**不得**插值成连续剂量反应。
5. ★ `ŵ_k` 是乘性可交换模型下的**描述性估计量**；`dose = 0` 处 `ŵ ≈ 0.55 < 1`
   ⇒ **量纲不可跨 regime 直接比较**，只可比较 `ratio = ŵ₂/ŵ₁`（与 `D-155` §10-5 一致）。
6. ★ `m_s` 是**条件量**：本卡只答「给定各层 `m_s`，两层逃逸的分配是否与共享一个每候选加成相容」，
   **不**答「总逃逸为什么是那个数」。
7. ★ **`k = 3` 层全程不用**（`CORR-35` ①）。
8. ★ **`c2` 三题集不是"独立题目集"**（`CORR-34`）：它们由同一 `facts`/`ev` 用不同 RNG 生成
   ⇒ 相关性未知 ⇒ **不得**把「四个 qset 都同号」读成「四次独立复现」。
9. ★ **不改** `§7.2-7b` 的状态 ⇒ **终止条件仍不成立**。
10. ★ 本卡的 36 个新格**不得**与 `D-154`/`D-155` 的 `dose=600` cell 合并成"更大的样本"
    来增强 `H124` 的显著性 —— 它们的 `dose` 不同，合并会被 `dose` 异质性污染
    （正是 `D-155` 证明的错误）。
