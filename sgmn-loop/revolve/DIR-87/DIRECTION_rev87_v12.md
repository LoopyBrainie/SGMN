## §1 主假说与否证条款

**H87**：$S$ 的容量由**实现类型**决定，两种 kind 在 `N_SLOTS` 附近呈**不同形状**：
- **H87-a（explicit 硬崖）**：`ExplicitKVCore` 在 $N\le N_{\rm SLOTS}$ 时命中率**≈1**，越过 `N_SLOTS` 后**塌到 ≈0**（无干扰，仅有硬上限）。
- **H87-b（hebbian 渐进 + 随 $d$ 增长）**：`HebbianCore` 命中率随 $N$ **单调不增**（干扰型），且容量点 $N^\ast$ 随 $d$ **单调增长**。

**否证条款**：若两 kind 的容量曲线**形状相同**且 $N^\ast$ 的 $d$ 标度相同 ⇒ 「kind」不是容量相关轴 ⇒ **H87 否证**（容量塌缩为单一数字），须在 VERDICT 明写。

## §2 MVP 标准与冻结阈值

**MVP**：一条**容量曲线**（命中率 vs 已存 $N$）+ **容量点 $N^\ast$**，覆盖 `2 kind × 2 d × 5 seeds`。

- **主判据（只看形状与序，不看绝对数）**：
  - **`C87-SHARP`**：explicit 在 $N \le 0.9\,N_{\rm SLOTS}$ 的命中率 $\ge 0.99$；且越过 `N_SLOTS` 后须**按环形缓冲的精确律**衰减 —— $\mathrm{hit}(N)=N_{\rm SLOTS}/N$，判据取 $|\mathrm{hit}(2N_{\rm SLOTS})-0.50|\le 0.15$。
  - **`C87-GRAD`**：hebbian 命中率随 $N$ **单调不增**（允许 $\le 1$ 处非单调，须报出位置），且 $N=N_{\rm SLOTS}$ 时 $< 0.90$。
  - **`C87-DSCALE`**（★ rev 1.2 重新界定**可计算域**）：hebbian 的 $N^\ast(d{=}64)/N^\ast(d{=}8)>1$（**序**判据）。★ 该判据**只在 rehearse 协议下可计算**；在 `oneshot`（主）协议下 $N^\ast(d{=}8)=N^\ast(d{=}64)=0$ ⇒ 比值 $0/0$ ⇒ **记「不可计算」**（`DEF-87-07`），**不得记 FAIL**，也**不得**记 PASS。
- **$N^\ast$ 的绝对数值 = 只报告，不设门**。★ 理由（`CORR-10`）：hebbian 容量的**结构上限未知**，把门设在天花板上方会重犯 `DEF-91-32`。故 $N^\ast$ 走报告口径。
- **★ $N^\ast$ 的操作化定义（冻结，rev 1.1 新增）**：$N^\ast:=\max\{N\in\mathcal N: \mathrm{hit}(N)\ge 0.90\}$，$\mathcal N$ 为 §2 的冻结网格；若网格最小非零 $N$ 已 $<0.90$ ⇒ 记 $N^\ast=0$（**是读数，不是缺失**）。★ 该阈值 $0.90$ 只用于**定义** $N^\ast$、不用于否决；$N^\ast$ 本身仍只报告。
- **命中率定义（冻结）**：写入 $N$ 条后，对**每条已存键**查询，取 top-1 命中「该键对应的值」的比例；`N=0` 时为 0。
- **★ 解码方式（冻结，rev 1.1 新增）**：两个核的 `read` 都返回**向量**（`ExplicitKVCore.read` 是 $\mathrm{softmax}(\beta\cos)$ 加权平均，`HebbianCore.read` 是 $Wq$），**都不是** top-1 拾取 ⇒ 命中必须在**测量层**解码：$\hat j=\arg\max_j \cos(y,\,v_j)$，命中 $\iff \hat j=i$。$\{v_j\}_{j<N}$ 取**测量层自持的真值表**，**不取核的 `vals`**（`vals` 也是 `n_entries` 环形缓冲，$N>N_{\rm SLOTS}$ 时会被覆盖）。
- ★ 判据「从未被计算」不得记 PASS/FAIL；窗口外读数不算。

**★ 写入协议（rev 1.2 新增，`DEF-87-07`）**：两核的 `write` 语义**根本不同** ⇒ 协议必须显式冻结。
- **`oneshot`（主协议，全部主判据只用它）**：每条目**恰好写一次**，与装置逐事件语义一致（框架 §3.1 每一步一次更新）。
  此协议下 `ExplicitKVCore.write` = **精确存储**（`:205-213` 直接 `copy_`），而 `HebbianCore.write` = **单次梯度步**（`:276-296`，$W\leftarrow W-\eta G$）⇒ **一次写几乎不存任何东西**。
- **`rehearse`（次协议，只报告、不作主判据）**：对同一批 $N$ 条目**重复 `E=32` 轮**后测量，用以检验「hebbian 是否需要排练才具备容量」。$E=32$ **预先冻结**、不作网格、不据结果调。
- ★ **两协议的结果不得混报**；`oneshot` 与 `rehearse` 的命中率必须分列两栏。

## §3 测量对象与要求的 worked example

测量对象 = `core.write(k,v)` / `core.read(k)` 这一对公开 API 在 $N$ 增长下的 top-1 命中率。
**Stage A 必须含 worked example `A87-00`**（★ rev 1.2 重写：原「返回 $v_0$ 到 `1e-5`」在**正确装置**上不可达，见 `DEF-87-06`）。
目的仍是证明「测量对象是**这个** core、$d$ 是**这个** $d$」，但改为**按 kind 分别断言恒等式**：
- **explicit**（$N=1$ 写入 1024 槽）：`read(k_0)` 的解析解是 $y=a_0v_0$，其中 $a_0=\dfrac{e^{\beta}}{e^{\beta}+(N_{\rm SLOTS}-1)}$（空槽 $s=0\Rightarrow$ 权重 $e^{0}$）。断言 **$\cos(y,v_0)\ge1-10^{-9}$** 且 **$|a_0^{\rm obs}-a_0^{\rm pred}|\le10^{-6}$**（$a_0^{\rm obs}=\langle y,v_0\rangle/\lVert v_0\rVert^2$）。★ 印出 $a_0^{\rm pred}$、$a_0^{\rm obs}$、$\lVert v_0\rVert$、$\lVert y\rVert$、`N_SLOTS`、$d$。
- **hebbian**（$N=1$）：$y=W k_0$ 是**一次梯度步**的结果，**不是** $v_0$ ⇒ 断言**恒等式** $\lVert y-(W k_0)\rVert\le10^{-6}$（$W$ 由 `core._W()` 取出、手工重算），并**只报告** $\cos(y,v_0)$ 与其一阶解析预期。
★ 二者的共同点：都**不**假设 `read` 是「取回」，只验证「读的是这条通路」。

## §4 Stage A 守卫（任一 FAIL ⇒ 阻断正式轮）

- **`A87-00`** worked example（§3，rev 1.2 重写：explicit 断言 $a_0$ 解析值、hebbian 断言 $Wk_0$ 恒等式）。
- **`A87-01` 零基线**：$N=0$ 时命中率 **恰为 0**；未写入键的查询给出**机会水平**（随机值命中 $\approx 1/N_{\rm cand}$）。
- **`A87-02` 计数一致**：explicit core 在 $N\le N_{\rm SLOTS}$ 时 `min(core.count, core.N) == N` 逐 $N$ 成立（★ rev 1.1 修正：该核**无 `len`**，只有 `.count` 与 `.N`；**逐点**断言，不只抽样）。
- **`A87-03` ★ 越界守卫（本卡特有）**：全程断言**无优化器被创建**、`W` 的 `write_calls` **恒 0**、$P_k/P_v/\alpha$ **逐位不变**（前后快照比对）。任一违反 ⇒ 越界，整轮作废。
- **`A87-04` 平局/退化守卫**：若某 $d$ 下所有返回向量两两余弦 $>0.999$ ⇒ 该格「不可判定」，报出而非计 PASS。

## §6 rev 1.1 变更记录（rev 1.0 全文留档，判据改动全部记于此）

**触发**：实现前逐字核对装置（`dir22/sgmn_module_hebb_v7.py:188-231/232-318`）发现 rev 1.0 有三处**不可执行**，均为 `CORR-10` 同类（门/对象与装置语义不相容）。**未跑任何实验即修正**。

**`DEF-87-01`（判据不可达 · 主）**：rev 1.0 的 `C87-SHARP` 后半写「$N\ge1.1N_{\rm SLOTS}$ 时 $\le0.10$」。
但 `ExplicitKVCore.write`（`:205-213`）是**环形缓冲** `i = self.count % self.N`，`n_entries=N_SLOTS`。
$N$ 次写后**恰有** $N-N_{\rm SLOTS}$ 条被覆盖、驻留集恒为 $N_{\rm SLOTS}$ ⇒ 在核内可完美分辨的假设下
$$\mathrm{hit}(N)=\frac{N_{\rm SLOTS}}{N}\quad(N>N_{\rm SLOTS}).$$
代 $N=1.1N_{\rm SLOTS}$ 得 $\mathrm{hit}=0.909$，**远离 0.10**；要得 $\le0.10$ 须 $N\ge10N_{\rm SLOTS}=10240$。
⇒ 原门**不可达**，若照跑必在「装置正确」的前提下判 FAIL（即 `DEF-91-32` 的复现）。**改为**核对 $\mathrm{hit}(2N_{\rm SLOTS})=0.50$（±0.15）—— 该点是环形缓冲的**签名**，既可计算又可否证。

**`DEF-87-02`（判据对象不存在）**：`A87-02` 原写 `len == N`，但 `ExplicitKVCore` **没有** `__len__`，状态是 `.count`（累计写次）与 `.N`（容量）⇒ 改为 `min(core.count, core.N) == N`。

**`DEF-87-03`（判据依赖未定义量）**：`C87-DSCALE` 门在 $N^\ast$ 上，但 rev 1.0 **从未定义** $N^\ast$ ⇒ 补操作化定义（$\ge0.90$ 的最大网格点；$0.90$ 只用于定义、不用于否决）。

**`DEF-87-04`（测量对象语义未写清）**：两核 `read` 均返回**向量**而非 top-1 拾取 ⇒ 命中率必须由测量层「最近值解码」给出，且真值表须由测量层自持（核的 `vals` 同为环形缓冲，$N>N_{\rm SLOTS}$ 时被覆盖，若借它作真值会把「覆盖」误读成「命中」）。

**`DEF-87-05`（路径失效）**：§0 原写的 `dir23/sgmn_module_hebb_v7.py` 不存在；已按 MANIFEST md5 改指 `dir22/`（见 §0 新条）。

**口径未变**：主假说 H87、否证条款、`C87-GRAD`、`C87-DSCALE` 的**序**判据、$N^\ast$ 只报告、以及 `A87-00/01/03/04/05/06/07` 全部**一字未改**。冻结网格在此补全：$\mathcal N=\{0,1,2,4,8,16,32,64,128,256,512,900,1024,2048\}$。

## §7 rev 1.2 变更记录（rev 1.0/1.1 全文留档）

**触发**：实现前把 `A87-00` 的算术语义代入装置做**手算**，发现两处仍不可执行；其中一处是**结构性的**。

**`DEF-87-06`（容差不可达）**：rev 1.0/1.1 的 `A87-00` 要求 explicit「`read(k_0)` 返回 $v_0$ 到 `1e-5`」。
但 `ExplicitKVCore.read`（`:215-224`）对**全部** `n_entries` 槽做 softmax；$N=1$ 时 1023 个空槽 $s=0$ ⇒ 权重 $e^0=1$，
故 $a_0=\dfrac{e^{\beta}}{e^{\beta}+(N_{\rm SLOTS}-1)}$，$\beta=16$、$N_{\rm SLOTS}=1024$ 时 $a_0=0.999\,885$，
$\lVert y-v_0\rVert\approx1.15\times10^{-4}\lVert v_0\rVert$ —— **比 `1e-5` 大一个量级**。
⇒ 原断言会在**装置完全正确**时 FAIL（`CORR-16` 的典型误判源）。改为断言 $\cos\ge1-10^{-9}$ 且 $a_0$ 与解析值一致到 $10^{-6}$。

**`DEF-87-07`（结构性：两核的 `write` 语义不可比，主判据会「不可计算」）**：
`ExplicitKVCore.write` 是**精确存储**（`copy_` 到槽），`HebbianCore.write` 是**一次梯度步**（$W\leftarrow W-\eta G$）。
⇒ 在「每条目写一次」下，explicit 是一击记忆、hebbian **几乎什么都没存**。
后果：hebbian 的命中率在**所有** $N$ 上都≈机会水平 ⇒ $N^\ast(d{=}8)=N^\ast(d{=}64)=0$ ⇒ `C87-DSCALE` 的比值是 $0/0$。
⇒ 因此：(i) 显式冻结**两条协议** `oneshot`（主）与 `rehearse`($E=32$，只报告)；
(ii) `C87-DSCALE` 重新界定「仅在 `rehearse` 下可计算」，`oneshot` 下记**不可计算**（既非 PASS 亦非 FAIL）；
(iii) H87-b 的「渐进衰退」只在 `rehearse` 下才可能被测到 —— **这一点本身即 §7.2-4 的结论**，不预先假定。

**口径未变**：H87 主假说与否证条款、`C87-SHARP`（rev 1.1 的环形缓冲律）、`C87-GRAD`、$N^\ast$ 只报告、
`A87-01`/`02`/`03`/`04`/`05`/`06`/`07` **一字未改**；网格 $\mathcal N$ 与 rev 1.1 相同。

**累计**：rev 1.0 → 1.1（`DEF-87-01..05`）→ 1.2（`DEF-87-06..07`）。全部缺陷均在**未跑任何实验前**由纸面推导发现。
