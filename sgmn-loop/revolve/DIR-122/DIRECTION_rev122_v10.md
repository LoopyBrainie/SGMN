## §2 判据（**开卡前冻结**）

### §2-1 待测的假说

> **`H122`**：**逐 seed 的逃逸率是 seed 的属性** —— 它在**独立的干扰项抽样**上**可复现**。

★ 这是 `D-152`「逃逸 = 纯 seed 泄漏率」的**稳健性**前提：`D-152` 的逐 seed 率
（`0 / 0.0652 / 0.3913 / 0 / 0.0435 / 0.1957 / 0.1087 / 0 / 0.1087`）**只在一个 48 项抽样上测过**。
若换一批干扰项抽样后这些率不再随 seed 走，则「seed 级 regime」是**该抽样的人工产物**。

### §2-2 `J122-1`（**主**：seed 效应必须在**每一个**独立抽样里重现）

对每个 `j ∈ {556, 557, 558}` 分别计算（**逐字复用 `dir121.mech121` 的 `D_row`**）：

$$\texttt{D\_row}^{(j)} = \sum_{s=1}^{9} \frac{(E_{sj} - \bar{e}_j)^2}{\bar{e}_j},\qquad \bar{e}_j = \frac{1}{9}\sum_s E_{sj}$$

零分布（**与 `D-152` 逐字相同**）：条件在第 `j` 个题集的**逐项逃逸数** `C_i^{(j)}` 上；
对每个 `C_i = c` 的项，把它的 `c` 次逃逸**均匀分给 `c` 个不同的 seed**（无放回）。
`B = 20000`，`BI_SEED = 20261123`，**单侧上尾**。

**`J122-1` 成立 ⟺ 三个 `p_j` 全部 `≤ 0.025/3 = 0.00833333`**（Bonferroni，族内 `α=0.025`）。

### §2-3 `J122-2`（**核心**：率是否**跟着 seed 走**）

$$\Gamma = \sum_{j<k}\ \sum_{s=1}^{9} Z_{sj}\,Z_{sk},\qquad Z_{sj} = E_{sj} - \bar{e}_j$$

零分布：**在每个题集 `j` 内独立置换 9 个 seed 标签**（各题集边际完全保留，只摧毁
「同一 seed 跨题集对应」）。`B = 20000`，`BI_SEED = 20261124`，**单侧上尾**。

**`J122-2` 成立 ⟺ `p_Γ ≤ 0.025`**。

★ 为什么要有这一条：`J122-1` 只要求每个抽样里**有** seed 间异质性，**不要求是同一批 seed**。
若每个抽样里"突出的 seed"都不同，则 `J122-1` 可以全过而「率是 seed 属性」**仍然为假** ——
`J122-2` 正是排除这种情况的那一条。

### §2-4 `J122-3`（`report-only`，不参与判决）

① 9×3 的 `r_sj` 表 · ② 逐 seed 三个率的最大−最小差 · ③ 每个题集 `D_row` 的**最大贡献 seed** ·
④ 主读数里 3 个 `r = 0` 的 seed（`20260501` / `20260504` / `20271203`）在三个 c2 题集上是否**仍然** `= 0`。

## §3 测量对象的手算例（**必须被断言**：`T122-*`）

### §3-1 `Γ` 的手算例 A（完全对齐 ⇒ 最大正）

`E`（行 = seed，列 = 题集）：

```
       j=0  j=1  j=2
s=0     0    0    0
s=1     1    1    1
s=2     2    2    2
```

列均值 `ē = (1, 1, 1)` ⇒ `Z = [[-1,-1,-1], [0,0,0], [1,1,1]]`。
`Γ = Σ_{j<k} Σ_s Z_sj Z_sk = 3 对 × ((-1)(-1) + 0 + (1)(1)) = 3 × 2 = **6**`。

### §3-2 `Γ` 的手算例 B（反对齐 ⇒ 负）

```
       j=0  j=1  j=2
s=0     0    2    0
s=1     1    1    1
s=2     2    0    2
```

列均值 `ē = (1, 1, 1)` ⇒ `Z = [[-1, 1, -1], [0, 0, 0], [1, -1, 1]]`。
- 对 `(0,1)`：`(-1)(1) + 0 + (1)(-1) = -2`
- 对 `(0,2)`：`(-1)(-1) + 0 + (1)(1) = +2`
- 对 `(1,2)`：`(1)(-1) + 0 + (-1)(1) = -2`

⇒ `Γ = -2 + 2 - 2 = **-2**`。

★ 两个例子一起说明 `Γ` **有符号、且"对齐"才为正** —— 这正是 `J122-2` 要的方向。
