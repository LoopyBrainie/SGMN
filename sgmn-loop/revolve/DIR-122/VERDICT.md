## §2 机制（不只是数字）

### §2-1 三个「硬规则 seed」在三个独立抽样上**全部精确为 0**

主读物里 `r = 0` 的 seed 是 `20260501 / 20260504 / 20271203`。
在三个 c2 题集上它们的 `E` 分别是 `[0,0,0] / [0,0,0] / [0,0,0]`
⇒ `always_zero_seeds` 与 `main_zero_seeds` **完全同一个集合**。
★ 这是本卡最干净的机制证据：一个近似硬规则（"见到就一定要选"）的训练结果，
**换一批干扰项抽样仍然一次都不逃逸** —— 它不是那次抽样的运气。

### §2-2 最大的泄漏 seed 仍然最大

`20260503`（主读物 `r = 0.3913`，42 次逃逸里占 18 次）在 c2 上 `E = [12, 10, 9]`，
`r = 0.2667 / 0.2273 / 0.2000` —— 在 `557`、`558` 上是**最高**，在 `556` 上是第二（仅次于 `20260506` 的 14）。
⇒ 主读数里的"最强泄漏者"不是抽样偶然。

### §2-3 两两秩相关：`0.815 / 0.881 / 0.627`

| 题集对 | Spearman |
|---|---|
| `556` vs `557` | **0.815** |
| `556` vs `558` | **0.881** |
| `557` vs `558` | **0.627** |

⇒ 9 个 seed 的**排序**在独立抽样之间高度一致 —— 这正是 `J122-2` 的 `Γ` 所测的东西。

### §2-4 ★★ 但「可复现」**不等于**「固定常数」—— 这条必须并列写

`report-only` 的逐 seed 跨题集同质性（`Q ~ χ²(2)`，`p = exp(−Q/2)`）：

| seed | `E`（556/557/558） | `Q` | `p` |
|---|---|---|---|
| 20260501 | 0 / 0 / 0 | 0.00 | 1.0000 |
| 20260502 | 6 / 3 / 3 | 1.59 | 0.4508 |
| 20260503 | 12 / 10 / 9 | 0.57 | 0.7526 |
| 20260504 | 0 / 0 / 0 | 0.00 | 1.0000 |
| 20260505 | 2 / 0 / 4 | 4.11 | 0.1281 |
| **20260506** | **14 / 2 / 6** | **11.91** | **0.0026** |
| 20271126 | 6 / 3 / 4 | 1.13 | 0.5686 |
| 20271203 | 0 / 0 / 0 | 0.00 | 1.0000 |
| 20271210 | 4 / 0 / 4 | 4.16 | 0.1250 |

⇒ **8/9 个 seed 与"固定率"相容**；**`20260506` 一个**显著超额离散
（`0.311 / 0.045 / 0.133`；9 倍 Bonferroni 校正后 `0.0026 × 9 = 0.0235 < 0.05`，仍成立）。
★ **正确的表述**：逐 seed 逃逸率是**可预测**的（能由另一次抽样预测其水平与排序），
但**不是一个固定标量**。**不得**把 `E` 写成「该 seed 的固有泄漏率」再拿去精确算期望。
★ 这也是 `J122-1`/`J122-2` 与本节**方向相反却不矛盾**的原因：前者测"seed 轴是否带信息"，
本节测"带的信息是否是一个常数"。

### §2-5 抽样间的总量差异

三个题集的总逃逸数：`556 = 44`、`557 = 18`、`558 = 30`
（可逃逸项 `45 / 44 / 45`）。`557` 明显偏低（`n_seen` 分布也偏：`{0:4,1:9,2:29,3:6}`，多 `n_seen=3` 的项）。
★ 这是**题目构造抽样**带来的整体水平差异，与 `D-152`「题目轴在给定 seed 后无残余结构」**不冲突** ——
后者说的是"在固定 seed 后题目分布不可区分"，不是"不同抽样的总量相同"。

## §6 可带走的结论

1. **`D-152` 的「逃逸 = 纯 seed 泄漏率」通过稳健性检验**：seed 效应在**三个独立干扰项抽样**上
   都重现（`p = 0.0 / 0.0 / 0.0012`），且逐 seed 水平**能跨抽样预测**（`Γ = 270.33`、`p = 0.00015`，
   零分布 `q99 = 195.33`）⇒ **`D-152` §7-4 的"须降级"保留条件未触发**。
2. **硬规则 seed 是硬的**：主读数里 3 个 `r = 0` 的 seed 在三个独立抽样上**全部精确为 0**。
3. ★★ **但率不是固定常数**：`8/9` 个 seed 与固定率相容，`20260506` 一个显著超额离散
   （`p = 0.0026`）⇒ 逐 seed 率可用于**预测/排序**，**不可**用于精确计算期望值。
4. **抽样会给总量带来整体水平差**（`44 / 18 / 30`），但这**不矛盾于** `D-152` 的"题目轴无残余结构"
   —— 后者是条件在 seed 后的分布结论，不是"总量相同"。
