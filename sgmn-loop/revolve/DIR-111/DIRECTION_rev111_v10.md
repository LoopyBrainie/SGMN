## 1 主假设与否证条款

**$H_{111}$（串联最弱环，内点版）**：在**内点**（`|δ_Q| ≥ 0.10 ∧ |δ_O| ≥ 0.10 ∧ δ_Q + δ_O ≤ 0.95`），
`m` 读出量的复合损伤服从**最弱环** `max(δ_Q, δ_O)` 而非**求和** `δ_Q + δ_O`，
即**每个**合格裁决点都满足 `MAXerr < SUMerr`，其中
`MAXerr = |δ_B − max(δ_Q, δ_O)|`、`SUMerr = |δ_B − (δ_Q + δ_O)|`。

**否证条款**：若**存在**任一合格裁决点满足 `MAXerr ≥ SUMerr` ⇒ $H_{111}$ **被证伪**。

**★ 可识别性条款（与证伪分开，不得混报）**：若合格裁决点**少于 3 个**（共 6 个候选：
`m × {rank_eff, cos_mean} × 3 个新 γ`），则判 **`C111-NO-INTERIOR-POINT`** ——
$H_{111}$ **既未证实也未证伪**（此装置在这些 γ 上**无法**内点检验）。
★ 该状态**不得**记作 PASS，也**不得**记作 FAIL。

## 2 MVP 标准（数值阈值全部在此冻结，跑任何格之前）

### 2.1 裁决点（**机械枚举，不得按结果挑选**）

`m × {rank_eff, cos_mean} × γ ∈ {0.0010, 0.0025, 0.0100}` = **6 个候选**，全部在 **`L8`**。
- `q` **排除**：`δ_O(q@L8) ≡ 0` 是架构恒等式（§0.1）⇒ `MAXerr ≡ SUMerr`，无信息。★ 由 `A111-7` **证明**该恒等式成立，不是假设。
- `L16` **排除**于裁决：`DEF-110-04` + `m@L16` 的 `δ_B = 1.000` 已贴上界。`L16` 只作**报告块**（§5.3），**不进判决**。

### 2.2 内点门（**本卡的核心冻结项**）

裁决点 `p` **合格** ⟺ **同时**满足：

1. `|δ_Q(p)| ≥ TAU_ARM`（`0.10`，沿用未改）
2. `|δ_O(p)| ≥ TAU_ARM`（`0.10`，沿用未改）
3. **`δ_Q(p) + δ_O(p) ≤ CEIL_MAX`**，`CEIL_MAX = 0.95`（`= 1.0 − 0.05`；`δ_B` 的上界是 `1.0`）

★ 第 3 条是本卡**新增**的，理由是 §0.2：`δ_Q+δ_O > 1` 时求和模型预测**不可容许值**，
该处比较**无信息**。`0.05` 的余量吸收 `δ_B` 归一化后的数值残差（`A111-5` 核 `δ_B ≤ 1+1e-9`）。

### 2.3 判决码（**唯一**判定路径）

设合格集 `Q`，`n_q = |Q|`：

| 码 | 条件 |
|---|---|
| `C111-NO-INTERIOR-POINT` | `n_q < 3` ⇒ 未证实未证伪（§1 可识别性条款） |
| `C111-FALSIFIED` | `n_q ≥ 3` ∧ `∃p∈Q: MAXerr(p) ≥ SUMerr(p)` |
| `C111-WEAKEST-LINK-CONFIRMED` | `n_q ≥ 3` ∧ `∀p∈Q: MAXerr(p) < SUMerr(p)` ∧ `median_{p∈Q}(MAX/SUM) ≤ 0.90` |
| `C111-WEAKEST-LINK-WEAK` | `n_q ≥ 3` ∧ `∀p∈Q: MAXerr(p) < SUMerr(p)` ∧ `median(MAX/SUM) > 0.90` |

★ **余量条款的理由**：`MAXerr < SUMerr` 在 `MAX/SUM → 1` 时几乎无意义（近乎打平）。
`0.90` 要求最弱环**至少赢 10%**（无量纲比值，**不是**绝对噪声带 —— `DEF-110-05` 禁的是后者）。
`C111-WEAKEST-LINK-WEAK` 是**独立的弱结论码**，**不得**升级为 `CONFIRMED`。

### 2.4 `γ` 网格（3 个**新**点，`DIR-109` 未用过）

| γ | 预测（**预注册，不是阈值**） | 设计意图 |
|---|---|---|
| **0.0010** | 内点（`δ` 小） | 提供内点裁决点 |
| **0.0025** | 内点（预计落在 `δ_Q+δ_O ≈ 0.7–0.9`） | 主力内点 |
| **0.0100** | **越界**（预计 `δ_Q+δ_O > 1`） | ★ **反向对照**：内点门**必须**拒它 ⇒ 检验门本身 |

★ 依据（不是挑选，是量级外推）：`γ=0.005` 时 `m@L8` 的 `δ_Q+δ_O` 为 `1.467/1.652`；
`γ` 降 2× 大致使 `δ` 减半 ⇒ `0.0025` 落在 `0.73/0.83`（内点）；`γ` 升 2× ⇒ `0.0100` 应越界。
★ **若预测错**（例如 `0.0025` 也越界），按 §2.3 走 `NO-INTERIOR-POINT`，**不得**事后改 `γ` 或改 `CEIL_MAX`。

### 2.5 算例（`§2.4` 逐位复核，`A111-5`）

用 `DIR-110` 冻结值 `m.cos_mean@L8 γ=0.050`：

```
X_NONE=0.580  δ_Q=0.427  δ_O=0.851  δ_B=0.853
max(0.427,0.851)=0.851   ⇒ MAXerr = |0.853-0.851| = 0.002
sum       = 1.278        ⇒ SUMerr = |0.853-1.278| = 0.425
MAX/SUM   = 0.005
δ_Q+δ_O   = 1.278 > 0.95 ⇒ ★不合格（越界）
```

★ 这条算例**同时**验 §2.4 的 `max/sum` 算术、`A111-5` 的 `δ_B ≤ 1` 恒等、**和** §2.2 的门：
它**正确**地把一行"看起来 0.005 极其漂亮"的数据判为**不合格**。

合成内点算例（纯函数回归，`A111-5b`）：
```
(a) δ_Q=0.30 δ_O=0.50 δ_B=0.55 ⇒ max=0.50 sum=0.80 ⇒ MAXerr=0.05 SUMerr=0.25 ratio=0.200
    ⇒ 合格 ∧ 最弱环赢 ⇒ 计入 CONFIRMED
(b) δ_Q=0.30 δ_O=0.50 δ_B=0.78 ⇒ max=0.50 sum=0.80 ⇒ MAXerr=0.28 SUMerr=0.02 ratio=14.0
    ⇒ 合格 ∧ 求和赢 ⇒ 计入 FALSIFIED
(c) δ_Q=0.60 δ_O=0.50 δ_B=0.90 ⇒ sum=1.10 > 0.95 ⇒ 不合格（门起作用）
```
