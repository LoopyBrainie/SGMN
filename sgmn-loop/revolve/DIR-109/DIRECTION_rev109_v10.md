## §1 主假说与否证条款

**$H_{109}$**：读出训练造成的损伤是 **`{W_q, W_o}` 的乘性（交互）效应** ——
**单独**训练任一侧都不足以复制 `DIR-104` 的 `−0.22`；只有**两侧同时**可训练时才崩。
⇒ 状态侧对应：`W_q` 与 `W_o` 的**位移**都不大，崩的原因是**乘积 `‖W_o W W_q‖` 的增益爆炸**。

**否证条款**：若 `D_Q` 或 `D_O` **单独** ≥ `TAU_ATTR = 0.10` 且 ≥ `2×` 另一侧且 `|I| < TAU_ATTR`（`§2.3` 的求值顺序）
⇒ 归因给**单侧**，$H_{109}$ **否证**（记 `C109-WQ-DOMINANT` 或 `C109-WO-DOMINANT`）。

★ **两子句分立**（`DEF-88-1` 纪律）：
- **子句 A（归因）**：`D_BOTH` 的损伤能否被 `D_Q`/`D_O` 的可加分解解释。
- **子句 B（状态）**：训练是否把**读路径增益**抬了 `≥ TAU_GAIN = 10×`（未训练 vs 训练，同层同 γ）。
  子句 B 是**独立判据**，不是子句 A 的注脚 —— 因为「谁负责」与「怎么坏」是两个问题。

### 2.3 判据量 A：损伤的 2×2 分解（**主判据**）
三 seed 合并 `n = 144`：
$$D_Q = a_{\rm NONE}-a_Q,\quad D_O = a_{\rm NONE}-a_O,\quad D_{B} = a_{\rm NONE}-a_{\rm BOTH},\quad I = D_B - D_Q - D_O$$
其中 $a_\ast$ = 该臂 `acc_item`（三 seed 均，即 432 项合并后的比例）。

**冻结求值顺序（互斥且穷尽，见 §2.4 算例 3）**：
1. `D_B < TAU_ATTR` ⇒ **`C109-NO-DAMAGE`**（与 `DIR-104` 冲突 ⇒ 须回查，不得直接采信）
2. `D_Q ≥ TAU_ATTR` ∧ `D_O ≥ TAU_ATTR` ∧ `|I| < TAU_ATTR` ⇒ **`C109-BOTH-ADDITIVE`**
3. `D_Q ≥ TAU_ATTR` ∧ `D_Q ≥ RATIO·D_O` ∧ `|I| < TAU_ATTR` ⇒ **`C109-WQ-DOMINANT`**
4. `D_O ≥ TAU_ATTR` ∧ `D_O ≥ RATIO·D_Q` ∧ `|I| < TAU_ATTR` ⇒ **`C109-WO-DOMINANT`**
5. `D_Q < TAU_ATTR` ∧ `D_O < TAU_ATTR` ∧ `D_B ≥ TAU_ATTR` ⇒ **`C109-MULTIPLICATIVE`** ← **$H_{109}$ 证实**
6. 其余 ⇒ **`C109-NO-CLEAN-ATTRIBUTION`**（读出全部记录，不作归因断言）

`TAU_ATTR = 0.10`（= `DIR-104` 的 `TAU_CONTENT` 量级；`n=144` 下最小可探测 `Δ = 0.0347`，
见 `DIR-104` §3.1 同一算法）· `RATIO = 2.0`。

**γ-稳健性**：两 γ 给出**同一判决码**才算「γ-稳健」；不一致则码后加 `-GAMMA-DEPENDENT` 并**逐 γ 分报**。

### 2.4 算例（**冻结前逐位对上**；`A109-5` 用它们验算脚本）

**算例 1（分解，`n=144`）**：设 `a_NONE=102/144=0.7083`、`a_Q=96/144=0.6667`、
`a_O=50/144=0.3472`、`a_BOTH=12/144=0.0833`
⇒ `D_Q=0.0417`（6 项）、`D_O=0.3611`（52 项）、`D_B=0.6250`（90 项）、
`I = 0.6250 − 0.0417 − 0.3611 = 0.2222`。
按 §2.3 顺序：① `D_B=0.6250 ≥ 0.10` 不停；② `D_Q<0.10` 不成立；③ 不成立；④ `D_O≥0.10` ∧ `D_O≥2·D_Q`（0.3611≥0.0833）∧ `|I|=0.2222 ≥ 0.10` ⇒ **② 的 `|I|<TAU` 前提不满足 ⇒ 落到 6** ⇒ `C109-NO-CLEAN-ATTRIBUTION`。
★ **此算例故意设计成"单侧占优但交互也大"**，用来证明 `|I|<TAU` 这个前提不是装饰。

**算例 2（分解，`H_{109}` 成立的样子）**：`a_NONE=0.7083`、`a_Q=0.6944`、`a_O=0.6806`、`a_BOTH=0.0833`
⇒ `D_Q=0.0139`、`D_O=0.0278`、`D_B=0.6250`、`I=0.5833`。
⇒ `D_Q,D_O < 0.10` ∧ `D_B ≥ 0.10` ⇒ **判 `C109-MULTIPLICATIVE`**（第 5 条）✓

**算例 3（穷尽性）**：对 `(D_Q, D_O) ∈ {<TAU, ≥TAU}²` 四种组合逐一走 §2.3：
- 双 `<TAU`：若 `D_B<TAU`→1，否则→5 ✓ 全覆盖
- `Q≥TAU,O≥TAU`：`|I|<TAU`→2；否则 3/4 的 `|I|<TAU` 前提不满足、5 前提不满足 ⇒ 6 ✓
- `Q≥TAU,O<TAU`：`|I|<TAU ∧ Q≥2O`→3；其余（`|I|≥TAU` 或 `Q<2O`）⇒ 6 ✓
- 对称 ✓
⇒ **无遗漏、无重叠**（每一支都唯一确定）。

**算例 4（状态读数）**：取实测 `INJ γ=0.005 seed=20261028 L16: κ=66.785` ⇒ `κ/γ = 13357`。
若未训练侧实测 `κ ≈ 0.005`（⇒ 增益 ≈ 1），则 `A109-B` 的 `增益比 = 13357 ≥ TAU_GAIN=10` ✓。
**手算**：未训练增益 = `‖W_o W W_q‖_F/(‖W_o0‖ _F‖W0‖_F‖W_q0‖_F)`；三矩阵皆 `randn/√896`
⇒ `E‖A‖_F² = 896²·(1/896) = 896` ⇒ `‖A‖_F ≈ 29.93`，乘积归一化后 `≈ 1` ✓（与 `‖W⁰‖_F=29.9333` 同源，`ENV-NOTES` 已记）。

### 2.5 判据量 B：状态级读数（**子句 B**，两侧都测）

每格在**训练前**与**训练后**各测一次（`measure_state`）：
- **位移（`D-138` 纪律：只测位移，不用梯度幅度）**：`ρ_q = ‖ΔW_q‖_F/‖W_q^0‖_F`、`ρ_o` 同；`‖ΔW‖_F ≡ 0` 作守卫。
- **读路径增益**：`gain = ‖W_o W W_q‖_F / ‖W_o^0 W W_q^0‖_F`（`W` 训练中冻结 ⇒ 分母同 `W`）。
- **注入量**：`κ(ℓ) = mean(γ‖m‖)/mean(‖h‖)`（沿用 `D104.measure_kappa` 口径，**但四臂全测**）。
- **题间可分辨性**（三层各一）：
  - 输入侧 `c`：`cos_mean_c`、`rho_c`、`rank_eff_c`
  - 定址侧 `q`：`cos_mean_q`、`rho_q_struct`、`rank_eff_q`
  - 输出侧 `m`：`cos_mean_m`、`rho_m`、`rank_eff_m`
  ⇒ **必须同时读 `c`**，否则无法区分「装置本来不可分辨」与「训练导致塌缩」（§0.2）。
- `rank_eff = (Σσ)²/Σσ²`（参与比；秩 r、奇异值相等 ⇒ `rank_eff = r`，见算例 5）。

**算例 5（`rank_eff`）**：16×896 矩阵若恰有 4 个相等的非零奇异值 ⇒ `(4σ)²/(4σ²) = 4` ✓；
全等（秩 1）⇒ `1`；全各向同性（秩 16、等奇异值）⇒ `16`。

**子句 B 判据**：`gain(训练后)/gain(T-NONE 同 seed 同 γ) ≥ TAU_GAIN = 10` 在 `T-BOTH` 上
**三 seed 全成立**（L16 口径；`gain` 由 `‖·‖_F` 定义，与层无关，另逐层报 `κ` 比值）。
- `≥ TAU_GAIN` ⇒ **`C109-B-GAIN-EXPLOSION`**
- `< TAU_GAIN` ⇒ **`C109-B-NO-GAIN-EXPLOSION`**（⇒ 须另找状态侧解释，本卡**不**猜）

★ `q` 探针的**自洽守卫**（`A109-3`）：在 `read` 的补丁里用 `q=(W_q@cᵀ)ᵀ`、`y=(sg(W)@qᵀ)ᵀ`、`m=(W_o@yᵀ)ᵀ`
**重算**，与 `orig(...)` 的返回逐元素比 ⇒ 相对误差 `< 1e-5`（同算子同顺序，应近机器精度）。

## §6 边界（**不得外推**）

1. **不得**外推为「读出训练必然有害」——本卡只测**一个** primitive、**一个**训练配方（600 步 / Adam `lr=1e-3` / `N_TRAIN_KEYS=16`）、
   **两**个 γ、**三** seed。
2. **不得**把本卡结论用到**写入臂**（`MEM`）——四臂**全部** `do_write=False`。
   写入臂的归因是**另一张卡**（`MEM` 的训练代价与 `INJ` 不同，`DIR-104` §4 已显示两者都在 −0.17…−0.22 但未分离）。
3. **不得**把 `ρ_q`/`ρ_o`（位移）读成「功能」——位移大不等于功能坏；本卡**只**用它作机制描述（`D-138`/`D-139` 纪律）。
4. **不得**再以梯度幅度推断参数被训练（`D-139` 纪律）——本卡一律用**位移** `ρ`。
5. **不得**把 `cos_mean ≈ 1` 自动读成「塌缩」——必须先看 `c` 侧的 `cos_mean_c`；
   若 `c` 本身就不可分辨，则「塌缩」是**装置属性**，不是训练后果。
6. **不得**外推为「`CEIL=1.0` ⇒ 只需修训练」——`CEIL` 是 oracle 口径（`DIR-104` §6.3）。
7. **不得**忽略地板效应：`INJ/MEM ≈ 0.02…0.10`，主判据**没有向上余量**；
   但本卡的判据是**臂间差**（`T-NONE` 0.2778 有充足余量）⇒ 不构成功效限制。
8. **不得**把本卡读成「γ 无效」——γ 的作用已由 `DIR-104` §4 结算（两项抵消）。
