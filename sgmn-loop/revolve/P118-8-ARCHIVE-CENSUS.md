## §2b 第四类：`register_basenums` 被**自己的记叙污染**（`DEF-118-30`）

**实测事件**：我在本轮**追加更正块到登记表**后，审计的 `register_basenums` 从 **108 → 109**。定位结果：

```
更正块新增的基号 = [0]      ← 来自正文里的通配写法 `revolve/DIR-0x/VERDICT.md`
正则 = re.compile(r"DIR-(\d+)")   ⇒  `DIR-0x` 命中为基号 `0`
```

★ 即：**只要有人用 `DIR-0x` 这种通配写法，这个计数就 +1**。
★★ 而「追加一段正确描述」改变了一个**被用作分母候选的观测量** —— 这是循环污染：
　 文档→度量→分母→分数→文档。`register_basenums` **不是归档的属性，而是记叙的副产物**。

★★ **纪律落点**：任何「从自有文档数数」的指标，必须证明自己对**新增记叙稳定**。
　 判别方法：**在写任何东西之前先记下该值，写完再量一次**；若变动，则该指标**不可用作判据**。
　 （本轮正是靠这个「先量–写–再量」才发现的；若只量一次，它会静默成 109。）
