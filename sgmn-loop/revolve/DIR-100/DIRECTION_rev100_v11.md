## §2 冻结判据（阈值**不得**事后改；改则新开 revision）

**装置**：`dir99/R1_task99.py` 逐字派生；**键固定为 `white`**（`D-128`：32/32 可分辨内容）。
**臂**（只换 `Wq` 的来源，`Wo/gamma` 一律照常训练）：

| 臂 | `Wq` 来源 | 作用 |
|---|---|---|
| `wq_train` | 照常训练（= `D-129` 的 `white` 臂） | **基线**，必须复现 `acc_held = 0.0000` |
| **`wq_solved`** | ★ `Wq := M`，**冻结**（`M` 只由 **16** 训练事实拟合） | **主臂** |
| `wq_solved_init` | `Wq` **初始化为** `M`，之后**自由训练** | 训练会保住还是毁掉它 |
| `wq_oracle` | `Wq := M_all`（**32 个全见**拟合），冻结 | **上限**：线性查询的顶层 |

**主判据量**（沿用 `DEF-99-01` 纪律，且**避开** `DEF-99-05` 的撞值）：
```
Δ_ho(arm) = acc_held(W_written) − acc_held(W⁰)      # W⁰ = 只去掉写入内容
```
**`H100`（主假说）**：`wq_solved` 在 **2 seed 均值**上同时满足
- **(a)** `Δ_ho ≥ 0.125`，**且**
- **(b)** `acc_held(W_written) ≥ 0.375`。

★ (b) 的作用：4 选 1 **机会水平 = 0.25**，而基座地板 `acc_held(W=0)` 实测 **0.1250**（`D-129`）。
(b) 使判据**同时高于**机会水平与基座地板 ⇒ **不可能**因"关掉记忆"而通过（`DEF-99-05` 的教训）。

**否证线**：`Δ_ho < 0.0625` **或** `acc_held < 0.25` ⇒ `H100` 否证。

**闭合条款（预注册）**：若 `wq_solved` **与** `wq_oracle` **都** < 0.25 ⇒ 障碍**在查询之后**
（`W` 对 `he` 事实的内容 / `Wo` 的输出映射 / 决策余量）⇒ 读侧线**改判**为"查询不是瓶颈"，
须另起方向，**不得**再在 `Wq` 上加臂。

## §7 边界（不得外推）

1. 键固定 `white` = **上界臂**（用 oracle `K`）⇒ 若 `wq_solved` 成立，只能说「**给定已存好的内容**，
   查询是障碍」；**不得**说「可实现机制已拿到 held-out 收益」。
2. `M` 用 `tr` 的 **16** 个事实拟合 ⇒ 它**不是**可实现机制的一部分（需要标签）；它是**可行性证明**。
   可实现版本须解决「`M` 从何而来」（候选：由 `Pk` 与 `z` 的自监督一致性给出），**本卡不做**。
3. `acc_held` 是「**已写进 `W`、读侧未训练**」的 16 个事实，**不是**"没写过的新事实"。
4. 2 seed、3 层、600 块、32 事实、`η=3e-5`、`α=1`、`λ=0.05`、`READ_STEPS=600`。
5. `cos` 只是**前提量**，不是判据；判据只有 §2 的 (a)(b)。
6. **不得**用 `π` 判内容（`DEF-98-04`）。**不得**外推 `γ` 闭环以外。

### `DEF-100-02`（守卫容差写错，非装置变）
`A100-0` 断言 `maxcos < 1e-6`，实测 **1.7e-06**。而该格 `acc_tr=0.8125`、`acc_ho=0.0000`
与 `D-129` 的 `white` 格**逐位相同** ⇒ 装置没变，是**容差**写成了浮点噪声量级。
⇒ 改为 `maxcos < 1e-4`（"数值上为零"的正确表述）。

### `DEF-100-03`（★ 实质错：`M` 拟合在**错的空间**）
- **现象**：`A100-1` 在位复算 `cos_he(M)` = **−0.0000**，而前提核是 **0.9965–0.9985**。
- **根因**：rev 1.0 把 `M` 拟合到 `Knew` = **white 变换后**的键，并把 `q_tf` 置为**恒等**。
  但前提核的 0.998 是在 **raw（近共线）键空间**得到的。
  ★ **机制**：最小范数最小二乘能否泛化，取决于**目标的有效秩**。
  raw 键近共线（`cos` 中位 **0.997**）⇒ 目标近似 **rank‑1** ⇒ 16 个样本足以定出该映射（`cos_he` 0.998）。
  white 键**互相正交**（32 维张成）⇒ 目标 **rank 32** ⇒ 16 个样本**欠定** ⇒
  最小范数解在 `tr` 上精确插值（`cos_tr`=1.0）却**不泛化**（`cos_he`≈0）。
  ⇒ 这不是"线性解不存在"，而是**查询映射的样本复杂度**问题。
- **正确构造**（由几何决定，非口味）：`M` 拟合 **raw** 键，**保留** `q_tf = tf.qmap`。
  因 white 映射在键张成上**是等距**（`A k_i = √n·v_i`、`‖v_i‖=1`、`‖A k_i‖=√n`），故
  `qmap(M c) = s·A·(M c) ≈ s·A·k_raw = TF(k_raw) = k_new` ✓ —— 余弦在两侧同值。
  ⇒ rev 1.1：`Wq := M_raw`（`(d_k,d)`），`q_tf` **全部保留** `tf.qmap`（**不再**置恒等）。
- **由此得到一条独立结论（写进 VERDICT）**：
  **`Wq` 的障碍是"16 个事实定不出一个进入 32 维正交键张成的线性映射"，不是"不存在线性解"。**
  `D-129` 的 `white` 臂失败由此获得机制解释（它必须学的是复合 `A∘M`，而 `M` 本身已欠定）。

★ `A100-1` 从此**按 raw 空间**判定（与前提核同一空间），另**报告**有效空间 `cos_eff_he`
（`cos(qmap(M c_he), K_new_he)`）以显式核对等距性。
