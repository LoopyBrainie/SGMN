## §1 卡 §3 的两处**表述缺陷**（数值本身不是伪造，是**标签与前提**没写清）

设 `X := ΔG(2)`、`Y := ΔG(4)`、`σ := sd(Y)`（D-67 尺规 `0.001947184`）、
`a := sd(X)/σ`、`ρ := corr(X, Y)`。因为 `SHAPE = 2X − Y`：

```
Var(SHAPE) = σ² ( 4a² + 1 − 4aρ )
```

- **缺陷 ①（标签反向）**：卡 §3 两行标为「独立增量」与「全相关」，但按上式反解：
  - `sd(SHAPE) = σ = 0.001947` ⇒ 在 `a = 1/√2` 下要求 **`ρ = +0.7071`** —— 这**正是**等方差独立增量
    给出的相关系数（`corr(δ₁+δ₂, δ₁+…+δ₄) = 2s²/(s√2·2s) = 0.7071`）⇒ 该行标签**对**；
  - `sd(SHAPE) = σ√3 = 0.003373` ⇒ 在 `a = 1/√2` 下要求 **`ρ = 0`** —— 这是**零相关/最大方差端**，
    却被标成「**全**相关」⇒ **标签反向**。★ `ρ = 1` 端的真值是 `σ√(4a²+1−4a) = σ·0.414 = 0.00081`（**更小**）。
- **缺陷 ②（上界的前提没写）**：`σ√3` 这个**上界**依赖 `a = 1/√2`（等价于「四轮增量同方差且不相关」）。
  一般地 `ρ = 0` 端的上界是 **`σ·√(4a² + 1)`**，随 `a` 增大而增大：
  `a = 1/√2 ⇒ 0.003373` · **`a = 0.776（实测）⇒ 0.003593`** · `a = 1 ⇒ 0.004354`（此时 `3se@200 = 0.000924 > 闸门`）。
  ⇒ **卡 §3 的说法「两种极限下 `3se` 都 ≤ 闸门」应当读作**：「在 `a = 1/√2` 的前提下」；
  该前提在实测里**不严格成立**（`a = 0.776`），但**结论仍成立**（见 §3）。
