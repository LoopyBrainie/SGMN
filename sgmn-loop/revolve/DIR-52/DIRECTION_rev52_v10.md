## §0 本卡要回答的唯一问题，与边界

**D-67 已确认的效应**：AR(1)（`φ=0.9`）使六臂全部变差，但**前重臂 `Fu` 比后重臂 `Ku` 变差更多**：

```
ΔG = Δμ_K − Δμ_F = (+0.000860862) ± (3se = 0.000810078),  n = 52,  ΔG>0 的配对 34/52
```

D-67 的卡片**明文禁止**把它的解释性假设（§3.2「AR(1) 使相邻轮次键冗余 ⇒ 前重先写的条目被后续相关写入埋掉」）写成架构结论，理由是「**未**做逐轮分解」。本卡补做这件事。

**本卡要回答的唯一问题**：
> 这 `+0.000861` 的放大，是在**哪一轮**被生产出来的 —— **早段**（前重臂刚写完第一批时）还是**晚段**（后续相关写入累积之后）？

**两个互斥的机制签名（预注册，先于数据）**：

| 记号 | 机制 | 预测 |
|---|---|---|
| **M1 · 晚段累积**（= D-67 §3.2 的口头解释） | 前重臂**早写**的条目被**后续**高度相关的写入反复覆盖 ⇒ 伤害在**后面的轮次**才累积出来 | `SHAPE < 0` |
| **M2 · 早段生效** | 伤害近似正比于**该轮发放的写入数**；前重的配额本来就偏前（`W_F=(3.86,3.46,2.26,1.06)`）⇒ 差异在**第 2 轮**就出现 | `SHAPE > 0` |

**边界（不得外推）**：
1. 只测 `φ ∈ {0, 0.9}` 一档、`n_kv=60`、`R_pres=4`、`r=8`、`θ=0.9` ⇒ **不得**写「AR(1) 修正律」或「剂量-响应指数」。
2. **不得**把本卡的轮次结论外推到**读侧**（读流仍 iid）、其他 `θ / r / n_kv / N_read`、其他 `φ`。
3. **不得**用本卡的 `SHAPE` 反改 D-67 的 `DOS` 判定、阈值、`SUCCEEDED` 计数。
4. `Δμ_{U0}`、`ΔR_μ`、`B` 臂塌陷**仍不得**当判据（D-67 卡 §1 冻结「只报告」）。
5. 本卡是**机制定位**，不是新的效应确认 ⇒ `SHAPE` 不显著时**不得**写成「AR(1) 无影响」（D-67 的效应仍然成立）。

## §2 测量对象（唯一判据量）与**两条结构事实**

### 2.1 定义（冻结）

```
μ_{φ,p}(ρ) := ret_jitter_margin(P, K, vb, N_READ, R_HO8).mu
             其中 P = W(ρ) − W0，W(ρ) = 只呈现前 ρ 轮（keep 截断到 stream_idx < ρ·n·2M）后的状态
G_φ(ρ)  := μ_{φ,K}(ρ) − μ_{φ,F}(ρ)                （K = 后重臂 Ku，F = 前重臂 Fu）
ΔG(ρ)   := G_{0.9}(ρ) − G_{0}(ρ)                  （ΔG(0) ≡ 0：未写时两臂状态逐位相同）
ΔδG_ρ  := ΔG(ρ) − ΔG(ρ−1)                        （逐轮增量）
μ(0)    := 未写基座 W0 上的同一读数（ρ=0）
```

**唯一主判据量**：

```
EARLY := ΔG(2)                 （早段 = 第 1–2 轮；★ 见 2.2：第 1 轮结构性贡献 0）
TOTAL := ΔG(4)                 （= D-67 的 ΔG）
LATE  := TOTAL − EARLY         （晚段 = 第 3–4 轮）
SHAPE := EARLY − LATE = 2·ΔG(2) − ΔG(4)
```

### 2.2 ★ 结构事实 F-52-a：第 1 轮对 `φ` **逐位无关**

`dir26o/R1_ar1.py::build_stream_ar1` 的 AR(1) 递推从 `ρ=0` 起以 `Gf[i,0] = U[i,0]` **初始化**
（即第 0 轮方向直接取 iid 抽样，对所有 `φ` **逐位相同**）⇒ 只呈现第 1 轮时两档 `φ` 的写流**完全一致**
⇒ **`ΔδG_1 ≡ 0`（精确恒等，不是"小"）**。

★ 本卡因此把「早段」定义为 **前 2 轮**（`EARLY = ΔG(2) = ΔδG_2`），只有 **3 个有信息增量**（`ΔδG_2, ΔδG_3, ΔδG_4`）。
★ 该恒等式**必须**在 Stage A 中被**实测断言**（`A52-3`）；若实测不为 0 ⇒ 装置或本卡的理解有误 ⇒ **拦住正式轮**。

### 2.3 ★ 结构事实 F-52-b：`Σ_ρ ΔδG_ρ ≡ ΔG(4)` 是**算术恒等式**，不得当判据

`Σ_ρ ΔδG_ρ = Σ_ρ [ΔG(ρ) − ΔG(ρ−1)] = ΔG(4) − ΔG(0)`，而 `ΔG(0) ≡ 0`（同种子两档 `φ` 在未写时状态逐位相同）。

⇒ 「逐轮贡献之和等于总效应」**必然成立**，它只是**完整性检查**（不成立 ⇒ 实现有 bug）。
⇒ **本卡的判据只能是 `SHAPE`（形状）**，**不得**写成「分解成功 / 可加性成立」。

### 2.4 工作例（开卡前必须给定并通过）

`dir52/workex52.py`：对 1 个种子（`61000`）逐位核验三件事——
① `μ(4)` 必须与**未截断**的同装置读数**逐位相同**（`max|Δ| = 0`）⇒ 证明"截断到 4 轮 ≡ 完整呈现"；
② `Σ_ρ ΔδG_ρ` 与 `ΔG(4)` 的差 `≤ 1e-15`（§2.3 恒等式）；
③ `ΔδG_1` 与 `0` **逐位相同**（§2.2 恒等式）。

## §4 判据表与判定分支（冻结）

设 `n` = 有效种子数，`se = sd_seed(SHAPE)/√n`，`t = t_{0.95,n−1}`。

| 编号 | 谓词 | 阈值 |
|---|---|---|
| **P1（主）** | `mean(SHAPE) < −max(δ*, 3·se)` | `δ* = 0.000430` |
| **P2（否证支）** | `mean(SHAPE) > +max(δ*, 3·se)` | 同上 |
| **P3（有效性）** | 有效 `n ≥ 320`（剔除率 ≤ 20%）且 `Σ_ρ ΔδG_ρ − ΔG(4) ≤ 1e-12` 每种子成立 | 冻结 |
| **P4（分辨率闸门，先于 P1/P2 判定）** | `3·se ≤ 0.000861` | 见下 |

**判定分支（互斥、按序；`SUCCEEDED` 只认第 ④ 支）**：

1. **P3 不过** ⇒ `INVALID`（判据不可计算，**不得**记 PASS/FAIL）。
2. **P4 不过** ⇒ **`INFEASIBLE-POWER`**（连"全部局部化"都分辨不了 ⇒ 本卡在冻结 `n` 下**测不出形状**；
   先例：D-67 卡 rev 1.2 的 `INFEASIBLE-POWER`）。**不得**硬判。
3. **P1 过** ⇒ **`PASS`** ⇒ `H52` 确认 ⇒ **计入 `SUCCEEDED`**。
4. **P2 过** ⇒ `EARLY-LOCALIZED` ⇒ `H52` **被否证** ⇒ **不计入**。
5. **P4 过但 P1/P2 都不过，且 `3·se ≤ δ*`** ⇒ `NOT-LOCALIZED`（形状可分辨但两侧都不显著）⇒ **不计入**。
6. **P4 过但 `3·se > δ*`，且 P1/P2 都不过** ⇒ `INCONCLUSIVE-BELOW-RESOLUTION`
   （只能分辨"强局部化"，测不出中等偏置）⇒ **不计入**，并在结论中**如实写明分辨下限**。

★ 第 ⑥ 支是本卡的**主要诚实风险**：`n=400` 下若增量强相关，`3se(SHAPE)` 可达 `0.000506`（见 §5），
此时"中等偏置"（< 59% 总效应）**测不出** ⇒ 必须报 `INCONCLUSIVE-BELOW-RESOLUTION`，**不得**写成"未局部化"。
