```

EARLY  = ΔG(2)
```

### ★★ P4 正当性的**精度勘误**（`DEF-52-2`，见 `DIRECTION_rev52_v13.md`）

卡 §3 原表把 `ρ=0` 端标成「全相关」（**标签反向**），且上界 `σ√3 = 0.003373` **隐含前提
`a := sd(ΔG(2))/sd(ΔG(4)) = 1/√2`**。通用式：`Var(SHAPE) = σ²(4a² + 1 − 4aρ)`，
故 `ρ=0` 端上界 = **`σ·√(4a²+1)`**（`a=0.776` 实测 ⇒ `0.003593`；`a=1` ⇒ `0.004354` ⇒ 会超闸门）。

⇒ **VERDICT 写 P4 时，必须**：
1. 从 `EARLY.sd` / `TOTAL.sd` 算出**实测 `a` 与 `ρ`**，代入上式给出**实测**上界 —— **不得**照抄 "两种极限都 ≤ 闸门"；
2. 报告**实测** `sd(SHAPE)` 与投影 `3se@200`；
3. 报告**临界** `sd(SHAPE) = 0.000861·√n_eff/3`（`n_eff=200` ⇒ **0.004059**），说明当前余量；
4. 若最终落第 ② 支 `INFEASIBLE-POWER`，**必须**写明是 `sd` 超过了 0.004059，并指出卡 §3 的
   上界前提（`a=1/√2`）在本装置**不严格成立**（实测 `ρ ≈ 0` 而非 iid 的 0.707）。
★ 本勘误**不改**任何决策输入（`δ*`/闸门/`n`/种子段/`min_n_eff`/分支序），实测下**分支不变**。
