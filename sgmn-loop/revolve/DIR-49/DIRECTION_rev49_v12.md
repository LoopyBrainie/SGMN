## §0 一句话

**写入一个新对时，它对旧记忆的破坏，是不是由「它的键与旧记忆的键有多重合」决定的？**
若答案是「**是**」⇒ 干扰是**选择性**的 ⇒ 「键空间设计」是一条**可用的防御**；若答案是「否」⇒ 干扰是**均匀**的 ⇒ 只能靠容量/replay/其它机制兜底。

## §1 主假说与否证条款

**`H49`（合取，三条都必须成立）—— 「干扰强度被键重叠度单调调制（键重叠是**调制因子**，不是唯一来源）」**

- **P1（单调调制）**：把四臂按实测 `ov_k` 递增排序（`ortho → d0.0 → d0.5 → d1.0`），相邻配对差
  `ADJ := mean_over_3segments( rel(ov_k 小) − rel(ov_k 大) )` 满足 **`ADJ ≥ ADJ_MIN = 0.10`** 且 **`ADJ ≥ 3·se(ADJ)`**；
- **P2（端点差）**：端点差 `DELTA_END := rel(ortho) − rel(d1.0)` 满足 **`≥ DELTA_END_MIN = 0.30`** 且 **`≥ 3·se`**；
- **P3（基底存在性）**：**零键重叠**的干扰写**仍造成可测损伤**：`rel(ortho) ≤ REL_ORTHO_MAX = 0.95`
  ⇒ 干扰**不是**「只有键重合才伤」，而存在一个**与键无关的基底损伤**。

**否证/替代结局（各自独立，按 §5 顺序命中）**
| 条款 | 条件 | 结局 |
|---|---|---|
| F1 | `DELTA_END` 不成立（≤ 0 或 < 3se） | `NO-KEY-MODULATION` —— 干扰与键重叠**无关**（均匀） |
| F2 | `rel(ortho) ≥ 0.95` | `PURE-KEY-SELECTIVE` —— 干扰**只**由键重合决定（无基底） ⇒ `H49` 的 P3 不成立 |
| F3 | P2 成立但 P1 不成立 | `PARTIAL-MONOTONE` —— 有端点差但中间段不单调 |
| F4 | 任一判据量与其阈值相距 `< 3se` | `MARGINAL` —— 判据不可分辨 |

★ **为什么 P3 必要（不是"顺手加的"）**：`probe49c` 实测**正交**干扰写（`ov_k = 1.2e-8`）也把目标打到 `rel1 = 0.666` ⇒ 键重合**不是唯一**来源；
若卡片只测 P1/P2，就会把"存在基底损伤"这一事实**藏进**结论里。⇒ P3 把基底**显式写成判据**，使 `PURE-KEY-SELECTIVE` 与 `PASS` 成为**互斥**结局。

## §3 测量对象（**已用 worked example 校验**）

### 3.1 单实例流程（**一实例 = 一个目标对 = 四臂配对**）

对实例 `sd`：
1. 内容流 `a_0 … a_{NMARK−1}`（`perstep`，`NMARK = CTX+1+max(W) = 36`，**固定长度生成后切片** —— `DEF-48-4` 的修法，本卡沿用）；
2. `H_t = tanh(a_t A1 + b1)`、`k_t = tanh((0 if t=0 else H_{t−1}) Pk1)`、`v_t = tanh(H_t Pv1)`（逐字沿用 `dir46/dir48`）；
3. 写 `index 0,1,2`（上下文）+ `index 3`（**目标对**）⇒ 得 `(U,V)` 与 `c0 = cos(W k_3, v_3)`；
4. **分叉**四臂（从**同一** `(U,V)` 出发 ⇒ 目标与 `c0` 四臂**逐位相同**）：
   - 每臂构造 `a_4`（`ortho` 用梯度下降求正交；`d0.0/d0.5/d1.0` 用线性混合 `a_4(w) = norm((1−w)·a_4^base + w·a_2)`）；
   - 重建 `(K,V)`（`a_4` 变了 ⇒ `k_5` 变；`v_5` 不变）；
   - 写**干扰对** `index 5` ⇒ 读 `c1 = cos(W k_3, v_3)` ⇒ **`rel1 = c1/c0`**；
   - 再写 `index 6..12` 七个自然对 ⇒ 读 `cN` ⇒ `relN`（附带）。
5. 读数附记：`ov_k = |cos(k_3, k_5)|`、`ov_v = |cos(v_3, v_5)|`、`res = ‖W k_5 − v_5‖`。

### 3.2 ★ 构造不变量（**卡的核心，也是 Stage A 的重点**）

| 不变量 | 为什么必须 | 怎么保证 | 怎么验 |
|---|---|---|---|
| **四臂的 `ov_v` 逐位相同** | 否则"伤害随 `ov_k` 变"可能是"伤害随**值**变" | 只改 `a_4` ⇒ `v_5 = tanh(H_5 Pv1)`（`H_5` 只依赖 `a_5`）不变 | `A49-3`（标定实测：四臂 `ov_v` 全为 `0.5115571265921358`，**逐位相同**） |
| **四臂的目标 `(k_3,v_3)` 与 `c0` 逐位相同** | 否则四臂起点不同 | `k_3` 只依赖 `a_2`、`v_3` 只依赖 `a_3`，都不改 | `A49-5` |
| **`ov_k` 四档确实分开** | 否则"剂量"是假的 | `ortho` 由优化保证；`d1.0` 由 `a_4 = a_2` 保证 | `A49-4`（`ortho ≤ 1e-5`、`d1.0 ≥ 0.999`、中间两档按序） |
| **`res`（残差）不是隐藏驱动** | 残差大 ⇒ 写得猛 ⇒ 伤害大 | `res` 随剂量只漂 **14%**（`1.029 → 1.176`），而 `rel1` 掉 **89%** | `res` 逐臂记录（**不入判据**，作报告）；`probe49b` 实测 `pear(ov_k, res) = 0.065`（实例内） |

### 3.3 worked example（`dir49/workex49.py`，**逐位**）

独立手写链重算 3 实例 × 4 臂的 `ov_k / ov_v / c0 / c1 / cN / rel1 / relN`，与实现**逐位相等**（`ATOL=1e-9`，理由见 §10 `DEF-49-3`）；两条链一致才算过（`A49-2`）。

**诊断结论（决定卡形）**：
1. ★ **键重叠度自然分布够宽** ⇒ 可分层 ⇒ 不必判 `INFEASIBLE-PREMISE`（任务卡红线①**不触发**）。
2. ★ **但自然臂混淆无法排除**（`ov_k` 同时与实例、偏移、值重叠纠缠）⇒ 必须用**构造剂量臂**：把 `a_4` 连续旋到目标键上，**只**操纵 `ov_k`，把 `ov_v` 与目标 `(k,v)` 钉死。
3. ★ **正交锚可达 `ov_k ~ 1e-8`** ⇒ "零重叠"这一端点**可测**，P3 可判。
4. ★ **`relN` 无分辨力** ⇒ 本卡**只**判 `rel1`；`relN` 留作报告（"干扰损伤**不可自愈**"由 D-71 负责，不在本卡重复主张）。
5. ★ **逐实例三段全单调只有 30.5%** ⇒ 单实例噪声大（`rel1` 的 `3se ≈ 0.10`）⇒ **判据必须用配对差的均值**（`ADJ`）而非"逐实例全单调"，后者是噪声主导的伪判据（**`DEF-49-1`**）。
