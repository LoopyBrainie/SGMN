## §4 ★★ `J124-2` 为什么**作为判据无效**（`DEF-124-01`）

### §4-1 事实一：`dose = 0` 的 `m` **超出 `u ≥ 1` 的可达上限**

`mech123.solve_u` 有一条**继承来的**限制：`if m >= hi_val: return 1.0`，其中
`hi_val = N₁·p₁(1) + N₂·p₂(1)`（`p₁(1) = 2/3`、`p₂(1) = 1/3`）——
理由是「`u < 1` 无物理意义（加成不可能为负）」。

| 数据 | 每层 `hi_s` | `Σhi` | `Σm` | 边界激活层数 |
|---|---|---|---|---|
| `dose = 600` | `78.333` | `705.00` | `133` | **0 / 9** ✓ |
| `dose = 0` | `22.000` | `198.00` | **`248`** | **7 / 9** ✗ |

★★ **`dose = 0` 的每一层（7/9）的 `m_s` 都超过该层在 `u = 1` 处的可达上限**
（例：`N₁ = 23, N₂ = 20` ⇒ `hi = 22`，实测 `m` 到 `36`）。
⇒ `û` 被**夹在边界 `u = 1`** ⇒ `θ_s = N₁·(2/3)/m_s` 是**边界值**，
而**不是**产生数据的那个 `u` ⇒ ★ **零模型不是数据的生成模型**。

★ 这也说明 `dose = 0` 的真实每候选加成 **`< 1`**（未训练模型**轻微回避**「训练值」）——
`solve_u` 的定义域根本不含真值。

### §4-2 事实二：该检验在 `H124` **为真**时的 size 是 **`0.9405`**

用 `dose = 0` 的**结构**（`N₁ = 23`、`N₂ = 20`、9 层）+ **共同 `u`**（即 `ratio = 1`，
`H124` 为真）合成数据，再跑同一个 `strat_test`：

| `u_true` | 边界激活层占比 | **拒绝率**（应 ≈ `α = 0.05`） |
|---|---|---|
| `0.55` | `0.978` | **`0.9405`** |
| `0.80` | `0.807` | **`0.3695`** |

⇒ ★★ **当 `H124` 为真且 `u < 1` 时，这个检验有 94% 的概率「拒绝」**。
它是一个被违反的边界所产生的**假阳性机器**，不是混杂的证据。

**对照（`dose = 600` 结构，`u ≥ 1`，边界不激活）：**

| `u_true` | 拒绝率（应 ≈ `0.05`） |
|---|---|
| `2.0` | `0.0135` |
| `9.2` | `0.0360` |

⇒ 两者都 `≤ α` ✓ ⇒ ★ **`J124-1` 不受此缺陷影响**（它的边界从未激活）。

### §4-3 因此的处置

按卡片 §8 的预案（「`J124-2` 不可执行」行），`J124-2` 记 **不可采用/不可执行**，
判决落**第 1 行**，且**归因一律不可判**。

★★ **我没有做**的事：没有把 `solve_u` 的定义域放宽到 `u > 0` 然后重跑 `J124-2`。

## §8 缺陷（全部是我自己的）

### `DEF-124-01` —— ★★ 我把 `solve_u` 的 `u ≥ 1` 夹紧**原样继承**，没检查负对照是否满足

`mech123.solve_u` 的 `if m >= hi_val: return 1.0` 在 `DIR-123` 里**从未被触发**
（`dose = 600` 的 `Σm = 133 ≪ Σhi = 705`）。我把它抄进 `DIR-124` 时**没有验证**
`dose = 0` 是否落在定义域内 —— 而它**不在**（`Σm = 248 > Σhi = 198`，7/9 层激活）。

**后果**：`J124-2` 的零模型在**被数据违反的边界**上取值 ⇒ size `0.9405`（应 `0.05`）。
**若我不做 `diag124_clamp.py`，我会把 `p = 2.7e-04` 当成"混杂已检出"写进证据行**，
从而得出**与事实相反**的结论（"超加性只是先验"）。

**修法（本卡内）**：`J124-2` 记**不可采用**；改用**模型无关**的 `ŵ` 比较（§5）作为
非判据读数。**未做**：没有放宽定义域重跑（那是看到结果后的改动）。
★ **教训（写进后续所有卡片）**：**继承一个有定义域限制的求解器时，必须先验证新数据落在定义域内**；
`solve_u` 这类"夹紧"函数**必须**把它是否被触发**打印出来**（本卡现在 `diag124_clamp.py` 会打印）。

### `DEF-124-02` —— `stats` 的浮点归一：双侧 `p` 可算出 `1 + 1e−16`

`A124-10` 因严格 `<= 1.0` 判 FAIL。**修法**：`_tails` 把三个尾概率夹到 `≤ 1`（概率 `> 1` 无意义）。

### `DEF-124-03` —— `strata_of` 的 `qset` 轴**漏乘 `n_seeds`**

首版 `N1 = n_of(r, 1)`（单 cell），但该层覆盖 9 个 cell ⇒ 应为 `9 ×`。
被 **`S3`**（结构核的"ΣN1 须等于池化分母"）在开卡前抓到。**修法**：乘以 `n_seeds`。

### `DEF-124-04` —— 首版 `S11` 断言"水平贴近 `α`"，那是**错的期望**

精确条件检验在离散小样本下**必然保守**（实测 `0.0095 / 0.0350 / 0.0378 < 0.05`）。
**修法**：改成断言「**有效性**（`≤ α + MC` 误差）+ **不退化**（`≥ 0.005`）」。

### `DEF-124-05` —— 首版 `S12` 禁用词自匹配造成**假 FAIL**

`banned = ["stratum_obs(", ...]` 的字面量本身出现在源码里 ⇒ 永远命中。
**修法**：用**拼接构造**（`"stratum" + "_obs("`）并排除 `#` 注释行与 `banned =` 行。

### `DEF-124-07` —— ★★ 判决表**缺少"负对照失效"一行**

卡片 rev 1.1 §2-3 的 5 行只覆盖「`J124-1` 可执行/不可执行 × `J124-2` 拒绝/不拒绝」，
**没有**「`J124-2` 可执行但**不可信**（size 失效）」这一种。
⇒ 冻结规则的字面输出（第 2 行）与有效性作废后的采用结果（第 1 行）**不一致**，
而冻结表**没有条款**决定哪个优先。

## §10 证据边界（**不得外推**）

1. ★★ **`J124-2` 的读数（`p = 2.68e-04`、方向 `high`）不得被引用为任何证据** ——
   该检验在 `H124` 为真、`u = 0.55` 时的 size 是 `0.9405`（§4-2）。
2. ★★ **`H124` 成立的证据只来自 `dose = 600`**，而那是**与 `D-154` 同一批 cell** ⇒
   **不是独立确认**（§2-3）。**不得**把它与 `D-154` 当两个证据相加。
3. ★★ **归因不可判**：`§5` 的 `ŵ` 比较只是**模型无关的描述性读数**，不是判据。
   任何「已证明超加性来自学习」的写法都**越界**。
4. ★★ **只有 `k ∈ {1,2}` 两个可用层** ⇒ 一个自由度；**两点无法确定形状**
   （不能区分二次 / 阶跃 / 饱和）。
5. ★ **`w_k` 是乘性可交换模型下的描述性估计量**；`dose = 0` 的 `ŵ ≈ 0.55 < 1` 说明
   该模型在未训练态连"加成非负"都不成立 ⇒ **`w` 的量纲不可跨 regime 直接比较**，
   只能比较 `ŵ₂/ŵ₁` 这个**比值**。
6. ★ **`m_s` 是条件量**：本卡只答「给定各层 `m_s`，`k=1`/`k=2` 的分配是否与共享一个
   每候选加成相容」；**不**答「总逃逸为什么是那个数」。
7. ★ **`k = 3` 层全程未用**（`CORR-35` ①）；`A124-7` 是结构守卫。
8. ★ **不改** `§7.2-7b` 的 `不足` 状态 ⇒ **终止条件仍不成立**。
9. ★ **不回答**「什么把 seed 分成两类」（= `P121-2`）、**不测**真实 LLM 任务收益。

## §11 可带走的结论

1. ★★ **`H124` 在训练态成立**：`k=2` 层的每候选加成高于 `k=1` 层
   （分层双侧精确检验 `p = 3.67e-04`，`ŵ₂/ŵ₁ = 1.957`）。
   ★ 但按卡片 §2-6 预注册，**不计入 `SUCCEEDED`**（同批数据的复核，非独立确认）。
2. ★★★ **合并（pooling）本身就是错误指定** —— 这是本卡最重要的方法学结论。
   同一个效应，合并 `p = 4.08e-03`、按 seed 分层 `p = 3.67e-04`（**锐 11 倍**）。
   机制：`D-153` 已证的 seed 级异质性在被合并时**撑宽了零分布**。
   ⇒ 后续任何跨 seed 汇总的判据都必须**先分层**。
3. ★★ **`u ≥ 1` 这条限制在未训练态不成立**（真实 `u ≈ 0.55`）——
   凡继承 `solve_u` 的方向都必须先验证定义域（`DEF-124-01`）。
4. ★ **模型无关的 `ŵ₂/ŵ₁` 在未训练态是 `0.935`（平坦）**，在训练态是 `1.957`（翻倍）
   ⇒ **描述性上**，超加性是训练态特有的；但它**不是判据**。
5. ★ **负对照的功效必须先算**：`dose = 0` 只有 1 个题集（`ΣN₁ = 207`），
   运行点功效仅 `0.2487` ⇒ 即使不失效，它也**只能排除强混杂**。
