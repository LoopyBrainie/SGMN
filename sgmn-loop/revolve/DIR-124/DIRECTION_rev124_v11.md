## §2 MVP 标准（**冻结**，含数值阈值）

### §2-0 「完成」的定义

本方向的 MVP = **三个产物**（缺一不算完成）：

1. **`J124-1` 判决**：在**训练态（`dose = 600`）**上，用**分层**精确条件检验判定 `w₂ > w₁`；
2. **`J124-2` 判决**：在**未训练态（`dose = 0`，`W = W⁰`）**上，用**同一统计量**做**负对照**；
3. **归因陈述**：`§2-3` 判决表把两者组合成一句**关于归因的话**（能/不能归因于学到的加成）。

### §2-1 `J124-1`（主判据，α = **0.05**，`dose = 600`）

**统计量**：按 **seed 分层**（9 层；`AXIS = "seed"`，理由见 §2-4）的**精确条件检验**。

对每层 `s`：
- 机会数 `N₁ˢ = Σ_{q∈4题集} #{i : n_seen_i = 1}`、`N₂ˢ = Σ_q #{i : n_seen_i = 2}`
  —— ★ **只由结构决定**（`n_seen` 直方图 × 层内 cell 数），与被测观测无关；
- 条件量 `m_s := e₁ˢ + e₂ˢ`（实测）；
- `û_s` 由 `N₁ˢ·p₁(û_s) + N₂ˢ·p₂(û_s) = m_s` **唯一**确定（左侧对 `u` 严格递减）；
  `θ_s := N₁ˢ·p₁(û_s)/m_s`；
- 原假设下 **`e₁ˢ | m_s ~ Binomial(m_s, θ_s)`**，且**层间独立**
  ⇒ **`S := Σ_s e₁ˢ`** 的零分布 = 各层二项分布的**精确卷积**
  ⇒ **给定 `m_s` 后没有任何剩余多余参数**（不是 plug-in 近似）。

**判据**：**双侧精确 `p ≤ 0.05` 即拒绝**。
双侧定义：`p = Σ_{k : pmf(k) ≤ pmf(S)·(1+1e−9)} pmf(k)`（`DIR-123` 同一约定）。
方向 = `sign(S − Σ_s m_s·θ_s)`（`high` / `low` / `eq`）。

★ **为什么双侧**：`H124` 的方向来自 `D-154` 的读数 ⇒ 若用单侧就等于**挑了方向**。
双侧消除该选择偏倚；代价是功效从 `0.9273` 降到 **`0.8694`**（§2-5，机器算的），仍 `≥ 0.80`。

## §3 测量对象 + 工作例（**可手算**，逐位复核）

### §3-1 测量对象

`e₁ˢ` / `e₂ˢ` = 第 `s` 个 seed 在 `n_seen = 1` / `= 2` 的项上**逃逸**的项数，
`逃逸 := 1[n_seen ≥ 1 ∧ pick_argmin ∉ tv]`（`mech122.escape_mask`，与 `DIR-119`…`DIR-123` 同一实现）。
`pick_argmin` 取 `mech_by_mult["10000"]` / `c2["10000"][rng]`（`mult = 1e4` 已饱和，`D-119` 冻结）。

`dose = 600` 时上述取值与 `D-154` **逐字相同**（`A124-2` 守卫断言回归）。

### §3-2 工作例（合成，**非观测值**）

两层：`A: N₁=4, N₂=5, e₁=3, e₂=0`（⇒ `m=3`）、`B: N₁=6, N₂=3, e₁=1, e₂=0`（⇒ `m=1`）。

**层 A**：解 `4·p₁(û) + 5·p₂(û) = 3`。
试 `û = 2`：`4·(2/4) + 5·(1/5) = 2 + 1 = 3` ✓ **精确**，且唯一（左侧严格递减）。
⇒ `θ_A = 4·(1/2)/3 = 2/3` ⇒ `Binomial(3, 2/3)` = `[1/27, 6/27, 12/27, 8/27]`
= `[0.0370370370, 0.2222222222, 0.4444444444, 0.2962962963]`。

**层 B**：解 `6·p₁(û) + 3·p₂(û) = 1` ⇒ `û = 11.6846584384`、`θ_B = 0.8768943744`
⇒ `Binomial(1, θ_B)` = `[0.1231056256, 0.8768943744]`。

**卷积**（`S` 的零分布，`S ∈ 0..4`）：

| `S` | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| `pmf` | `0.00455947` | `0.05983438` | `0.24957903` | `0.42620657` | `0.25982056` |

（校验：`pmf[0] = (1/27)(0.1231056) = 0.004559` ✓；和为 `1.000000000000000` ✓）

**观测** `S = e₁ᴬ + e₁ᴮ = 3 + 1 = 4`。
- `E[S] = 3·(2/3) + 1·0.8768944 = 2.8768944` ⇒ `S = 4 > E[S]` ⇒ 方向 **`high`**；
- **上尾** `= pmf[4] = 0.2598205554`；
- **下尾** `= 1.0000000000`；
- **双侧** `= pmf[0]+pmf[1]+pmf[2]+pmf[4] = 0.5737934260`
  （`pmf[3] = 0.426207 > cut = 0.2598206` ⇒ 排除 ✓）。

⇒ `strat_test` 实测 `p_two = 0.5737934260`、`p_upper = 0.2598205554`、
`direction = high`、`reject = False`、`expect = 2.8768943744` —— **与手算逐位相同**。
★ 此例留在 `test_mech124.py` 作硬编码断言。

## §6 边界（**不得外推**，与 `D-154` §6 并行）

1. ★★★ **`J124-2` 不拒绝 ≠ 无混杂**：负对照只有主检 `1/4` 的机会数（§2-2），
   运行点功效仅 **`0.2487 @ ratio = 2`**（§2-5b）⇒ 只能排除 `ratio ≳ 4` 的**强**混杂。
   ⇒ ★ **归因在本卡一律不可判**，与本卡落在哪一行无关。
2. ★★ **`J124-1` 与 `D-154` 的 `J123-1` 是同一批数据** ⇒ 两者高度相关，
   **不得**当两个独立证据相加/相乘。
3. ★ **`J124-1`/`J124-2` 是不同数据**（`dose=600` vs `dose=0`）⇒ 可并列，但
   `J124-2` 回答的是**归因**，不是 `H124`。
4. ★★ **只有 `k ∈ {1,2}` 两个可用层** ⇒ 一个自由度的比较，**两点无法确定形状**
   （不能区分二次 / 阶跃 / 饱和）。
5. ★ **`m_s` 是条件量**：本卡只答「**给定**各层 `m_s`，`k=1` 与 `k=2` 的分配
   是否与"共享一个每候选加成"相容」；**不**答「总逃逸为什么是那个数」。
6. ★ **`û_s` 是乘性可交换模型下的估计量**；若真实机制不是乘性权重，`θ_s` 只是
   归一化摘要，**不得**读成已证实的机制参数。
7. ★ **不改** `§7.2-7b` 的 `不足` 状态 ⇒ **终止条件仍不成立**。
8. ★ **不回答**「什么把 seed 分成两类」（= `P121-2`）、**不测**真实 LLM 任务收益、
   **不碰** `k=3` 层。

## §8 缺陷预案（事前写清，避免事后找理由）

| 若… | 则… |
|---|---|
| `dose = 0` 的 `m` 全为 `0`（无逃逸） | `J124-2` **不可执行** ⇒ 判决表按「`J124-2` 不可执行」处理：行 1 降级为 **`H124` 成立但无负对照**（归因**不可判**），并在 `VERDICT` 写明 |

| `θ_s` 无解（`m_s` 超出可达范围） | 该层跳过并计数；若全部跳过 ⇒ 行 4 不可判 |
| `dose = 0` 的 `W_bitwise_same` 为假 | ★ **负对照无效** ⇒ `J124-2` 记不可执行（训练态冒充未训练态是最坏的假阴性） |
| 三轴结论不一致 | 只按**预注册轴 `seed`** 判决；另两轴写进 `VERDICT` 的 report-only 段并**明确标注不一致** |
