## §0 术语与前提更正（`CORR-35`，★ 最重要的一节）

### §0-1 逃逸的精确定义（照代码，不照直觉）

`escape_mask(...)` 的定义是：

> **逃逸 ⟺ `n_seen ≥ 1` 且 选中的值 ∉ `tv`**

其中 `tv` = **训练侧 8 个值**。★★ 由此推出两个**不依赖观测**的恒等式：

1. **正确值恒 ∉ `tv`**（`partitions_colocated` 把 16 个值切成训练侧 8 / 留出侧 8，
   eval key 的正确值属留出侧）⇒ **选对也被算作逃逸**。
2. ⇒ **在 `n_seen = 3` 层，逃逸 ⟺ 选对**（3 个干扰项全 ∈ `tv`，「∉ `tv`」只剩正确值一条路）。
   ⇒ ★ **该层测的是准确率，不是泄漏倾向**，**不得**进「剂量」比较。

`precheck123.S5` 用**穷举**（`k=0..3 × 4` 个正确位置 `× 4` 个选择 = 64 组）机械确认了这两条。

### §0-2 ★★ 任务行给的判据在机制上不可执行（这是本卡的立论根据）

`P122-1` 原文写：「若 `p₃ > p₁` 显著 ⇒ 剂量型；若 `p₁ ≈ p₃` ⇒ 阶跃型」。
**这不可执行**，有两个独立理由：

**(a) `k = 3` 层恒退化。** 由 §0-1-2，`p₃` 是准确率，与 `p₁` 不是同一个量。

**(b) 原始 `p_k` 在任何「每候选权重」模型下都被机制强制成递减。** 设每个见过的候选权重
`u = 1+b`、每个未见过候选权重 `1`，则

| `k` | 见过槽 | 未见过槽 | 逃逸（= 选未见过）概率 |
|---|---|---|---|
| 1 | 1（权重 `u`） | 2（权重 1） | `p₁ = 2/(u+2)` |
| 2 | 2（权重 `u`） | 1（权重 1） | `p₂ = 1/(2u+1)` |

而 `p₁ > p₂ ⟺ 2(2u+1) > u+2 ⟺ 3u > 0` —— **对任何 `u > 0` 恒成立**。
⇒ ★★ **原始逃逸率必然随 `k` 递减，这是装置的算术后果、不是 `M1` 的证据**。
任何「`p₃ > p₁` 所以是剂量型」的读法，都是把装置几何当成机制发现。

### §0-3 ★★★ 正确的等价量：每候选加成 `w_k`（`k`-不变量）

定义

```
        S_k · (3 − k)
w_k  := ───────────────        S_k = P(选已见干扰项 | k)，U_k = P(选未见面干扰项 | k)
        U_k ·    k
```

即「**每个见过的候选**相对「每个未见过的候选」的权重比」。代入 §0-2 的 `p_k`：

`w₁ = u`、`w₂ = u` —— **代数上恒等于 `u`，与 `k` 无关**（`precheck123.S7-a` 在 `u ∈ [1,200]`
的 1992 个点上核到 `max|Δ| = 2.8e-14`）。

⇒ ★ 于是「`M1` 是否是均匀加成」变成一个**可检验的陈述**：

> **`H123`：`w₁ = w₂`** —— 即每候选加成**与「见到几个」无关**。

而不是「`p₁` vs `p₂`」（那恒真）。

### §0-4 `H123` 的等价形式：一个**参数无关**的精确预测

令 `OR = [p₁/(1−p₁)] / [p₂/(1−p₂)]`。由 `w_k` 的定义反解 `S_k/U_k = w_k·k/(3−k)`：

```
OR = 4 · w₂ / w₁
```

（`S7-b` 核到 `max|Δ| = 8.9e-16`）。⇒ ★★ **`H123` ⟺ `OR = 4`**，
这是一个**不带任何多余参数**的精确数值预测 —— 与 `DIR-122` 的 `1/36` 同类的强预测。

## §3 手算例（开卡前逐字算过）

### §3-1 `w_k ≡ u` 与 `OR = 4`（取 `u = 4`）

`p₁ = 2/(4+2) = 1/3`，`p₂ = 1/(2·4+1) = 1/9`。

- `S₁ = 2/3`、`U₁ = 1/3` ⇒ `w₁ = (2/3)·2 / ((1/3)·1) = (4/3)/(1/3) = 4` ✓
- `S₂ = 8/9`、`U₂ = 1/9` ⇒ `w₂ = (8/9)·1 / ((1/9)·2) = (8/9)/(2/9) = 4` ✓
- `OR = (1/3 ÷ 2/3) / (1/9 ÷ 8/9) = (1/2) / (1/8) = 4` ✓

### §3-2 机制强制递减（取 `u = 1`，即「见过值只多一票」）

`p₁ = 2/3 ≈ 0.667`、`p₂ = 1/3 ≈ 0.333` ⇒ **`p₁ > p₂` 恒成立**（任意 `u > 0`）
⇒ 原始率比较**零信息**（§0-2b）。

### §3-3 条件检验的手算（取 `m = 40`）

解 `612·2/(û+2) + 891/(2û+1) = 40` ⇒ `û = 40.148`；
`p₁(û) = 2/42.148 = 0.047451`、`p₂(û) = 1/81.296 = 0.012301`；
`E[e₁] = 612 × 0.047451 = 29.04`、`E[e₂] = 891 × 0.012301 = 10.96`
⇒ 和 `= 40.00` ✓（自洽）；`θ = 29.04/40 = 0.72600`。
`Binomial(40, 0.726)` 的精确双侧接受域 = **`23..35`**（实际水平 `0.01962`）。
⇒ 若实测 `e₁ = 22` ⇒ 拒绝且 `e₁ < E` ⇒ **次加性**；若 `e₁ = 37` ⇒ 拒绝且 `e₁ > E` ⇒ **超加性**。

### §3-4 `n_seen` 的 pmf 对照

`Hypergeom(15, 8, 3)`：`k=0: 0.0769`、`k=1: 0.3692`、`k=2: 0.4308`、`k=3: 0.1231`。
