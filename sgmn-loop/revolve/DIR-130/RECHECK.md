## §1 事实：`K15` 的 `FAIL` **属实**，缺口是**文档**的

`K15` 的 `检查` 有两个合取项：① 每处纪律都要有 `S\d+` 断言**执行**它；
② **并在段落里点名**该 `S` 编号。本卡满足 ①、不满足 ②：

| 位置 | 小节 | 是否本节有 `S` | 判定 |
|---|---|---|---|
| `L185` | `§6 工作例` —— `**不得**打印属于判据的**聚合读数**（\`p₃₅₀\`/\`p₃₀₀\` 及其任一中间聚合）` | **无** | ⇒ 记 `FAIL` 的那一处 |
| `L231` | `§9 修订记录` —— `★ 只加 S9，判据/阈值一字未动：--stage precheck 不得打印 C2/C3` | 有（`S9`） | `PASS` |

★ 成因是**版本演进**，有案可查：`S9` 是 **`v1.2` 才补的**（`§9` 原文「**只加 `S9`**，判据/阈值一字未动」），
而 `§6` 那段纪律是更早写的，**补 `S9` 时没有回链 `§6`** ⇒ 纪律正文与它的守卫在文档上**脱钩**。
机械佐证（`check_cards.py --probe-k15-scope`，`Cycle 254` 实跑）：本卡命中 **2 处 / 分布在 2 个小节**；
卡内共 **9** 个 `S` 编号（`S1`…`S9`）；`§6` 的 body 里没有任何 `S\d+`。

## §2 但纪律**没有**被忘记配守卫 —— `S9` 真的在跑

★ 这一点必须写清，否则本 `RECHECK` 会被误读成「这张卡只有文字纪律」：

## §3 ★ 本节是本文的真正价值：`S9` 的覆盖度**窄于**它所执行的纪律

`§6` 禁的是「`p₃₅₀`/`p₃₀₀` **及其任一中间聚合**」。而 `S9_FORBIDDEN`（从
`precheck130.py` 用 `ast` 读出，不 `import`）只有 **5 个字面 token**：

```
('p₃₅₀ =', 'p₃₀₀ =', '★ 判决:', 'C130-FRAC', 'C130-PROTOCOL')
```

把它当检测器逐例实测（**机械复算，不是论证**）：

| 场景 | 文本 | `S9` 是否命中 |
|---|---|---|
| 判据终值、带空格 | `p₃₅₀ = 0.0` | **命中** ✓ |
| 判据终值、**无空格** | `p₃₅₀=0.0` | **漏** ✗ |
| `p₃₅₀` 的**分子**（中间聚合） | `frac>0 的 (sub,C) 对数 = 12345` | **漏** ✗ |
| `p₃₅₀` 的**分母**（中间聚合） | `可算 (sub,C) 对数 = 18000` | **漏** ✗ |
| 逐 `k` 的 `frac==0` 计数（中间聚合） | `k=3: frac==0 的 C 有 84 个` | **漏** ✗ |
| 判决行 | `★ 判决: C130-FRAC-STABLE-BOTH-SIDES` | **命中** ✓ |

⇒ **6 例漏 4**，其中**三个**正是 `§6` 明文禁止的「**及其任一中间聚合**」，另一个是
同一个终值的**无空格写法**。★ 也就是说：`S9` 执行的只是 `§6` 纪律的**一个真子集**。

★ **必须同时说明的两点，否则会夸大**：
1. **这是"latent"（潜伏）缺口，不是已发生的违规**。`precheck130` 现在**不打印**上表任何一行；
   `P134-2` 的逐卡实跑裁定（trainer，`stdout` 原样留档）给出 **11 张 0 违规**，
   机械佐证是「11 份输出中含 ≥20 个数字的行数 = **0**」。⇒ 当前**没有**判据读数被泄漏。
2. 本卡的 `S9` 是**卡片自己冻结**的禁用词表 —— 按 `K16` 的判读（`P134-1`/`P134-2`），
   「哪些词算 formal 的判据读数」**只能由卡片在开卡时自己定**，核对器**不得**代拟通用词表。
   ⇒ 这不是「`S9` 写错了」，而是「`S9` 写得比它要执行的纪律**窄**」。

## §4 为什么这是**文档缺口 + 覆盖不足**，而**不是**「这张卡把实验做错了」

- 判据（`C0`/`C2`/`C3`/`C4`/`C5`）、阈值、读数、`VERDICT` 的结论**全部未受影响**：
  `K15` 查的是**卡片文本**是否点名守卫，与实验是否成立**无关**。
- `S9` 在**开卡时刻**通过，且 `P134-2` 复跑仍是 0 违规 ⇒ 纪律在实际执行上**没有被违反过**。
- 唯一真实的问题是：**若日后有人往 `precheck` 里加一行中间聚合，`S9` 不会拦**。
  这是**守卫的强度**问题，`P130-4`（「纪律必须配机械守卫」）只保证**有**守卫，未保证**够**。
