## §0 为什么必须有这一卡（**上卡留给本卡的确切问题**）

`D-157` 的结论是：`H126`（`ratio>1 ⟺ frac(û<1)=0`）在 **9 个剂量**上 **9/9 相符**、
其中 **3/3 out-of-sample**，转折夹到 `(300, 350]`。**但** `DEF-126-09` 明确指出该卡的
**否证条款从未成立**：

> 卡片 §2-1 说「至少一个 `frac_d=0` 且 `d<450` ⇒ 否证 `H126-alt`」，
> 而卡片 §1-1 自己把 `H126-alt` 参数化为 `D* ∈ (300,450]`。
> **`D* = 325` 与全部 9 个点同样吻合**（`300<325 ⇒ ratio<1` ✓、`350≥325 ⇒ ratio>1` ✓）。
> ⇒ **`d < 450` 不能否证该族。**

⇒ 真正的困难是**原理性的**：在**剂量扫描**里，`frac` 与 `dose` 是**同一个单调阶跃函数**
（在**同一区间**切换），所以「`u` 制度」与「某个剂量阈值」在**任何**剂量采样下都
**观察等价** ⇒ **剂量轴在原理上无法分开两支**（`D-157` §9 边界 1）。

**要分开，必须让 `frac` 在固定 `dose` 下变化。** 本卡做这件事。

## §1 主假设与否定条款

### §1-1 三个竞争的假设（**必须同时立**，且**逐参数枚举**）

| 支 | 内容 | 在「固定 `dose`、换子集」下的预测 |
|---|---|---|
| **`H127`（中介，主假设）** | 在**每一个结构** $(d,S)$ 上：`frac(d,S) = 0 ⇒ ratio(d,S) > 1`，且 `frac(d,S) > 0 ⇒ ratio(d,S) < 1` | 符号**随 `frac` 变**（子集变 ⇒ 闸门变 ⇒ `frac` 变 ⇒ 符号变） |
| **`H127-alt-1`（纯剂量阈值）** | `∃D* ∈ (0,∞)`：`ratio > 1 ⟺ dose ≥ D*` | 符号在**同一 `dose` 内恒定** |
| **`H127-alt-2`（写量阈值）** | `∃M*`：`ratio > 1 ⟺ Σm ≤ M*`（或 `max m_s ≤ M*`） | 符号**随 `Σm` 变**（子集变 ⇒ `Σm` 变 ⇒ 符号变） |

★★★ **`H127-alt-1` 的整个参数族被一次枚举（`DEF-126-09` 的教训，逐字执行）**：
`D* ∈ (0,∞)` 是**连续统**，但对**任何** `D*`，在固定 `dose` 处的预测都是**同一个常数**。
⇒ **在任一固定 `dose` 内观察到一次符号翻转，就同时否证 `(0,∞)` 上的每一个 `D*`。**
⇒ 该族的否证**不需要**逐点枚举 —— 只需一处**剂量内符号不一致**。这是本卡成立的
**逻辑基础**，不是"多算几个数"。

★★ **`H127-alt-2` 不能靠 `J127-1` 否证**：它也预测剂量内符号变化（因 `Σm` 随子集变）。
⇒ 必须**单独**检验（`J127-3`）。★ 若 `Σm` 与 `frac` 在全部 121 个结构上给出**相同**符号预测，
则**本设计也无法分开 `u` 制度与写量阈值** ⇒ 必须在 `VERDICT` 明写该边界（不得声称分开）。

### §1-2 主假设（本卡的判据对象）

> **`H127`**：$\forall (d,S) \in \mathcal G$：`frac(d,S)=0 ⇒ ratio(d,S)>1` **且**
> `frac(d,S)>0 ⇒ ratio(d,S)<1`，其中 $\mathcal G$ = **112 个新结构**（见 §2-1）。

★ 这与 `H126`（`DIR-126` §1-2）**判据文字逐字相同**，差别**只在自变量**：

上看 ⇒ **112 个判据点从未被算过**。

### §1-3 否定条款（**逐字冻结**）

`H127` 在下列任一情形下**被否证**：

- **(F-a)** `frac = 0` 且 `ratio < 1`；

★ 三种**不可判**（明确区别于"否证"与"成立"）：

- **(N-c)** 该剂量在该子集上不足 **9/9** 个 cell。

## §3 测量对象与工作例（**逐位冻结**）

### §3-1 测量对象

一个结构 $(d,S)$（`d` = 剂量、`S` = 非空题集子集）的读数是一个字典：

```
R(d,S) = { k=|S|, N1=Σ_{r∈S} #(n_seen=1), N2=Σ_{r∈S} #(n_seen=2),
           gate=(2N1+N2)/3, Σm=Σ_s m_s, max_m=max_s m_s,
           frac, m_lo, m_tot, ratio, w1, w2, p1, p2, e1, e2,
           pred=+1/-1,  obs=+1/-1,  verdict ∈ {相符,(F-a),(F-b),(N-a),(N-b),(N-c)} }
```

- `N₁/N₂` **只由 `n_seen` 直方图决定**（与训练无关）；**`S` 一变，`N₁/N₂` 与 `e1/e2` 同时变**
  ⇒ 这是本卡的边界①（**不得**把 `frac` 的变动单独归因于 `u` 制度）。
- `frac` 由 **`mech126.frac_low_u(obs)`** 给出（**逐字复用，不得重写**）；
- `ratio` 由 **`mech125.w_hat(obs)`** 给出（**逐字复用**）；
- `obs` 由 **`mech125.stratum_obs(ctx, strata)`** 给出，而 `strata` 由
  **`mech125.strata_of(ctx)`** 给出 —— ★★ **唯一的实现接缝**：把
  `ctx["rngs"]` 覆写为 `S`。`strata_of` 的 `N1/N2` 与 `idx=[(si,r) for r in rngs]`
  **都**读 `ctx["rngs"]` ⇒ 结构与观测**同时、一致地**切到 `S`，不会错配。

### §3-2 工作例（**机器算定，由 `precheck127` 逐位断言**）

★★ **闸门是「逐结构」的**，不是全局的 —— 这是本卡的**全部自变量**。15 个闸门
（`probe127_struct.py` 机器算出，结构核）：
`k=1`：`555→22.0000`、`556→21.0000`、`557→15.6667`、`558→19.6667`；
`k=2`：`43.0000 / 37.6667 / 41.6667 / 36.6667 / 40.6667 / 35.3333`；
`k=3`：`58.6667 / 62.6667 / 57.3333 / 56.3333`；`k=4`：`78.3333`。
★ 跨度 **`15.6667 → 78.3333` = 5.000×**，15 个**互不相同**。

**`W6` —— 构造性 `(F-a)` 反例（结构 `(9,29)`、闸门 `15.6666666667`）**：
`(e1,e2)=(1,1)`、`m=2 ≤ 15.6667` ⇒ `û = 14.9537143160282575 ≥ 1` ⇒ **`frac = 0.0`**
⇒ `pred = +1`；而 `ŵ₁ = 16.0`、`ŵ₂ = 14.0`、**`ratio = 0.875 < 1`** ⇒ `obs = −1`
⇒ **不符（(F-a)）**。★ **证明 (F-a) 在本结构下可达。**

**`W7` —— 构造性 `(F-b)` 反例**：`(e1,e2)=(7,9)`、`m=16 > 15.6667`
⇒ `û = 0.9614224914779670 < 1` ⇒ **`frac = 1.0`** ⇒ `pred = −1`；而 `ŵ₁ = 0.5714285714`、

★ **证明 (F-b) 在本结构下可达。**

**`W8` —— 相符例（`frac=0 ∧ ratio>1`）**：`(e1,e2)=(2,1)`、`m=3 ≤ 15.6667`
⇒ `û = 9.5544099584148707` ⇒ **`frac = 0.0`**、`pred = +1`；`ŵ₁ = 7.0`、`ŵ₂ = 14.0`、
**`ratio = 2.0 > 1`** ⇒ **相符** ✓。

**`W9` —— 闸门的严格判定（本结构）**：`gate = (2·9+29)/3 = 15.6666666667`；
`m = 15` ⇒ `û = 1.0827776542660876 ≥ 1` ⇒ **非 low**；`m = 16` ⇒ `û = 0.9614224914779670 < 1`
⇒ **low**。⇒ 对整数 `m` 即「**`m_s ≥ 16` 才算 low**」。

★★ **可达性枚举（`W6`/`W7` 的强度）**：在 `(9,29)` 上扫**全部** 261 个 `(e1,e2)`，
排除 `p₁ = 1`（`e1=9`，29 个）后 **232 个可算**：**(F-a) `46` 个、(F-b) `17` 个、相符 `38` 个**
⇒ 违例空间占 **`63/232 = 27.2%`** ⇒ 判据在新结构上**远非空转**。

★ 上述五例在 `precheck127` 里**逐位断言**（`P127-S3`）—— **不得凭记忆重建**
