## §0 问题

`D-151` §2-6 测得逃逸（escape）在 seed 之间**显著过离散**：逐 seed 逃逸数
`[0, 3, 18, 0, 2, 9, 5, 0, 5]`，二项 sd ≈ 2.05 而极差 0…18 ⇒ Pearson 离散 `χ²/df = 8.11`
⇒ 记作「**seed 级 regime**」，并禁止把 `r = 0.1014` 读成"每项独立泄漏率"。

**但这个结论只用了行边缘（逐 seed 合计）**。它没有回答一个更上游的问题：

> 逃逸到底需要**一个**维度还是**两个**维度？
> 即：在给定「每个 seed 自己的泄漏倾向」之后，**题目身份**还有信息吗？

两个可能的答案都改变解释：
- **只需 seed 维度**（`P(escape)=p_s`，与题目无关）⇒ 分裂是「每次训练得到一个泄漏率」，
  题目**不带**信号。此时 `D-151` 的 regime 说法被**加强**（残差是纯抽样噪声）。
- **两个维度都需要** ⇒ 在 seed 倾向之外，**特定题目系统性地更容易漏出** ⇒
  「seed regime」部分是**把题目效应误记在 seed 头上**。

## §2 主假设与判据（**阈值冻结**）

### §2-1 主假设 `H121`

> **逃逸表需要两个维度**：在给定每个 seed 自身的泄漏倾向（行边缘）之后，
> **题目身份（列边缘）仍有超额集中** ⇒ 不只有 seed 倾向，还有**题目结构**。

### §2-2 否证条款

若 `J121-1` **不成立**（即 `p_A ≥ 0.025`，无法在 `α=0.025` 下拒绝「seed-only」），
则 `H121` **否证** ⇒ 结论为「逃逸只需 seed 维度：分裂 = 每 seed 一个泄漏率，题目不带信号」。

### §2-3 判据（全部冻结）

| 判据 | 零假设 / 条件 | 统计量 | 阈值（**冻结**） |
|---|---|---|---|
| **`J121-1`**（主，测 **item 结构**） | 条件在**行边缘**（逐 seed 逃逸数固定）；每 seed 从 46 题中**均匀无放回**抽 `R_s` 题 | `D_col = Σ_i (C_i − c̄)² / c̄`，`c̄ = 42/46` | **`p_A ≤ 0.025`**（单侧上尾，`B=20000`） |
| **`J121-2`**（测 **seed 结构**） | 条件在**列边缘**（逐题逃逸数固定）；每题把 `C_i` 次逃逸**均匀分配给 `C_i` 个不同 seed** | `D_row = Σ_s (R_s − r̄)² / r̄`，`r̄ = 42/9` | **`p_B ≤ 0.025`**（单侧上尾，`B=20000`） |
| **`J121-3`**（report-only） | — | 逐 seed 泄漏率 `p̂_s = R_s/46` + Clopper–Pearson 95% 区间；列边缘直方图；`max_i C_i` | **不进判决** |

★ **族错误率**：`J121-1` 与 `J121-2` 是同一张表的两个条件视图（**不独立**）⇒
按 `DEF-112-04` 的口径，**族内 `α=0.05`，两测各 `0.025`**（Bonferroni）。`J121-3` 不参与。

★ **`J121-1` 与 `J121-2` 的地位不同**：`J121-1` 是**主判据**（决定 `H121`）；
`J121-2` 是**对照/一致性检查** —— 它在给定列边缘后重测行结构，用于判「`D-151` 的 seed regime
是否只是题目结构的副产品」。`J121-2` 不影响 `H121` 的成立与否，但**必须报**。

### §2-4 判决表（冻结，开卡前写下四种结局的读法）

| `J121-1` | `J121-2` | 读法（**冻结**） |
|---|---|---|
| ✓ 显著 | ✓ 显著 | **两维都需要** ⇒ `H121` 成立；逃逸 = seed 倾向 × 题目结构，**不得**再单称「seed regime」 |
| ✓ 显著 | ✗ 不显著 | `H121` 成立；且**题目结构是唯一可检维度**（给定列边缘后行不再超额）⇒ `D-151` 的「seed regime」**须改写**为「题目 regime」 |
| ✗ 不显著 | ✓ 显著 | `H121` **否证** ⇒ 逃逸 = 纯 **seed 泄漏率**，题目**不带**信号；`D-151` 的 regime 说法**被加强** |
| ✗ 不显著 | ✗ 不显著 | `H121` **否证** 且两向皆不超额 ⇒ **表的稀疏性本身**解释了离散（`42` 个事件 / `414` 格）；`D-151` 的 `χ²/df=8.11` **须重新解读**（可能是稀疏偏差，不是 regime） |

★ 第 4 行是**必须**写进判决表的一格：若两向都不超额，则原先的过离散读数很可能来自
**稀疏格上的 Pearson χ² 抬高**，而不是真实的 seed 异质性 ⇒ 那种情形下 `D-151` §2-6 的
regime 结论**不成立**，须由本卡显式更正（`CORR`）。

## §3 测量对象与手算例（**冻结**）

**测量对象**：`9 × 46` 的**二元逃逸表** `X[s, i]`（`s` = 9 个 seed，`i` = 46 个 `n_seen ≥ 1` 的题）。
`X[s,i] = 1` ⟺ 该 seed 在第 `i` 题上**选了未见值**（`escape_mask`，逐字沿用 `mech120.partition`，
**不新造第二套逻辑**）。行边缘 `R_s = Σ_i X[s,i]`（合计 42）、列边缘 `C_i = Σ_s X[s,i]`。

### §3-1 手算例 A（`D_col`，`J121-1` 的统计量）

`2 seed × 3 题`，表：

```
        i1 i2 i3 | R
  s1     1  0  0 | 1
  s2     0  1  1 | 2
  ---------------+--
  C      1  1  1 | 3
```

`c̄ = 3/3 = 1` ⇒ `D_col = (0² + 0² + 0²)/1 = 0`。
`D_row`：`r̄ = 3/2 = 1.5` ⇒ `D_row = ((1−1.5)² + (2−1.5)²)/1.5 = 0.5/1.5 = 1/3`。

**`J121-1` 的零分布可完全手算**（条件在行边缘 `R=(1,2)`，3 题）：`s1` 从 3 题取 1（3 种）、
`s2` 从 3 题取 2（3 种）⇒ **共 9 张等概率表**。逐张算 `D_col`：
`{i1}×{i1,i2}`→`C=(2,1,0)`→`2` · `{i1}×{i1,i3}`→`2` · `{i1}×{i2,i3}`→`C=(1,1,1)`→`0`
· `{i2}×{i1,i2}`→`2` · `{i2}×{i1,i3}`→`0` · `{i2}×{i2,i3}`→`2`
· `{i3}×{i1,i2}`→`0` · `{i3}×{i1,i3}`→`2` · `{i3}×{i2,i3}`→`2`
⇒ **`P(D_col = 0) = 3/9`、`P(D_col = 2) = 6/9`**；观测 `D_col = 0` ⇒ `p_A = P(D_col ≥ 0) = 1`。
（手算例**必须被断言**，见 `test_mech121.py` 的 `T121-1`。★ `DEF-120-01` 的教训：
只写在文档里的手算例会被一路带进正式跑。）

### §3-2 手算例 B（`D_row`，`J121-2` 的统计量）

同一张表，条件在**列边缘** `C=(1,1,1)`：每题把 1 次逃逸分配给 2 个 seed 之一 ⇒ `2³ = 8` 张等概率表。
- 全给 `s1` ⇒ `R=(3,0)` ⇒ `D_row = ((3−1.5)²+(0−1.5)²)/1.5 = 4.5/1.5 = 3`（1/8）
- 全给 `s2` ⇒ `R=(0,3)` ⇒ `3`（1/8）
- `R=(2,1)` ⇒ **3 种**（哪 2 题给 `s1`）⇒ `D_row = (0.25+0.25)/1.5 = 1/3`（3/8）
- `R=(1,2)` ⇒ **3 种** ⇒ `1/3`（3/8）

观测 `D_row = 1/3` ⇒ `p_B = P(D_row ≥ 1/3) = 6/8 = 3/4`。（`T121-2`）

### §3-3 显著性方向

两测都用**单侧上尾**（`≥` 观测）—— 备择方向是「**超额集中**」，不是「过度均匀」。
★ 过度均匀不构成本卡的备择（那会对应"逃逸被刻意分散"，无机制先验）。方向冻结。
