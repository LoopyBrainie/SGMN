## 1 主假设 `H110` 与否证条款

> **`H110`（串联/最弱环）**：`W_q` 与 `W_o` 在读出链上串联，故对**可测点**，复合损伤 `δ_B` 贴近 `max(δ_Q, δ_O)` 而**显著偏离** `δ_Q + δ_O`；
> 即 `|I_rel| := |δ_B − δ_Q − δ_O| ≥ TAU_ADD`，且 `|δ_B − max(δ_Q,δ_O)| < |δ_B − (δ_Q+δ_O)|`。

**否证条款（预先冻结）**：若存在**至少一个**被 §2.3 分类为 `TESTABLE` 的点满足 `|I_rel| < TAU_ADD`（即**可加成立**），则 `H110` **被证伪**，判决记 `C110-ADDITIVE-HOLDS`。
若**没有任何**点被分类为 `TESTABLE`，则判决记 `C110-NO-TESTABLE-POINT`，且**该状态不得**记作 PASS 或 FAIL（用户规则：判据「从未被计算」不得记作 PASS/FAIL）。

**判据 C（report-only，不进主判据）**：模型比较 —— 对每个**可测**点计算 `SUM` 模型（`δ_Q+δ_O`）与 `MAX` 模型（`max(δ_Q,δ_O)`）的绝对误差，报 `MAX/SUM` 误差比。

## 2 判据定义（全部**预先**冻结；阈值不改，改则新开 revision）

### 2.1 被测对象与相对损伤

记 `X(arm, γ, ℓ, obj, met)` 为 3 seed 的均值。**被测对（obj, met）只有 4 个**：
`q.rank_eff`、`q.cos_mean`、`m.rank_eff`、`m.cos_mean`。
★ **`c` 不是被测对象，只作内建对照**（它是基准模型隐状态，不是读出链自己的量）。

相对损伤（`rank_eff` 与 `cos_mean` **统一用同一式**，因为二者都随损伤**朝 1 走**）：

```
δ_X(arm) = (X(arm) − X(T-NONE)) / (1 − X(T-NONE))        # 远离 T-NONE、趋近边界 1 的程度
I_rel    = δ_B − δ_Q − δ_O
```

★ 用同一式而**不给任何一个量开特例**，是为了避免"按结果挑归一化"。

### 2.2 阈值（**先于任何 `I_rel` 计算**冻结）

| 符号 | 值 | 定义与理由 |
|---|---|---|
| `TAU_ARM` | **0.10** | `δ < TAU_ARM` ⇒ 该臂对**这个量**"不作用"。理由：与 `DIR-109` 的 `TAU_ATTR=0.10` 同量级（不可察觉效应），且本装置实测 `δ` 呈**两极分布**（0.000/−0.070 与 0.542–0.919），**0.10 落在空隙里**，非刀口取值 |
| `TAU_SAT` | **0.05**（并**强制扫** `{0.02, 0.05, 0.10, 0.20}`，见 §2.3） | 损伤臂距边界 `1` 的归一化距离 `< TAU_SAT` ⇒ 该点**饱和**。归一化距离 `= |X(T-BOTH) − 1| / |1 − X(T-NONE)|`。扫四个值是为了**不靠单一阈值**成立 |
| `TAU_ADD` | **`max(0.10, 3·SD_pooled)`** | 可加阈值。`SD_pooled` = **逐 seed 配对**的 `δ` 的标准差的合并（三 seed 名 `20261028/20261104/7` 对全部臂相同 ⇒ 配对良定义）。并**强制扫** `{0.10, 0.15, 0.20}` |

### 2.3 点的三分类（对每个 (obj, met, ℓ) 逐点判，`ℓ ∈ {L8, L16}`）

按**结构**分类，**不按结果**分类：

1. **`DEGENERATE`**：`|δ_Q| < TAU_ARM` 或 `|δ_O| < TAU_ARM` ⇒ 有一臂**根本不作用于该量** ⇒ 该点上的"归因"是**空话**（算术上可能 `I_rel≈0`，但没有信息）。
2. **`SATURATED`**：`|X(T-BOTH) − 1| / |1 − X(T-NONE)| < TAU_SAT` ⇒ 损伤臂已贴边界 ⇒ **无向上/向下余量**，可加性不可测。
3. **`TESTABLE`**：既非 1 也非 2 ⇒ **只有这些点能裁 `H110`**。

★ **`L8` 是"无反馈参照层"**：`c@L8` 在任何注入之前，四臂**逐位相同**（`A110-7` 复核）⇒ 在 L8 上不存在跨层反馈，是装置给的最干净对照。

### 2.4 判决码（**冻结**）

| 码 | 条件 |
|---|---|
| `C110-ADDITIVE-HOLDS` ⇒ **`H110` 证伪** | ∃ `TESTABLE` 点使 `\|I_rel\| < TAU_ADD` |
| `C110-SERIES-WEAKEST-LINK` ⇒ **`H110` 证实** | 全部 `TESTABLE` 点 `\|I_rel\| ≥ TAU_ADD` **且** 每点 `\|δ_B − max\| < \|δ_B − sum\|` |
| `C110-NO-TESTABLE-POINT` ⇒ **判据未计算** | 无 `TESTABLE` 点（**不记 PASS/FAIL**，`SUCCEEDED` 不动） |
| 其他 | `C110-MIXED`（逐点列出，不合并） |

## 3 测量对象已核（**worked example**，`m.rank_eff@L8`，`γ=0.005`）

从 `stage_verdict.json` 的 24 格按 (arm, γ) 取 3 seed 均值：

| arm | `m.rank_eff@L8` |
|---|---:|
| `T-NONE` | **8.743** |
| `T-Q` | **3.813** |
| `T-O` | **2.312** |
| `T-BOTH` | **1.624** |

逐步代入 §2.1：

```
δ_Q = (3.813 − 8.743)/(1 − 8.743) = (−4.930)/(−7.743) = 0.6367
δ_O = (2.312 − 8.743)/(1 − 8.743) = (−6.431)/(−7.743) = 0.8305
δ_B = (1.624 − 8.743)/(1 − 8.743) = (−7.119)/(−7.743) = 0.9194
I_rel = 0.9194 − 0.6367 − 0.8305 = −0.5478
MAX 模型误差 = |0.9194 − 0.8305| = 0.0889
SUM 模型误差 = |0.9194 − 1.4672| = 0.5478
饱和距离 = |1.624 − 1|/|1 − 8.743| = 0.624/7.743 = 0.0806 > TAU_SAT(0.05) ⇒ 非饱和
```

⇒ 该点分类 `TESTABLE`（`δ_Q`、`δ_O` 都 ≥ 0.10；饱和距离 0.081 > 0.05）。
⇒ `|I_rel| = 0.548 ≥ TAU_ADD(0.10)`；`MAX` 误差 0.089 < `SUM` 误差 0.548（**6.2×**）⇒ **该点支持最弱环**。
★ 该例子同时说明界限形状是对的：`rank_eff` 与 `cos_mean` 都朝 1 走，故分母统一取 `(1 − X_NONE)`。

7. **不得**据此改 `§7.2-7` 状态 —— 本卡仍只涉**代价侧**，不产生任务级收益。
