## §2 方法：与 `P135-16` 同一套，但靶子不同

`P135-16` 打的是**读数**（探针输出变不变）；本轮打的是**守卫**（该红时红不红）。
判据换成：**构造一个它本该拒绝的世界，看它是否真的拒绝。**

★★ **关键：本轮必须区分两件完全不同的事**（上一轮只有第一件）：

| 问 | 含义 | 若答案是否 |
|---|---|---|
| **(A) 它能不能红？** | 守卫是否**活的**（分支可达、`fails` 真追加） | **真洞**（死守卫） |
| **(B) 它红了，别人知道吗？** | 红灯是否**被送达**（退出码/横幅/读数） | **真洞**（`P135-16` k04 同型） |

★★★ **第 1 条缺陷正是 (B) 失败**：md5 校验**红了**（`FAILED=1` 打印出来了），
但没有人**读**它 —— 脚本继续走完并宣告成功。**(A) 通过、(B) 失败** ⇒ 单看 (A) 会误判为「守卫健康」。

## §4 `repack.sh`：md5 复核只报告不阻断（★ 最重）

代码现状（改造前）：

```bash
OK=$(grep -c ": OK$" /tmp/_mf_check.txt)
BAD=$(grep -c ": FAILED$" /tmp/_mf_check.txt)
say "MANIFEST 校验：OK=$OK  FAILED=$BAD"
if [ "$BAD" != "0" ]; then grep "FAILED" /tmp/_mf_check.txt | head -20 | tee -a "$LOG"; fi
...
say "===== 打包结束（全部校验通过）====="
```

★ `BAD != 0` 分支**只有 `grep`，没有 `exit`**。`grep` 的退出码被丢弃，脚本继续。
全文唯一的 `exit 1` 在 line 147，只管 `rebuild_full.sh` 的返回码。

**定点复现**（逐字照抄 line 138–149，篡改一个受管文件）：

```
MANIFEST 校验：OK=1  FAILED=1
a.txt: FAILED
===== 打包结束（全部校验通过）=====
★ rc=0
```

★★★ **包已损坏、日志里有 FAILED、横幅仍说「全部校验通过」、退出码 0。**

★ 为何这条特别危险：`OK=N FAILED=0` 是历轮 handoff 的**唯一打包凭据**，
而它**从来不承担门禁作用** —— 只要 `rebuild_full.sh` 成功，`repack.sh` 必以 0 退出，
无论 md5 复核结果如何。⇒ 「凭据」与「门禁」被**混为一谈**了整整若干轮。

## §5 `sync_check.sh:87`：读数假绿

改造前：

```bash
echo "✔ 两侧 md5 相同：$(( n_l < n_r ? n_l : n_r )) 个共有文件（逐字节比对）"
```

★★ **两处缺陷叠加**：
1. 那个数是 **`min(n_l, n_r)` = 共有文件名数**，**不是** md5 相同的文件数；
2. 该行**无条件**打印 ⇒ `differ.txt` 非空（内容不同）时**照样打 `✔` 与「md5 相同」**。

**实测对照**（同一批 `n_l/n_r/n_di`）：

| `n_di` | 改造前打印 | 改造后打印 |
|---:|---|---|
| 0 | `✔ 两侧 md5 相同：45 个共有文件` | `✔ 两侧 md5 全同：45 个共有文件` |
| **3** | **`✔ 两侧 md5 相同：45 个共有文件`**（★ 与 n_di=0 **一字不差**） | `★★ 两侧 md5 相同：42 / 45 个共有文件（**3 个不同**，见下）` |

★★★ **`n_di=0` 与 `n_di=3` 打印完全相同** ⇒ 只读这一行的人**无法**区分同步与不同步。
★ 而历轮 handoff 引用的「两侧 `.ops/scripts` **45 项全同**」正是照着这句抄下来的。
★ 退出码是对的（`--strict` 给 4），**但人不读退出码，人读那一行**。

## §6 修复（三处，全部「让读数有唯一来源」）

### §6-1 `repack.sh` —— md5 复核改为硬闸门

`BAD != 0` ⇒ 打印 FAILED 明细 **并 `exit 10`**，**不再**打印「打包结束」。
★ 新增退出码 **10**。★ 实测 `repack.sh` 全文的退出码集合改造前只有 **{0, 1}**
（`1` 只用于 `rebuild_full.sh` 返回非零）⇒ `10` 无冲突。★ 注意 **4/6/8/9 属于
`rebuild_full.sh`，不属于本脚本** —— 两者不可混引（本文 §8 的表是 `rebuild_full.sh` 的）。

### §6-2 `sync_check.sh` —— 第 87 行的读数由 `differ.txt` 决定

```bash
_n_same=$(( (n_l < n_r ? n_l : n_r) - n_di ))
if [ "$n_di" -eq 0 ]; then echo "✔ 两侧 md5 全同：$_n_same 个共有文件（逐字节比对）"
else echo "★★ 两侧 md5 相同：$_n_same / ... 个共有文件（**$n_di 个不同**，见下）"; fi
```
★★ **原则：一个读数只能有一个来源。** 改造前的错误不是算错，而是**用名字计数冒充 md5 计数**；
   修法不是再算一遍 `n_same`，而是**让这一行由 `differ.txt` 决定**。

### §6-3 `audit_consistency.py` —— 新增 ⑪ 自盘存

`check()` 现在记录「已执行几个检查、属于哪一项」；十处节标题改走 `section(tag, title)`；
末尾断言三项：

```
⑪a 十项必须全部执行到（未执行者列出名字）
⑪b 每项执行的检查数 == 冻结预算 {①2 ②1 ③1 ④7 ⑤6 ⑥3 ⑦2 ⑧11 ⑨5 ⑩3}
⑪c 已执行总数 == 41
```

★★ **必须先快照再断言**：⑪ 自己的 3 条 `check()` 也会计数 ⇒ 不快照就会把自己算进 ⑩ 的桶
并把总数抬到 43（实测踩中：`⑩ 4/3`、`总数 43/41`）。现改为 `_ran_snapshot` / `_total_snapshot`。
★★ **只为「已执行」造断言，不为「恒失败分支」造必然通过的断言** —— 后者是假守卫（同 `k17`）。
