## 1. 要检验的问题

### 1.1 问题的精确形式

> **在「基座参数冻结 + Freeze C」下，基座自身的同分布 NLL 相对 $\gamma{=}0$ 基线的偏离，是否随在线步数 $N$ 增长？**

即：给基座接上一条 $\gamma$ 门控的读取通道后，**注入项本身**造成的代价（"静态注入税"）已知存在（`D-15` ② 实测 **+0.0442 nats/token**）；本轮问的是**它会不会随记忆状态 $W$ 的累积而变大**。

- **不是**「基座会不会退化」——`D-15` ② 已答：会。
- **是**「退化是否**累积**」——即在**长视窗**下，$W$ 的演化是否让注入项的统计性质漂移，从而**逐步**侵蚀基座。

### 1.2 为什么这不是 `D-15` / `D-26` 的重复（**必读，防止重复立题**）

| 已有轮 | 它测了什么 | 它**没有**测什么 |
|---|---|---|
| **`D-15`**（DIR-09） | 读通道相对纯基座的**净损失 +0.0442 nats/token**，归因到「读出走未训练的随机 $W_q,W_o$」 | **单一终点**（1024 token）的**静态**量；**无 $N$ 轨迹** |
| **`D-26`**（DIR-19） | 有「**基座保持探针**」，量的正是 **wikitext-2 valid 的 NLL**（ΔPPL） | ①它是**诊断量**不是主假说（主假说 H5′「保护 ⊃ 早停」**FAIL**）；②读数在「**基座可训**」regime（其边界原文：「部分来自『基座在任务分布上被训练』」⇒「**只能读成『放开基座训练不伤基座』**」）⇒ **不覆盖「基座冻结」**；③**无 $N$ 轨迹** |
| **`D-58`**（DIR-34） | $\Delta_{\rm content}$ = `S`−`T` 的**出样本**值（单终点，$n{=}400$） | **$N$ 轨迹**；且它比较的是**臂间**，不是**基座相对** |

⇒ 本轮的唯一新量是 **$\Delta_{\rm base}$ 作为 $N$ 的函数**。若这一点在本轮实现中无法与上述三者区分，**本轮应判 `NOT-ADDRESSING` 并终止**（不得硬凑）。

### 1.3 主假说与证伪条款

**H86（主假说）**：在基座冻结 + Freeze C 下，基座的同分布 NLL 相对 $\gamma{=}0$ 的偏离**随在线步 $N$ 单调增长**（$|\Delta_{\rm base}(N)|$ 增长），即「长期基座能力保持」在**累积**意义上不成立。

**证伪条款（写在冻结前，不得事后改）**：
- 若 $\Delta_{\rm base}(N)$ 在 $N\in\{0,150,300,600\}$ 上**不随 $N$ 增长**（C86-b 不过），且**功效充分**（P86 过）⇒ **H86 `FALSIFIED`**。
- ★ **重要**：`FALSIFIED` 在本轮是**对架构有利**的结果（"基座长期保持"成立），**不是**失败。**本轮价值不依赖 H86 的方向**——两种结果都把 §7.2-7a 从「未测」推进到「已测」。
- 若功效不足（P86 不过）⇒ 记 **`INFEASIBLE-POWER`**（**不得**记 `FALSIFIED`）。此即「判据未被计算 ≠ PASS/FAIL」的执行。

### 1.4 状态词（四值，互斥）

`SUCCEEDED` · `FALSIFIED` · `INFEASIBLE-POWER` · `PREMISE-NOT-MET`（前提未满足）·

## 3. 测量对象的操作化

### 3.1 三臂的分工（**全部来自既有装置，未新造**）

装置 `dir33/R1_task33.py` 的 `read_W(W, arm, sd)`：

```python
if arm in ("G0", "N"):
    return torch.zeros_like(W)      # 读出对 W 的依赖被切断
if arm == "S":
    return W.flatten()[scratch(sd)].reshape(D_V, D_K)   # 固定随机子空间
return W                             # T：真实记忆
```

且 `gam = torch.zeros(1) if arm == "G0" else P[f"g{l}"]`；**写入块对所有臂无条件执行**（`P.update(upd)` 不在臂分支内）。

| 臂 | 读出 $y$ | $\gamma$ | 含义 | 在本轮的角色 |
|---|---|---|---|---|
| **`G0`** | $0$ | $0$ | 纯基座，**无任何注入** | **基线**（$ \Delta_{\rm base}$ 的被减项） |
| **`N`** | $0$ | $\gamma$ | **有注入、无记忆内容**（$m=\tanh(c\,W_o+b_o)$ 不依赖 $W$） | **静态注入税的隔离对照**：`N`−`G0` 与 $N$ 无关（**必须是常数**） |
| **`T`** | $Wq$ | $\gamma$ | 完整记忆 | **被测对象**：$W$ 累积 ⇒ 注入统计漂移 |

★ **关键结构性事实**：`N` 的读出**对 $W$ 完全无依赖** ⇒ **`N` 臂的 $\Delta$ 在数学上不可能随 $N$ 变化**。因此：
1. `N`−`G0` 的**平坦性**是一个**装置自检**（A86-7）；
2. **只有 `T` 臂能承载 $N$ 轨迹**；若 `T` 也平坦，则说明"$W$ 累积不改变注入"，这是 H86 的证伪。

### 3.2 主量的定义（配对，写死）

$$\Delta_{\rm base}(N) \;=\; \mathrm{NLL}_{T}(N) \;-\; \mathrm{NLL}_{G0}(N)$$

- 两者在**同一** $(seed, \text{doc})$ 上、**同一**已写入状态 $W(N)$ 上评测；$\gamma$ 相同；
- 配对单位 = $(seed, doc)$；$\mathrm{NLL}$ = 逐 token 交叉熵均值（与 `D-58` 同口径）；
- **正号 = 接上记忆读出让基座变差**；
- 诊断量（不进判据）：$\Delta_{\rm inj}(N)=\mathrm{NLL}_N(N)-\mathrm{NLL}_{G0}(N)$（应恒等于其 $N=0$ 值，A86-7）。

### 3.3 测量对象的**工作例**（Stage A 必跑，A86-5）

在**单个** $(seed, doc)$、$N$ 取第一个非零检查点、$\gamma=0.05$ 上：

1. 手算第 1 挂载层、$t=1$ 处的注入项：取装置记录的 $c$、$W_o$、$b_o$、以及 `N` 臂的 $y=0$，手算 $m_{\rm hand}=\tanh([c;0]W_o+b_o)$，与装置记录的 $m$ 比较 ⇒ **相对误差 $<10^{-12}$**；
2. 手算 `G0` 臂的损失：$\gamma\equiv0$ ⇒ 注入项恒为 $0$ ⇒ 基座输出应与**不挂载**时逐位相同 ⇒ 与"无记忆前向"比较 **max abs diff $=0$**；
3. 手算 $\Delta_{\rm base}$ 的一个配对样本并与 JSON 中该配对值比较 ⇒ **相对误差 $<10^{-12}$**。

★ 三条**任一不过** ⇒ 装置实现不符卡 ⇒ **阻断正式轮**（不得进 Stage B）。

## 7. 边界（**不可外推**，写完轮次后逐条核对）

- **不能**外推为「SGMN 长期有害/有益」——本轮只测**基座自身**的同分布 NLL 偏离，不测任务收益；
- **不能**外推为「$D$-族任一任务的收益消失」——本轮不训练读取侧；
- **不能**外推为「所有 $\gamma$ / 挂载层集合」——只测 $\gamma\in\{0.05,0.15\}$、挂载层 $[8,12,16]$；
- **不能**外推为「跨会话」——本轮**单会话内**，会话语义仍是 `D-27` 的事；

- **不能**把"参数逐位不变"当"行为不变"——**这正是本轮要测的**（Freeze C 只保证前者）；
- **不能**外推为任何通用 LM 能力/长期记忆能力结论；
- **不能**用 `D-15`/`D-16` 的 NLL 数值做跨轮比较（协议与文档集不同）；
- `NLL` 是**wikitext-2 分布的**同分布 NLL，$\gamma$ 门控的注入是**声明口径**，换口径会换结论。
