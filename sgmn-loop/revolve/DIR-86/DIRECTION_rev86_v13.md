## §0 `DEF-86-2`：`INJ` 臂在 LLM 装置上**不可构造**（rev 1.1 §1.5 的设计错误）

### 0.1 错误

rev 1.1 §1.5 把 `INJ` 定义为「`y = 0`、$\gamma>0$」。**该构造在本装置上使注入项恒为 0**：

在用装置（根 `sgmn_module.py`，`LayerMem.read`，`:60-76`）的读出链路是

$$c=\mathrm{sg}(h^-)\;\to\; q=W_q c\;\to\; y=\mathrm{sg}(W)\,q\;\to\; m=W_o y\;\to\; \text{injection}=\gamma\,m$$

**$m$ 到 $c$ 的路径只有 $y$ 一条**。因此 $y\equiv0 \Rightarrow m\equiv0 \Rightarrow$ 注入 $\equiv0 \Rightarrow$ **`INJ` $\equiv$ `BASE`**。
$\Rightarrow$ rev 1.1 若照此实现，"静态注入税" $\Delta_{\rm inj}$ 会读出**恰好 0**——那是**假测量**，不是零结果。

### 0.2 为什么 rev 1.0 的同一构造是对的

玩具装置（`dir33/R1_task33.py`）是 $m=\tanh([c;y]\,W_o+b_o)$，**$c$ 有一条不经 $y$ 的直连路径** ⇒ $y{=}0$ 时 $m=\tanh(cW_o+b_o)\ne0$，注入仍在。
⇒ **同一个符号构造在两套装置上语义不同**。这正是 rev 1.1 "装置从玩具改LLM"时**没有被同步复核**的地方。

### 0.3 纠正后的 `INJ`（**用装置自带的既有开关，零改动**）

`LayerMem.__init__` 已有参数（`:44`）：

```python
self.no_write = no_write      # True => 不执行写入（用于分离写介导的效应）
```

⇒ **`INJ` = $\gamma=$ 目标值、`no_write=True`**：$W$ 永远停在初值 $W(0)=W_0+UV^\top$，**注入照常施加**。

| 臂 | 构造 | 注入 $\gamma m$ | $W$ 随写变化 | 含义 |
|---|---|---|---|---|
| **`BASE`** | $\gamma=0$（3 层全 0） | $0$ | — | 纯基座 |
| **`INJ`** | $\gamma=$ 目标，**`no_write=True`** | $\ne 0$ | **否**（恒 $W(0)$） | **注入存在、记忆内容不存在** |
| **`MEM`** | $\gamma=$ 目标，正常写 | $\ne 0$ | **是** | 完整记忆（承载 $N$ 轨迹） |

★ **`INJ` 在四个 $N$ 上必须逐位相同**（$W$ 与 $\gamma$ 都不随 $N$ 变）⇒ A86-7 从"数学必然"变成**真实的实现守卫**（防我在代码里让 `INJ` 误读到 $W$）。
★ **零装置改动**：`no_write` 是既有参数，满足「只换测量层与自变量」。

### 0.4 ★ $W(0)\ne W_0$（三臂确实互不相同）

`sgmn_module.py:49-51`：

```python
self.W0 = mk(d_v, d_k)                                    # 固定基准
self.U  = (torch.randn(d_v, r) * 0.1)                     # 可写
self.V  = (torch.randn(d_k, r) * 0.1)                     # 可写
```

$W = W_0 + UV^\top$ ⇒ **$W(0)=W_0+UV^\top\ne W_0$**（$U,V\sim0.1\,\mathcal N$，$r{=}8$）。
⇒ `INJ`（读 $W(0)$ 冻结）与 `MEM`（读 $W(N)$）在 $N{=}0$ 也**不同值**，但**同量级** ⇒ 两者是**两个不同臂**，不是同一件事的两个名字。这是 `INJ` 作为"静态注入税"对照的正当性来源。

- **不能**把玩具装置上 `INJ`（$y{=}0$）的语义迁移到本装置——同名不同义；
