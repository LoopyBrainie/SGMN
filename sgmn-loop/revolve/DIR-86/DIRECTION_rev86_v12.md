## §3 $\gamma$ 的实际施加方式（A86-11′ 的答案，**实测**）

```python
# dir21/sgmn_module_hebb_v7.py
self.gamma = torch.tensor(float(gamma), device=device, requires_grad=True)   # :380
...
for li in mount_layers:                                                      # :704
    m = LayerMem(..., gamma, ...)                                            # 每层独立 gamma
...
hs_out = hs_out + mem.gamma * m                                              # :738
```

- **逐层独立**：`mount_layers=[8,12,16]` ⇒ **3 个独立的 $\gamma$ 张量**，初值均为 0.05。
- **可冻结**：`requires_grad=True` 是默认；要固定到目标值须显式 `requires_grad_(False)` 并写回数值。
- **注入形式**：`h⁺ = h + γ·m`（与 rev 1.0 §3.1 的 `h + γm` 一致）。

⇒ **A86-11′ 的执行口径**：把 3 个 `mem.gamma` **全部**设为目标值并 `requires_grad_(False)`；**记录 3 个实际施加值**（须全等于目标，容差 $10^{-12}$）。**不得**只设第一层。

## §7 边界（在 rev 1.0 §7 与 rev 1.1 §4 基础上追加）

- **不能**把 $N$ 当 token 位置（§1.2）；
- **不能**把 `BASE` 的 $\gamma{=}0$ 代数恒等当"行为等价"的证明——它只证注入项被乘 0，**不证** $m$ 的计算没有副作用（须 A86-13 实测）；
