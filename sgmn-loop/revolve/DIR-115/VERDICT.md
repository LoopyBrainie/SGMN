## §0 一句话结论

在覆盖已修好的划分（`SPLIT`，`class_seen_frac_held = 1.0000`）上，把**训练好的**注入项在 **64×** 的增益范围
（`γ ∈ [6.25e-5, 4e-3]`，7 个非零点）内扫描：**没有任何 γ 使留出准确率达到或超过基座先验**（全部 `mean₆ ≤ 13.83/48 < 17/48`）。
⇒ **注入项对未见键不携带可用正信号**，`H115` 证实。

★★ 而**真正的发现在对照臂里**：**未训练**的同一注入在任何 γ 下几乎无害（`16.0–16.8/48` vs 先验 `17/48`），
**训练后**在**每一个** γ 上都要再低 **2.2–6.0 项**（**7/7** 同号）。
⇒ **损伤不是"增益调得不好"，而是"训练把读出的方向弄错了"** —— 而**方向错了，任何增益都救不回来**：
调小 γ 只是把一个**错方向的推**变小，不会让它指对。这就是 `P114-3` 的答案。

### §2.4 ★ 形状：**非单调**（本卡没有把它当判据 —— 见 §8 草案 B）

曲线 **13.67 → 11.00 → 10.50 → 12.33 → 13.00 → 13.67 → 13.83**：中段下陷、两端回升（U 形），`argmax γ = 4e-3`、`argmin γ = 2.5e-4`。
`monotone_nonincreasing = False`。
⇒ ★★ **§8 草案 B 的撤回是对的**：若把单调性当判据，本卡会以"形状不单调"判失败，**而 `H115` 的真意（无可用正信号）其实成立**。
⇒ 单调性作为 **report-only** 保留（卡片 §6-1）。

### §2.5 `COLOCATED`（report-only；覆盖 0，**绝对水平受结构上界约束，不作判据**）

其自有先验 **18/48**（`A115-5`；≠ `SPLIT` 的 17/48 ⇒ 锚点划分相关）。`d=600` 的 `mean₆`：
`5.00, 2.33, 4.17, 4.50, 2.50, 2.33, 2.33`（γ 升序）⇒ 配对差 **−13.0 ~ −15.7 项**，远差于 `SPLIT` 的 −3.2 ~ −6.5。
⇒ 与 `D-145`（覆盖解释 77.4% 的损伤）自洽：覆盖 0 的一侧损伤量级大得多。

### §2.6 ★★★ `ORACLE`：它不是"oracle"，而是一个**中性向量对照**（本卡最重要的边界，`DEF-115-06`）

`install_ceil` 在 `γ=γ_tr` 下注入**正确值**的**输入嵌入**：`acc = 0.3541666666666667` 在 `mult ∈ {0.25, 1, 4}`
**三个 mult 完全相同**，且**恰等于先验 17/48**；而同格的正常（学到的）注入是 `0.2708`。

⇒ ★ **机制解释**：`install_ceil` 注入的是 `model.get_input_embeddings()` 的向量，即**输入嵌入**；
而 transformer 的**输出**方向由 `lm_head`（unembedding）决定，**它不是输入嵌入的转置**
⇒ 沿 `emb[t]` 移动**并不**抬高 token `t` 的 logit ⇒ 这个"oracle"注入的是一个**对该 token argmax 中性**的向量。
⇒ ★★★ **因此本卡不能**说「连正确内容也救不回来」——**我从未沿正确的*输出*方向注入过**。
本卡能说的是：**同样量级的注入可以做到无害**（`emb[correct]` 恰好中性、`17/48` 不动），
**而学到的 `m` 在同一量级上是有害的**（`13/48`）⇒ **缺陷在学到的方向里，不在通道的幅度极限里**。
★ `mult` 从 0.25 到 4（有效强度 16×）**完全无变化** ⇒ 进一步印证该向量在输出侧近似"无作用"。

## §6 机制（**结论所依赖的因果链**）

1. **信号确实存在，但太弱**：`C(γ)` 从 5.50 单调升到 **8.33/31 = 26.9%**（chance 25%）⇒ 注入带了一点正确方向的信息。
2. **破坏更强**：`D(γ)` 恒在 **8.8–12.5 / 17**（52%–74%）⇒ 正确的先验被压过的速度始终快于建立正确的速度。
3. **责任在训练**：同 γ 下 `d=0` 几乎无害（`16.0–16.8`）而 `d=600` 差 2.2–6.0 项（7/7 同号）⇒
   **是把 `Wq/Wo` 拟合到 16 个训练键这件事**造成了未见键上的错方向，**不是**"注入"这个动作。
4. **通道幅度不是瓶颈**：`emb[correct]` 在该量级上**完全中性**（`17/48` 不动，`16×` 强度也无变化）⇒ 同样幅度可以无害。
5. ⇒ **`P114-3` 的答案**：残余损伤 = **训练把读出方向对未见键弄错**；**增益不是可用的救法**（任何 `γ>0` 都掉 3.2–6.5 项，唯一安全值是 `γ=0`，而那等于关掉记忆）。

### §6.1 开放项：**网格下界未探到"临界 γ"**
`γ = 6.25e-5`（`γ_tr/16`）仍掉 **3.33** 项 ⇒ 注入的下限不在本卡网格内。
★★ 若 `‖m‖` 足够大，则 `γ·‖m‖` 在 `6.25e-5` 处**仍不小** ⇒ 开关近似**阶跃**（"开就掉"）。
★ **本卡没有测 `‖m‖`** ⇒ 这是**推断**，不是读数。下一个方向应直接测 `‖γ·m‖ / ‖h‖` 并向下扩网格（`1e-6`, `1e-7`）。

## §7 边界（**不可**外推）

1. ★★ **网格有下界**：只测了 `γ ∈ [6.25e-5, 4e-3]`。**不得**说「任何 γ 都不可能有益」（`γ→1e-9` 未测，§6.1）。
2. ★★★ **`ORACLE` 不是 oracle**（`DEF-115-06`）：注入的是**输入嵌入**，不是输出方向
   ⇒ **不得**说「即使给正确答案也无收益」。本卡只支持「同量级的注入**可以**无害，而学到的方向有害」。
3. **只有 `SPLIT` 参与判据**（覆盖 1.0）；`COLOCATED`（覆盖 0）**绝对水平受结构上界约束**，仅作配对差报告。
4. **本装置没有写入**：`train_read_frozen` 全程 `no_write=True`、`W` 不进优化器且 `sg(W)` 前向 ⇒
   **`W` 逐位不变**（`A115-8` 实测 18/18 格）⇒ **不得**说「关联记忆强度/容量/遗忘」；本卡测的是**读侧校准后的读出**。
5. **`γ` 在本装置从未被训练**（`A115-4c`：唯一取值 `{0.001000000047}`）⇒
   **不得**推断 v2.4 §4 的学习型 γ 会选错值，**不得**说「框架的增益机制有问题」。
6. **单调性不是判据**（§2.4 / §8 草案 B）；`D` 与 `C` 不是独立证据（同一批 48 项、同一 `item_ok`，`DEF-112-04`）。
7. **单点 primitive、16 值 × 2 事实、单 token 候选、48 项评测集** ⇒ 不得外推别的池规模/多点 primitive。
8. **`ACC0` 是划分相关的**（`SPLIT` 17/48、`COLOCATED` 18/48）⇒ 不得跨划分搬用。
9. **本卡不改** `§7.2-7b` 的 `不足`（修好"无信号"不等于修好"有收益"）、不改 Freeze A–E、不判复合律（`P114-1`）。
10. **`C115-INCOMPLETE` 不得**记作 PASS/FAIL；`INCONCLUSIVE-BAND` 本轮未出现（`band_gammas=[]`）。

## §8 撤回的草案（**留档，不删改**）
