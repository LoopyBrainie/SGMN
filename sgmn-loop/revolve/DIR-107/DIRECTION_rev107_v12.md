### §12.2 ★ 缺陷 `DEF-107-05`（我的，第 3 次同类）

**冻结守卫时未核「该守卫在被冻结的装置上是否可满足」。**
`A107-1` 在 rev 1.0 冻结时是**可满足的**（当时装置就是 dir93 模板）；rev 1.1 换模板后
它就变成**恒不可满足**，而 rev 1.1 的 §9.4 还写着「rev 1.1 必须再 PASS `A107-1`」
—— **两版自相矛盾，我在 rev 1.1 里没有发现**。

★ 与 `DEF-106-13`（阈值坐在度量天花板之上）、`DEF-130-01`（同族）**同一缺陷类**：
**冻结/沿用一个数之前，必须核它在当前装置上是否可达** —— 不只是"它过去是真的"。

### §12.3 修正后的 `A107-1`（**rev 1.2 生效**）

- **`A107-1a`（装置忠实性锚 · 主）**：`n=16` 单格（`split=0`, `seed=20261028`）的
  **`acc_train` 必须复现 `D-136`/`A106-2` 的 `0.9375`**（容差 ±0.0625）。
  ★ 理由：rev 1.1 的装置从 `dir106` 逐字派生 ⇒ 忠实性应锚在**派生源的同一点**上。
- **`A107-1b`（可解释性 · 主）**：同一格的 **`acc_held` 必须 `≥ 0`** 且
  **`acc_held` 严格小于 `acc_train`**（否则「读出器没区分训练/留出」⇒ 装置无判别力）。
  ★ 不再把 `0.0625` 当锚。
- **`A107-1c`（记录 · report-only）**：报出该格 `acc_held` 与 `D-121` 的 `0.0625` 之差，
  **只登记不判定**，理由见 §12.1。

★★ **`A107-10`（`acc_train ≥ 0.50`）保留原样**（rev 1.1 已 PASS），它是 rev 1.1 的动机守卫。

### §12.4 rev 1.1 的 §9.4 相应作废

rev 1.1 §9.4 中「`A107-1`（… `acc_held = 0.0625` …）rev 1.1 **必须再 PASS**」一句
**由本节取代**。rev 1.1 其余条款（含"若 `A107-10` 仍 FAIL 不得降阈值"）**继续有效**。
