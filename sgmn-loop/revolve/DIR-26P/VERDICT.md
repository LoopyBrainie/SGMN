## 3. 机制（不只是数字）

### 3.1 塌陷的分解：**阈值失配 77% + 输入结构直接损害 23%**

主世界（$b{=}40$）的「门控增益塌陷」总量 = $+0.0660-(-0.0267)=\mathbf{0.0927}$：

| 分量 | 量 | 占塌陷 | 可否由重新标定回收 |
|---|---|---|---|
| **① 阈值失配**（`τ_iid` 在 AR(1) 下过度跳过） | **+0.0713** | **76.9%** | **已回收**（本轮） |
| **② 输入结构对可检索性的直接损害** | +0.0215 | 23.1% | **不可回收** |
| ②a 其中：**动力学臂**（无条件写也变差，`E0` −0.0123） | +0.0123 | 13.3%（残余的 57%） | 不可 |
| ②b 其中：**策略臂残余**（重新标定后门控仍略差于 iid 档） | +0.0092 | 9.9% | 不可 |

冗余世界（$b{=}4$）：塌陷总量 = $+0.3127-(+0.1994)=\mathbf{0.1133}$ ⇒ 回收 **+0.0738（65.1%）**、残余 **+0.0396（34.9%）**（其中动力学臂 0.0117、策略臂 0.0279）。

★ **取整口径**：分解用**未取整**分量计算。表中三项各自独立四舍五入 ⇒ 相加为 0.0928，与总量 0.0927 差 0.0001；百分比 76.9% / 23.1% 由未取整值求得，恒等式 `recov + res == tot` 由 `crit` 落盘的 JSON 保证。**不得**把 76.9 / 23.1 精炼成「常数」，也不得写进架构结论或后续卡片的阈值。

⇒ ★★ **跨世界的关键读数**：两个世界的**可回收绝对量几乎相同**（**+0.0713** vs **+0.0738**，差 3%），而两世界的塌陷总量不同（0.0927 vs 0.1133）⇒ ⇒ **「阈值失配」造成的损失是与世界无关的常数，而「直接损害」随世界的收益基数放大** ⇒ 重新标定能救回的是一个**固定量**，不是**固定比例**。

### 3.2 「阈值失配」的具体形态：**不是阈值太高，而是同一阈值在 AR(1) 下跳得太多**

- $\tau_{\rm iid}=0.0950$ 在 AR(1) 下的**门控率升到 0.4741**（标定目标是 0.400）⇒ **多跳 54 次**（DIR-26-O 的读数）。
- $\tau_{\rm AR}=0.1045$（**更高**）把门控率拉回 **0.4276** ⇒ **写回 44.7 次**（30/30 正）。
- ★ 写回的是**哪一批**：写侧 `clean` 比例 **0.8600 → 0.9117**（冗余世界 0.8633 → 0.9100），$\mathrm{skip\_frac\_repeat}$ 0.9831 → **0.9900** ⇒ ⇒ **重新标定后的门控跳得更「专」**：它跳过的是**真正同向重复**的写（99.0% 的跳都落在重复写上），而把**中等重复（尚未编码完）的写写回** ⇒ ⇒ **收益机制被直接定位：门控增益 = 「剔掉真重复」+「保留未编码的写」；阈值失配破坏了后者。**
- ⇒ 这也解释了为什么 $\tau_{\rm AR}$ **更高**却更好：$\cos$ 分布整体上移 ⇒ 要维持同一**跳过率**必须抬阈值，而抬阈值恰好把「未编码完的写」从跳过集里放出来。

### 3.3 「直接损害」的残余：AR(1) 让**累积方向带固定偏置**

- 动力学臂 `E0`（无条件写）在 AR(1) 下也变差（$\mathrm{ret}_1$ −0.0123、$\mu$ −0.0017）⇒ **原始写动力学本身**受输入时间结构影响（DIR-26-O 的 P2 未命中本项，但它在本轮成为残余的**过半**来源）。
- 策略臂残余（+0.0092）：重新标定后门控仍比 iid 档低 ⇒ 即使写数回到标定量（549.5 vs iid 档 558.7，仍少 9 次），**同向叠加**仍让写侧方向带偏置（DIR-26-O 的 $\lVert P\rVert$ +0.0247/+0.0366 机制）。
- ⇒ **两种机制都真实存在，但不对等**：阈值失配是**可操作的**主因（77%），直接损害是**结构性的**残余（23%）。

### 3.4 对架构的含义（本轮的可操作结论）

1. **标定的门控阈值是输入谱的函数**（DIR-26-O 的结论，本轮**机制确认**：不仅"是"，而且"改标定能拿回大部分"）⇒ 部署必须**按输入过程标定 $\tau$**，用 iid pilot 标定的常数**不可跨输入过程复用**。
2. **但按输入过程标定不够**：残余 23%（主世界）/ 35%（冗余世界）来自输入结构本身 ⇒ 架构**不能**只做重新标定，必须让写入在**非 iid 输入**下保持**方位角多样性**（这是已登记的候选 C「方位角多样性的因果对照」的动机）。
3. **门控的收益有两个可分离的分量**（承接 DIR-26-O §3.2⑤）：「剔冗余」（冗余世界为主，+0.3127，对输入谱**不敏感**）与「补对齐/多样性补偿」（主世界为主，+0.0660，对输入谱**耦合**）⇒ 本轮把后者拆成**可回收（阈值失配，77%）**与**不可回收（结构偏置，23%）**两部分。
4. **标定必须可观测**：本轮的 $\tau_{\rm AR}$ 依赖一个 **AR(1) pilot**（$S{=}20261041$、$\rho{=}0.40$、$r{=}8$、$\cos\theta{=}0.9$）⇒ 真实部署里「输入过程的 pilot」本身就是一件需要基础设施的事（D-45 的 $\alpha$ 产生规则问题在**输入谱**维度上重现）。

## 4. 边界（不可外推的东西）

- **不可外推为「重新标定能救回 77%」这一固定比例**：只测了 1 个标定点（$\rho{=}0.40$）、1 族 AR(1)（一阶、跨轮、逐条目、作用于键的抖动方向）、4 档 $\varphi\in\{0,0.3,0.6,0.9\}$、1 个装置族（$r{=}8$）、2 个世界（$m{=}60/24$）、30 种子、1 个读侧口径（口径 O）。
- **不可外推为「重新标定能救回 100%」**：**明确不成立** —— 残余 23.1%（主世界）/ 34.9%（冗余世界）**不可由标定回收**；不得把「阈值失配」写成「唯一原因」。
- **不可外推为「标定阈值 = 最优阈值」**：本轮只测了「与 iid 标定**同跳过率**」这一个标定点；$\rho$ 轴、其它跳过率、以及「标定到最优」未测。
- **不可外推到负相关 / 谱形状 / 其它相关性族**：只测了 $\varphi\ge0$ 的一阶 AR(1)。
- **不可外推到剂量律**（$G/R_\mu$/标尺律）：本轮没有 F/K/U 臂 ⇒ D-43/D-45 的剂量会计不受影响。
- **不可外推到任务层 / LLM / 跨会话 / 真实信息寿命**。
- **不可外推为「门控机制不好」**：iid 下门控仍是正收益（主世界 +0.0660、冗余世界 +0.3127）。
- **Stage C 非判决**：只有 2 个正 $\varphi$ 档 ⇒ P3 不可评 ⇒ 按卡片 §2.3 记 `N/A-STAGE-C-NONDECISIVE`；其读数只用于**跨世界一致性**。
- **机制解释中「方位角多样性 = 检索所需」是读数一致的解释，非直接测量**（未直接测方位角与读出方向的夹角，也未做「人为打散方位角」的对照 ⇒ 候选 C 仍开放）。
- **「可回收量是常数、不可回收量随基数放大」只由 2 个世界支撑**，不是定量的普适律。
- $\varphi{=}0.3$ 档的恢复量 **+0.0069（15 正 / 13 负）不过 P2** ⇒ 恢复只在**足够相关**时出现（$\varphi\ge0.6$ 才过阈）。
- 控制口径 X（外来值读）在 $\tau_{\rm AR}$ 臂上的读数与 `tau_iid` 同型（`X.ret1` 保持低位）⇒ 收益仍属**内容选择**，不是通用注入——本轮未新增独立的 X 判据，但 `X` 字段随臂落盘可复核。
