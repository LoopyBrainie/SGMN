## §2 结论（**只能这样说**）

**在本装置、本协议下，信息寿命由「新写入的干扰」决定，不由 `λ` 正则衰减决定：**
1. **衰减项不足以致死**：纯 `λW` 跑满 32 对（512 内层步 = **5.12 `τ_ref`**），跨半比例仅 **9.15%**，KM 中位寿命**在窗内未达**；
2. **干扰项在 2 对之内致死**：写新对时 KM 中位寿命 **2 对**（0.32 `τ_ref`），7 对内跨半 **98.67%**；
3. ⇒ 寿命的**量级差异 ≥ 16 倍**，且 §3 的机制读数说明这不是同一过程的强弱，而是**两个不同机制**。

★ 这正面回应了框架 §5.5 的警告「**正则衰减不等于已验证的信息寿命**」：在低秩因子在线系统里，`τ_ref = 1/(ηλ) = 100` 步**不是**寿命。

## §3 机制（**本轮有直接读数，不是推断**）

| 读数 | `decay` 臂（只有 `λW`） | `busy` 臂（`λW + α` 新写入） |
|---|---|---|
| `‖W_d‖/‖W_0‖` @ `d=4 / 8 / 16 / 31` | **0.1747 / 0.0697 / 0.0218 / 0.0062** | **1.0309**（`d=4`，**在涨**） |
| `c(d)/c(0)` @ 同上 | **0.9322 / 0.8314 / 0.7544 / 0.7272** | **0.0233**（`d=4`） |
| 参考幅度衰减 `(1−ηλ)^{16d}` @ `d=4/8/16` | 0.5256 / 0.2763 / 0.0763 | 同左（同一步数） |

**三条机制结论：**
1. ★★ **余弦对"整体收缩"几乎不敏感**：`decay` 臂的幅度在 31 对后只剩 **0.62%**，但余弦仍保住 **72.7%** —— 这与"余弦是尺度不变量"一致。⇒ **幅度衰减不是寿命**，`τ_ref` 那种"幅度时间常数"根本量不到读出寿命。
2. ★★ **`decay` 臂那 9.15% 的跨半来自各向异性，不是幅度**：`λ` 项在因子化系统里是 `U ← U(I − ηλ VᵀV)`、`V ← V(I − ηλ UᵀU)`，`VᵀV` 各向异性 ⇒ `W` 的列空间**漂移**，余弦缓慢下滑（0.93 → 0.73）。★ 实测幅度衰减**远快于**参考律（0.0218 vs 0.0763 @ 256 步，快 3.5 倍）——因为因子化把 `λ` 作用在**两侧**，而参考律只作用在单侧全矩阵上 ⇒ **§5.5 的参考律在本装置连幅度都不准**（这也解释了为什么不能把 `τ_ref` 直接搬过来）。
3. ★★ **`busy` 臂是"覆盖"而不是"更快衰减"**：`‖W‖` 在 `d=4` 时**还涨到 1.03**，但目标余弦已塌到 **2.3%** ⇒ 新写入把 `W` 的**方向**改掉了，而总幅度未减。⇒ 干扰 = **方向替换**，与"正则把它抹平"是两个机制。

## §4 证据边界（**不得外推**）

1. ★★ **只一格装置、一格协议**（`η=0.2`、`λ=0.05`、`D_H=8`、`D_K=D_V=16`、`r=2`、`KEY_SCALE=0.5`、`N_REP=16`、`perstep` 内容、`CTX=3`）⇒ **不得**写"寿命 = 2 对"这类普适结论，也不得写"寿命 ∝ 1/(写入率)"。
2. ★★ **`decay` 臂的"寿命 > 32 对"是**下界**（右删失），不是测得的寿命值**；`ratio ≥ 16` 是**下界比值**，不得写成具体倍数。
3. ★ **"衰减项不足以致死"只是"在 512 步内不足以致死"**：`mean_L = 27.50`、四分位 10/32/32 说明有约 20% 实例在 32 对内跨半 ⇒ 更长时间尺度上是否收敛到"衰减主导"**未测**。
4. ★ **`busy` 的发散 9.8% 不是随机缺失**：发散实例是轨迹爆炸，被剔除 ⇒ `p_busy` 的读数建立在"未爆炸"的条件样本上；`W=16` 时发散 31%、`W=32` 时 79%（§4 标定）⇒ **窗口越大，幸存者偏倚越重**，本卡因此把 `busy` 窗冻结在 8 对。
5. ★ **本卡不测**：多次重放同一目标（DIR-47 的 `replay` 会**延长**寿命，本卡刻意不用 replay）、AR(1)/`period2` 内容、读器训练参与、跨会话持久化、`S` 组件的调度。
6. ★ **不得**把本卡当 DIR-46（`C(N_w)` 同点可读性）或 DIR-47（`replay` 局部修复）的翻案：三者口径不同（同点 vs 跨点、分组 vs 全局、寿命 vs 修复），且本卡**没有**重算它们的任何格点。
7. ★ **`quiet` 臂"全删失"不是结论**，而是**设计自检**：它证明"读数不改状态"，因此 `decay` 与 `busy` 的差别只能来自**经历步的内容**。
