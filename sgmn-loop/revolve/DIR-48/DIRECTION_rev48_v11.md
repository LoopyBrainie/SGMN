## §0 一句话

**把「目标对写下去之后」的每一步分成两种"里面放什么"** —— 什么都不放（只让 `λW` 正则项跑）/ 放**新对**（`λW + α` 干扰项一起跑）——

## §3 测量对象（**已用 worked example 校验**）

### 3.1 定义（**一实例 = 一个目标对 = 一条寿命**）

对实例 `sd`：
1. 内容流 `a_0 … a_{CTX+W_arm−1}`（`perstep`，逐行归一化到 `√D_H`）—— **逐字**沿用 `dir46/R1_task46.content`（种子 `sd+7777`）；
2. `H_t = tanh(a_t A1 + b1)`、`k_t = tanh((0 if t=0 else H_{t−1}) Pk1)`、`v_t = tanh(H_t Pv1)` —— 逐字沿用；
3. **上下文对** `t = 0,1,2`（`α=1`，只为让 `W` 非空；**永不被测**）；
4. **目标对** `t = CTX = 3`（`α=1` 写入）⇒ 这是本实例**唯一**被测对象；
5. **"经历"步** `d = 1 … W_arm−1`：按臂决定"里面放什么"，**都用同一批 `k_{CTX+d}, v_{CTX+d}` 与同样的 16 内层步**；
6. 读数（**纯读，不改状态**）：`c(d) = cos(W_d k_CTX, v_CTX)`、`‖W_d‖`，`d = 0 … W_arm−1`（`d=0` = 目标对刚写完）；
7. **半衰期**：`L := min{d ≥ 1 : c(d) < RHO·c(0)}`；若窗口内未跌破 ⇒ **右删失**，记 `L = W_arm` 且 `censored = True`（★ 不记 0、不丢弃）；
8. **`C(0)` 定义域**：`c(0)` 必须有限且 `> 0`，否则该实例记 `undef`（**与发散分开计**）。

### 3.2 三臂（**唯一自变量 = 经历的步"里面放什么"**）

| 臂 | 经历的步 | 窗口 | 作用 |
|---|---|---|---|
| `quiet` | **什么都不做**（只读数） | `W=16` | ★ **设计自检锚**：`c(d)` 必须与 `c(0)` **逐位相同**（读数不改状态） |
| `decay` | `G = 0·(Wk−v)kᵀ + λW`（`α=0`，**同样步数**） | `W=32` | **纯 `λ` 衰减项**，隔离 §5.5 的 `τ_ref = 1/(ηλ) = 100` 内层步 = **6.25 对** |
| `busy` | `G = 1·(Wk−v)kᵀ + λW`（`α=1`，写**新对**） | `W=16` | `λ + α` **干扰项** |

★ **匹配的三条**：① 目标对的写入与其之前的前缀（`t=0..3`）三臂**逐位相同**；② 经历步的内层步数 `N_REP=16` 三臂相同；③ `decay` 与 `busy` 用**同一批** `k/v`（同一 `content` 流）⇒ 差别只有 `α`。
★ **`quiet` 为什么不是废话**：它是**唯一**能证明「读数不改状态」的臂；`A48-4` 用它当退化锚（若读数有副作用，`quiet` 的 `c(d)` 就会漂）。

### 3.3 worked example（`dir48/workex48.py`，**逐位**）

手工重算 4 实例 × 3 臂 × 各自窗口的 `c(d)`/`‖W_d‖`/`L`，与实现**逐位相等**（`ATOL=1e-12`）；并用**不读实现**的独立手写循环复算同一批 ⇒ 两条链一致才算过（`A48-2`）。

**诊断结论（决定卡形）**：
1. ★★ **`busy` 的窗口必须按"发散预算"定，不是按"想看多久"定**：发散率随写入数**陡增**（`6:5% · 8:8.5% · 10:16% · 12:20% · 16:31%`；`W=32` 时 79%）。发散实例**不是随机缺失**：它们是轨迹爆炸，剔掉就是**幸存者选择**。rev 1.1 取 **`W_busy = 8`**：发散 `0.085 + 3se = 0.112` 距 `N_DIV_MAX = 0.20` 有余量；而 `p(L≤7)` 已 **1.000**、`KM_med = 2` ⇒ **加长窗口只增偏倚、不增信息**。`decay` 无干扰、`W=32` 发散 0.005 ⇒ 保留长窗给 P1b 下界。
2. ★ **"信息寿命"不能用绝对门限 0.5**：`C(0)` 的实测分布为 [+0.86, +1.00]（这是"刚写完"的读数），但同一装置在**多对写入后**的整槽均值只有 0.057（DIR-47）⇒ 绝对门限会把"装置本身的低读出"和"寿命"混在一起。⇒ 改用**相对半衰** `RHO=0.5`（每个实例以自己的 `C(0)` 为基准），与 DIR-47 §3.1 的 `C(0)` 无矛盾（那里根本没有 `C(0)` 这个概念）。
3. ★ **衰减项并非"无效应"**：`decay` 在 32 对内跨半 **0.227**（`≤15` 时 0.192）⇒ 纯正则项**也能**慢慢掐死读数（机制见 §6.2：因子化 `λ` 更新各向异性 ⇒ 方向漂移），所以 P1a 用 `≤0.30` 的**单向界**而不是"为零"；且 F1/F3 给出"衰减主导/部分衰减"的独立结局。
4. ★ **发散与右删失必须分开计，且 `quiet` 也会发散**（`DEF-48-6`）：`quiet` 的 `div = 0.005` 来自**前 4 次写**（前缀含 `α=1`）就已爆炸的种子，与"读数"无关 ⇒ 不能断言"`quiet` 永不 `undef`"，只能断言"**读数不改状态**"（NaN 感知的逐位相同）。
5. ★★ **`torch.randn(n, d)` 的取值依赖 `n`**（`DEF-48-4`）：三臂窗口长度不同 ⇒ 若各自按长度生成内容流，同种子的 `k/v` **不同**、"三臂用同一批 `k/v`"不成立（实测 `content(sd,19)` **不是** `content(sd,20)` 的前缀）。⇒ **协议冻结**：一律按 `NMARK = CTX+1+max(W) = 36` 生成后再切片。

### 6.1 装置

`‖W‖` 的参考衰减 `(1−ηλ)^{256} = 0.0763`（`d=16` 对 = 256 步）—— 用于 §6.2 的"幅度 vs 余弦"对照。

### 6.2 机制（**可推导，且本轮有直接读数**）
- `decay` 臂的 `G = λW = λUVᵀ` ⇒ `U ← U(I − ηλ VᵀV)`、`V ← V(I − ηλ UᵀU)`。**若 `VᵀV` 各向同性**，则 `W` 只是被**均匀**缩小 ⇒ `cos(Wk, v)` **完全不变**（余弦是尺度不变的）。
- 所以 `decay` 臂能跨半（0.19–0.23）**只能**来自 `VᵀV` 的**各向异性** ⇒ `W` 的列空间**漂移**，而不是幅度衰减 ⇒ ★ 预测：`‖W‖` 比值应接近 `(1−ηλ)^{16d}` 而余弦比值应**慢得多**（形式化于 `R1_task48` 逐 `d` 记录的 `wnorm`）。
- `busy` 臂额外加入 `α(Wk_d − v_d)k_dᵀ` ⇒ 对目标对是**交叉项** `−α(Wk_d − v_d)(k_dᵀ k_t)`（DIR-46/47 同一式子）⇒ 寿命被压到 1–2 对。
★ 本卡**不**宣称这是"架构的信息寿命公式"；它只是把 §5.5 的警告在本装置上**拆成两项并各自给数**。

## §8 红线

1. **不得**把右删失 `L = W` 当 `0`、当"已跨半"或丢弃（判据必须是 **KM 删失感知**）；
2. **不得**用绝对门限 `c < 0.5` 代替相对半衰 `c < 0.5·c(0)`（§4-2：绝对门限会把"装置低读出"与"寿命"混淆）；
3. **不得**把 `p_decay ≈ 0.19` 读成"衰减无效应"（它是**单向界**，且 F1/F3 明确给出"衰减主导/部分衰减"两条独立出路）；
4. **不得**把 `busy` 窗口拉到 16 对以上（`W=32` 时 79% 发散 ⇒ 幸存者是被**选择**出来的）；
5. **不得**把本卡当 DIR-46/47 的翻案，也不得把 `Δ_hit`（DIR-47）或 `C(all)`（DIR-46）当寿命证据（它们的时点/口径都不同）；
6. **不得**改动 `N_INST`/`W_*`/`RHO`/`P1A_*`/`P2A_MIN`/`MED_BUSY_MAX`/`N_DIV_MAX`/`SEED` 之外任何已冻结项（改则新开 revision）；
7. **不得**把 `τ_ref` 当"本装置的寿命定律"：§5.5 只对全矩阵 `α=0` 参考系统成立；本卡测的是**偏离**它多少；
8. 与 `D-01…D-70`、DIR-43/44/45/46/47 的判定与计数**一字不改**。
