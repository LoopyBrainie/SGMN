## §3 ★★★ 机制（**不只是数字**）：读出位的 `K` 个向量是「引导」不是「载荷」

### 3.1 rev 1.1 的更正方向被实验证伪

rev 1.1 §10.4 曾把 `K=1` 就是 1.0000 归因为「**跨层再入**」（一个向量经层 8→12→16 再入）。
本轮按 §10.4 加 `--mount`，用 `SGMNStack(model,[8],d,d,R,ALPHA,LAM,ETA_WRITE,gamma,DEV,...)` **直接构造单层栈**
（**未改** `R2_task91.MOUNT` 常量），smoke `--mount both --ks 1,32 --seeds 20261028`：

| 挂载 | `K` | `acc_all32` | 秒 |
|---|---|---|---|
| `[8,12,16]` | 1 | 1.0000 | 509.3 |
| `[8,12,16]` | 32 | 1.0000 | 508.3 |
| **`[8]`（单层）** | **1** | **1.0000** | **495.4** |
| **`[8]`（单层）** | 32 | 1.0000 | 495.9 |

⇒ **单层 `[8]` 的 `K=1` 也是 1.0000** ⇒ 没有跨层再入也成立 ⇒「跨层再入」解释**不成立**。
（第二轮复现：496.1 / 495.9 s，读数逐位相同。）

### 3.2 ★★★ 决定性通道诊断（`dir102/diag102_channel.py`）

**线索（`dir101/R1_task101._read_r101:88-94`）**：注入 `m` 是 `(B,L,d_model)`、**在所有位置**返回并加进残差，
而 `_m_override` 的 `m[idx] = mo` **只改 `idx = arange(B)*Ln + (Ln-2)`，即每题一个位置**。
⇒ 其余位置的 `m = \mathcal W_o y`（**真实检索值**）**原样保留**。

于是按位置过滤注入、**复用同一训练好的 `tab` 只改读出侧**，四模式（`triple`、`K=1`，两轮复现一致）：

| 模式 | 含义 | `acc_all32` |
|---|---|---|
| `all` | 现状（全位置注入 + 读出位覆盖 `tab[·]`） | **1.0000** |
| `readout_only` | **只**在 `Ln-2` 保留，其余**清零** | **0.3125** |
| `nonreadout_only` | 除 `Ln-2` 外全保留，读出位**清零** | **0.0625** |
| `none` | 全位置清零 | **0.0938** |

⇒ **单通道都不行**（0.3125 / 0.0625），**合起来才 1.0000** ⇒ **两通道真实协同**，不是"某一路泄漏"。

### 3.3 ★ 机制陈述（`DEF-102-03`）

- **载荷（payload）** = 其余位置的 $m=\mathcal W_o y$ —— 逐位置、**因事实而异**，承载"哪个值"。
- **引导（cue）** = 读出位那一个 `tab[code_i]` —— **与事实无关**，功能是让基座**读得出**已被检索到的内容。

⇒ 因为引导天然与事实无关，**一个向量就够** ⇒ `K=1` 与 `K=32` 同为 1.0000。
⇒ **本卡把「码本行数 `K`」当作"记忆参数的自由度数目"是第二个、独立的混淆**：
  `K` 量的是**引导向量**的可压缩度，**不是记忆的可压缩度**。
⇒ 这同时解释了上一轮的三个诊断读数（随机常数 **0.0312** = 引导方向错、`m≡0` **0.0312** = 无引导、
  拟合过的常数 **1.0000** = 引导对了）—— 与"常数装不下 32 个答案"**不矛盾**：常数**不需要**装答案。

## §5 ★ 证据边界（**不得外推**）

1. ★★ **`K_min = 1` 量度的是「读出位引导向量的压缩下限」，不得外推为「记忆通路的压缩下限」。**
   记忆内容的承载通路（其余位置的 $\mathcal W_o y$）在 `K=1` 与 `K=32` 下**完全相同**，
   本卡**没有**对它做任何压缩 ⇒ 本卡**不**证明"记忆可以存进 1 组参数"。
2. **本卡不是前向任务收益证据**。`acc_all32` 是 4 选 1 的**检索准确率**，
   不是"记忆改善了 LLM 任务"。`§7.2-7` 状态**不变（`不足`）**。
3. **不得外推到真实近共线键族**：`D-128` 已证键共线是绑定约束、`D-114` 的 `cos` 中位 `0.997`。
   本卡的 32 个 nonce 键（5 字符随机）不代表真实语料。
4. **不得外推到 `K>32`**：`K=32` 已是逐事实一行（= `A101-1` 的 `free` 臂），再大无意义。
5. **不得**把 `A102-2`/`A102-2p` 的失败读作"装置错误"——它们的前提（常数注入应当无用）**已被证伪**，
   作废是**修正前提**，不是掩盖失败。
6. **`0.99` 与 `D-131` 最大 `0.9688` 只差 0.0212**（§1.4 已预注册此脆弱处）。
   本轮缓解条款（`A102-1` 逐位 1.0000）**已生效**，故读数可解读；但该接近度仍是本判据的已知弱点。

## §8 结论

1. **`H102` 否证**：存在 `K=1 ≤ 8` 使 `acc_all32 = 1.0000 ≥ 0.99`（两 seed 逐位相同）。
2. **`K_min = 1`**，`share_ks = [1,2,4,8]`（全部 ≥0.99）；读数在 `K=1` 即饱和，`K` 从 1 到 32 **完全无影响**。
3. **机制**：读出位注入是**引导（cue）**而非**载荷（payload）**；载荷在其余位置的 $\mathcal W_o y$ 上逐位置存在。
4. **对 `§7.2-2` 的正面答案**：读出位那部分注入参数**可共享到极限 `K=1`**。
5. **`SUCCEEDED` 保持 49**（主假说被否证，不计入）。
6. **边界**：`K_min` 量的是**引导**压缩下限，**不得**外推为记忆压缩下限；本卡**不是**任务收益证据，`§7.2-7` 仍 `不足`。
