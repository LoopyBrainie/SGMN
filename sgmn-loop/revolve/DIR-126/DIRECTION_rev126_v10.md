## §1 主假设与否定条款

### §1-1 两个竞争的假设（**必须同时立**）

在 `D-156` 的 6 个剂量 `{0, 25, 150, 300, 450, 600}` 上，下列两支**同样拟合 6/6**：

| 支 | 内容 | 机制含义 |
|---|---|---|
| **`H126`（中介）** | `ratio > 1 ⟺ frac(û<1) = 0`，其中 `frac` 是**逐层**解出的 `û_s<1` 的层所占的 `Σm` 比例 | `u` 制度（「见过值被回避 / 被偏好」）是**原因**；剂量只是通过它起作用 |
| **`H126-alt`（纯剂量阈值）** | `ratio > 1 ⟺ dose ≥ D*`，`D* ∈ (300, 450]` | 与 `u` 制度**无关**；高剂量直接改变 `ratio` |

★★ **两支在 `dose ≤ 300` 与 `dose ∈ {450, 600}` 上不可区分**（互补的两段）。
★★★ **`{350, 375, 400}` 落在唯一的判别窗口内** ⇒ 这三个剂量点是**唯一能分开两支的位置**，
不是"多算三个数"。

### §1-2 主假设（本卡的判据对象）

> **`H126`**：`sign(ratio − 1) = −sign(frac)`，即 `frac = 0 ⇒ ratio > 1`、`frac > 0 ⇒ ratio < 1`。

### §1-3 否定条款（**逐字冻结**）

`H126` 在下列任一情形下**被否证**（对该剂量而言）：

- **(F-a)** `frac = 0` 且 `ratio < 1`；
- **(F-b)** `frac > 0` 且 `ratio > 1`。

★ 三种**不可判**（明确区别于"否证"与"成立"）：

- **(N-a)** `ratio` 不可算（`e1 = 0` 或 `e2 = 0` 或 `N₁ = 0` 或 `N₂ = 0`）；
- **(N-b)** 该剂量没有任何 `m_s > 0` 的层（`frac` 无分母）；
- **(N-c)** 该剂量的 9 个 cell 未齐（`< 9` 个）—— 本卡**要求 9/9**。

★★ **不可判 ≠ 否证 ≠ 成立**（`DEF-124-07` 的修法：判决表必须显式含"不可执行"这一类）。

## §2 MVP 标准（**阻塞门**，先于任何实验代码）

### §2-1 `J126-1` —— 主判据：三个新剂量的符号预测（**out-of-sample**）

对 `d ∈ {350, 375, 400}` 各算 `(frac_d, ratio_d)`，判 `pred_d = predict_sign(frac_d)` 与
`obs_d = sign_of_ratio(ratio_d)` 是否相符。

| 结局 | 处置 |
|---|---|
| **三个全部相符，且至少一个 `frac_d = 0`** | ⇒ **`H126` 成立**（强）：既确立中介、**又否证 `H126-alt`**（因该剂量 `< 450`） |
| 三个全部相符，但**全部** `frac_d > 0` | ⇒ **`H126` 未被否证、`H126-alt` 也未被否证** ⇒ 记**「不可判（两支都活）」**，只把 `frac` 的零点收窄到 `(400, 450]` |
| **任一剂量触发 (F-a) 或 (F-b)** | ⇒ **`H126` 被否证**（该剂量即反例，须逐字列出） |
| 出现 (N-a)/(N-b)/(N-c) | ⇒ 该剂量**不可判**；若三个都不可判 ⇒ 整卡记**不可执行** |

★★ **信息不对称必须明写**：最有价值的结局是"某个 `d < 450` 上 `frac_d = 0` 却 `ratio_d > 1`"。
若三点全部 `frac>0 ∧ ratio<1`，**不得**读成"机制成立"，只能读成"未否证"。

### §2-2 `frac` 的**冻结定义**（不得事后调整）

```
frac = Σ_{s: m_s>0 且 û_s<1} m_s   /   Σ_{s: m_s>0} m_s
```
- `û_s` 逐层用该层**自己的** `m_s` 解（`mech125.solve_u`，**放宽域 `u∈(0,∞)`**）。
- ★ **`û_s = 0`（夹紧层）算作 `û_s < 1`** —— 因为 `û=0` 确实是"见过值被回避"的极端端点，
  **不作特例、不排除**。排除版只作 **report-only** 灵敏度（`mech126.clamp_free_frac`）。
- ★ **严格 `frac == 0.0`** 判"零"，**不设容差**。`frac > 0` 一律判"非零"（哪怕只来自一个 `m=5` 的层）。
- `m_s = 0` 的层**不进分母**（无信息）。

### §2-3 `ratio` 的**冻结定义**（与 `D-155`/`D-156` 逐字同源）

`ratio = ŵ₂/ŵ₁`，`ŵ_k = (1−p̂_k)(3−k)/(p̂_k·k)`，`p̂_k = e_k/N_k`，**合并 9 个 seed × 4 题集**。
★ **不用 `solve_u`** ⇒ 无定义域风险（`D-155` §5）。

### §2-4 `J126-2` —— 秩一致（**全 9 个剂量**，单侧，精确置换）

在 `DOSE_ALL9 = {0, 25, 150, 300, 350, 375, 400, 450, 600}`（**9 个，不排除 pilot**）上：

> **`H126` 预测 `ρ(frac, ratio) < 0`**（`frac` 越高 ⇒ 越回避 ⇒ `ratio` 越低）。

- 统计量：Spearman `ρ`（平均秩）。
- 检验：**精确置换**（枚举 `9! = 362880`），**单侧**（`ρ` 偏负），`α = 0.05`。
- 判据：`ρ ≤ crit_rho`（临界值由 `mech126.perm_spearman` 机器算，开卡前填入 §2-7）。
- ★ 为什么需要它：`J126-1` 只有 3 个 out-of-sample 点；`J126-2` 用**全部 9 个**（含 6 个 in-sample）
  给出一个**会因新增点被打破**的整体一致性读数。★★ **必须写明它是 in-sample 主导的**。

### §2-5 `J126-4` —— **非空转门槛**（阻塞门，先于实验）

★★★ **这是本卡最重要的前置检查**：`frac` 与 `ratio` 都从**同一批** `(e1,e2)` 算出。
若「`frac=0 ⇒ ratio>1`」是**算术恒等式**，则 `J126-1` 空转。

**代数的冻结结论（开卡前已做）**：令 `x=p̂₁`、`y=p̂₂`、`a=x−2/3`、`b=y−1/3`：
- 单层 `û ≥ 1 ⟺ m ≥ (2N₁+N₂)/3 ⟺ N₁a + N₂b ≥ 0`
- `ratio > 1 ⟺ x + 3xy > 4y ⟺ a(2+3b) − 2b > 0`

⇒ **两者不是同一条曲线**。（反例：`a=−0.05, b=+0.035`、`N₁=68, N₂=99` ⇒ `m = 78.4 ≥ 78.33`
⇒ `frac = 0`，而 `ratio = 0.6898 < 1` ⇒ 触发 **(F-a)**。）

**门槛（冻结）**：有两种**独立**的验证，**两者都必须过**：

- **(a) 构造性见证（主）**：`§3-2` 的 **W4**（`frac=0` 而 `ratio=0.873148<1`）与
  **W5**（`frac=1` 而 `ratio=1.034972>1`）**都必须在 `precheck` 里逐位成立**。
  ⇒ 这直接证明：两类否证构型在**实际可观测的 `p̂` 范围**内**都可以出现**。
- **(b) 网格分歧率（辅）**：在 `(x,y) ∈ (0,1)²` 的 `401×401` 网格上（`160801` 格），
  `discordance = P(frac=0∧ratio<1) + P(frac>0∧ratio>1)` 须 **`≥ 0.05`**。
  ★ 实测 `0.586980`（`p_bad_a = 0.4282`、`p_bad_b = 0.1588`）⇒ 远超门槛。
  ★★ **但这个数字不宜读成「判据有 `0.59` 的功效」** —— 它被远离数据的
  高 `p̂` 区域主导。**只用它证明「不是算术恒等式」**，功效问题由 (a) 回答。

★ 任一不过 ⇒ 判据**近乎空转** ⇒ 整卡记**不可执行**（不得强行出判决）。

**该门槛与 `0.05` 在跑任何实验前冻结。**

### §2-6 `J126-3` —— report-only（**不是判据**）

- 逐剂量 `ratio` 的 bootstrap 95% CI（`mech126.ratio_ci`）；
- 逐层 `e1/m` 与 `θ_s` 的差（`over`），以及"同号层数"（`D-156` §3-1 的推广）；
- `clamp_free_frac`（排除夹紧层的灵敏度）；
- 单层 `(N₁,N₂) = (68,99)` 下的**理论分歧曲线**（`J126-4` 的副产品）。

## §3 测量对象与工作例（**逐位冻结**）

### §3-1 测量对象

一个剂量 `d` 的读数 = 一对 `(frac_d, ratio_d)`：
- `frac_d` 由 `mech126.frac_low_u(obs_d)` 给出（逐层 `û_s`）；
- `ratio_d` 由 `mech125.w_hat(obs_d)` 给出；
- `obs_d` = 9 个 seed × 4 题集（`555/556/557/558`）的 `e1/e2` 汇总；
- `N₁ = 68/seed`、`N₂ = 99/seed`（**只由 `n_seen` 直方图决定**，与训练无关）。

### §3-2 工作例（机器算定，供 `precheck` 逐位断言）

★★★ **闸门阈值是「逐层」的，不是全局的**：`û_s < 1 ⟺ m_s > (2N₁_s+N₂_s)/3`，
而 `N₁_s / N₂_s` 由该层**实际可用题集数**决定 ⇒ 不同剂量的阈值**不同**：

| 剂量 | 可用题集 | `N₁_s` | `N₂_s` | 闸门 `(2N₁+N₂)/3` | 实测 `max m_s` | `frac>0`？ |
|---|---|---|---|---|---|---|
| 0 | **1**（`555`） | **23** | **20** | **22.000** | 36 | 是 |
| 25 | 4 | 68 | 99 | 78.333 | 147 | 是 |
| 150 | 4 | 68 | 99 | 78.333 | 167 | 是 |
| 300 | 4 | 68 | 99 | 78.333 | 142 | 是 |
| 450 | 4 | 68 | 99 | 78.333 | 49 | **否** |
| 600 | 4 | 68 | 99 | 78.333 | 49 | **否** |

★ **新剂量 `{350,375,400}` 的 `c2` 已对所有剂量构建**（`R1_task125.build_c2`，`DEF-125-02` 已修）
⇒ 应为 **4 题集** ⇒ `N₁_s=68`、`N₂_s=99`、闸门 `78.333`（与 `450/600` 同结构）⇒ **可比**。
★★ **`dose=0` 的结构不可比**（1 题集、`(23,20)`、闸门 `22.0`）—— 见 §9 边界 11。

**例 W1（4 题集结构）—— `(N₁,N₂)=(68,99)`、`(e1,e2)=(46,35)`**：
- `m = 81 > 78.3333` ⇒ `û < 1` ⇒ **low** ✓
- `x = 46/68 = 0.676471`；`y = 35/99 = 0.353535`
- `ŵ₁ = (1−x)·2/x = 0.956522`；`ŵ₂ = (1−y)·1/(2y) = 0.914286`
- `ratio = 0.955844 < 1` ⇒ `obs = −1`；`frac = 1.0` ⇒ `pred = −1` ⇒ **相符** ✓

**例 W2 —— 同一结构、`(e1,e2)=(42,37)`**：`m = 79 > 78.3333` ⇒ low；
`ŵ₁ = 1.238095`、`ŵ₂ = 0.837838`、`ratio = 0.676715 < 1`、`frac = 1.0` ⇒ **相符** ✓

**例 W3 —— 闸门的严格判定**：`m = 78 ≤ 78.3333` ⇒ `û ≥ 1` ⇒ 不进 `frac` 分子。
对本结构（整数 `m`）即「`m_s ≥ 79` 才算 low」。

**例 W4 —— 构造性 `(F-a)` 反例（`frac=0` 但 `ratio<1`）**：`(e1,e2)=(41,30)`、`m=71 ≤ 78.3333`
⇒ `frac = 0.0` ⇒ `pred = +1`；而 `ŵ₁ = 1.317073`、`ŵ₂ = 1.150000`、`ratio = 0.873148 < 1`
⇒ `obs = −1` ⇒ **不符**。★ **证明 (F-a) 在本结构下可达。**

**例 W5 —— 构造性 `(F-b)` 反例（`frac>0` 但 `ratio>1`）**：`(e1,e2)=(49,38)`、`m=87 > 78.3333`
⇒ `frac = 1.0` ⇒ `pred = −1`；而 `ŵ₁ = 0.775510`、`ŵ₂ = 0.802632`、`ratio = 1.034972 > 1`
⇒ **obs = +1** ⇒ **不符**。★ **证明 (F-b) 在本结构下可达。**

★★ W4/W5 是本卡**判据非空转的构造性证据** —— 比网格百分比有说服力得多（网格被远离数据的
高 `p̂` 区域主导）。二者都在**实际可观测的 `p̂` 范围**内（见 `D-156` §2：`p̂ ∈ 0.027–0.78`）。

★ 上述五例在 `precheck126` 里**逐位断言**（`P126-S3`），不得凭记忆重建
（`DEF-125-04`⑤ / `DEF-126-02` 的教训）。

## §9 边界（**开卡前写定，结题时不得放宽**）

1. ★★★ **只有 `k ∈ {1,2}`** ⇒ 一个自由度；`frac` 与 `ratio` 都是这**一个**自由度的函数
   ⇒ 本卡测的是"两个函数的符号是否同步"，**不是**"两个独立机制是否一致"。
2. ★★★ **`frac` 与 `ratio` 同源**（同一批 `(e1,e2)`）⇒ 即便判据通过，也只能说
   "**在该结构的读数上**符号同步"，**不能**说"证明了因果"。要证因果需要**干预**（改 `u`）。
3. ★★ **三个新剂量是 out-of-sample，六个旧剂量是 in-sample** ⇒ `J126-2` 的 `ρ` 由旧点主导；
   只有 `J126-1` 是真正的样本外检验。**不得**把 `J126-2` 的显著读成"独立确认"。
4. ★★ **`frac` 是 `Σm` 加权的比例，不是层数比例** ⇒ 一个大层可以决定 `frac` 是否为 0。
   `VERDICT` 必须同时报 `n_low`（层数）与 `m_lo/m_tot`（加权）。
5. ★★ **`dose = 25` 仍是 report-only 探针**（`DIR-125` 已声明）⇒ 本卡不因它改判。
6. ★ **`frac` 的零点位置**只能被收窄到相邻两个已测剂量之间，**不得**插值成连续曲线
   （`D-156` 边界 ⑥）。若某新剂量落进退化区（`û≈0` 层很多），其 `ratio` 同样**不宜强解读**
   （`D-156` 边界 ②）。
7. ★ **本卡不测任务收益**：`acc_argmin`/`acc_argmax` 只是 report-only；`ratio` 是**价值层偏好强度**，
   **不是**能力。用户规则：**内容性收益 vs 通用注入收益不得混报**。
8. ★ **不改** `§7.2-7b`（仍 `不足`）⇒ **终止条件仍不成立**。
9. ★ **不得**据本卡说"`H124` 与训练量无关"（`D-156` 已把它降格为剂量特异）。
10. ★ **不得**把本卡的"符号同步"当作 `D-156` §3 机制的**证明**——它只是**一个**可判的推论。
11. ★★★ **`dose = 0` 的结构与其他剂量不可比**：它只**有题集 `555`** ⇒ `N₁_s = 23`、`N₂_s = 20`、
    闸门 `22.000`（其余剂量是 `(68,99)`、闸门 `78.333`）⇒ 它的 `frac = 0.859` 是在**一个不同结构**上算的。
    ★ 本卡**不排除**它（开卡前已定"9 个全用、不排 pilot"），但 `J126-2` 的 `ρ` 因此含一个
    **结构不可比点** ⇒ `VERDICT` 必须报告**排除 `dose=0` 后的 `ρ`** 作为稳健性对照（report-only）。
    ★★ **不得**因该对照更"好看"或更"难看"而事后改判据。
12. ★★ **`frac=0` 是「每一层 `m_s` 都没跨过自己那个闸门」的**汇总量**，不是「没有任何层在 `u<1`」** ——
    两者在**单层**时等价，多层时 `frac` 是 `Σm` 加权 ⇒ 一个 `m_s` 刚过闸门的小层即可让 `frac>0`（但极小）。
    ⇒ `VERDICT` 必须同时报 `frac`、`n_low`/`n_valid`、以及**最大 `m_s` 与闸门的差**，
    以便读者判断该点是"勉强翻"还是"确定翻"。
