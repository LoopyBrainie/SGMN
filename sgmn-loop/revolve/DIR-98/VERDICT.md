## 二、机制（不只是数字）

### 2.1 共线 ⇒ rank-1 ⇒ 无可分辨内容（`D-126`+`D-127` 的因果被证实）

`cos(k_i,k_j) ≈ 0.9986` ⇒ 所有键近似同一向量 `k̄` ⇒ `ΔW = −η Σ_i outer(Wk_i−v_i, k_i)` 的**右因子单一**
⇒ `ΔW` 实际是 **rank-1**（实测 stable rank **1.0005**）⇒ 所有 `r_i = W k_i` 近同向 ⇒ `argmax` 为**常数下标**
⇒ `N_hit^v ≤ max_v m_v = 2`（实测 **1**）。

### 2.2 ★ 共线不是"记忆写不进去"，而是"写进去的**没有方向**"

`t_i = v_i − W⁰k_i` 在共线键下**近似为常数**（`v_i` 近共线 + `W⁰k̄` 恒定）⇒ 所需修正几乎是**一个共同向量**
⇒ rank-1 就够吃到它 **88–93% 的范数**（`π = 0.886–0.931`）⇒ **`W` 确实被大幅修正了，但修正的方向对所有事实一样**
⇒ 事实之间**没有任何可分辨差异**。这就是「内容贡献 = 0」的真身。

### 2.3 ★ `intact@10`：预算不是约束，几何才是

给共线键 **10 倍写入预算**：`N_hit^v` **仍是 1/32**（6/6 格），`π` 只从 0.886 升到 0.897，秩 1.04→1.28。
⇒ **"多写几遍"救不了共线**。这是本卡最强的因果对照：唯一变动量是键几何，输出跟着变；
唯一不变的是几何，10 倍预算也拉不动内容。

### 2.4 去相关后秩只到 ~5，却足够装满 32 个事实

`white` 的 `stable rank(ΔW)` = **4.94–5.51**（不是 32）。说明 32 个事实的可分辨内容**落在 ~5 维子空间里**即可
完全分辨 —— 秩不是关键量，"键是否给出**可区分**的右因子"才是。
（反证：`center` 秩仅 1.014–1.075，却有 `N_hit^v = 15`；秩与内容**不单调**。）

### 2.5 可实现机制：因果居中已能拿到一半

`center`（`μ_t` = 此前键的滑动均值，`μ_0 = 0`，**不看未来**）把键 `maxcos` 从 0.9987 降到 **0.374–0.419**，
`N_hit^v` 从 **1** 升到 **3–15/32**。⇒ **便宜、可落地的机制真实有效，但不足以达 24/32**；
要达到 32/32 需要**真正正交化**（`white` 臂）。

## 三、判决的可靠性：为什么这是**因果**而非相关

1. **唯一自变量是键变换**：`v` 侧未动（`v_rule_mode("mean",…) = zv.mean(0)`，不含 `k`，已核源码）；
   `η=3e-5`、`α=1`、`λ=0.05`、seed、层、事实集、写入块全部相同。
2. **`γ=0` 使键与 `W` 解耦**（`A98-9` 实测 `max|Δ|=0.000e+00`）⇒ 各臂**键集完全相同**，
   差异只可能来自"写规则怎么吃这套键"。
3. **范数已配平**（`A98-3`，写相后实测范数比 **1.000**）⇒ 不是"写入强度"的假效应（共线诊断的关键混杂）。
4. **两个对照同时有效**（`oracle` 32/32、`oracle^π` 0/32）⇒ 判据量本身可信。
5. **`intact@10` 排除预算** ⇒ 只剩几何。

## 四、★ 主判据量 `π` 被证明是**坏判据**（重大缺陷，须留档）

`π(intact@1) = 0.886–0.931` —— **比 `π(white@1) = 0.883` 还高**，而前者的 `N_hit^v` 是 **1**、后者是 **32**。
⇒ **`π` 与"有没有存下内容"不单调、甚至轻微反相关。**

**根因**（§2.2）：`π` 按**范数**加权，而共线键下所需修正的范数**被共同分量主导**；`π` 量的是
"共同分量吃到了多少"，恰恰**不是**"事实之间是否可分辨"。`π` 高只说明 `W` 被整体平移了。

**这同时说明我 rev 1.2 的 §0 算术是错的**：我当时断言"即便键完全正交，写入只走到目标的 ~3.5%，
故 `N_hit^v ≥ 24` 不可达"。实测 **`moved` 只需 0.18（不是 `need ≈ 1.0`）就拿到 `N_hit` = 32**
⇒ 那个"不可达"论证**不成立**，`N_hit^v` 在原生预算下**本来就可达**。
⇒ **教训**：`need = ‖W_or − W⁰‖` 是**最小范数精确解**的范数，而写规则到达的 `W` 并非最小范数解；
**"需要走到 `need`"是错误假设**。`DEF-97-03`（先测装置再冻阈值）须扩展为：
**先测装置的"可达性"，再断定某阈值"不可达"**。

**处置**（不改冻结判据、不追认）：
- 判决仍按冻结的 §1.3 执行（`π(white@1) ≥ 0.5` ⇒ `CONFIRM`），**未改阈值、未改文字**。
- 但**结论的实质依据改为 `N_hit^v`**（有阳/阴虚对照的量），`π` 仅作**已废判据**留档（`DEF-98-04`）。
- ★ **不得**在后续轮次再用 `π` 作内容判据。

## 六、边界（不得外推）

1. **`white` 是上界臂，不是可实现机制**：`A` 由一次**离线采集**估得，且把键投到 32 维事实跨度上
   ⇒ **事实内块间差异被消去**。这**多于**"去相关"本身。`center` 才是机制候选。
2. 只在**本装置**：`d=896`、600 块、32 事实、`η=3e-5`、`α=1,λ=0.05`、**`γ=0`**、2 seed、3 层（8/12/16）。
3. ★ **`γ=0` ⇒ 开环（write-only）消融**：键不随 `W` 变。**不得**外推到 `γ>0` 的闭环训练
   （闭环下键会随 `W` 漂移，共线程度可能改变）。
4. **`P=10` 不是收敛**：`white@10` 的 `π` 0.994 只是"更近"，**不得**称"到达固定点"。
5. **不得**把 `N_hit^v` 的改善当作"记忆已改善 LLM"：`D-125` 的 `acc_held ≡ 0` 仍未解；
   本卡**没有**测读侧任务、生成质量、任何 LLM 收益。
6. **不得**说"v2.4 的键生成是错的"：本卡只测**本实现** `k = Pk(h)` 在此语料/装置的共线程度
   （`Pk` 是 `randn/√d` 的**随机固定**投影，未做任何去相关）——这是**实现选择**，不是框架条文。
7. **不得**用 `π` 作内容判据（`DEF-98-04`）；**不得**用秩比值代替内容读数（`D-127` §五-6）。
8. **不得**把 `center` 的部分改善（3–15/32）说成"已解决"：它**未过** 24/32。

## 八、对 `§7.2-7b` 的意义

缺口第五次收窄，且**第一次拿到"什么是绑定约束"的因果结论**：

~~是否经 `W`~~（是）→ ~~是否经写入内容~~（否）→ ~~写入为何不产生内容~~ →
~~写入规则是否有能力存储~~（**有能力**，去相关后 32/32）→
**现为「键生成 `Pk(h)` 产生近共线键 ⇒ `ΔW` 秩-1 ⇒ 无可分辨内容」**（本卡**已证**）。

★ 仍未闭合：`7b` 的终局问题是**任务收益**（`acc_held ≡ 0`），而本卡只到"内容存得下"。
⇒ 下一步自然方向：**键去相关后，读侧能否把内容读出来并转化为任务收益**（读侧 + 任务，仍空）。
