## §1 主假说与否证条款

### §1.1 定义域（**封闭**，三支互斥且穷尽；遵 `DEF-96-10`）

## §2 判据量（**逐字沿用 `D-127`**，不得重定义）

### §2.1 `N_hit^v`（主判据量）

`N_hit^v(W) = Σ_i [ argmax_j cos(r_i, v_j) ∈ S_i ]`，其中 `r_i = W k_i`，`S_i = { j : v_j ≡ v_i }`（值一致即命中）。

- **零期望** `E_random = Σ_v m_v² / 32`。★ `D-127` 实测本装置为 **1.3125**（22 单例 + 5 二元）——
  **不得**按 `1/32`、**不得**用严格下标 `N_hit^s`。
- 同时报 `N_hit^s`（严格下标）与 `N_hit^v_L2`（`−‖r_i−v_j‖²` 的 argmax）作**一致性披露**；
  三者不一致时以 `cos` 版为准并披露差异。

### §2.2 `stable rank` 与**比值**

`stable_rank(X) = ‖X‖_F² / σ₁(X)²`。**`S98` 用比值** `ρ_a = stable_rank(ΔW_a) / stable_rank(ΔW_intact)`
（同一 seed、同一层）。★ 用比值而不用绝对门限的理由（写进卡，防 `DEF-97-03` 重演）：
`ΔW = −η Σ_i outer(Wk_i − v_i, k_i)` 是**恰好 32 个 rank-1 项之和** ⇒ 秩的**解析上界是 32**；
且 `center` 臂的 32 个键**和为 0** ⇒ 键跨度至多 **31**。故"秩 ≥ 32"是**不可达**的门限（`D-127` 预注册稿里的
`M98-1` 原写 ≥32 ⇒ **本条按 `DEF-97-03` 的教训预先修正**）。比值在同 run 同状态内自归一，无此病。

### §2.3 键去相关的**度量**（`A98-1` 用）

对变换后的 32 个键 `K'`（`896×32`）：

- `maxcos(K') = max_{i≠j} |cos(k'_i, k'_j)|`
- `nrank(K')` = `K'` 的奇异值中 `> 1e-3 · σ₁` 的个数（数值秩，冻结阈值 `1e-3`）
- 另报 `κ(K') = σ₁/σ_r`（条件数，仅披露）

## §3 装置与自变量（**唯一改动点 = 键**）

逐字派生 `dir97/R1_task97.py` + `dir91/probe91_kpool.py`。装置不变：
`d=896`、600 块、32 事实、`R2_task91.make_stack(gamma=0.0, seed=200) `、`η` 取默认、`alpha=1`、`lam=0.05`、
`ARM = K_mean_V_mean`、2 seed（`20261028`、`7777`）、3 层（8/12/16）、`E_random` 由数据算出。

**唯一自变量 = 写入键的变换 `T`**（`k' = s · T(k)`）。`v` 侧**不动**：`v_rule_mode("mean", zv, ...) = zv.mean(0)`，
**不含 `k`**（已核源码）⇒ 变换 `k` **不污染 `v`**，是干净的单变量。

| 臂 | `T` | 说明 |
|---|---|---|
| `intact` | 恒等 | 基线，须复现 `D-127` 的 ≤1/32 |
| `center` | `k − μ` | **可实现机制**：`μ` = 写入流上**此前**键的滑动均值（因果，不看未来） |
| `white` | `A k` | **去相关上界**：`A` 把键映到事实跨度内的**正交**方向（`A = U√n K⁺`） |

### §3.1 范数保持（**冻结，防混杂**）

写入步 `G = α·outer(Wk−v, k) + λ(W−W0)` 对 `k` 是**二次**的（`outer(...)·k` 与 `k` 本身各一次）
⇒ 若 `T` 把 `‖k‖` 缩小 10 倍，写入强度缩 **100 倍**，会让"去相关无效"的假象出现。

**冻结处置**：每臂每层用**一个标量** `s` 使 `mean_i‖s·T(k_i)‖ = mean_i‖k_i‖`（`intact` 的 `s=1`）。
`s` 由 §3.2 的采集遍**一次算定**，写相与测量**共用同一个 `s`**（不随写入过程变化）。

### §3.2 `μ`、`A`、`s` 的估计（**一遍采集**）

在同一 seed 新栈上、`no_write=True` 做**一次前向采集**得原始键 `K_raw`（`896×32`，每层一组），然后：

- `center`：`μ = mean_i K_raw[:,i]`；`s` 按 §3.1。
- `white`：`K_raw = UΣVᵀ`（薄 SVD）；`A = (U√n) K_raw⁺`，`n=32`；`s` 按 §3.1。对 32 个已知键**恰好** `A k_i = U_i√n`
  ⇒ 两两 `cos = 0`、`‖·‖ = √n` ⇒ 去相关**最大化**。
- ★ **如实标注**：`A` 由**一次离线采集**估得、且把键投到 32 维事实跨度上 ⇒ **事实内块间差异被消去**。
  这**多于**"去相关"本身 ⇒ `white` 是**上界臂**，**不得**称作任何可实现机制。
  `center` 才是"可实现机制"臂。

### §3.3 一致性（同一变换必须同时作用于**写**与**测量**）

`_write_patched`（写相）与 `key_matrices_arm`（测量）都经 `k_rule(...)` 产生键。本卡把变换挂在
**`LayerMem` 实例属性** `m.key_tf` 上，两处**都读同一个 `m.key_tf`** ⇒ 写进 `W` 的键与测量用的键
**逐位同源**。★ 若两处不同源，本卡**无意义**，故须有 `A98-2` 断言。

## §5 测量对象与**手算算例**（冻结前必须过）

**测量对象**：`N_hit^v(W, K', V)`，其中 `W` 是写相结束后的 `Wfull`，`K'` 是 §3.3 同源变换后的键。

**手算算例（`n=3` 玩具，`d_k=d_v=2`）**——本卡在实现前**必须先复算通过**：

设 `v_1=[1,0]`、`v_2=[0,1]`、`v_3=[1,0]`（⇒ `S_1={1,3}`、`S_2={2}`、`S_3={1,3}`；`Σ|S_i|=2+1+2=5`），
`W = I`，`k_1=[1,0]`、`k_2=[0,1]`、`k_3=[0.5,0.5]/(‖·‖)`。

则 `r_1=[1,0]`、`r_2=[0,1]`、`r_3≈[0.707,0.707]`：
- `i=1`：`cos` 对 `v_1,v_2,v_3` = `1, 0, 1` ⇒ `argmax` 取**首个**最大（`j=1`）∈ `S_1` ⇒ **命中**
- `i=2`：`0,1,0` ⇒ `argmax j=2` ∈ `S_2` ⇒ **命中**
- `i=3`：`.707,.707,.707` ⇒ 三者相等，`argmax` 取**首个** `j=1`，且 `1 ∈ S_3` ⇒ **命中**
⇒ **`N_hit^v = 3/32`-式的 `3/3`**；**`N_hit^s`**：`i=3` 的 `argmax=1≠3` ⇒ **`2/3`**。
⇒ ★ 两者**必须不同**（`3/3 ≠ 2/3`），否则说明 `S_i` 没被用上。
`E_random = 5/3 ≈ 1.667`。★ 实现须先跑此算例，不一致 ⇒ 测量层有错，**不得**开 Stage A。

## §6 边界（**不得外推**，写进 VERDICT）

1. `white` 臂是**上界**，**不是**任何可实现机制；`center` 臂才是机制候选。
2. 本卡只测**写侧键几何**这一条因果；**不测**读侧、不测多步读出、不测生成质量、不测 LLM 任务收益。
3. 只在**本装置**（`d=896`、600 块、32 事实、`K_mean_V_mean`、`η` 默认、2 seed、3 层、`α=1,λ=0.05`）。
4. **不得**把 `N_hit^v` 的改善当作"记忆已改善 LLM"：`D-125` 的 `acc_held ≡ 0` 仍未解。
5. **不得**把 `INVALID`（自变量没动）当作"否证 `H98`"，反之亦然（`§1.1` 三支互斥）。
6. **不得**说"v2.4 的键生成是错的"：本卡只测**本实现**的 `Pk(h)` 在此语料/装置下的共线程度。
7. ★ 若 `A98-1` 对 `center` 也失败（居中不足以去相关），**只**说明"居中这个机制不够"，
   **不**说明"去相关没用"—— 后者由 `white` 臂回答。
8. **不得**用 `S98`（秩比值）代替 `H98`（可分辨性）：秩是**结构**，`N_hit^v` 是**内容**（`D-127` §五-6）。
