## 3. 边界（开跑前声明）

- 本轮**只动读侧**（查询方式 + 是否训练）；写规则、记忆结构（显式 KV）、$\alpha,\lambda,\eta,\beta$ 沿用 DIR-16。

- 「读侧训练」只训 $(W_o,\gamma)$（cue 模式下 $W_q$ 不参与）⇒ ⇒ **不能**外推为「读侧任意参数化都能如此」。
- 合成回忆是**单条事实、末位或中段**；**不能**外推为长期记忆、跨会话或多跳。
- 全部结论限于 `Qwen2.5-0.5B-Instruct` + wikitext-2 + 本卡声明的协议。

| # | 坑 | 应对 |
|---|---|---|
| 1 | cue/misaddr 模式下 **$W_q$ 不参与前向** ⇒ 若优化器含它 ⇒ 「训练」实际不训练任何东西 | A2' 的第②条断言 $W_q$ 梯度恒 0 ⇒ 优化器**只含 $W_o,\gamma$** |

## 修订 40（装置/判据缺陷 · D34）：`ctx` 模式下 $W_q$ 的梯度恒为 0 ⇒ E3 的「训练」不可解释

- **症状**：A2' 的第③条 FAIL：`‖g_Wq(ctx)‖ = 0`（在 cue 模式下这是**预期**的——$W_q$ 不参与前向；
  但在 `ctx` 模式下 $q=W_qc$ ⇒ $W_q$ **应当**拿到梯度）。
- **分析（待复检）**：显式 KV 核的读出是 $y=\mathrm{softmax}(eta\cos(q,K))\,V$，其中 $V$ 在正常模式下**被 detach**
  ⇒ ⇒ $y$ 对 $q$ 的依赖只经由 softmax 权重 $a$；若读出的**混合**在目标条目上塌缩（$approx \mathbf{1}_{target}$），
  则 $\partial L/\partial approx0$ ⇒ ⇒ $\partial L/\partial qpprox0$ ⇒ ⇒ $W_q$ 拿不到梯度。
  ⇒ ⇒ **这本身是一条机制事实**：在「检索已正确」的条件下，$W_q$ **不再有可学的信号**
  ⇒ ⇒ 即「读出映射的可学性依赖于检索未成功」⇒ ⇒ 与 DIR-16 的结论（原始签名才是关键）方向一致。
- **处置（正式轮前）**：① 复核上述解释（打印读出权重与 $\partial L/\partial a$）；② 若成立 ⇒
  **A2' 的第③条改判为「`ctx` 模式下 $W_q$ 的梯度可以为零，但必须在报告里说明其机制含义」**（**只增判据的说明，不改 H1–H5**）；
  ③ E3（`ctx`+训练）若因 $W_q$ 无梯度而**只训到 $W_o,\gamma$** ⇒ ⇒ 仍可作为「不可寻址的读取」对照
  （它与 E1 的差别只剩**检索是否命中**）⇒ ⇒ **H3 的可比性不受影响**，但必须在裁决书里写明。

## 修订 42（脚本缺陷 · **D36 · 最严重**）：`freeze_write()` 未在文档间解冻 ⇒ 第 2 篇起写阶段空转

- **症状**：smoke#2/#3 中命中恒为 1/8；`vals_written` 在第 2 篇起为空；`A2' ③` 的 `‖g_Wq(ctx)‖ = 0`。
- **根因**：`eval_arm` / `train_arm` 在**文档循环内部**调用 `st.freeze_write()`（把 `no_write=True` 留在装置里），
  下一轮文档的**写阶段**因此什么都不写 ⇒ ① 记忆为空 ⇒ 命中只剩第 1 篇；② 读出恒为 0 ⇒
  $\partial y/\partial a = V = 0$ ⇒ **$W_q$ 的梯度精确为 0** ⇒ 「`ctx` 模式不可训」是**假象**。
- **修复**：每篇文档开始前调用 `st.unfreeze_write()`。
- **复验（smoke#4）**：`A2' ③` 的 `‖g_Wq(ctx)‖ = 5.437e-06` ✓（非零）；
  `A2' ⑤` 的命中 = 1.0000 ✓；`A4'` 的 loss 1.3237 → **0.0247**（此前 2.2253 是噪声）。

## ★ 正式轮必须改的一处设计：**任务饱和**（smoke#4 的核心发现）

smoke#4 的五臂结果：

| 臂 | 命中 | 目标码 log-prob |
|---|---|---|
| `E1_cue_train` | **1.0000** | **−0.0000** |
| `E2_misaddr_train`（内容错） | 0.0000 | **−0.0000** |
| `E3_ctx_train`（不可寻址） | 0.0000 | **−0.0000** |
| `E4_cue_notrain` | 1.0000 | −1.9425 / −1.8222 |
| `E5_base` | — | −2.0146 / −1.9148 |

⇒ ⇒ **三个训练臂全部饱和到 lp ≈ 0** ⇒ ⇒ **任务层指标在本设计下无法分离三个臂** ⇒ ⇒
**H2/H3 在本设计下必然 FAIL，但 FAIL 的原因不是「记忆内容无用」，而是「任务太容易」**。

**为什么 E3（命中 0）也能到 lp = 0？** ⇒ `ctx` 模式下读出虽然检索不到真值，但它读到了**同一篇文档写入的其它位置**
（本次写入 39 条，命中 0 只说明**内容**不是真值，但**位置**仍在同一篇内）⇒ ⇒
读出映射可以学会「把当前位置附近的写入内容搬进输出」⇒ ⇒ **任务只要求复现「这一篇里的某个位置」** ⇒ ⇒ 太容易。

⇒ ⇒ **正式轮的三条改动（判据不变，改的是任务难度）**：
1. **评测码留出**：训练时只出现码 $c_{\rm train}$ 的首 token；评测时用**训练中从未出现**的码 $c_{\rm eval}$ ⇒ ⇒
   读出映射无法靠记忆码的 token 分布取胜 ⇒ ⇒ 必须真正从**记忆内容**里解码。
2. **多位置干扰**：评测文档内**插入了其它文档的写入**（干扰项）⇒ ⇒ 读出不能靠「位置就近」取胜。
3. **目标码增长**：目标改为码的**前 3 个 token**（teacher forcing 于评测期）⇒ ⇒ 单 token 可被位置捷径解掉，3 token 不行。

⇒ ⇒ **判据 H1–H5 的命题/方向/阈值完全不变**；只改**任务构造** ⇒ ⇒ 属 rev 1.2 的设计修订（留档，不追认）。

## 修订 43（卡片）：H1 的方向以「目标码 log-prob 越高越好」为准

# 卡片 rev 1.3（smoke#4 → smoke#5 前冻结，2026-11-04）

## 修订 44（设计 · 撤销 rev 1.2 的第 3 条「目标码增长为 3 token」）

- **被撤销的条目**：rev 1.2 改动 3「目标改为码的**前 3 个 token**（teacher forcing 于评测期）」。
- **撤销理由（装置因果语义对齐）**：v2.4 §2.3 的写规则是
  $$k_{l,t}=\mathrm{sg}(P_k(h_{l,t-1})),\qquad v_{l,t}=\mathrm{sg}(P_v(h_{l,t}))$$
  ⇒ ⇒ **位置 t 的条目只存 $h_t$ 这一枚 token 的信息**（外加键 $k_t$、签名 $h_{t-1}$ 所携带的上下文）
  ⇒ ⇒ 码的**第 2、3 个 token 根本不在码首 token 所在的那一条条目里**（它们在各自位置的条目里）
  ⇒ ⇒ 「让读出复现 3 个 token」要求的是**跨条目的组合**，这不是 §2.2 的读取接口（单条目 + 线性读出）能表达的事
  ⇒ ⇒ 该改动属「任务与装置不匹配」，**不是更严的判据** ⇒ ⇒ 撤销。
- **替代**：目标**保持单 token**（码首 token）⇒ ⇒ 读出必须从**一条**条目里解出 ⇒ ⇒ 与 §2.2 的接口形式一致。

## 修订 45（设计 · 「多位置干扰」的具体化）

- rev 1.2 的「多位置干扰」原意是「评测文档内插入了其它文档的写入」⇒ 本 rev 把它落成**成对文档**：
  - 每篇文档 D = `fill_target + CUE_A + 码`；同时构造配对的干扰文档 D' = `fill_dist + CUE_A + 异码`；
  - `fill_target` 与 `fill_dist` 是语料中**相距 ≥ 400 token** 的两个切片 ⇒ ⇒ 两篇的**上下文签名必不同**
    （签名 = 写入时的 $h_{t-1}$，随上下文不同而不同）⇒ ⇒ 地址匹配仍能分辨两篇；
  - 两篇**线索相同**（都是 `CUE_A`）⇒ ⇒ 若只靠「线索」检索，两篇不可分辨 ⇒ ⇒ 内容成为唯一的区分依据
    ⇒ ⇒ 命中与否才能测「内容是否被检索到」；
  - 两篇**码不同**且码全局唯一 ⇒ ⇒ 训练码与评测码零重叠 ⇒ ⇒ 读出映射无法靠记住码的 token 分布取胜。
- **写阶段**：目标文档与干扰文档**都写**（否则干扰文档不进入记忆 ⇒ 干扰无效）。

## 修订 46（判据工具 · 冻结三条）

1. **饱和预检门 A3'**（正式轮开跑前必须 PASS）：
   $$\mathrm{spread}\big(\mathrm{NLL}(E_1),\mathrm{NLL}(E_2),\mathrm{NLL}(E_3)\big)\ \ge\ \varepsilon_{\rm sat}=0.05$$
   ⇒ ⇒ 若不达标 ⇒ **任务平凡** ⇒ ⇒ 判据无信息量 ⇒ ⇒ **不得开正式轮**（纪律 ㉔）。
2. **判据一律走 NLL 口径**：`paired(a,b) = b − a` ⇒ ⇒ 「A 优于 B」判 `mean(paired) > 0`；log-prob 作为第二口径同时报告（纪律 ⑳）。
3. **N_ENTRIES：64 → 128**（**脚本参数，不是装置改动**）：目标 + 干扰两篇合计 ~74 条 ⇒ 64 会**槽位回绕**

# 卡片 rev 1.4（smoke#5 → smoke#8 后冻结，2026-11-04）——★★ 根因级修订

## 修订 47（★★ 设计 · 根因：「位置就近」捷径来自 §2.3 的因果写）

- **症状（smoke#5）**：rev 1.3 的干扰项**并没有**打破饱和：`E1`(命中 1) / `E2`(命中 0) / `E3`(命中 0) 的目标码 log-prob **全部 = −0.0000**。
- **根因（★ 本方向最重要的机制发现）**：v2.4 §2.3 的写规则把 $h_t$ 存进 $v_t$，而 **$h_t$ 的因果上下文包含位置 t 之前的所有 token**
  ⇒ ⇒ **码之后的每一个位置，其 $h_t$ 都含码的身份** ⇒ ⇒ **「读对条目」与「读邻位条目」都能解出码**
  ⇒ ⇒ 于是「内容对 vs 内容错」（E1 vs E2）的对照**在结构上不可能分离** ⇒ ⇒ 任务再次平凡。
- **处置（唯一的结构性修法）**：**把码放在文档的最后一个 token**
  ⇒ ⇒ 码之后**没有任何位置** ⇒ ⇒ **只有码自己那一条条目持有它的身份** ⇒ ⇒ 邻位条目（干扰项）在**身份上**不可解
  ⇒ ⇒ E1/E2 的对照才第一次具备分辨率。
- **码的形式随之改为「单 token 稀有词」**（而非 3 token 数字码）：
  - 3 token 数字码 ⇒ **第 1 个 token 的身份**同时出现在码后第 2、3 条目里 ⇒ ⇒ 仍可被邻位解出 ⇒ ⇒ 不解决根因；
  - 单 token 码且位于文末 ⇒ ⇒ **身份唯一性**成立 ⇒ ⇒ 解决根因；
  - 稀有 ⇒ ⇒ 基座几乎不可能猜中（A2'⑨ 实测基座 NLL ≥ 3）⇒ ⇒ 目标必须靠记忆读出。
- **对 ctx 臂（E3）的连带效果**：干扰文档也以码结尾 ⇒ ⇒ `ctx` 的混合里有**两份「码分量」**（目标码 + 干扰码）
  ⇒ ⇒ 混合在**身份上不可解**（两个不同的码）⇒ ⇒ E3 也不再有捷径。
