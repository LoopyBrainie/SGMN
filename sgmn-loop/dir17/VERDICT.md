## 2. 结论

### 2.1 ★★★ **主假说【证实】：记忆内容确实能产生任务收益，且收益可被「内容对照」钉死**

DIR-16 的 H7 FAIL 留下的问题（「检索成功 ≠ 任务收益，中间隔着读出映射」）在本轮被补上：

1. **读出映射可以被训练**（§4 的读侧联合训练从未实现 ⇒ DIR-09 的缺口在此闭合）：
   训练后 E1 的目标码 NLL = **9.3845**，未训练的同装置 E4 = **15.2413** ⇒ **Δ = 5.857 nats（p=1.25e-12，180/180）**。
2. **收益确实来自「记忆内容」，而不是「读接口本身」**（H2，纪律 ㉑ 的「同 γ 的内容对照」）：
   E1 与 E2 **装置相同、训练相同、γ 相同**，**只差地址是否指向目标条目**
   ⇒ ⇒ 内容对 vs 内容错 = **+1.848 nats（t=17.20，p=1.25e-12，三种子全正）**。
3. **可寻址性本身有独立价值**（H3）：E1（内容寻址）vs E3（现状的 $q=W_qc$ 软匹配，同训练）
   ⇒ ⇒ **+1.726 nats（t=19.04，p=1.25e-12）**。
4. **三者缺一不可**：
   - 只写不训（E4）⇒ **相对基座零收益**（Δ = −0.0209，p=1）⇒ **「有记忆 + 会寻址」不够，必须学会读出**；
   - 训了但读不出内容（E2）⇒ 只能拿到基座之上的一部分（+3.99），且**显著低于真正的读出**（+1.85 的缺口）；
   - 读出但不可寻址（E3）⇒ 同上，**寻址贡献 +1.73**。
   ⇒ ⇒ **完整的链条「写 → 寻址 → 读出映射 → 任务收益」首次端到端跑通并被逐段量化。**

### 2.2 ★★ **修正 DIR-10 的归因**（本轮最重要的架构含义之一）

DIR-10 的裁决写的是「收益来自**可训练读接口**而非可塑记忆」（其 H3 当时是 **实质 FAIL**：
`joint − joint_nowrite = +0.00003`）。
本轮的 **H2 内容对照**（同装置、同训练、**只换地址是否指向目标条目**）给出 **+1.848 nats** 的显著差异
⇒ ⇒ ⇒ **DIR-10 的归因需要再次修正**：
> 在**可寻址读取**（内容寻址 + 正确命中）的前提下，收益**确实由记忆内容承载**；
> DIR-10 之所以测不出内容贡献，是因为它的协议里**根本读不到正确的内容**（当时的地址机制命中≈随机）。

⇒ ⇒ 这与 DIR-15/DIR-16 的结论构成一条完整因果链：
**DIR-11～14 测出「写侧规则写不出可检索的内容」⇒ DIR-15 换掉地址机制 ⇒ DIR-16 证明可推广
⇒ DIR-17 证明「读得到」确实等于「用得上」。**

### 2.3 ★★ **新发现：训练 γ 会破坏寻址**（H6/H7 ⇒ 对 v2.4 §4 的一条具体修正）

- **现象**：E1（γ 可训）的命中 **0.8722**，而**完全未训练**的 E4 命中 **1.0000** ⇒ ⇒ **训练把寻址精度打掉了 12.8%**。
- **逐条排除**（均有实测依据，见卡片 rev 1.5）：
  ① 槽位回绕（成对写入 68 条 ≤ 128 槽，**无回绕**）；② 训练阶段记忆残留（每篇都 `restore_all`，**干净**）；
  ③ $W_o$ 破坏命中（命中判据比较的是**未过 $W_o$** 的读出 $y$）；④ 干扰文档抢占匹配（E4 同样写两篇且命中 1.0）。
- **剩余解释（被 R2 证实）**：v2.4 §6.1 的读写前向耦合
  $$h^{\rm read}_t = h^{\rm base}_t + \gamma\, m_t$$
  ⇒ ⇒ **训练 $\gamma$ 改变了读阶段的前向分布** ⇒ ⇒ **写侧记下的签名（训练前的 γ）与读侧用于匹配的前缀表示（训练后的 γ）不再对齐**
  ⇒ ⇒ 地址匹配退化。
- **R2 的对照证明**（卡片 rev 1.5 修订 50 冻结于开跑前）：
  - H6：仅把 $\gamma$ 从优化器里拿掉，命中 **0.8722 → 0.9630**（Δ = −0.0907，t=−6.43，p=4.46e-10，三种子一致）⇒ ⇒ **「γ 漂移破坏寻址」被证实**；
  - H7：$\gamma$ 锁定后**任务收益不降反升**（NLL 9.3845 → **8.9641**，Δ=+0.4204，t=6.25，p=5.53e-09）⇒ ⇒ **γ 的可训练性在本协议下是净有害的**。
- **⇒⇒ 对 v2.4 的具体修正建议**：
  v2.4 §4 规定「任务损失只更新读取侧 $\phi=(\phi^q,\phi^o)$ 与 $\gamma$」。
  在**可寻址读取**的完整协议下，**$\gamma$ 应当被冻结**（或改用与寻址无关的独立目标定标），
  否则「前向耦合」会把写侧签名与读侧查询拉离。
  ⇒ ⇒ 这条建议是**有方向性的、可证伪的**（R2 已给出反例方向）。

### 2.4 ★★ **机制性发现：因果写使「位置就近」成为天然捷径 ⇒ 任务必然饱和**

本方向在设计阶段撞上并解决了两个连续的任务饱和，根因值得单独留档：

- **饱和 #1（smoke#4）**：E1/E2/E3 的目标码 log-prob **全部 = −0.0000**，连**命中 0** 的臂也饱和
  ⇒ ⇒ 判据无信息量（H2/H3 的 FAIL 不构成「记忆内容无用」的证据）。
- **饱和 #2（smoke#5）**：加入「同线索、异码、异上下文」的干扰文档后**仍然饱和** ⇒ ⇒ E2（命中 0）依然 nll=0.0000。
- **★ 根因**：v2.4 §2.3 的写规则把 $h_t$ 存进 $v_t$，而 **$h_t$ 的因果上下文包含位置 t 之前的全部 token**
  ⇒ ⇒ **码之后每一个位置的 $h_t$ 都含码的身份** ⇒ ⇒ **「读对条目」与「读邻位条目」都能解出码**
  ⇒ ⇒ 「内容对 vs 内容错」在结构上**不可能分离** ⇒ ⇒ 任务再次平凡。
- **★ 唯一的结构性修法**：**把码放在文档的最后一个 token**
  ⇒ ⇒ 码之后**没有任何位置** ⇒ ⇒ **只有码自己那一条条目持有它的身份** ⇒ ⇒ 邻位条目在**身份上**不可解。
  ⇒ ⇒ 为此码必须从「3 token 数字」改为「**单 token 稀有词**」（3 token 码的**第 1 个 token** 仍被后两条目持有 ⇒ 不解决根因）。
  ⇒ ⇒ 干扰文档也以码结尾 ⇒ ⇒ `ctx` 混合里有**两份码分量** ⇒ ⇒ 混合在身份上也不可解。
- **⇒⇒ 沉淀为纪律**：**判据 FAIL 前必须先排除「任务平凡」**（纪律 ㉔，本方向新增），
  并配套一条**机器可检的饱和预检门 A3'**：$\mathrm{spread}(\mathrm{NLL}(E1),\mathrm{NLL}(E2),\mathrm{NLL}(E3)) \ge 0.05$，
  **不达标不得开正式轮**。本方向正是靠这条门避免了「用无信息量的判据跑完 200 篇训练」。

### 2.5 ★ 附带收获：命中指标的**口径**（`last_yr` vs 读出）

命中判据比较的是 `last_yr` = **未过 $W_o$** 的读出 $y$（D22 引入的诊断量口径）⇒ ⇒
**$W_o$ 不进入命中判定** ⇒ ⇒ 命中是**纯检索指标**，可以与任务指标严格分离。
这条口径在本轮被实际用到：它是排除「$W_o$ 破坏寻址」这一候选解释的直接依据。

## 3. 边界（**支持范围 / 不能外推为**）

### 3.1 支持范围（本文结论成立的边界）

1. **装置层**：DIR-17 装置 = DIR-16 装置的逐字派生 + 读参数分组/冻结接口；写规则、显式 KV 核、因子化读出映射全部未改
   ⇒ ⇒ 结论对**该写规则**（§2.3 的因果位置级写）与**该读接口**（内容寻址 + 线性 $W_o$）成立。
2. **规模**：Qwen2.5-0.5B-Instruct，3 层挂载，$d_k=d_v=64$，$r=16$，$\eta=10^{-5}$，$\gamma_0\approx0.053$，Adam lr=1e-3。
3. **任务**：单文档事实回忆（`fill + " The vault code is" + <稀有词>`），目标 = 码的**首 token**，
   评测码与训练码**零重叠**；每篇配一个「同线索、异码、异上下文」的干扰文档。
4. **规模上限**：只到 0.5B；**未测 ≥7B**（DIR-23 候选）。

### 3.2 **不能外推为**

1. **不能外推为「§7.2 的前向任务收益已普遍成立」**：只在本装置 + 本任务 + 本规模成立；
   其它读取机制（软匹配、混合读、稀疏字典）未测。
2. **不能外推为「记忆改善了 LLM 的通用能力」**：本任务只测**单点事实回忆**，不是通用能力提升。
3. **不能外推为「v2.4 的写规则是好的」**：写侧仍是 §2.3 的因果位置级写；
   本轮证明的是**在写侧内容已经可被寻址的前提下**，读出映射能把它兑现成任务收益。
   （写规则本身的缺陷由 DIR-13/DIR-14 负责，已分别证伪「共线键」「键不匹配」。）
4. **不能外推为「γ 在任何协议下都该冻结」**：本结论限定在**可寻址读取 + 前向耦合**的协议下；
   若 γ 的漂移被某种机制补偿（例如写侧与读侧用同一个 γ 快照），结论可能改变。
5. **不能把 E1 的 0.8722 命中当作「可寻址性只能到 87%」**：该数字是**训练 γ 之后**的；
   γ 锁定后为 0.9630 ⇒ ⇒ 可寻址性在无 γ 漂移时接近饱和（剩余 3.7% 未单独归因）。

## 5. 对 v2.4 的反哺（本轮产出）

1. **§7.2「前向任务收益」的归属改写**：
   「读侧联合训练后有收益」⇒ **「在可寻址读取 + 内容对照下，记忆内容贡献 +1.85 nats，
   寻址性贡献 +1.73 nats，训练相对未训练贡献 +5.86 nats，而只读不训相对基座为 0」**。
2. **§4 的 $\gamma$ 条款**：建议冻结 $\gamma$（证据：H6/H7）。
3. **§2.3 的因果写**的一个未被记载的后果：**位置就近天然是一个可用的解码捷径** ⇒ ⇒
   任何以「回忆某条事实」为目标的评测协议，**必须把目标放在序列末尾**，否则该协议无法区分「读对」与「读邻位」。
4. **§2.2 的读取接口**：DIR-15/16 已给出「可寻址性契约」（同空间、同尺度、同位置 ⇒ 原始量的同一性），
   本轮补上**该契约足以支撑端到端任务收益**的一条正面证据。
5. **方法论**：§7.1 末段禁令（不得以「模型太小」为唯一失败解释）在本方向得到正面执行：
