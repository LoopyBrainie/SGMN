## 1. 装置要新增的两项（唯一允许的装置改动）

### 1.1 可训基座子集（对应旋钮 N3 / N4）

```python
# 在 SGMNStack 上加两个只读属性（不改任何前向逻辑）：
#   trainable_base_params(mode) -> list[(name, tensor)]
#     mode="none"  ⇒ 空（基座全冻结，= DIR-17/18 的做法）
#     mode="all"   ⇒ 全部基座参数
#     mode="lowrank" ⇒ 基座参数的**低秩子空间**（对每个权重 W 取其前 r 个主方向）
#     mode="layers" ⇒ 只放开 MOUNT 指定的层（= 旋钮 N4）
# ★ 关键：**每个被放开/关闭的参数必须有一个「生效性检查」**
#   （纪律 ⑭）⇒ Stage A 断言「放开后这些参数的梯度非零有限」「关闭后梯度恒 0」。
```

**低秩子空间的具体化（必须可实现、可验证）**：
- 对每个 2-D 基座权重 $W$（形状 $[d_{out}, d_{in}]$），取其 **SVD 前 $r$ 个方向**，
  构造投影 $P = U_r U_r^\top$（行空间投影）；
- 被训子空间 = $P W$（只允许沿 $U_r$ 方向变化），通过参数化 $W = W_0 + U_r A$ 实现；
- **生效性检查**：`‖ΔW‖` 必须**恰好**落在 $\mathrm{span}(U_r)$ 内 ⇒ 用 `‖(I−P)ΔW‖ ≈ 0` 断言。

### 1.2 KL 正则（对应旋钮 N2）

```python
# 在 train_arm 的任务损失上追加：L_total = L_task + λ_kl * KL(π_θ(·|x) || π_θ0(·|x))
# ★ π_θ0 必须**冻结快照**（训练开始前拷贝一份基座）⇒ 开销：再存一份基座（fp32 2.0 GB）
#   ⇒ 在 3 GB 沙箱上**不可行** ⇒ ⇒ DIR-19 在 CPU 上**只能跑 N1 / N3 / N4 / N5 四个旋钮**，
#   N2（KL 正则）必须等 GPU 服务器恢复才能测。
#   ⇒ ★ 这一条必须写进卡片（受限声明），不得假装测过。
```

## 2. 臂表（草案，8 臂）

| 臂 | 配置 | 作用 |
|---|---|---|
| `E5_base` | 无记忆基线 | 基线 |
| `E5_base_mem` | 挂记忆但**零训练** | 「加装记忆本身」的代价（基座退化的下界） |
| `N1_frozen_base` | 基座全冻结 + 读取侧训练 | DIR-17/18 的标准做法 ⇒ **收益对照** |
| `N1_nowrite` | 同上但**写步从不执行** | 收益归因（沿用 DIR-18 的 H2″ 教训） |
| `N4_low_layers` | 只放开低层基座参数 | 旋钮 N4 |
| `N3_lowrank` | 只放开基座权重的低秩子空间（r=8） | 旋钮 N3 |
| `N5_disjoint` | 训练数据与基座保持评测数据**不相交** | 旋钮 N5（**必须做** ⇒ 防止「退化」其实是「数据分布变了」） |
| `E5_base_cap` | 纯基座 + 与记忆任务同分布的对照训练 | 排除「任何联合训练都会让基座退化」 |

## 3. 判据落地方案（写在卡片里，冻结后才跑）

| 判据 | 阈值 | 备注 |
|---|---|---|
| **H1'** | `N1_frozen_base` 相对 `E5_base_mem` 有显著收益 | > 0.5 nats, p<0.05, 逐种子同向 |
| **H2'** | `N1_frozen_base` 的超额 $\Delta\text{code}-\Delta\text{ctrl} > 0.5$ | 内容性（沿用 DIR-18 的 H13 口径） |
| **H3'** | `N1_frozen_base` 的基座退化 $\Delta_{PPL}$ 无显著退化 | 退化 < 0.05 nats |
| **H4'** | 存在旋钮 $R\in\{N3,N4\}$ 使退化**显著低于** `N1_frozen_base` 且收益保留 ≥ 90% | 非平凡保护 |
| **H5'** | $R$ 的收益保留率 > 早停对照 | 「保护」不只是「少训练」 |
| **H6'** | $D_{kv}$ 在有训练时 > 0、零训练时 = 0 | 度量自检 |
| **H7'** | 所有臂的基座退化 ≤ 事先声明的界 | 界 = 0.10 nats |
| **A19-1…A19-8** | Stage A（见卡片 §3） | 装置正确性 |
