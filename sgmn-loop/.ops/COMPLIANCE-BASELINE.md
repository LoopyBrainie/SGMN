## §5 ★ 实测发现的工具缺陷：`K15` 假 `N/A`（本轮最重要的一条）

`K15` 全库 **103/103 全部 `N/A`**，理由是同一句：「本卡未声明任何阶段打印纪律 ⇒ 无守卫可配」。
**这句话对 `DIR-130` 是假的。**

`DIR-130` 的卡片（`DIRECTION_rev130_v12.md`）**明写**了阶段打印纪律：

```
185:**不得**打印属于判据的**聚合读数**（`p₃₅₀`/`p₃₀₀` 及其任一中间聚合）。
```

而 `k15()` 的谓词是**字面**正则 `不得打印|不得输出|禁止打印`：

```python
if re.search(r"不得打印|不得输出|禁止打印", ln):   # 语料实际是 **不得**打印
```

markdown 强调记号 `**` 夹在 `不得` 与 `打印` 之间 ⇒ **匹配不到** ⇒ 走 `if not hits:` 分支 ⇒ 记 `N/A`。
实测：全库原样命中 **0** 处；去掉 `*`/`_`/反引号后再匹配，`DIR-130` 的 3 个 revision 共 **4** 处（v10/v11 各 1、v12 2 处）。

★★ **这条缺陷的性质比它的大小严重**：
1. `N/A` 读作「不适用」，在报表里**最好看** —— 它不是 `FAIL`，不会引起注意，也不会被计数为问题；
2. `K15` 恰恰是 `P130-4` 那条教训（「阶段纪律必须配机械守卫」）的**工具化产物**，
   而它对自己教训的**原始卡片**（`DIR-130`）是盲的 —— **守卫看不见它要守的东西**；
3. 它同时使 `§4` 的「D 疑空转」这一列**看起来像"卡片都没有这个需求"**，而真相是**谓词太窄**。

⇒ **处置**：本轮**只记录、不修**。理由有二：① 本任务的产物是**基线快照**，
   一边测一边改仪器会让基线不可复现（§1 钉的是当前工具 md5）；
   ② 修 `K15` 必须同时补一条**能变红**的夹具（`DEF-129-01`），那是独立任务。
   ⇒ 已开 **`P133-4`** 承接（含判据：修后 `DIR-130` 不得再是 `N/A`，且新夹具在旧实现上必须红）。

★★ **有没有可能是"谓词太窄"普遍存在？我们把口径放宽试过了**：
把谓词放宽成 `(不得|禁止|不应|严禁)…{0,14}(打印|输出|含)` 并去强调后，
全库命中 **15** 处、涉及 **7** 个 DIR（`DIR-130`/`26S`/`31`/`46`/`65`/`88`/`91`）。
**逐条读过原文后，其中 6 个是假阳性** —— `含` 在这些句子里是"包含/含有"而非"输出"：
`DIR-65`「不得保留…的说法（**含** D-85 的措辞）」、`DIR-88`「不得修改装置（**含** :93-94）」、
`DIR-91`「不得外推为 y 完全**不含**信息」、`DIR-31`「不得把 C3 读成…对**输出**无影响」（讲的是解释口径而非打印）、

  谓词既要**足够宽到**能看见目标，又要**窄到**不把无关句子算进来；`K15` 现在两头都没做到。

## §7 复现（自包含，无需额外脚本）

```bash
cd sgmn-loop && SGMN_ROOT=$PWD PYTHONDONTWRITEBYTECODE=1 python3 .ops/scripts/check_cards.py --all \
  > /tmp/all_cards.txt 2>/dev/null
```

得到 `■ DIR-n` 与 `   PASS|FAIL|N/A Kk` 两种行后，按下表口径聚合（与本文数字逐位一致）：

```python
import re, collections, pathlib
txt = pathlib.Path("/tmp/all_cards.txt").read_text(encoding="utf-8")
rows, cur = [], None
for line in txt.splitlines():
    m = re.match(r"■ DIR-(\d+)\s+card=(\S+)", line)
    if m: cur = int(m.group(1)); continue
    m = re.match(r"   (PASS|FAIL|N/A)\s+K(\d+)\s", line)
    if m and cur: rows.append((cur, int(m.group(2)), m.group(1)))
era = lambda n: "DIR-≤100" if n <= 100 else ("101-120" if n <= 120 else "121-130")
agg = collections.defaultdict(collections.Counter)
for n, k, s in rows:
    agg[(k, era(n))][s] += 1; agg[(k, "ALL")][s] += 1
for k in sorted({r[1] for r in rows}):
    c = agg[(k, "ALL")]; ap = c["PASS"] + c["FAIL"]
    print(k, c["PASS"], c["FAIL"], c["N/A"], f"{c['PASS']/ap*100:.1f}%" if ap else "—")
```

★ 聚合规则：**通过率的分母是 `PASS+FAIL`（适用），不是总判据数**。
若改用总判据数做分母，`K15` 这类「全 N/A」会显示 `0%` 而不是 `—`，
把「从未触发」误报成「全员违规」—— 这与它现在的「假 N/A」是同一枚硬币的两面。
