★ 顺带核过其余 12 条**不是空转**：`K19` 在 103 张卡上实际扫了 **500** 个 `.py` 文件（它那 103 条 `PASS` 明细逐条带计数），
`K4/K5/K14/K17/K18/K22` 的 `N/A` 均来自真实前置条件（如「判据不含重采样」「没有备择族」「不扫源码」），

## §5b ★ 第二处工具缺陷：`K22` 的**适用门按符号搜 α**（`Cycle 252` 已修，`P133-3`/`决定二百四十一`）

★ 本表是**重生成**版：`K22` 的适用门已在 `Cycle 252` 修掉（`决定二百四十一`）、
`K15` 的假 `N/A` 已在 `Cycle 253` 修掉（`决定二百四十二`，见 §5 开头）⇒ `K22` 与 `K15` 两栏的数字
都与**更早**的版本**不可直接比较**。

旧适用门是**字面搜符号**：`re.search(r"\bα\b|alpha", 卡片全文)`。这在本框架里是错的 ——
**α 首先是写入率/门控参数**：`SGMN_v2.4_架构设计.md` §7.2 第 1 行「写入映射与门控」的括号里写的就是
「$\alpha$ 的产生规则」，装置里是 `G = α(Wk−v)kᵀ + λW`，代码里写作 `ALPHA`/`ALPHA, LAM`。
⇒ **符号被领域本身占用了，按符号建的谓词就会系统性误判**。逐张归因（机器核，非手数）：

| 归因 | 张数 | 实例 |
|---|---|---|
| LaTeX 架构符号 `$\alpha$` / `\alpha` | **17** | `DIR-22/26/28/29/30/31/32/33/55/58/61/71/87/88/89/91/127` |
| 裸 `α` = **写规则** | **16** | `DIR-38` `G=α(Wk−v)kᵀ+λW`；`DIR-39` 参数表 `η=0.2, α=1.0` |
| `α=0` = **decay 控制臂**（写率置零） | **1** | `DIR-48` `G = 0·(Wk−v)kᵀ + λW` |

⇒ 旧口径「适用」**48** 张，其中 **34 张是假阳性（误报率 71%）**；新口径 **15** 张，逐张核过都是真显著性水平
（`DIR-19/20/21/23/92/104/112/113/114/120/121/122/123/124/126`）。
★ 顺带修出一处**假阴性**：旧门只认 ASCII 的 `p<0…`、**不认 `≤`** ⇒ `DIR-112`（`p ≤ 0.0012`/`p≤0.035`）
被**静默判 `N/A`** —— 与 §5 的 `K15` 假 `N/A` **同一物种**。

★★ **本节要留的教训（比 `K15` 那条更根本）**：`K15` 是**正则太窄**（`**不得**打印` 匹配不到），
`K22` 是**词表选错了对象**（拿领域的物理符号当统计学符号）。两者都表现为 `N/A` 或错误的适用集合，
而 `N/A` 在报表里**最好看** —— 缺陷因此能长期潜伏。

## §6 边界（不得外推）

- **不得**把本表的 `FAIL` 反推为「当时的实验做错了」：它只说明**卡片文本**未满足**当前谓词**。
- **不得**用本表去改任何历史卡（`P130-1`/`P131-1`）；本表**只作基线**。
- **不得**把本表接进 `audit_consistency.py` 或 CI 红绿（会全红，且把方法学退化成品控门禁）。
- **不得**把「`K24` 82.5% FAIL」读成「后期卡片更差」：`K24` 的尺子是**新引入**的，
  对早期卡片本就不可能满足（见 `P133-2` 任务行与 `P132-1` 的校准结论）。
- **不得**把 `D`（疑空转）当作「该纪律没必要」：`K15` 已证其中至少一条是**工具缺陷**而非需求缺失。
- 本表是 **`check_cards.py` 当前实现**的快照（§1 已钉 md5）；工具一变本表即**过期**，须重生成 ——
  `Cycle 252` 即因修 `K22` 适用门而**重生成过一次**（`K22` 由 `45 FAIL / 57 N/A` 变为 `12 FAIL / 90 N/A`）。

## §7 复现（自包含，无需额外脚本）

```bash
cd sgmn-loop && SGMN_ROOT=$PWD PYTHONDONTWRITEBYTECODE=1 python3 .ops/scripts/check_cards.py --all \
  > /tmp/all_cards.txt 2>/dev/null
```

得到 `■ DIR-n` 与 `   PASS|FAIL|N/A Kk` 两种行后，按下表口径聚合（与本文数字逐位一致）：

```python
import re, collections, pathlib
txt = pathlib.Path("/tmp/all_cards.txt").read_text(encoding="utf-8")
rows, cur = [], None
for line in txt.splitlines():
    m = re.match(r"■ DIR-(\d+)\s+card=(\S+)", line)
    if m: cur = int(m.group(1)); continue
    m = re.match(r"   (PASS|FAIL|N/A)\s+K(\d+)\s", line)
    if m and cur: rows.append((cur, int(m.group(2)), m.group(1)))
era = lambda n: "DIR-≤100" if n <= 100 else ("101-120" if n <= 120 else "121-130")
agg = collections.defaultdict(collections.Counter)
for n, k, s in rows:
    agg[(k, era(n))][s] += 1; agg[(k, "ALL")][s] += 1
for k in sorted({r[1] for r in rows}):
    c = agg[(k, "ALL")]; ap = c["PASS"] + c["FAIL"]
    print(k, c["PASS"], c["FAIL"], c["N/A"], f"{c['PASS']/ap*100:.1f}%" if ap else "—")
```

★ 聚合规则：**通过率的分母是 `PASS+FAIL`（适用），不是总判据数**。
若改用总判据数做分母，`K15` 这类「全 N/A」会显示 `0%` 而不是 `—`，
把「从未触发」误报成「全员违规」—— 这与它现在的「假 N/A」是同一枚硬币的两面。
