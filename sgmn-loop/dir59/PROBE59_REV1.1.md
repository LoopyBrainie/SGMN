## §1 缺陷 `DEF-59-1`（怎么发现的、错在哪、影响面）

**发现路径**：卡 §2.3 要求"测量对象必须用一个具体工作例核对"。在 `workex59.py` 里按冻结文字**独立重实现**了 16 步前向 + 写更新 + 读数，结果 `max|ΔW| = 0.0`（$W$ 轨迹逐位一致）**但** $E_{\rm own}$ 差 `8.8e-2`、$E_{\rm written}$ 差 `1.3e-2`。差在**读数**而不在动力学 ⇒ 配对错了。

**错在哪**（`probe59a.rollout_measure` 第 40–50 行 + `measure`）：

```python
if l == 1:                      # ★ 无条件收集 ⇒ t = 0..15，共 16 对
    K1.append(k); V1w.append(v)
gs = T33.targets(P_own)         # ★ 只有 t = 1..15，共 15 个
...
zip(K1, gs)                     # ★ 配成 (k_0,g_1), (k_1,g_2), …, (k_14,g_15)
```

⇒ `E_own` 实际测的是 $\|W k_t-\mathbf{g_{t+1}}\|$，而 $g_{t+1}=P_v(h_t)$ **恰好等于该步写入的值** $v_t$（同一个 $P_v$、同一个 $h_t$，只是 $h$ 取自"未写入的初始轨迹"）。
⇒ 于是在 **OWN 臂里 $E_{\rm own}$ 退化成存储保真的另一个副本**（rev 1.0 实测二者 0.8777 vs 0.8862，几乎相等），"载荷"与"存储"在 OWN 臂里**不可分**；FOREIGN 臂的对比因此被污染。

**影响面**：`E_written` **未受影响**（它配的是 $(k_t,v_t)$，同下标，16 对）；受影响的是 `E_own` 及一切由它导出的配对差（rev 1.0 §3 的整张表、§5 的 $3\mathrm{se}$ 与 $\delta_{\rm eq}$ 取法）。**rev 1.0 的 PASS 判据依赖的就是这张表** ⇒ 必须撤回。

## §3 结论变化：rev 1.0 的 `PASS` **撤回**，改判 `INFEASIBLE-PREMISE`（限"关联层读法"）

1. **存储对来源盲：成立且更稳**（−0.0090 ± 0.0270，17/32；在 `AL` 强信号臂里同样 −0.0178 ± 0.0255）。这条 rev 1.0 的结论**保留**（`E_written` 的配对本来没错，rev 1.0 的 +0.0028 ± 0.0261 与修正版 −0.0090 ± 0.0270 同结论）。
2. **"任务载荷对来源盲"不成立为可判命题**：修正后阳性对照只有 **−0.0319 ± 0.0126（25/32，2.5σ）** —— rev 1.0 宣称的"6.7σ 有功效"是缺陷配对造出来的假象。要 null 的对象只有 **3.2%**；任何 $\delta_{\rm eq}$ 只能取到 0.02 量级，而 $n{=}96$ 时 $1.96\mathrm{se}\approx0.0125$ ⇒ 检验**贴着边缘**，且"3% 的载荷差"根本不承载"来源是否影响任务"这种框架级结论。
3. ⇒ 判 **`INFEASIBLE-PREMISE`**：**在关联层（$\|Wk-v\|$）上，"$P_v$ 的来源"没有可判内容** —— 存储对来源盲（真结论，但那是**存储**，不是**载荷**），载荷通道本身太小（3.2%）。这与 rev 1.0 试图下结论的对象不是同一个东西。
4. **附录结论加强**：强载荷只在"写值取 $h_{t-1}$"时出现（`AL` 同源 −0.2371，32/32；外源 **+0.0266，比不写还差**）。这仍然是**改 §2.3 写入规则**（机制），不属 §7.2 开放项。

## §4 不是终点：本框架行的规范操作化是**任务损失**（redirect，不是弃置）

D-76（DIR-53，$P_k$ 的离线学习）已确立本框架行（§7.2 第 523 行）的规范操作化 = **训练读数头的任务损失** $L$（`train_arm40`，250 步、lr 0.03、`n_eval=400`），其动态范围是

$$L_{\rm 差}\approx 0.16\text{–}0.6,\qquad R=L_{\rm FIX}-L_{\rm ORACLE}\approx0.23\text{–}0.43,$$

即**效应占 headroom 的 40%–140%**；而关联层只有 3.2%。⇒ **要问「其他来源」，必须在任务损失层问**，且判据形态可沿用 DIR-53 的**相对口径**：

- 地板臂：`NONE`（$\alpha{=}0$，记忆关掉）⇒ $R=L_{\rm NONE}-L_{\rm OWN}$ = 记忆的贡献（headroom）；
- 主判据：$\Delta=L_{\rm FOREIGN}-L_{\rm OWN}$。**若 $\Delta\ge3\mathrm{se}$ 且 $\Delta\ge0.20R$ ⇒ 来源进入任务**；若 $|\Delta|<\delta_{\rm eq}=0.20R$（整个 $1.96\mathrm{se}$ 区间落在 $\pm\delta_{\rm eq}$ 内）**且** 对照组 $\Delta_{\rm own-none}=L_{\rm OWN}-L_{\rm NONE}\le-3\mathrm{se}$ **且** $R\ge0.20$ ⇒ **来源盲（规范自由度）**。
- 外源仍取**相邻种子**的 $P_v$（同分布同形状；本轮已证两套值近正交：$\cos$ 中位 −0.0455 / 最大 $|\cos|$ 0.8779）。
- $\delta_{\rm eq}=0.20R$ 与 DIR-53 的 `frac_headroom = 0.20` **同式**（"不超过 headroom 的 20%"），是**相对**等价界，比 rev 1.0 的绝对 0.030 更能承载框架级结论。

**先要 task 级探针 59D**（3 臂 × 3 格）测出 $R$、$\mathrm{se}(\Delta)$、以及"$\alpha{=}0$ 是否真的显著变差"，才能给卡定阈值 —— 关联层已证明**不能**替代它。
