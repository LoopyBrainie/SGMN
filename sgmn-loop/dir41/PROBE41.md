## §3 **共享图的边缘律：按装置源码逐字核对**（Advisor 的硬要求）

装置 `dir31/R1_grad.py::build`：

```python
g = torch.Generator().manual_seed(seed)
def rn(*shape, scale=1.0, rg=False):
    return (torch.randn(*shape, generator=g) * scale).requires_grad_(rg)
s_h = 1.0 / math.sqrt(D_H)
P[f"Pk{l}"] = rn(D_H, D_K, scale=s_h)          # 写入映射（固定）
```

任务层 `dir33/R1_task33.py::build`：`P["Pk{l}"] = P["Pk{l}"] * KEY_SCALE`（`KEY_SCALE = 0.5`）。

⇒ ⇒ **装置的有效 `Pk1` = `randn(D_H, D_K)/√D_H × KEY_SCALE`**（`D_H=8, D_K=16`）
⇒ ⇒ `shared_pk1_for(seed)` **逐字复刻该边缘律**（独立生成器 ⇒ 与任何单个装置实例的 `Pk1`
**不逐位相同**，但**同分布**）⇒ ⇒ **只改「是否跨实例共享」，不改分布**。
⇒ ⇒ ★ **不得**再只靠「`n=2` 的范数比」当证据 ⇒ 正式轮的 Stage A 用 **n=400** 的分布检查（见卡）。
