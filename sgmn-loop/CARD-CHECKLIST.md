# 开卡清单（CARD-CHECKLIST）

> **用途**：冻结一张方向卡的 MVP 标准 / 判据**之前**，逐条过这张表。
> 每条都对应一次**真实发生的缺陷**，不是泛泛的最佳实践。
> **本文件是纪律的唯一归档地**（`handoff.md` 每轮被覆盖，规则只写在那里会随覆盖丢失）。
>
> **条目格式（强制，不得省略任一字段）**：
> 　**必须有** **原文** / **触发** / **依据** / **检查** 四项，可用两种渲染之一：
> 　　（a）**项目式**：`### K<n> · 一句话`，下接 `- **原文**：` `- **触发**：` `- **检查**：`；
> 　　（b）**表格式**：`## K<n> · 一句话`，下接 `| **触发** | … |` `| **依据** | … |` `| **检查** | … |`。
> 　**原文** = 迁入前的逐字措辞（`P131-1` 的硬约束：「只搬家、不改口径」）——**不得润色**。
> 　（`K1` 为 `P130-1` 原生条目，用**表格式**；`K2`–`K24` 为迁入条目，用**项目式**。）
> 　**检查**行末尾必须带执行方式标记之一：
> 　　`①自动化` = 脚本可直接判定（`grep` / 正则 / **AST** / 子进程）；
> 　　`②留痕`   = 要求**具体产物**存在且可被检索（如必须含某段、某 `.py`、某个打印）；
> 　　`③人工`   = 需阅读理解。
> 　**没有执行方式的条目是口号，不是纪律** ⇒ 不得写入本文件。
> 　**判读** = **可选**字段，仅当该条纪律的 `原文` **宽于可机械判定的范围**时出现：
> 　　它是核对器实际采用的**操作化定义**（须与 `原文` 一同阅读，**不替换** `原文`）。
> 　　★ 该字段由 `P133-1` 引入：`check_cards.py` 为让谓词可执行而对 5 条做了窄化，
> 　　但窄化原先**只写在脚本的局部变量里** ⇒ 归档无从核对，两边必然漂移。
> 　　现文本唯一来源是 `check_cards.py` 的 `INTERP` 字典，本文件**逐字**镜像它，
> 　　由审计 **⑧** 断言两边**字符串同一**：`INTERP` 里**每一条**，本文件必须有
> 　　对应 `判读` 行且**逐字相同**；反之不得有孤儿 `判读` 行（⑧e / ⑧f）；
> 　　`判读` 须**紧接** `检查` 行（⑧g）；其标签只许 `[窄化]` 或 `[降级]`（⑧h）。
> 　　★ 标签语义：**`[窄化]`** = `原文` 比可机械判定的范围宽，核对器按窄的一侧实现；
> 　　**`[降级]`** = 该条**不再由核对器判定**（`P134-1`：`K16` 由 `①自动化` 降为 `②留痕`
> 　　—— 它必须真跑 `precheck` 子进程，而「哪些词算判据读数」只能由卡片在开卡时自己冻结）。
>
> **当前条目数：26**（`K1` 为 `P130-1` 新立；`K2`–`K24` 由 `P131-1` 从 `handoff.md` 迁入；`K25` 为 `P133-8` 新立；`K26` 为 `P133-11` 新立）。
> ★ **历史更正（`P131-1`，2026-11-23）**：迁移前该段自称「已积累**十七条**纪律」，
> 　**机械点算实为 23 条**（正则 `；(?=\*\*)` 切分，见 `decisions/DECISIONS.md` 决定二百三十四）——
> 　手写计数漂移 6 条，**本身即 `DEF-128-03`「结构计数必须由代码数」的反例**。
> 　故本表**不沿用**「十七条」这一说法；条目数由 `grep -c '^### K'` 机械得出。
>

## K1 · 判据用 `frac(û<1)` 时，**必报 seed 数**，并报该 seed 数下 `frac>0` 侧的**稳定性**

| 项 | 内容 |
|---|---|
| **触发** | 判据里出现 `frac`（即 `frac = Σ_{û_s<1} m_s / Σ_{m_s>0} m_s`）—— 无论作为被解释量、解释量、还是 `sign(ratio−1) = −sign(frac)` 的一部分 |
| **依据** | `D-161`（`DIR-130`）· `DEF-130-01` · `P130-1` |
| **必做 ①** | 在**判据段本身**（不是只在「边界」或「装置」段）写出 seed 数，形如 `9 seed` / `n_cells=9` |
| **必做 ②** | 报该 seed 数下 `frac>0` 的**稳定性**：可复用 `dir130/mech130.py` 的子集枚举（遍历全部 `2⁹−1 = 511` 个非空 `cells` 子集），成本极低、零重训 |
| **为什么** | `frac` 的**两档不等价**：`frac=0` 是**结构性**的（`dose=350` 全域 `û_min=1.5061578590702887`、余量 **+50.6%**、511 种削法 `p₃₅₀ ≡ 0.0`）；`frac>0` 是**证据量性**的（最近的 `û<1` 层只差 **3.6%**，`p₃₀₀` 从 `k=9` 的 **`1.0`** 单调掉到 `k=1` 的 **`0.1523809523809524`**）。余量比 **14.1×** |
| **不做的后果** | ① `frac>0` 结论**不可复现**（换 seed 数就翻）；② 更隐蔽：`k=1` 时 `dose=300` 有 **84.76%** 也读 `frac=0` ⇒ `frac=0 ⟺ dose≥350` 这条共线**退化成"两剂量多半都读 0"**，判据丧失分辨力却仍显示"零违例" |
| **检查** | `②留痕` —— 卡片的判据段须同时含 seed 数与稳定性读数；缺任一即不得冻结 |

- **原文**：**"阶段纪律"必须配机械守卫才能生效**（`DEF-130-04` + `P130-4`）**只解决了「有没有守卫」，没解决「守卫够不够」** —— 凡某条纪律声明「已被 `S\d+` 守住」，其守卫的判据必须**覆盖**该纪律的**全部禁止形式**；而**禁止集按语义/层级定义**时（含全称量词、聚合层级、来源），守卫必须**判「量」而非判「写法」**。
- **依据**：`P133-8`（`DIR-130` 的 `S9` 实测：现行字面词表命中 **2/6**、漏 **4/6**；且其自测 `T13` 的见证集**由被测词表反推** ⇒ 自证循环，只证明「检测器非空转」）；`revolve/P133-8-GUARD-COVERAGE.md`（全库普查 + 改造示范）；`revolve/DIR-130/RECHECK.md`。
- **触发**：卡片声明某条纪律「已被 `S\d+` 守住」，且该纪律的**禁止集不是按字面定义**的（以**全称量词**、**聚合层级**或**来源**界定，例如「`p₃₅₀`/`p₃₀₀` **及其任一中间聚合**」这类括注）。
- **检查**：卡片须为每条此类纪律留一处**覆盖声明**，写清三件事：(a) **禁止集如何枚举**（每种禁止形式 ≥1 条代表实例）**或**该守卫如何在**源头**让被禁量不可打印（只报布尔 / 脱敏 / 带身份载体）—— 二选一，且须**写明覆盖的是纪律的哪个子集**；(b) 守卫的**自测见证集独立于被测判据生成** —— 由被测词表反推的见证**只证明「检测器非空转」，不证明「纪律被守住」**；(c) 若禁止集**枚举不完**，须说明原因并给出结构性替代。`②留痕`（「够不够」判不了：形式千变、语义需人读 ⇒ **不接硬门**；机械部分由 `check_cards.py --probe-guard-coverage` 的普查/演示承担）。★ **不进 `check_cards.py` 的 `REGISTRY`**：若进，会给 103 张卡各加一条「形式代理 `PASS`」，那正是 `P133-1` 防的**假 `PASS`**（纪律实质未证却记合规）⇒ 实发判据仍为 **103 × 13 = 1339**，一条未变。★ **判据形态必须与禁止集的定义形态一致**：按**字面**定义的禁止集（`C130-FRAC`/`C130-PROTOCOL`/`★ 判决:`）用文本判据**恰当**；按**语义**定义的禁止集用文本判据**必漏**（实测漏 4/6）。

### K26 · 禁止集的**可执行性**：按语义定义的禁止集**不得**只靠一张字面词表（`K25` 的**前置形态门**）
- **原文**：**纪律的禁止集必须可枚举（白名单），且该纪律至少配两道网（一道字面 + 一道形式无关）或明示「不可枚举」并降为 `②留痕`**（`P133-9`）
- **依据**：`P133-9`（`DIR-130` `v1.3` 的 `Agg` 载体 + `S10`：把「及其任一中间聚合」这类**不可枚举**的括注**实测**转成可执行——白名单 + 源头载体 + 数字来源审计）；`P133-10`（全库普查 **138** 条禁止语句：**可枚举 99 / 欠定义 39**；其中 `U1` 开放类别 **28**、`U4` 误读禁令 **7**、`U2` 开放列举 **1**、`U3` 符号二义 **1**）；`revolve/P133-10-SEMANTIC-DISCIPLINE-CENSUS.md`；`revolve/DIR-130/RECHECK.md`；`DEF-130-04`。
- **触发**：新卡或新 revision 引入一条**阶段纪律**（「`X` 阶段不得 …」），且该纪律的禁止集**不是按字面 token 列举**的——以**全称量词**（任何/一切/每处…）、**聚合层级**（跨读数的聚合）、**来源**（属于 `formal` 的）或**开放列举**（「包括但不限于 …」）界定。
- **检查**：三步，缺一不可。**(1) 先判能不能枚举**：禁止集能否写成本卡内的**有限白名单**（每种禁止形式 ≥1 条**代表实例**，且实例取自本卡而非通用词表）。**(2) 若能枚举 ⇒ 至少配两道**形态互不相同**的网**：(i) **字面网**（白名单 token 判据）＋ (ii) **形式无关的网**（在**源头**让被禁量不可打印或**根本不算出来**：只报布尔／脱敏／带身份载体／不构成该量）—— ★ **只有一道字面网的判「未配网」**（`P133-8` 实测字面网命中 **2/6**、漏 **4/6**；再加一张词表只是同一形态的重复）。**(3) 若不能枚举 ⇒ 明示「不可枚举」+ 写明**为什么判不了**（禁止对象是推论？符号二义？开放列举？）+ 该条降 `②留痕`**，且**不得**再声称「已被 `S\d+` 守住」。两道网各自须有**独立于被测判据生成**的自测见证（沿用 `K25` 的 (b)：由被测词表反推的见证只证明「检测器非空转」）。　`②留痕`
- **★ 为什么必须是「三选一」而不是「两选一」（`P133-10` 实测）**：① **不能**写成「凡语义型纪律都须配机械守卫」——`U4`（误读／解读禁令，本库 **7** 条）禁的是「把某个量读成某个结论」这一类**推论**，禁止集是**推论方式**的开放集 ⇒ 任何守卫都判不了，必须留 `②留痕` 这条**合法出路**；② **不能**写成「凡语义型纪律都须降 `②留痕`」——`U1`（**28** 条）与 `U2`（**1** 条）已在 `DIR-130` 上被 `P133-9` **实测**转成可执行 ⇒ 判据形态**可以**被改造成可枚举；③ `U3`（符号二义，**1** 条）可靠「**用法的证据**」收窄（`P133-3`），但判据本身仍是语义判据 ⇒ 属 `②留痕`。
- **★ 与 `K25` 的分工（正交，勿混写）**：`K25` 问「守卫**够不够**」（覆盖度：禁止集如何枚举／源头不可打印，**二选一**）；`K26` 问「禁止集**能不能**枚举」（可执行性：能 ⇒ **必须两道网**；不能 ⇒ 明示降 `②留痕`）。故 `K26` 是 `K25` 的**前置形态门** —— 形态未定就不必谈覆盖度。
- **★ 不进 `REGISTRY`、不接硬门（同 `K25` 的理由）**：若进，会给 103 张卡各加一条「形式代理 `PASS`」＝`P133-1` 防的**假 `PASS`**（纪律实质未证却记合规）⇒ 实发判据仍为 **103 × 13 = 1339**，一条未变。★ 机械部分只在 `check_cards.py --probe-semantic-discipline` 的**普查**里（**只报告、不判定**），供开卡时引用。
